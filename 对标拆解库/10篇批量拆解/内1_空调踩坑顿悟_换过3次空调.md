## §2 爆点 3 件套

**1. 爆点一句话**：这篇爆不是因为它讲"空调怎么选"，而是抓住**准备买 1.5 匹、怕被参数和低价忽悠、又想薅 2026 国补**的高意图人群，在"下单前最后一步"的**避坑焦虑 + 损失厌恶**——它把"省几百"翻译成了"3 年多亏 1000 + 白丢国补 300"（讲总拥有成本，不讲性能）。

**2. 可复用公式**：`换过/用过/装过 N 次 {品类} 我悟了 + 宁可多花 {金额} + 这 N 种 {品类} 白送也别买` + 每种算损失账 + 收尾 N 数字口诀 + 埋下篇钩子

**3. 下次场景**：参数水深、有"缩水/马甲/阉割款"现象、用户怕被低价+参数话术带偏的品类——**热水器（燃热/水泵）、洗衣机（电机/容量虚标）、冰箱（能效/变频/串味）、电视（芯片/分区背光）**。

## §3 核心结论（根因重排 · CEO 修正）

### 为什么能跑到 14.1 万（本号天花板）· 4 条根因

1. **标题强点击 + 内容强承接（双强罕见，不偏科）**：自曝顿悟 + 损失锚 + 反常识清单负责**点击**，正文每种"原理 + 损失账 + 判断法"负责**承接**——闸门 A（算法）和闸门 B（用户）同时过。大多数爆款只强一项，它两项都顶。
2. **损失量化驱动阅读**：把"空调不好"翻译成"电费/国补/维修/换机会亏多少钱"——**抽象避坑变可计算损失**，是点击后继续阅读的核心动力。
3. **决策降维制造收藏**：复杂参数压成"≥28kg / ≥5.0 / 一级"3 个买前检查项——不止制造收藏，更**降低用户决策成本**（看完不用记原理，记 3 个数）。
4. **高意图人群精准命中**：具体到 1.5 匹 / 国补 / 价位段 / 马甲款 / 缩水款，击中"下单前最后一步"焦虑——**家电最值钱的是购买决策前流量，不是泛流量**。

### 运营加分项（非核心根因）
"好安装比好空调更重要"是**系列化延展钩子**，影响关注/回访/下篇选题，但**不直接决定本篇点击/完读/收藏**——不应与 4 条根因并列。

### 主要短板

1. **评论钩子弱**（收藏 149 > 评论 43，工具型 > 争议型）。**稳化方案**（不点名品牌，避免品牌争议/审核风险）：①"你家外机多少 kg？发型号我帮你看是不是缩水" ②"国补后 2000 左右，选华凌/海尔/美的还是小米？"（投票式）③"空调最不能省的是外机重量、能效，还是安装？"
2. **中段结构略机械**：5 段并列整齐。第 3-4 种后插一句"反常识小结"制造情绪高点（"空调最坑人的不是明着差，是参数写得都对、关键硬件偷偷减了"），打破模板疲劳。
3. **事实校验链不足**：硬数据多但无来源标注。后续同类爆文应在内部素材库沉淀证据来源，正文轻量引用（"据国标"/"拆机实测"），防懂行用户挑战 + 账号长期安全。

### 沉淀给账号的 5 条可复用经验
1. **成熟品类，反向避坑 > 正向推荐**（"哪 5 种白送也别装" > "买什么空调好"）
2. **个人踩坑经历是强开头资产**（"换过 N 次 X 我悟了" > "老师傅提醒"）
3. **每个参数必须翻译成钱和体验**（APF→电费、外机重量→用料、毛细管→温控波动）
4. **结尾必须给"可执行检查表"**（3 个数 / 先看 3 项 / 满足 4 条再买——别写"按需选择"）
5. **不只反低价，也要反盲目高端**（边界感 = 专业买手定位，长期信任关键）
