### B. 内容层（说什么）

**1. 选题类型**：阵营对决型 + 反参数迷信型 + 系统协同解释型。表面选题"国产 Mini LED 和索尼差在哪"，本质选题"**为什么国产参数已经很强，但实际观感还是差索尼一点？**"开头先承认国产强（TCL Q9M Pro 100% BT.2020、海信 E8Q Pro 7000nits/分区破 5000），再抛"但索尼更舒服"反直觉判断。

**2. 痛点标签**（高端电视用户四重焦虑）：

| 痛点 | 文章对应 |
|---|---|
| 参数焦虑 | 国产分区/亮度/色域都强，为什么不如索尼舒服 |
| 阵营焦虑 | 国产旗舰和索尼旗舰到底选谁 |
| 预算焦虑 | 8000 以内国产值不值，15000 以上索尼值不值 |
| 体验解释焦虑 | "舒服""氛围感""协调性"这些玄学有没有技术原因 |

**3. 内核归类**：争议性判断 + 技术解释 + 阵营平衡（不是内 2 三品牌横评，也不是内 4 价格段解码，而是**价值观冲突型对决**）。

**4. 信息增益**（5 条，CEO 拆）：
- ①国产不是输在参数，而是输在"协同"——全文主轴
- ②**XR 认知芯片=焦点优先处理**（不是哪里都增强，而是知道人眼先看哪里；人物前景+高亮广告牌同框时优先处理人脸纹理/肤色/眼神光）
- ③**国产芯片像"士兵"，XR 像"将军"**（H7/TSR AI 是好士兵，XR 是知道往哪儿进攻的将军——极强传播金句）
- ④**5000 分区压不住光晕，问题在控光协同**（索尼 X95L 仅 480 分区，但外媒评价光晕控制/黑位仍强于 6120 分区的海信 E8Q Pro）
- ⑤**面板不是差距，系统工程才是差距**（国产面板已顶级，索尼也用同样几家；真正差距在面板+背光+芯片+算法+出厂调校的全链路协同）→ **"画质不是一个参数，而是一套系统工程"= 可沉淀的方法论母句**

**5. 核心观点**（判断母句）：
> 国产电视差索尼的不是分区和亮度，而是把面板、背光、芯片、算法拧成一股绳的能力。
> （国产 Mini LED 赢在纸面参数和性价比，索尼赢在芯片算法/控光精度/系统协同；8000 以内国产很能打，15000 以上追求旗舰画质可认真考虑索尼。）

**6. 参数翻译系统化**（强，但和内 4 不同——内 4 把硬件参数翻译成"冬天体验"，内 5 把画质系统翻译成"观感差距"）：

| 参数/概念 | 用户能理解的体验 |
|---|---|
| BT.2020 色域 | 纸面色彩覆盖强，但不等于整体画面舒服 |
| 峰值亮度 | 高亮能力强，但要看控光协同 |
| 分区数 | 分区多不等于光晕少 |
| XR 认知芯片 | 知道人眼先看哪里，优先处理焦点 |
| 景深图 | 前景后景层次更自然 |
| Backlight Master Drive | 每颗灯珠知道该亮多少、什么时候灭 |
| 背光响应延迟 | 动态画面是否拖尾、光晕是否跟得上 |
| 面板 | 只是基础，系统协同才决定最终画质 |
| 系统协同 | 画面协调性、动态效果、氛围感 |

**人话总结**：静态画面比参数，国产赢；动态画面比效果，索尼赢。

**【CEO 新增字段 · 核心争议判断】**：国产硬指标已逼近甚至领先，但芯片算法、控光精度、系统协同仍落后索尼 1-2 年。——这是能引战但又能讲清楚、可被反驳可被讨论、可被证据支撑的判断，是这篇的爆款内核。

### C. 结构层（怎么写）

**1. 标题公式**：`同技术前提 + 阵营对比 + 差距悬念 + 具象比喻`

| 标题组件 | 作用 |
|---|---|
| 同样是 Mini LED | 建立公平比较前提 |
| 国产 vs 索尼 | 阵营对立，天然争议 |
| 为何始终差 | 强判断，逆国产参数党 |
| 一层窗户纸 | 具象比喻，制造好奇 |

**"窗户纸"的聪明**：承认差距存在+差距不是巨大鸿沟+保留国产追赶希望+降低拉踩感（没说"索尼吊打国产"）。
**可复用公式**：`同样是{技术/配置}，为何{阵营A}始终差{阵营B}"一层窗户纸"？`（⚠️ "始终差"天然有争议和品牌风险，谨慎用）

**2. 钩子类型**：阵营对立钩子 + 反参数迷信钩子 + 技术内幕钩子。点击动力="国产参数已经这么猛，为什么看起来还是差索尼一点？"——用户是高端电视用户/参数党/影音爱好者/品牌阵营用户，非普通低价选购。

**3. 开头模式**（先抬后转四步）：
- 第一步：先承认国产参数强（TCL/海信色域、亮度、分区都很强）
- 第二步：抛出观感反差（两台机器摆一起看，索尼就是更舒服）
- 第三步：指出参数无法解释（这种舒服很难用参数表解释，但真实存在）
- 第四步：给研究承诺（研究半个月，把答案捋清楚）

→ 避免"无脑崇洋"，也避免"无脑吹国产"。

**4. 情绪骨架**：国产参数碾压的爽感 → 索尼观感更舒服的反差 → 技术拆解 → 承认国产性价比 → 高端预算分流 → 国产终会追上的收束。**不是纯拉踩，而是"理性承认差距"**——在敏感话题里完全站一边很容易被喷。

**5. 结构模型**：阵营对决 + 三技术层拆解（芯片篇/控光篇/面板篇）+ 价格篇 + 选购建议 + 未来判断。每篇"国产做法 vs 索尼做法 + 差距根因"。

**6. 收尾模式**：预算分流（8000 以内国产旗舰主流 / 15000 以上 65-75 寸可认真考虑索尼 / 等等党关注 618 双 11 Bravia 9）+ 趋势判断（国产硬指标已逼近，软实力索尼仍领先 1-2 年）+ **"窗户纸"金句封口**（"那一天，窗户纸就算彻底捅破了"，呼应标题闭环）。

**【v3 字段 · 核心反转点】**：有。反转方式=先承认国产参数强（抬）→ 抛出索尼观感仍优（转）→ 分层拆解差距根因（释）→ 预算分流收口（衡）。**"先抬后转"是高争议选题的安全结构**，可沉淀为标杆挑战型通用开头。

**【v3 字段 · 评论设计】**：**主动型（阵营驱动）**。靠标题+核心观点的争议判断天然引战，非靠结尾抛问题。评论强来自内容本身的阵营对立+逆主流判断，不依赖结尾钩子。

### F. 信任层

**1. 信任来源**（4 点）：
- ①**先承认国产强**（降低国产支持者防御）
- ②**把主观体验拆成技术原因**（"索尼看着舒服"用 XR/焦点处理/景深图/背光调度/系统协同解释，非玄学）
- ③**不把索尼神化**（明确国产硬指标已逼近，差距在缩小）
- ④**给预算分流**（不是让所有人买索尼，而是 8000 以内国产/15000 以上索尼——信任感关键）

**2. 站队平衡度**：**高争议判断 + 中高平衡度**。有争议（标题"始终差"）+ 有平衡（正文承认国产参数/性价比/进步）。**比内 2 更平衡，比内 3 更有争议**——所以评论比内 3 强，风险又比内 2 点名雷鸟负面更可控。

**3. 账号定位暗示**：高端电视技术解释者 / 阵营争议仲裁者 / 画质系统工程拆解者——**牛科技在电视高端内容的重要方向**。

### G. 可复用性

**1. 可复用机制（母体重命名 · CEO 校准）**：从"国产 vs 外资单挑对决型"升级为**「标杆品牌挑战型」/「参数强者 vs 体验标杆型」**——核心不是国别，而是"**参数强的一方 vs 体验标杆的一方**"。这样更易迁移：

| 参数强方 | 体验标杆方 | 标题示例 |
|---|---|---|
| 国产 Mini LED | 索尼 | 美的冰箱参数强，但为什么东芝保鲜体验更稳？ |
| 国产洗烘 | LG | 国产洗烘配置高，为什么 LG 洗烘体验仍有一层窗户纸？ |
| 国产热水器 | 林内/能率 | 国产热水器堆料强，为什么林内能率恒温还更稳？ |

**完整公式**：`同样是{技术}，为何{参数强方}始终差{标杆品牌}"一层窗户纸"？` + 开头先承认参数强→抛真实观感差距→分技术层拆原因→讲价格差值不值→按预算分流→结尾趋势判断。

**核心母句**（可跨品类复用）：**"参数赢了，体验为什么还没赢？"**

**2. 变异方向**：
- 电视内部：Mini LED→OLED（vs LG）/ 98 寸巨幕（vs 三星）
- 其他品类：热泵洗烘（vs LG）/ 零嵌冰箱（vs 日系）/ 燃气热水器（vs 林内能率）
- 反向写法："国产 Mini LED 已经追上索尼了吗？参数赢了，体验还差在哪？"（争议方向反转）

**3. 不可硬搬点**（5 条）：①"始终差"风险高，无证据不乱用 ②需极强技术解释，否则像崇洋 ③必须先承认国产优势再讲差距 ④必须给预算分流，否则像劝买索尼 ⑤海外价格/国补/型号参数需复核时效性（**文章自标"国补政策信息待核实"必须保留**）。

**4. 可复制边界**：适合=国产/低价阵营纸面参数已强 + 标杆品牌仍有体验/算法/系统协同优势 + 用户对"参数强但体验差一点"有真实感知 + 能讲清差距非玄学 + 能按预算给建议。不适合=标杆优势不明显 / 差距只能靠主观感受 / 易引发民族情绪但无法平衡 / 无预算分流。

- **要评论**：必须同时满足①阵营/品牌对决（用户有站队对象）②争议性判断（逆主流/反常识/承认差距/点名别碰）。缺一评论就弱。

## §5 内 5 = 第五种爆款母体「阵营价值观对决型 / 标杆品牌挑战型」

**定义**（CEO 确认）：承认国产参数赢，但标杆品牌体验仍领先。核心冲突不是"索尼好还是国产好"，而是**"参数党 vs 画质体验党"**。这类文章天然易有评论，因为触碰用户阵营——国产支持者、索尼信仰用户、参数党、影音发烧友、性价比用户都会进来表达立场。

**母体核心母句**：**"参数赢了，体验为什么还没赢？"**

**与四母体的区分**：比内 2"产品横评"更高维——内 2 是同阵营内（国产三强）怎么选，内 5 是跨阵营（国产 vs 标杆）价值观对决。**评论来源不同**：内 2 来自品牌站队，内 5 来自国产阵营 vs 索尼信仰 / 参数党 vs 观感党。

**沉淀给账号的 5 条经验**（CEO 提炼）：
1. 阵营对立比普通品牌对比更易引评论
2. 强争议标题必须配平衡正文：先承认对方优势，再讲差距
3. 高端家电差距往往不是单参数，而是系统协同
4. "参数赢了，体验为什么没赢"是高价值内容母体
5. 预算分流是防止品牌吹捧感的关键收口

**下一篇判定**：如果还是品牌对比，要判断它是普通横评，还是也带"阵营价值观对决"——后者才能套内 5 母体。
