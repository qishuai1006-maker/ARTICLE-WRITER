## 附 · 归因标签字典速查表

### 归因标签（主因选 1，辅因最多 2）

| 标签 | 含义 | 数据特征 |
|---|---|---|
| 标题强点击 | 标题本身吸引人 | CTR>7%，展现正常 |
| 平台愿意推 | 算法给流量 | 展现>1万，CTR 不一定高 |
| 内容承接强 | 完读/收藏/评论好 | 完读>60% 或 收藏>均值×2 |
| 选题过窄 | 受众小 | CTR>5% 但展现<3000 |
| 标题弱 | 有展现没人点 | 展现>3000，CTR<4% |
| 疑似限流 | 触发限流词或惩罚 | 展现<1000，非新号 |
| 时效失配 | 错过热点窗口 | 与热点间隔>3天 或 非黄金时段 |
| 品类疲劳 | 同品类连续低表现 | 同品类连续 3 篇普通/限流 |
| 公式可复用 | 标题结构有效，可跨品类 | CTR>6% 且非偶然时效驱动 |
| 公式需降权 | 标题结构已疲劳 | 同结构连续 2 篇 CTR<5% |

### 下次动作（6 选 1）

| 动作 | 适用场景 |
|---|---|
| 复用 | 爆款/点击强/承接强，结构和角度可直接复用 |
| 改标题再试 | 推荐强/承接强但标题弱，换标题可能翻身（必填建议标题） |
| 换账号试 | 选题好但账号调性不符，A号扑 B号可能爆 |
| 降权 | 品类疲劳或公式疲劳，暂停 1-2 周 |
| 冻结 | 连续低效且有明确失效原因，暂存可解冻 |
| 淘汰 | 选题过窄无优化空间，或冻结后重试仍无效，永久移出 |
