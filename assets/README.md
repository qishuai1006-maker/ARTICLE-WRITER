> **目的**：把爆款标题、优质开头、金句沉淀下来，让 T3 写作时直接"借鉴"而不是"现想"。
> **最后更新**：2026-06-11


## 三类资产的区别

| 类型 | 来源 | 复用优先级 | 用途 |
| --- | --- | --- | --- |
| **titles_proven/** | 自己 100 篇已爆款 | ⭐⭐⭐⭐⭐ | T1.5 标题终稿 |
| **titles/** | 外部 54 篇借鉴 | ⭐⭐⭐⭐ | T1.5 标题模板 |
| **openings/** | 内外混合 | ⭐⭐⭐ | T3 开头参考 |
| **golden_lines/** | 内外混合 | ⭐⭐ | T3 结尾钩子 |

## 使用规则

### T1.5（骨架 + 标题选型）：

```
1. 优先用 assets/titles_proven/[对应品类]_[对应模板]_已爆.md（自己验证过的）
2. 没匹配 → 用 assets/titles/[对应品类]_[对应模板].md（外部借鉴）
3. 都没匹配 → 用 prompts/01-选题/选题_三追问.md 里的样本库
```

### T3 写作：

```
1. 开头参考 assets/openings/[对应骨架].md
2. 结尾参考 assets/golden_lines/评论区钩子_优选.md
3. 标题终稿复用 assets/titles_proven/ 对应样本
```

## 资产更新机制

### 自动沉淀（推荐）

每天 18:00 由 Hermes 跑 `daily_distill.py`：
1. 抓昨日已发布文章的飞书数据
2. 对比 v1.0 预测模板 vs 实际表现
3. 高表现（> 1万展现）→ 入对应库

### 手动沉淀

跑完 T4 发现某篇特别优秀：
1. 把标题加到 `titles_proven/` 对应文件
2. 把开头加到 `openings/` 对应骨架文件
3. 把金句加到 `golden_lines/`
4. 立刻 git commit

## 维护规则

- **每月清理一次**：展现量 < 1000 的标题从 `titles_proven/` 移到 `_archive/`
- **不删 `titles/`**：外部借鉴永远有用
- **沉淀节奏**：每周至少 2-3 个新样本（保持资产新鲜度）
