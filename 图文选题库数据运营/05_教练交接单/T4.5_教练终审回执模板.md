## 小修边界

仅当结论为“小修后通过”时使用。

允许的小修：

- 调整措辞
- 删除有风险句子
- 弱化绝对化表达
- 调整段落顺序
- 补充来源标注但不新增实质论点

不允许的小修：

- 新增产品型号
- 新增技术路线
- 新增或修改参数结论
- 新增品牌判断
- 改变推荐逻辑
- 改写标题承诺

如果 Claude Code 的修改超出允许范围，必须重新提交 T4.5，不能直接发布。

## 退回范围

仅当结论为“退回重练”时使用。Codex 必须明确退回范围，Claude Code 按范围处理。

- 仅正文措辞调整：T5 不动，T6 重新适配。
- 正文结构重写：T3 重写，T4 重审，T6 重做；T5 视引用是否变化决定。
- 删改技术路线 / 换型号 / 改参数结论：T3、T4、T5、T6 全部重走。
- 证据链断裂：退回 T2，重新验证后再进入 T3-T6。
- 标题承诺变化：T3、T4、T6 重走；封面图如含标题或核心卖点，T5 也要重做。
