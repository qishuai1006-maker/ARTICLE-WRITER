# 教练交接单说明

这个文件夹用于承接 Codex 教练组给 Claude Code 运动员的生产指令。

每次 Codex 完成周选题规划、单篇选题裁判或外部爆款迁移判断后，都应该在这里落一份 Markdown 文档，方便 Claude Code 直接读取并执行 T1-T7。

## 使用规则

- `CURRENT_本周选题训练计划.md`：当前最新的周训练计划，Claude Code 优先读取。
- `选题交接单_模板.md`：单篇选题进入生产前的标准交接格式。
- `T4.5_教练终审回执模板.md`：Codex 做发布前终审时使用，明确通过、小修或退回范围。
- 历史交接单建议按日期命名：`YYYY-MM-DD_选题交接单_品类或主题.md`。

## Claude Code 执行前必须确认

1. 先读取 `CURRENT_本周选题训练计划.md`。
2. 再读取对应的单篇选题交接单。
3. 只生产已经通过 Codex 裁判门的选题。
4. 按交接单里的文章类型、用户痛点、标题方向、证据要求和风险提醒执行。
5. 如果素材阶段发现证据链断裂，暂停并回报，不要硬写。
6. 是否触发 T4.5 以交接单字段为准，Claude Code 不自行推断。
7. T4.5 如果给出“小修后通过”，只能做措辞、删句、弱化表达等小修；新增论点、参数、型号或推荐逻辑必须重新提交终审。
8. T4.5 如果给出“退回重练”，按 Codex 标注的退回范围处理 T3/T4/T5/T6，不能只改正文就发布。
