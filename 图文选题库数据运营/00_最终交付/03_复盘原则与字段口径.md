# 复盘原则与字段口径

**核心目标**：让每篇文章的数据变成下一次选题的依据，而不是只留下数字。

---

## 1. 三个核心指标

### 展现量

代表平台是否愿意给推荐。

判断问题：

- 选题覆盖面够不够大？
- 标题有没有触发平台推荐？
- 是否疑似限流？

### 阅读量

代表真实吃到的流量规模。

判断问题：

- 这篇文章实际有没有起量？
- 是不是只 CTR 高但阅读规模小？
- 是否值得作为周会核心样本汇报？

### CTR(%)

代表标题点击效率。

判断问题：

- 标题结构有没有吸引力？
- 是否值得改标题再试？
- 是否说明公式可复用？

> 复盘时不能只看 CTR。CTR 高但阅读量很低，只能说明标题有局部点击信号，不等于爆款。

---

## 2. 表现分层口径

| 分层 | 含义 | 动作倾向 |
|---|---|---|
| 爆款 | 展现、阅读、CTR 同时强 | 复用结构，提炼公式 |
| 点击强 | CTR 高，说明标题有吸引力 | 可复用或换更大品类测试 |
| 推荐强 | 展现高，平台愿意推 | 优先检查标题和内容承接 |
| 承接强 | 完读率、阅读时长、互动表现好 | 改标题再试 |
| 普通 | 数据中等，无明显强信号 | 降权或小规模继续测试 |
| 疑似限流 | 展现极低或阅读为 0 | 暂停复用，进入风险复盘 |

当前 2026-05-22 批次：

| 分层 | 数量 |
|---|---:|
| 普通 | 28 |
| 点击强 | 8 |
| 爆款 | 6 |
| 推荐强 | 5 |
| 疑似限流 | 4 |
| 承接强 | 3 |

## 3. 主因归因原则

主因只能选一个。

正确写法：

- 标题强点击
- 平台愿意推
- 内容承接强
- 选题过窄
- 标题弱
- 疑似限流
- 时效失配
- 品类疲劳
- 公式可复用
- 公式需降权

错误写法：

- 综合原因
- 多方面因素
- 可能是平台问题
- 暂不确定

主因必须能回答：

> 如果下一次要提升结果，最该改哪里？

---

## 4. 下次动作口径

| 动作 | 使用场景 |
|---|---|
| 复用 | 爆款、点击强、推荐强且阅读规模不错 |
| 改标题再试 | 内容或题材有信号，但标题弱 |
| 换账号试 | 题材适合另一个账号调性 |
| 降权 | 数据普通、信号不强，但还有观察价值 |
| 冻结 | 疑似限流、连续低效、风险不明 |
| 淘汰 | 非核心品类、无优化价值、持续低效 |

`改标题再试` 必须填写 `建议改写标题`。

## 5. 品类口径

推荐品类：

- 电视
- 冰箱
- 空调
- 洗衣机
- 油烟机
- 热水器
- 显示器
- 手机
- AI
- 家电综合

使用原则：

- 能归明确品类就归明确品类。
- 跨品牌集团、家电产业、外资撤退、品牌关系类，可归 `家电综合`。
- 不建议继续使用 `其他`，除非确实无法归类。

## 6. 文章类型口径

### 选购横评

典型标题：

- A 和 B 怎么选
- 多品牌横评
- 价位推荐
- 参数路线比较

适合：

- 冰箱、电视、空调、热水器、油烟机等高决策成本品类。

### 教程避坑

典型标题：

- 安装猫腻
- 使用误区
- 清洗/维修/自查
- 师傅不会告诉你的事

适合：

- 空调、油烟机、洗衣机、热水器。

### 趋势科普

典型标题：

- 行业趋势
- 技术路线
- 涨价/国补/撤退
- 平台或产业变化

适合：

- 电视、AI、家电综合、政策类选题。

## 7. 标题结构口径

| 模板 | 典型结构 |
|---|---|
| 内幕视角型 | 做了十年 / 拆开看 / 真实差距 |
| 内幕避坑型 | 避坑 / 猫腻 / 不告诉你 / 不踩坑 |
| 多品牌对决型 | 海信 TCL 创维 / 多品牌横评 |
| 对比选择型 | A vs B / 选谁 / 哪个更值 |
| 反问悬念型 | 为什么 / 到底 / 差距在哪 |
| 品牌锚点型 | 单品牌或品牌矩阵切入 |
| 其他 | 暂不能归入以上结构 |

后续建议减少 `其他`，持续补充更精确的标题结构模板。

---

## 8. 复盘底线

1. 不用感觉代替数据。
2. 不只看 CTR，要同时看展现和阅读。
3. 主因只能选一个。
4. 下次动作必须能执行。
5. 爆款必须提炼公式。
6. 扑文必须留下问题点。
7. 疑似限流样本比普通扑文更值得记录。
