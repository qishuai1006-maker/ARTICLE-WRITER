# 图文选题库使用手册

**适用对象**：ContentFleet 负责人、Codex、ClaudeCode  
**核心用途**：用飞书多维表格完成选题排期、发布数据追踪、周会汇报和公式库迭代。

---

## 1. 三张表怎么用

### 1.1 选题公式库

定位：方法论底座。

用来沉淀：

- 哪类标题结构有效
- 适合哪个账号
- 适合哪个品类
- 生命周期是活跃、验证中、降权还是冻结

使用原则：

- 公式不是单个标题，而是可迁移的标题结构。
- 爆款后要提炼公式，扑文后要记录失效信号。
- 每月做一次公式库升降级。

### 1.2 发稿排期

定位：生产指令台。

用来确认：

- 哪天发
- 哪个账号发
- 发什么品类
- 用什么标题结构
- 文章类型是什么
- 流量假设是什么
- 是否已排期、待调研、已通过、已发布

使用原则：

- 周二 10 点周会后，排期周期按“下周二到下下周一”处理。
- 后续不长期堆 `待评估`。
- 新选题进入排期前，必须有文章类型、标题结构模板、流量假设。
- 强时效或待调研选题必须有 `处理截止日`。

### 1.3 文章追踪

定位：真实数据反馈表。

用来沉淀：

- 展现量
- 阅读量
- CTR
- 完读率
- 阅读时长
- 点赞、评论、转发、分享、收藏
- 表现分层
- 主因归因
- 下次动作
- 建议改写标题

使用原则：

- 这是选题库最重要的数据源。
- 每周导入头条后台最新全量数据。
- 导入后做自动复盘，但关键样本要人工抽查。

## 2. 周会怎么用

每周二上午 10 点开周会，建议按这个顺序讲：

### 第一步：看 Dashboard v2

打开：

- `ContentFleet 周会运营看板 v2`
- Dashboard ID：`blkfM1WeXiIeF7ZB`

汇报顺序：

1. A｜周会总览：发布数、总展现、总阅读、平均 CTR、爆款数、限流数。
2. B｜账号表现：牛科技和牛科技说哪个账号更能打。
3. C｜品类策略：哪些品类值得继续排，哪些品类要降权。
4. D｜标题与文章类型：哪些标题结构和文章类型更有效。
5. E｜爆款样本：本周最值得复用的标题结构。
6. F｜风险与动作：哪些要改标题、冻结、淘汰。

### 第二步：看文章追踪明细

打开：

- `文章追踪 / 周会复盘总表`
- 视图 ID：`vewltbJPDh`

重点看：

- 阅读量前 10
- CTR 前 10
- 疑似限流样本
- `下次动作 = 改标题再试`
- `下次动作 = 复用`

### 第三步：定下周排期

按照“强品类 + 强账号 + 强结构”组合排。

优先级：

1. 爆款结构跨品类复用
2. 点击强结构换更大品类
3. 推荐强样本改标题再试
4. 疑似限流样本暂停，不直接复用

## 3. 每次生成选题时怎么用

### 3.1 先看数据，不先拍脑袋

生成下一周选题前，先读取：

- 近 30 天文章追踪
- 当前发稿排期
- 爆款样本池
- 周会复盘总表

### 3.2 选题评分

每个候选选题按 20 分评分：

| 维度 | 分数 |
|---|---:|
| 信息差深度 | 0-5 |
| 标题点击结构 | 0-5 |
| 品类/账号匹配 | 0-5 |
| 时效与风险 | 0-5 |

决策：

- 16-20：优先排期
- 12-15：补证据、改标题或待调研
- 低于 12：不排

### 3.3 生成排期

后续推荐模式：

- 每天固定一个品类
- 牛科技和牛科技说同天同品类
- 但标题角度错开
- 共享调研报告

示例：

| 日期 | 账号 | 品类 | 角度 |
|---|---|---|---|
| 周二 | 牛科技 | 冰箱 | 参数避坑 |
| 周二 | 牛科技说 | 冰箱 | 老炮真实差距 |

## 4. 每篇文章发布后怎么用

发布 3-7 天后，进入文章追踪复盘。

必填：

- 表现分层
- 主因归因
- 辅因归因
- 可复用点
- 问题点
- 下次动作
- 建议改写标题（仅改标题再试时）

原则：

- 主因只能有一个。
- 复盘必须能指导下一次动作。
- 不写“综合原因”“可能多方面因素”这类无效归因。

---

## 5. 每月怎么用

每月做一次公式库迭代：

1. 从爆款样本中提炼新公式。
2. 把连续有效公式升为活跃。
3. 把连续低效公式降权。
4. 把疑似限流或持续失效公式冻结。
5. 更新下月品类和账号策略。

公式库不是越多越好，宁愿少而准。
