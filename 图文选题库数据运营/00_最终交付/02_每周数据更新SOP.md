# 每周数据更新 SOP

**目的**：每周把两个头条账号后台最新数据更新到飞书 `文章追踪`，并让周会看板和复盘字段同步刷新。  
**推荐执行时间**：每周二周会前，或周会后确认下一周排期前。  
**原则**：先备份，再替换；先校验，再汇报。

---

## 1. 准备数据

从头条后台分别导出两个账号的图文数据：

- 牛科技
- 牛科技说

要求：

- 必须是全量已发布文章数据。
- 字段至少包含：标题、发布时间、ID、链接、展现量、阅读量、点击率、完读率、阅读时长、点赞、评论、转发、分享、收藏。
- 文件名可以变化，但必须能识别账号来源。

---

## 2. 更新前备份

每次替换 `文章追踪` 前，必须先导出当前表。

备份命名建议：

```text
文章追踪_替换前备份_YYYYMMDD.json
```

备份保存到：

```text
图文选题库数据运营/02_数据备份与导入包/
```

不要跳过备份。飞书记录删除后无法直接撤回。

---

## 3. 清洗与字段映射

Excel 字段 → 飞书字段：

| Excel 字段 | 飞书字段 |
|---|---|
| 标题 | 文章标题 |
| 发布时间 | 发布日期 |
| ID | 头条文章ID |
| 链接 | 文章链接 |
| 展现量 | 展现量 |
| 粉丝展现量 | 粉丝展现量 |
| 阅读量 | 阅读量 |
| 粉丝阅读量 | 粉丝阅读量 |
| 点击率 | CTR(%) |
| 平均阅读完成率 | 完读率(%) |
| 平均阅读时长 | 平均阅读时长(s) |
| 点赞量 | 点赞数 |
| 评论量 | 评论数 |
| 转发量 | 转发量 |
| 分享量 | 分享量 |
| 收藏量 | 收藏数 |

派生字段：

- 产品品类：从标题关键词自动判断。
- 文章类型：选购横评 / 教程避坑 / 趋势科普。
- 标题结构模板：内幕视角型 / 内幕避坑型 / 多品牌对决型 / 对比选择型等。
- 互动率(%)：`(点赞 + 评论 + 转发 + 分享 + 收藏) / 阅读量 * 100`。
- 表现分层：按展现、阅读、CTR、完读率综合判断。
- 主因归因、辅因归因、可复用点、问题点、下次动作：按复盘规则生成。

---

## 4. 推荐替换流程

1. 读取两个 Excel。
2. 生成导入包 JSON。
3. 生成复盘预览 CSV。
4. 创建新记录。
5. 确认新记录创建成功。
6. 删除旧记录。
7. 校验总记录数和账号篇数。

不要先删旧数据再导入新数据。

---

## 5. 更新后校验

必须校验：

| 校验项 | 目标 |
|---|---|
| 总记录数 | 等于两个 Excel 行数之和 |
| 牛科技篇数 | 等于牛科技 Excel 行数 |
| 牛科技说篇数 | 等于牛科技说 Excel 行数 |
| 总展现 | 与 Excel 合计一致 |
| 总阅读 | 与 Excel 合计一致 |
| Top 阅读文章 | 与 Excel 排序一致 |
| 表现分层 | 不为空 |
| 下次动作 | 不为空 |

本次 2026-05-22 校验结果：

- 总记录数：54
- 牛科技：40
- 牛科技说：14

## 6. 看板刷新

文章追踪替换后，Dashboard 理论上会自动刷新。

当前周会看板：

- `ContentFleet 周会运营看板 v2`
- ID：`blkfM1WeXiIeF7ZB`

如果看板组件没有数据：

1. 先确认文章追踪表是否有数据。
2. 再确认组件 `data_config` 的 `table_name` 和字段名是否正确。
3. 优先修组件配置，不要重复导入数据。
4. 如果旧组件配置残留严重，新建新组件，不在旧组件上反复修改。
