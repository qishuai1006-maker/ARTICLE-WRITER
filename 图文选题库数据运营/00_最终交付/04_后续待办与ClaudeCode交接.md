## 2. 优先级 P0：建立每周数据导入流程

当前一次性脚本在：

```text
图文选题库数据运营/03_工具脚本/
```

脚本：

- `inspect_xlsx_raw.py`
- `build_article_tracking_import.py`
- `create_dashboard_v2_blocks.py`

注意：

- 当前脚本路径写的是 2026-05-22 用户提供的两个 Excel。
- 后续每周复用时，需要改成最新 Excel 路径。
- 更好的方式是把脚本改成支持命令行参数：

```bash
python build_article_tracking_import.py \
  --file "牛科技.xlsx" --account "牛科技" \
  --file "牛科技说.xlsx" --account "牛科技说" \
  --date 2026-05-XX
```

每周更新流程：

1. 导出当前文章追踪备份。
2. 读取两个账号 Excel。
3. 生成导入包和预览 CSV。
4. 先创建新记录。
5. 成功后删除旧记录。
6. 校验总数、账号篇数、总展现、总阅读。
7. 打开 Dashboard v2 检查数据刷新。
