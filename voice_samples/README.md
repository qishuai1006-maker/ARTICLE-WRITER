# 语调样本库 README

> **目标**：积累 3-5 篇你自己的爆款片段，作为 T3 第三轮喂给 AI 的"风格锚点"。

## 为什么需要这个

老七聊 AI 的核心洞察：

> AI 的默认文风是几十亿篇"安全文本"的平均值。给它一篇你自己的文字当参考，它就不再往"平均值"偏——它往"你"偏。

**第三追问的作用不是改错别字，是给 AI 闻一下你的人味长什么样。**

## 样本要求

每篇样本必须满足：

| 项 | 要求 |
| --- | --- |
| **字数** | 200-400 字（不能太长，否则 AI 学到的太杂） |
| **来源** | 你自己写的（不是转载 / AI 生成） |
| **数据** | 选你已发布的、数据表现好的（阅读量 > 平均阅读 ×2） |
| **领域** | 标注（家电 / AI 工具 / 个人成长 / 其他） |
| **骨架** | 标注（问题链 / 故事线 / 拆解面） |
| **核心特征** | 用 1-2 句话说明这篇的"味道"是什么 |

## 至少准备几篇？

**最低**：3 篇（一类一篇，覆盖三种骨架）
**理想**：5-8 篇（一类 2-3 篇，覆盖同骨架不同风格）

## 文件命名规范

```
sample_NN_[骨架]_[领域]_[简短描述].md
```

示例：
- `sample_01_问题链_家电_油烟机选购开头段.md`
- `sample_02_故事线_AI工具_第一次用Claude的体验.md`
- `sample_03_拆解面_家电_油烟机参数误区观点.md`

## 文件模板

每个语调样本文件用以下结构：

```markdown
# 样本 NN：[简短描述]

**来源文章**：[完整标题 + 链接]
**数据表现**：[阅读量 / 完读率 / 评论数]
**领域**：[家电 / AI 工具 / 个人成长]
**骨架**：[问题链 / 故事线 / 拆解面]

## 核心味道（1-2 句话）

[这篇的"人味"是什么——例如："短句冲击 + 大量反问 + 几乎不用形容词"]

## 样本正文（200-400 字）

[直接复制你文章中你觉得最有"你味道"的段落]

## 不许学（反面教材）

[如果有什么是 AI 不该学到的，列出来——例如："这篇有点'铺垫太长'，下次别学"]
```

## 使用方法

### T3 第三轮时

```
但有一个要求——用下面这篇文章的语气和节奏来写：

[粘贴 sample 文件中的"样本正文"部分]
```

### 选哪个样本？

按"骨架 + 领域"匹配：

| 你要写的文章 | 推荐样本 |
| --- | --- |
| 问题链 + 家电 | `sample_NN_问题链_家电_xxx.md` |
| 故事线 + AI 工具 | `sample_NN_故事线_AI工具_xxx.md` |
| 拆解面 + 家电 | `sample_NN_拆解面_家电_xxx.md` |

**没有完全匹配的怎么办？** 选骨架匹配的优先（领域可以不同）。
