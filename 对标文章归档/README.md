# 对标文章归档

这里是 Super Writer 的**对标母本资产库**。

## 定位

本文件夹只保存外部爆款原文、截图、链接整理或用户上传的对标文章。

它不是临时素材夹，也不是洗稿输入区。对标文进入这里后，默认长期保存，用于反复拆解、派生、复盘和训练账号方法论。

## 使用规则

1. **原文入库**
   - 外部爆款文章、docx、截图、链接整理，优先放到本文件夹。
   - 文件名尽量保留原始标题，必要时前缀日期或品类。

2. **母本登记**
   - 每篇值得复用的对标文，都要在 `对标拆解库/` 下生成一张 `对标母本卡`。
   - 模板见：`对标拆解库/对标母本卡_模板.md`。
   - 入库后先登记到 `00_对标母本索引.md`，再决定是否建完整母本卡。

3. **原文隔离**
   - 情报拆解阶段可以读取原文。
   - 主笔写稿阶段默认不直接读取原文，只读取母本卡、拆解卡、证据卡和品类资料。
   - 禁止把原文段落顺序、事实组合、案例场景、句式节奏直接搬进新稿。

4. **多次派生**
   - 一篇母本可以派生多个目标品类、多个账号人设、多个文章原型。
   - 每次派生都要回填对应母本卡的“派生台账”，避免重复选题和重复消耗。

5. **不轻易删除**
   - 对标文默认不删除。
   - 如果质量差、违规风险高或明显标题党，在母本卡里标记为“反面样本”或“冻结”，不要直接丢弃。

## 推荐命名

```text
原始标题.docx
20260618_空调_原始标题.docx
20260618_电视_标题机制样本_原始标题.md
```

## 和其他目录的关系

- `对标文章归档/`：保存原文母本。
- `对标文章归档/00_对标母本索引.md`：记录当前母本状态、评级、建卡进度和优先派生方向。
- `对标拆解库/对标母本卡_*.md`：保存母本机制、派生方向、复用风险、派生台账。
- `对标拆解库/拆解卡_*.md`：保存某一次具体任务的拆解结果。
- `projects/`：保存最终产出的文章、图片、Word 和发布复盘。
