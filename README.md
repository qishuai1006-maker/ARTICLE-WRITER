# Super Writer · 家电图文爆款工业化生产系统

> **版本**：v3.4 · Orchestrator / Agent / Skill 四棒接力架构
> **最后更新**：2026-06-18
> **核心哲学**：不造轮子，只做降维打击。系统由 1 个总调度 + 4 个专职 Agent 接力协作 + 6 大独立 Skill 提供方法论弹药。

---

## 🚀 30 秒上手

```
唤醒指令：
"我发你一篇外部的爆款文章，你帮我拆解并平移写一篇 [冰箱/电视/洗衣机/空调] 的头条图文。"
```

系统会自动激活 Orchestrator（`CLAUDE.md`），依次调度 Agent 01 → 02 → 03 → 04 完成全流程。

## 📐 四棒接力流程

| 棒次 | Agent | 核心动作 | 产出物 |
|------|-------|---------|--------|
| 第零棒 | 🗃️ 母本入库 | 保存对标原文，登记可复用机制与派生方向 | 母本卡 |
| 第一棒 | 🕵️ 情报拆解 | 从母本卡提取钩子、情绪骨架、反转点 | 拆解卡 |
| 第二棒 | ✍️ 首席主笔 | 选人设/骨架 → 填证据卡 → 写稿 → 活人洗稿 | Markdown 初稿 + 合规自检 + 轻量证据卡 |
| 第三棒 | ⚖️ 风控主编 | 脚本检查 + 100分打分 + 合规终审 + 证据链核查 | 带评分的终稿 |
| 第四棒 | 🎨 视觉指挥官 | 封面 Prompt/封面直出 + 信息图数据提取 + 排版校验 | 封面图 + Prompt + 信息图需求卡 |

## 🎨 配图工作流

- **封面图**：必须走 ChatGPT/Codex 生图模型或真实版权安全图片，不使用代码图/PPT图。
- **内页信息图**：先写需求卡，再用 NotebookLM/结构化设计工具生成；如需本地叠字，必须做到高级底图 + 准确中文。
- **动态配图**：按文章类型决定 2-4 张图，每张图必须说明功能：点击 / 理解 / 收藏 / 对比。
- **落盘验收**：图片必须真实存在于 `outputs`，并通过 `Scripts/validate_visual_outputs.py`；对话预览不算成品。
- **Word/终稿**：只嵌入已落盘、已验收图片。临时图、占位图不得包装成最终成品。
