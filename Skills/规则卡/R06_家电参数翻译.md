## 规则

技术参数必须翻译成用户能感知的场景差异。读者不需要知道参数是什么，需要知道参数落到家里是什么感觉。

翻译公式：**参数差异 → 家里场景 → 用户感知**

## 正例

| 原始参数 | 正确翻译 |
|----------|----------|
| 多568个背光分区 | 看电影暗场细节更清晰，夜景不会糊成一片 |
| 峰值亮度高500nits | 白天拉开窗帘也看得清，不用每次看电视先拉窗帘 |
| 音响功率大20W | 不用额外买回音壁，看大片时低音有震感 |
| APF能效比5.2 vs 3.8 | 同样开8小时，一年电费差300多块 |
| 洗净比1.08 vs 0.9 | 衣领袖口的油渍一遍就干净，不用手搓 |
| 风量23m³/min vs 17m³/min | 爆炒辣椒时油烟不往脸上扑 |
| CADR 800 vs 500 | 30平的客厅，净化一遍快了将近一半时间 |

## 反例

> "Ultra采用了行业领先的Mini LED背光技术，分区数达到1624个，相比Pro的1056个多出568个分区，在暗场表现和对比度方面有显著提升。"

**问题**：堆砌技术术语，读者看完还是不知道"落到我家客厅是什么区别"。

## 判定条件

- 正文出现技术参数时，必须紧跟场景化翻译（不能只给数字）
- 翻译必须落到用户家里的具体场景（客厅/卧室/厨房/洗澡等）
- 禁止使用"行业领先""显著提升""全面升级"等空洞修饰
