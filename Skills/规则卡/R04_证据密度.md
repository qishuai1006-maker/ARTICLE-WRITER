## 规则

如果 L3 证据不足以支撑长文，不允许主笔靠泛泛经验扩写。

处理方式只能是：
1. 回到调研补证据
2. 缩短文章
3. 改成短决策文
4. 删除无证据段落

**绝对不允许**：为了凑字数而用"很多人觉得""其实这里面有讲究""说白了就是"等空话填充。

## 典型错误

> "说白了，买电视这事，很多人第一反应就是看画质。但画质这个东西，说起来简单，真要对比起来，每个人看法都不一样。有人觉得亮度重要，有人觉得色准重要，还有人觉得音响更重要。其实没有标准答案，关键还是看自己的需求。"

**问题**：整段 120 字，没有任何具体参数、型号或证据，纯粹是泛泛经验。

## 正确改法

> "Ultra 和 Pro 画质最核心的差距在两个参数：分区数多了 568 个[E02]，峰值亮度高了 500nits[E03]。落到家里就是：暗场不糊、白天看得清。"

50 字，两条证据，信息密度远高于原文。

## 判定条件

- `density_ratio`（正文字数 / 正文实际使用的 evidence_id 数量）> 250 为 ERROR
- 正文完全未引用任何 `[E0x]` 证据 ID 为 ERROR
- 证据不足时，禁止扩写，只能补调研或缩短
