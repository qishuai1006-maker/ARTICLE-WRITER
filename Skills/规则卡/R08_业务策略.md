## 规则

业务策略不只是禁词列表，还要做到正向定位。

策略必须包含四个层面：

1. **保护对象**（protected_models_or_brands）：哪些型号/品牌不能踩
2. **正向定位**（allowed_positioning）：应该怎么表达（"适合谁/不适合谁"）
3. **禁止定位**（forbidden_positioning）：绝对不能出现的表达
4. **结论方向**（conclusion_direction）：结尾必须回答什么

## 典型错误

**只做负向约束**：
> business_strategy: "不踩Pro"

**问题**：主笔只知道不能骂Pro，但不知道应该怎么写Pro。结果要么完全不提Pro（读者觉得缺信息），要么用极度委婉的废话敷衍。

## 正确改法

```yaml
business_strategy: "不踩Pro，场景区分。Ultra适合大促差价小、追求画质余量的人；Pro适合非大促、预算更敏感、追求成熟爆款的人。"
protected_models_or_brands: ["TCL T7M Pro", "Pro"]
allowed_positioning: ["适合", "场景"]
forbidden_positioning: ["Pro别碰", "Pro缩水", "Pro是丐版", "买Pro吃亏", "Ultra吊打Pro"]
conclusion_direction: "必须回答'到底怎么选'，不能只证明Ultra好"
```

## 判定条件

- 定稿卡中 business_strategy 不能只有禁词，必须包含正向表达
- 结尾段必须出现 allowed_positioning 中至少 1 个正向定位词
- 结尾段必须提及至少 1 个 protected_models_or_brands
- 全文不得出现 forbidden_positioning 中的任何词
- 封面不得把 protected model 做成被踩对象
