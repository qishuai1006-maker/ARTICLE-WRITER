## 规则

终稿不得出现"此处插图缺失：未指定"。

每个图位必须具备完整结构：
1. **编号**：info_1, info_2 等
2. **功能**：封面 / 理解 / 收藏 / 对比
3. **对应段落**：该图服务正文哪个段落
4. **核心关系**：图要表达的核心信息关系
5. **evidence_id**：图中数据来源的证据编号
6. **提示词方向**：生图时的关键描述
7. **禁止事项**：该图不能出现的内容

## 典型错误

> 【此处插图缺失：未指定】

**问题**：视觉指挥官没有为这个位置规划具体方案，主笔预留的占位符成了死位。

## 正确改法

```
[此处插入信息图1：Ultra vs Pro 核心参数对比，分区数+亮度+音响]
```

对应 visual_plan.yaml 中：
```yaml
- slot_id: "info_1"
  function: "对比"
  paragraph: "参数对比段"
  core_relation: "Ultra vs Pro 核心配置差异"
  evidence_id: "E02"
  prompt_hint: "分区数对比表"
  forbidden: "不做视觉拉踩"
```

## 判定条件

- 终稿全文搜索"此处插图缺失：未指定"，命中即 ERROR
- 每个正文图位在 visual_plan.yaml 中必须有对应 slot
- 每个 slot 必须包含 function / paragraph / core_relation 三个必填字段
- visual_plan 未覆盖所有正文图位时，状态卡不得 PASS
