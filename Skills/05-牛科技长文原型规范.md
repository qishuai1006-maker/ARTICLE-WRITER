# 05-牛科技头条长文原型规范

> **核心定位**：极简工作流 **Step 2 (降维生成)** 的最高纲领。  
> 规定了“牛科技 / 牛科技说”双重账号的灵魂与骨架。这决定了我们写出来的文章，到底是像一本“产品说明书”，还是像一篇能引爆头条信息流的“爆款导购指南”。

---

## 一、双重账号底色（写前必选）

在根据对标文章进行降维生成时，必须先明确套用哪个账号的人设：

### 1. 牛科技 A号 (工具老炮)
- **人设**：一个懂家电、会查资料、替读者算账的技术老炮。
- **姿态**：帮你指坑、帮你算钱、把参数翻译成体验、让购买动作变简单。
- **适合的原型**：价格损失、安装避坑、型号推荐、参数裁判。

### 2. 牛科技说 B号 (圈内老友)
- **人设**：一个看过无数机器、听过无数售后反馈、敢于说实话的圈内老朋友。
- **姿态**：我见过这种翻车、我不站品牌只看结果、这事不能全信宣传。
- **适合的原型**：内幕视角、品牌真实差距、拆机验证、家庭场景裁判。

---

## 二、动笔前必答的四个灵魂拷问

如果答不出以下四个问题，绝对不能进入撰写流程：

1. **读者不看这篇会损失什么？**  
   （多花钱、买错型号、装错、用不舒服、维修麻烦、被忽悠。）
2. **这篇挑战了什么默认认知？**  
   （比如：不是越贵越好；不是风量大就吸烟好；不是容积大就保鲜强。）
3. **专业点怎么翻译成用户结果？**  
   （蒸发器=串味风险；水量伺服=洗澡忽冷忽热；静压=高层排烟不倒灌。）
4. **读完后读者能做什么动作？**  
   （问客服一句话、看清铭牌、避开某个配置、收藏底线清单。）

## 三、6大爆款文章原型库

写之前先选一种主原型，绝对禁止把所有稿件都写成枯燥的“痛点 → 参数 → 总结”。

### 1. 价格损失账本型
- **适合**：安装收费、价格差、预算档、国补套路。
- **骨架**：具体损失场景 → 合理价格区间 → 钱差在哪 → 哪些该花/不该花 → 行动清单。

### 2. 场景翻车检查型
- **适合**：洗不干净、排烟差、烘不干、空调吹着冷。
- **骨架**：翻车现场 → 常见误判 → 真正原因 → 逐项自查 → 何时该换机器。

### 3. 专业人设真实差距型
- **适合**：海尔vs美的、TCLvs小米等品牌硬刚。
- **骨架**：普通人怎么选 → 这个选法漏了啥 → 3-5个真实差距 → 哪类家庭适合谁 → 一句话带走。

### 4. 拆机/结构验证型
- **适合**：双系统冰箱、洗衣机电机路线。
- **骨架**：宣传词疑问 → 看结构本质 → 两条路线对比 → 辨别方法 → 适合人群。

### 5. 型号/预算裁判型
- **适合**：618推荐、价位段选购指南。
- **骨架**：否定单一神机 → 按预算分层 → 每层给判断标准和代表型号 → 哪类人别买 → 保存清单。

### 6. 使用诊断纠错型
- **适合**：洗碗机摆放、油烟机清洁误区。
- **骨架**：效果不好先别怪机器 → 3-5个使用变量 → 正确做法 → 什么时候才说明机器不行。

## 四、与 Orchestrator 三棒接力的融合联动

本 Skill 已完美切入 `CLAUDE.md` v3.0 的 Orchestrator 架构。
它决定了整篇文章的**结构与逻辑骨架**，随后由 `04-活人写手感规范.md` 决定其**血肉与语气**。

**三棒接力协同：**
1. **第一棒（Agent 01 情报拆解）**：提取对标文章的情绪骨架、钩子和反转点，产出拆解卡。
2. **第二棒（Agent 02 首席主笔）**：👉 **【此时调用本规范】** 选择 A/B 号人设，套用 6 大原型之一，结合《推品逻辑手册》输出 Markdown 正文。然后调用 `04-活人语感` 润色字句、消灭 AI 味。最后调用 `03-配图规范` 输出封面 Prompt。
3. **第三棒（Agent 03 风控主编）**：调用 `02-出稿质检规则` 打分 + `06-合规红线词库` 终审。
