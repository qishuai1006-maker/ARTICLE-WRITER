## 二、禁词分级（黑名单）

> 命中级别：🔴 A 类法律红线 > 🟧 B 类实测限流 > 🟨 C 类疑似降权 > ⬜ D 类 AI 八股文。

### 🔴 A 类：广告法绝对化用语（法律红线 · 命中即违规扣分）

| 禁词 | 风险 | 安全替代 |
|------|------|---------|
| 最好/最佳/最强 | 广告法禁用 | 同价位表现突出 / 第一梯队 |
| 第一/No.1 | 广告法禁用 | 头部水平 / 销量靠前 |
| 唯一/独家 | 广告法禁用 | 少有的 / 为数不多的 |
| 必须/一定要 | 绝对化指令 | 建议 / 推荐 / 不妨考虑 |
| 碾压/吊打 | 贬损竞品 | 拉开差距 / 领先明显 |
| 横评 | 平台不鼓励无资质横评 | 清单 / 盘点 / 实测 / 对比 |

### 🟧 B 类：平台实测限流词（数据实锤 · CTR 归零级）

| 禁词 | 实测证据 | 安全替代 |
|------|---------|---------|
| 智商税 | 3 展现 vs 同选题 49138 展现 | 花冤枉钱 / 别踩坑 / 不值这个价 |
| 完美 | 87 展现 vs 同号平均 2 万+ | 综合表现强 / 几乎挑不出毛病 / 靠谱稳妥 |
| 秒杀 | 绝对化 + 营销话术 | 优势明显 / 强得多 |

### 🟨 C 类：疑似降权词（标题党 / 虚假热度 · 平台可能标记低质）

| 词/表述 | 风险 | 说明 |
|---------|------|------|
| 震惊/万万没想到/看哭了 | 标题党专项整治重点 | 平台重点打击 |
| 必买/必入/不买后悔 | 虚假承诺 | 制造不存在的紧迫感 |
| 疯传/刷屏/人人都在买 | 虚假热度 | 无数据支撑的跟风暗示 |
| 揭秘/曝光/惊天内幕 | 贬损类标题党 | 暗示阴谋论，降权 |
| 骗/骗局/割韭菜 | 攻击性贬损 | 商业诋毁风险 |
| 抢购/秒杀/最后一天 | 营销话术 | 促销关键词，内容号慎用 |
| 神器/神机/YYDS | 夸大网络用语 | 过度夸张降低可信度 |
| 买了必后悔/不看后悔/全家遭殃/闭眼入 | 强迫恐吓·无信息锚点 | 跟 check_title_delivery HARD_GREY 同步; 无信息能救, 直接换(见六章三种替代技术) |

### ⬜ D 类：AI 八股文（低完读 · 去 AI 味必杀）

| 表述 | 原因 | 安全替代 |
|------|------|---------|
| 随着…的发展/普及 | AI 八股开头 | 直接切入场景 |
| 在这个数字化时代 | AI 八股 | 删除 |
| 总而言之/综上所述 | AI 八股结尾 | 删除或口语收尾 |
| 毋庸置疑/不言而喻/毫无疑问 | AI 填充词 | 删除 |
| 随着科技的发展 | AI 八股 | 删除 |
| 你知道吗 | 播音腔 | 直接用事实或场景 |
| 不仅如此/与此同时 | AI 过渡 | 删除或用口语过渡 |
| 抖音达人说 | 引述竞品平台 | 有博主测过 / 网上有人实测 |

> CEO 厌恶黑名单（额外）：在这个数字化时代、总而言之、毋庸置疑、不言而喻、随着科技的发展、毫无疑问。

## 四、配图专属禁忌

### 全部配图通用红线

| 禁止方向 | 原因 |
|---|---|
| Pillow/PIL/matplotlib 脚本图作为正式图 | PPT 感强，不能承担平台点击 |
| 对话预览图未落盘却写入终稿 | 最终文件不可复现 |

| 低清小图 / 文件过小 | 手机端发糊，像搬运图 |

## 五、Agent 调用规范

- **Agent 01（情报拆解）**：拆解对标标题时，记录其用了哪些安全词结构，主动避开 B/C 类雷词。
- **Agent 02（首席主笔）**：写稿完成后，全文扫描 A/B/C 类，命中即替换；D 类是去 AI 味重点。
- **Agent 03（风控主编）**：终审逐条核查。命中 🔴A 类扣 5 分/个；🟧B 类（实测限流）扣 5 分/个并强制替换；🟨C 类扣 2 分/个；⬜D 类扣 1 分/个。
- **白名单校验**：终审时确认正文没有把"真实差距/猫腻/不踩坑"等安全词误删。

## 六、合规×爆款平衡:兑现机制 + 三种替代技术（CEO 0622 课题）

> **背景**：CEO 拿头条社区规范（禁"故事诱导推广 / 夸张式 / 悬念式 / 强迫式标题"）抛课题——简单翻译成"别写强标题"会把爆款能力阉割。平衡公式 = **每个爆款元素锚定一个可兑现的信息增量**。本章节是 Claude Code 域内的兑现框架（`check_title_delivery` 双向闸门 + Step 4.5 主控复核的判据来源）。

### 6.1 平台规范根因（四类禁项的共性）

| 社区规范禁项 | 真正禁止的 | 允许的空间 | 核心检验 |
|---|---|---|---|
| 故事诱导推广 | 故事是外壳, 推广是目的, 中间没干货 | 故事是载体, 专业知识/真实判断是核心 | 故事 3 段内有没有进型号/参数/判断? |
| 夸张式标题 | 与事实不符的放大 | 对真实数据/体验的强烈表达 | 说的正文能 100% 兑现? |
| 悬念式标题 | 藏住核心价值, 逼用户点进来才知道讲啥 | 透露方向+问题, 细节在文章里 | 标题告知了领域/问题吗? |
| 强迫式标题 | 制造虚假紧迫感, 用情绪代替信息 | 指出真实风险, 引发合理警觉 | 这个"风险"是真实存在的还是虚构的? |

**共性根因：吸引力元素脱离信息基础。** 平台不是限制吸引力, 是保护算法健康（点击×完读×互动）——奖励"既吸引点击又让用户读完觉得值"。

### 6.2 三种替代技术（无效吸引 → 有效吸引）

当 `check_title_delivery` 报 `hard_grey_word` 或 `strength_word_needs_fulfillment` 时, 用这三种技术**重写标题**（不是词表替换, 是换吸引力的来源）：

| 技术 | ❌ 夸张违规版 | ❌ 平庸阉割版 | ✅ 有效吸引版 |
|---|---|---|---|
| ① 信息权威感（替情绪刺激） | 这样用空调你家要出大事! | 空调正确使用指南 | 我拆了12台空调, 80%的人在犯同一个错 |
| ② 真实悬念（替人造悬念） | 买空调千万别看品牌, 内幕震惊了 | 买空调该关注哪些参数 | 同价位三台空调我测了一个月, 结果和预期完全不同 |
| ③ 精准场景代入（替强迫建议） | 不看这篇你一定买错洗碗机! | 洗碗机选购建议 | 厨房1.8米橱柜, 我怎么装下60cm洗碗机 |

**有效吸引 vs 无效吸引**：无效 = 靠情绪/悬念/恐惧拉点击 → 完读低 → 算法罚；有效 = 靠专业权威/真实数据/精准洞察拉点击 → 完读高 → 算法奖。

### 6.3 双向闸门（防夸张 + 防平庸）

兑现机制是**双向**的——不止防"夸张（兑现不了）", 也防"过度弱化（兑现了但冲击力删光 = 平庸 = 爆款阉割）"：

- **正向·防夸张**：标题每个爆款元素（数字/型号/强度词/悬念）正文必须兑现。`check_title_delivery` check 1-7。
- **反向·防平庸**：正文有可钩子硬实体（数字/型号/对比）, 标题却一个没用 = 把真实信息做成了平庸标题。`check_title_delivery` check 8。

**主控 Step 4.5 三问校验（挂创作时间轴）**：
- 创作前（Step 3 定标题）：吸引力的来源是真实信息的力量, 还是情绪操控？
- 发布前（Step 4.5 兑现检查）：标题暗示的承诺, 正文能 100% 兑现甚至超出？
- 发布后（`/fupan` 飞轮）：完读率低+负反馈高 = 吸引力透支, 回调；完读率高+互动健康 = 找到平衡点, 复制。

### 6.4 给智能体的判断框架（不是禁止清单）

写标题/正文规则时用框架表述, 不用禁词清单（禁词清单会让智能体学会查表换词, 而不是理解为什么该兑现什么）：

> 标题的吸引力必须来源于内容本身的真实价值——真实数据、真实测评、真实反常识的发现。可以写强烈的、有冲击力的标题, 但前提是正文能兑现这个冲击力。禁止用情绪制造虚假紧迫感, 允许用真实信息制造强烈期待感。
