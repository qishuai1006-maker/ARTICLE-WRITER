>

## 二、🆕 文章内表格必须转图片（P0）

**规则**：文章正文中的所有 Markdown 表格，不得直接保留在正文中渲染，必须转为 NotebookLM 信息图。

**原因**：
1. Markdown 表格在手机端显示效果差（列挤压、需要横向滑动）
2. 信息图比表格更直观，参数高亮/颜色区分一目了然
3. 头条图文的图片比文字表格更有吸引力，提升完读率

### 哪些表格必须转图

| 表格类型 | 转图方式 | 优先级 |
|---------|---------|--------|
| 产品参数对比表（3款以上） | NotebookLM 信息图 | P0 必须 |
| 价格档位表 | NotebookLM 信息图 或 ChatGPT | P0 必须 |
| 优缺点对比表 | NotebookLM 信息图 | P0 必须 |
| 楼层/场景对照表 | NotebookLM 信息图 | P0 必须 |
| 简短的两列对照（如"情况A vs 情况B"） | 可保留正文，不必转图 | P2 可选 |

### 执行流程

```
T3 写作时：
  全栈写手正常用 Markdown 表格写参数对比等内容
  在表格上方用注释标记：<!-- 表格转图：T5_xxx.png -->

T5 配图时：
  视觉分发师扫描 T3 中所有 Markdown 表格
  每个 <!-- 表格转图 --> 标记的表格，用 NotebookLM 生成对应信息图
  正文中表格替换为图片引用：![参数对比](T5_ChatGPT_参数对比.png) 或 ![参数对比](T5_参数对比图.png)

T6 终稿时：
  确认所有表格已被图片替代
  确认图片中的数据与原表格完全一致
```

## 八、封面图策略（5种类型轮换）

> **核心原则：封面和标题是互补关系。标题由平台渲染，封面做视觉冲击。**
> **硬性规则：封面图上文字 ≤ 10个字，绝不放文章标题。**

| 类型 | 适用选题 | 核心视觉 | 图上文字（≤10字） | 工具 |
|------|---------|---------|-----------------|------|
| **产品对决型** | 横评/对比 | 两产品并排"VS" | 品牌名+"VS" | ChatGPT |
| **价格冲击型** | 618/价格敏感 | 超大价格数字 | 价格数字 | ChatGPT |
| **避坑警示型** | 避坑/不推荐 | 红色警告/大叉 | 警示短句 | ChatGPT |
| **场景代入型** | 使用场景/体验 | 真实使用场景 | 场景关键词 | ChatGPT |
| **参数一击型** | 技术参数/科普 | 超大参数数字 | 参数数值 | ChatGPT |

**轮换规则**：连续两篇文章不使用同一种封面类型。

封面图提示词详见 `参考资料库/ChatGPT生图提示词手册.md` 中的模板 1-5。

## 十二、图片质量评估标准

| 维度 | 达标标准 | 不达标处理 |
|------|---------|-----------|
| **分辨率** | ≥1920×1080（16:9）或 ≥1080×1080（1:1） | 重新生成 |
| **文字清晰度** | 中文清晰可读，无乱码/模糊 | 重新生成 |
| **信息完整性** | 数据与 T2 素材包一致，无遗漏 | 修正后重新生成 |
| **路线一致性** | 技术路线数量 ≥ 文章实际路线数量 | 修正后重新生成 |
| **封面标题隔离** | 封面图不含文章标题，文字 ≤ 10字 | 重新生成 |
| **🆕 表格数据一致** | 转图后的数据与原文 Markdown 表格完全一致 | 重新生成 |

- ❌ 不得使用来路不明/无版权图片

- ❌ **封面图不得放入文章标题**（P0）
- ❌ **封面图文字超过 10 个字**（P0）
- ❌ **禁止使用即梦生图**（P0）
- ❌ **禁止使用 Pillow/PIL 脚本生图**（P0）

- ❌ 信息图中的数据不得与 T2 素材包矛盾
- ❌ 配图中的技术路线数量不得少于文章实际路线数量（P0）
- ❌ 🆕 **正文中不得保留 3 列以上的 Markdown 表格**（必须转图，P0）
