## 一、生图工具链（v4.0 统一标准）

> ⚠️ **禁止使用即梦（jimeng.jianying.com）！用户无即梦会员！**
> ⚠️ **禁止使用 Pillow/PIL 脚本生成信息图！质量不达标！**

| 优先级 | 工具 | 适用场景 | 特点 |
|--------|------|---------|------|
| **🥇 主力** | NotebookLM 信息图 | 参数对比图、人群选购图、优缺点图、场景对比图、封面图 | 专业信息图质量、支持中文、结构化数据驱动 |
| **🥈 降级** | Antigravity generate_image | NotebookLM 不可用或生成失败时的所有类型 | 全自动化、无需浏览器、AI生成质量 |
| **🥉 补充** | 网图搜索 | 品牌官网产品图、京东商品图、评测媒体样张 | 真实产品实拍（信息图无法替代的场景） |

### 降级触发条件

当以下任一情况发生时，从 NotebookLM 降级到 generate_image：
1. NotebookLM 网页无法访问（网络问题）
2. NotebookLM 生成连续失败 2 次
3. NotebookLM 笔记本配额耗尽

## 二、图片类型标准（7类）

| 类型 | 用途 | 尺寸规格 | 工具选择 |
|------|------|---------|---------| 
| **封面图** | 头条/公众号等平台封面，**视觉钩子**（标题不入图，封面做标题做不到的事） | 1920×1080（16:9）或 1080×1920（9:16） | NotebookLM 信息图 / 网图搜索 / 产品实拍拼合 |
| **参数对比图** | 四平台通用，展示产品核心参数差异 | 1920×1080（16:9） | NotebookLM 信息图 |
| **人群选购图** | 场景化选购建议，分人群推荐 | 1080×1080（1:1） | NotebookLM 信息图 |
| **优缺点总结图** | 产品/方案的优缺点一目了然 | 1080×1080（1:1） | NotebookLM 信息图 |
| **场景对比图** | 不同场景下的使用效果/体验对比 | 1920×1080（16:9） | NotebookLM / 网图搜索 |
| **场景体验图** | 小红书/头条配图，生活感、场景感强 | 1080×1080（1:1）或 16:9 | 网图搜索 |
| **封面文字图** | 无合适素材时的降级方案，纯视觉符号+极简文字（≤10字） | 1920×1080（16:9） | NotebookLM 信息图 |

## 三、配图数量标准（强制 5-6 张）

### 必出配图包（每篇文章 5 张，不可减少）

| 序号 | 图片类型 | 对应文章位置 | 说明 |
|------|---------|------------|------|
| ① | **封面图** | 文章最顶部 | **视觉钩子型封面，标题不入图**（详见封面类型轮换表） |
| ② | **参数对比图** | "核心参数对比"章节 | 产品/技术的横向参数表格可视化 |
| ③ | **场景对比图** | "深度拆解"章节（痛点模块2附近） | 不同场景/方案的使用效果对比 |
| ④ | **优缺点总结图** | "优缺点总结"或"选购建议"章节 | ✅❌ 格式的优缺点可视化 |
| ⑤ | **人群选购图** | "选购建议"章节结尾 | 分人群/预算段的推荐路线图 |

### 第6张配图（根据平台/内容类型选择 1 张）

| 条件 | 配图类型 | 说明 |
|------|---------|------|
| 小红书稿件 | 场景体验图 | 生活化、真实感的使用场景 |
| 涉及价格对比 | 价格走势/档位图 | 各产品价格区间可视化 |
| 涉及技术原理 | 技术原理图 | 工作原理示意图 |
| 产品外观重要 | 产品外观对比图 | 品牌官网/京东高清产品图拼合 |

### 搜索意图 → 配图侧重

| 搜索意图 | 必出5张之外的重点 | 第6张推荐 |
|---------|-----------------|---------| 
| 信息型 | 参数对比图要更详细 | 技术原理图 |
| 商业调研型 | 人群选购图要更细分 | 价格走势/档位图 |
| 交易型 | 优缺点图要更突出 | 产品外观对比图 |
| 经验型 | 场景对比图要更真实 | 场景体验图 |

## 五、NotebookLM 生成规范（v4.0 主力方案）

### 信息图生成标准流程

```
1. 数据准备
   └── 从 T2 素材包提取核心参数/对比数据
   └── 整理成结构化文本（Markdown 表格或有序列表）
   └── 确认技术路线数量与 T3 终稿一致

2. 访问 NotebookLM
   └── 打开 https://notebooklm.google.com
   └── 使用已有笔记本或新建笔记本
   └── 将 T2 素材包数据作为来源上传

3. 逐张生成信息图
   └── 粘贴下方对应模板的提示词
   └── 选择「生成信息图」功能
   └── 检查生成结果的质量和路线一致性
   └── 下载 PNG 到 outputs/ 目录
```

#### 类型C：封面图（v5.0 视觉钩子型 · 5种类型轮换）

> **核心原则：封面和标题是互补关系，不是重复关系。标题已经由平台渲染在封面上方，封面图再做一遍标题 = 浪费最贵的视觉位。封面要做标题做不到的事——视觉冲击。**
>
> **硬性规则：封面图上的文字 ≤ 10个字，绝不放文章标题。**

**5种封面类型（按选题风格轮换，连续两篇不重复）：**

| 类型 | 适用选题 | 核心视觉 | 图上文字（≤10字） |
|------|---------|---------|-----------------|
| **产品对决型** | 横评/对比/选购 | 两款产品并排，中间"VS"分隔，视觉对比强烈 | 品牌名 + "VS"（如"小天鹅 VS 海尔"） |
| **价格冲击型** | 618/双11/价格敏感选题 | 价格数字做视觉主角，大字体+对比色 | 价格数字（如"¥4299 vs ¥1699"） |
| **避坑警示型** | 避坑/不推荐/翻车类 | 红色警告视觉，产品上打叉或STOP标志 | 警示短句（如"别买这种"） |
| **场景代入型** | 使用场景/体验/教程 | 真实使用场景（满地泡沫/干净效果/安装现场） | 场景关键词（如"串味现场"） |
| **参数一击型** | 技术参数/硬核科普 | 单个核心数据超大字体+对比参考线 | 参数数值（如"洗净比 1.31"） |

**NotebookLM 提示词模板（5种）：**

**C1：产品对决型**
```
生成一张产品对决封面图。左侧 [品牌A] 产品图标，右侧 [品牌B] 产品图标，中间超大"VS"字样。背景干净简洁，两侧用对比色区分（蓝色 vs 橙色）。产品下方各标注1个核心优势数字。无标题，无长文字。视觉冲击力第一。16:9横版。
```

**C2：价格冲击型**
```
生成一张价格对比封面图。画面中央是两个超大价格数字：左侧 "[品牌A] ¥xxxx" 用红色，右侧 "[品牌B] ¥xxxx" 用绿色。背景简洁浅色。两个价格之间用箭头或对比线连接。底部可加一行小字说明价格来源（如"京东5月实时价"）。无标题，无文章标题。16:9横版。
```

**C3：避坑警示型**
```
生成一张避坑警示封面图。画面中央是醒目的红色STOP标志或大叉图标，背景是模糊的[品类]产品轮廓。主色调红+黑+白，警告感强烈。画面上最多4个字的产品类型标注（如"这种电视"）。无标题，无文章标题。16:9横版。
```

**C4：场景代入型**
```
生成一张[品类]使用场景封面图。画面展示[具体场景描述，如"打开冰箱门闻到异味的瞬间"/"洗衣机洗完后衣服缠成一团"]的生活场景感。色调真实自然，不做科技感处理。画面上最多6个字的场景标注（如"串味现场"）。无标题，无文章标题。16:9横版。
```

**C5：参数一击型**
```
生成一张参数冲击封面图。画面90%空间给一个超大核心参数数字"[参数值]"，用加粗字体+亮色（金色或红色）。底部一行小字标注参数含义（如"洗净比越高洗越净"）。背景深色简洁，数字就是唯一视觉焦点。无标题，无文章标题。16:9横版。
```

## 六、generate_image 降级方案（v4.0 新增）

> 当 NotebookLM 不可用时，使用 Antigravity 内置的 generate_image 工具生成配图。

### 降级生成规则

1. **提示词语言**：使用英文描述 + 明确要求中文文字标注
2. **风格指令**：在提示词中追加 `professional infographic, clean layout, data visualization, Chinese text labels`
3. **每张图单独调用一次** generate_image 工具
4. **生成后检查**：确认中文文字是否清晰可读（AI 生成的中文文字可能存在错误）

### 降级提示词示例

```
Generate a professional product comparison infographic chart.
Title (in Chinese): "万元级旗舰电视核心参数对比"
Compare 3 products in a clean table layout:
- Product A: [Name] - [Key specs]
- Product B: [Name] - [Key specs]  
- Product C: [Name] - [Key specs]
Style: Modern tech aesthetic, white background, blue-gray color scheme.
Green highlight for best-in-class values.
All text labels in Chinese. Clean data visualization. 16:9 aspect ratio.
```

### 降级质量标准

- 如中文文字出现错误/乱码 → 可接受但需在图注中补充文字说明
- 信息准确性 → 必须与 T2 素材包数据一致
- 视觉质量 → 允许略低于 NotebookLM，但必须清晰专业

## 七、网图搜索规范

### 搜索优先级

1. **品牌官网产品图** — 质量最高，无版权问题
   - TCL/索尼/三星官网 → 产品详情页
2. **京东/天猫商品图** — 实拍图为主
   - 搜索：`[品牌] [型号] 官方图`
3. **百度图片（CC0 协议）** — 无版权风险
   - 搜索：`[品类] [场景] 高清`
4. **IT媒体评测图** — RTINGS/Tom's Hardware 官方样张
   - 搜索：`[型号] review [媒体名]`

### 版权检查清单

- [ ] 图片有明确版权来源（品牌官网/CC0/授权）
- [ ] 不得使用来路不明的图片
- [ ] 评测媒体图需标注来源链接
- [ ] 人物出镜需有授权（特别小红书配图）

### 文件命名规范

```
T5_[序号]_[类型]_[主题].png
示例：
T5_01_封面图.png
T5_02_参数对比图.png
T5_03_场景对比图.png
T5_04_优缺点图.png
T5_05_人群选购图.png
T5_06_价格档位图.png
```

## 八、T5 执行前置要求（P0 · 必须遵守）

> ⚠️ **T5 生成前必须完成以下步骤，不可跳过：**
>

## 十、图片四维质量评估标准（v4.0 新增）

| 维度 | 达标标准 | 不达标处理 |
|------|---------|-----------|
| **分辨率** | ≥1920×1080（16:9）或 ≥1080×1080（1:1） | 重新生成或裁切 |
| **文字清晰度** | 中文文字清晰可读，无乱码/模糊 | 重新生成 |

| **路线一致性** | 技术路线数量 ≥ 文章实际路线数量 | 修正提示词重新生成 |
| **封面标题隔离**（v5.0） | 封面图不含文章标题文字，图上文字 ≤ 10字 | 重新生成 |

## 十一、图片与文章正文结合规范

T6 终稿适配时，按以下顺序插入配图：

| 插入位置 | 配图 | 图注要求 |
|---------|------|---------| 
| 文章最顶部 | ① 封面图 | 文章主题+核心结论 |
| "核心参数对比"章节 | ② 参数对比图 | "xx vs xx 核心参数对比（数据来源：xxx）" |
| "深度拆解"章节中部 | ③ 场景对比图 | "不同场景下的使用效果对比" |
| "优缺点"或"选购建议"前 | ④ 优缺点总结图 | "xx 优缺点一览" |
| "选购建议"章节 | ⑤ 人群选购图 | "不同需求人群的选购推荐" |
| 文章中部/结尾 | ⑥ 第6张 | 根据图片内容定制图注 |

**图注规范**：
- 每张图必须有 1 句话图注说明
- 数据型图片图注必须标注数据来源
- 图注不超过 30 字

## 十二、合规红线

- ❌ 不得使用来路不明/无版权图片

- ❌ 信息图中的数据不得与 T2 素材包矛盾
- ❌ **配图中的技术路线数量不得少于文章实际涉及的技术路线数量**（P0）
