## 二、🆕 文章内表格必须转图片（P0）

**规则**：文章正文中的所有 Markdown 表格，不得直接保留在正文中渲染，必须转为 NotebookLM 信息图。

**原因**：
1. Markdown 表格在手机端显示效果差（列挤压、需要横向滑动）
2. 信息图比表格更直观，参数高亮/颜色区分一目了然
3. 头条图文的图片比文字表格更有吸引力，提升完读率

### 哪些表格必须转图

| 表格类型 | 转图方式 | 优先级 |
|---------|---------|--------|
| 产品参数对比表（3款以上） | NotebookLM 信息图 | P0 必须 |
| 价格档位表 | NotebookLM 信息图 或 ChatGPT | P0 必须 |
| 优缺点对比表 | NotebookLM 信息图 | P0 必须 |
| 楼层/场景对照表 | NotebookLM 信息图 | P0 必须 |
| 简短的两列对照（如"情况A vs 情况B"） | 可保留正文，不必转图 | P2 可选 |

### 执行流程

```
T3 写作时：
  全栈写手正常用 Markdown 表格写参数对比等内容
  在表格上方用注释标记：<!-- 表格转图：T5_xxx.png -->

T5 配图时：
  视觉分发师扫描 T3 中所有 Markdown 表格
  每个 <!-- 表格转图 --> 标记的表格，用 NotebookLM 生成对应信息图
  正文中表格替换为图片引用：![参数对比](T5_ChatGPT_参数对比.png) 或 ![参数对比](T5_参数对比图.png)

T6 终稿时：
  确认所有表格已被图片替代
  确认图片中的数据与原表格完全一致
```

## 八、封面图策略（v2.2 · 五原则 + ChatGPT风格指南 + 五模板 + 五步流程）

> **Source of Truth：`参考资料库/头条封面执行规范.md`**（以下为摘要，完整规范以该文件为准）
>
> **核心使命：封面不是配图，是广告Banner。唯一任务是在0.5秒内拦截用户手指。**
> **硬性规则：封面文字≤10字，文字视觉面积≤20%，绝不放文章标题，封面和标题必须互补不重复。**
> **🆕 ChatGPT风格铁律：信息图/场景叙事优先，禁止要求"真实照片"或精细视觉对比。**

### 封面五原则（P0 · 必须逐条遵守）

1. **主体极度清晰** — 裁切到核心细节特写，不用产品全景图。冰箱拍保鲜抽屉、电视拍画质细节、空调拍压缩机、油烟机拍灶台油烟。主体占画面60%+，是绝对视觉中心
2. **文字是标签，不是主角** — 可带文字，≤10字，但视觉面积不超过画面15-20%。字号控制在"缩略图下勉强可读"。拿掉文字，图片本身仍应能传达核心信息。从五套公式（A≠B / 不是A是B / 买前先看X / 这X种慎买 / 数字差异）中选取
3. **色彩抢眼≤3种** — 加高饱和度色块背景（红/橙/深蓝），产品白/银/黑在信息流里是隐形的
4. **真实感>精美感** — 真实测评感>品牌广告感，加入温度计/分贝仪/手部操作等真实元素
5. **封面标题互补不重复** — 封面文字和标题说同一件事=信息浪费。标题说"为什么"，封面给"具体数字/结论"；标题说结论，封面给场景。两者叠加产生点击冲动

### 🆕 ChatGPT 封面风格指南（v2.2 · 基于电视vs油烟机封面实测）

> **核心发现**：ChatGPT 生成封面的能力不是均匀分布的。信息图/场景叙事远优于真实照片/精细视觉对比。

**ChatGPT 擅长**（优先选用）：
- 信息图/扁平设计 — 三段式/分层/阶梯式数据可视化（MiniLED三价位段 ✅ CTR数据好）
- 单场景叙事 — 一个清晰的故事场景，主体+背景+情绪（电视挂墙安全隐患 ✅）
- 结构化标签 — 产品参数卡、规格对比卡、标签式信息展示（三机参数卡 ✅）

**ChatGPT 不擅长**（避免使用）：
- "真实照片" — "realistic photo"出来的画面假，改用"infographic style"（油烟机封面 ❌）
- 精细视觉对比 — 左右两侧细微差异渲染不出，两侧画面几乎一样（油烟机吸烟对比 ❌）
- 动态效果展示 — 油烟流动、水雾扩散等静态图无法呈现差异

**提示词关键词替换**：`realistic photo` → `infographic style`；`detailed product shot` → `flat design`；`showing the difference` → `labeled comparison`

### 五种封面模板

| 模板 | 适用文章类型 | ChatGPT可靠性 | 核心视觉 |
|------|------------|-------------|---------|
| **A：产品特写+小标签文字** | 避坑/误区/单品分析 | ⭐⭐⭐⭐⭐ 最稳 | 产品细节占60-70% + 角落小色块文字(≤20%) |
| **B：左右对比分割图** | 横评/品牌对比/反常识 | ⭐⭐ 有风险 | 仅当差异极明显时可用（如OLED黑vs LCD灰） |
| **C：红绿判断图** | 参数纠错/选购指南/真假概念 | ⭐⭐⭐⭐ | 左红(错误) vs 右绿(正确) |
| **D：剖面图/透视图** | 技术拆解/管路分析/结构科普 | ⭐⭐⭐⭐ | 单一结构剖面 + 粗箭头 + 少标注 |
| **E：三分栏风险图** | X个坑/X类人群/X种风险 | ⭐⭐⭐ | 三栏各一场景 + 底部总结论 |

**默认选 Template A**，除非文章类型强制要求其他模板。**轮换规则**：连续两篇文章不使用同一种封面模板。

### 封面提示词标准结构（P0 · 禁止自行发挥）

生成封面提示词时必须按以下结构填写，详见 `参考资料库/头条封面执行规范.md` Step 4：

```
生成一张今日头条家电图文封面图，尺寸 1280×720，16:9 横图。
【主题】[文章核心矛盾，一句话]
【画面主体】[家电品类+核心细节特写，不使用全景图，占画面60%+]
【构图】[主体占60-70%] [文字位置：角落小色块，≤画面20%] [是否对比/分栏/剖面]
【封面文字】主标题：[6-10字，与标题互补不重复] 辅助标签：[可选]
  文字视觉面积≤20%，字号"缩略图下勉强可读"
【视觉风格】infographic/信息图风格 或 场景叙事风格（禁用"真实照片""realistic photo"）
【颜色】主色≤3种，深色背景+白色小字+红/黄/绿重点色块
【禁止项】无水印/无小字堆砌/无复杂背景/无产品排排站全景/文字不超画面20%/不要求真实照片效果
```

### 封面验收三项检查（P0 · T5c 阶段必须执行）

- [ ] **0.5秒识别**：一眼看出品类+矛盾+为什么值得点
- [ ] **缩略图检查**：缩小到微信头像大小，主体/色彩还清晰，文字不抢主体
- [ ] **标题互补检查**：封面文字和文章标题不重复，传递不同维度信息

## 九、🆕 T5 三阶段流程（T5a 规划 → T5b 分流生成 → T5c 统一验收）

### T5a · 配图规划（T1 审批通过后立即启动，可与 T2 并行）

1. **读取 T3 终稿** — 确认文章技术路线数量和名称
2. **对照骨架清单** — 确认 T2 素材包路线数量
3. **扫描正文表格** — 找出所有 Markdown 表格，标记哪些需要转图
4. **制定配图清单** — 每张图标注：图片类型 / 负责工具（ChatGPT or NotebookLM）/ 插入位置 / 数据来源

⏸️ 等待 T2 素材包完成（如 T3 也已完成则更佳）

### T5b · 分流生成（依赖 T2 素材包）

```
ChatGPT 批次（封面图/场景对比图/价格档位图/技术原理图）：
├── 生成提示词 → 更新 ChatGPT_出图/ 目录中的文件
└── 通知 CEO 让 ChatGPT/Codex 生成图片

NotebookLM 批次（参数对比图/优缺点图/人群选购图/表格转图）：
├── 生成 NotebookLM 提示词
├── 直接生成下载到 outputs/ 目录
└── 下载前 pwd 确认根目录，下载后 ls + sips 验证
```

### T5c · 统一验收

1. **文件完整性** — `ls outputs/T5_*.png outputs/T5_ChatGPT_*.png | wc -l`（期望 ≥5）
2. **分辨率检查** — ≥1920×1080（16:9）或 ≥1080×1080（1:1）
3. **路线一致性** — 配图技术路线数量 ≥ 文章实际路线数量
4. **🆕 工具标注** — 写入 T5_配图说明.md，每张图必须标注生成工具（ChatGPT / NotebookLM / 网图）
