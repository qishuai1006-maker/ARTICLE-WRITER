# 产品库搜索技能

本技能提供家电和家居产品数据库的检索和添加能力，支持按品类、品牌、价格、尺寸、自定义参数等多维度筛选产品，也支持通过电商链接提交未收录产品。

## 使用流程

### 常规搜索流程

```
用户提问 → 判断需要产品信息
  ↓
第1步：调用 产品结构接口 获取品类参数结构
  → 确认品类标识、品牌ID、自定义参数字段名
  ↓
第2步：调用 产品搜索接口 精确检索
  → 传入品类、品牌、filters 等参数
  → 获取产品列表、价格、配置、AI摘要等
```

**什么时候需要先调结构接口？**

- 首次查询某个品类时（了解该品类有哪些自定义参数）
- 需要使用 filters 进行高级筛选时（需要知道字段名 czone）
- 不确定品牌ID或子品类ID时

**什么时候可以直接调搜索接口？**

- 简单的关键词搜索
- 已知品类标识的快速查询
- 只需按价格/尺寸/推荐等级筛选时

### 数据自更新流程（搜索无结果时）

当用户询问某款产品但搜索无结果时，应主动引导用户添加，形成数据闭环：

```
用户问"XX型号怎么样" → 搜索接口 keyword=XX型号
  ↓
搜索结果为空（code=404）
  ↓
主动询问用户："该产品暂未收录，您可以提供京东商品链接，我来帮您添加到产品库"
  ↓
用户提供电商链接 → 调用产品添加接口
  ↓
添加成功 → 告知用户"下个工作日可查询结果"
  ↓
（下个工作日后）用户再次询问 → 搜索接口可查到该产品
```

**什么时候应该主动引导添加？**

- 搜索某型号无结果时
- 用户提到某款产品但品库中没有时
- 用户直接提供了京东商品链接时
- 用户反馈"没找到XX产品"时

## 接口2：产品搜索

按条件检索产品列表，支持多维度筛选和分页。

### 全部请求参数

#### 基础筛选参数

| 参数          | 必填 | 类型     | 说明                                    |
| ----------- | -- | ------ | ------------------------------------- |
| api_key     | 是  | string | API密钥：`718af82b5941ddc5f0f3606683554077599e79169dc3dc2a` |
| keyword     | 否  | string | 关键词搜索，匹配产品名称和型号（模糊匹配）。支持智能分词，详见下方说明 |
| pinlei      | 否  | string | 品类标识（英文），如 bingxiang、kongtiao。也可传数字ID |
| sclass      | 否  | string | 子品类ID，多个用逗号分隔，如 "101,102"             |
| brand       | 否  | string | 品牌ID，多个用逗号分隔，如 "201,202"              |
| yanse       | 否  | string | 颜色ID，多个用逗号分隔                          |
| tjnum       | 否  | string | 推荐等级，多个用逗号分隔，可选值：5,4,3,2,1（5=最高）      |
| nengxiao    | 否  | string | 能效等级，精确匹配，如 "一级"                      |
| product\_id | 否  | int    | 指定产品ID，精确查询                           |

#### 价格范围参数

| 参数         | 必填 | 类型  | 说明             |
| ---------- | -- | --- | -------------- |
| min\_price | 否  | int | 最低价格（参考价），单位：元 |

| 参数        | 必填 | 类型  | 说明         |
| --------- | -- | --- | ---------- |
| min\_kuan | 否  | int | 最小宽度，单位：mm |
| max\_kuan | 否  | int | 最大宽度，单位：mm |
| min\_gao  | 否  | int | 最小高度，单位：mm |
| max\_gao  | 否  | int | 最大高度，单位：mm |
| min\_shen | 否  | int | 最小深度，单位：mm |
| max\_shen | 否  | int | 最大深度，单位：mm |

#### 自定义 Filters JSON（高级）

| 参数      | 必填 | 类型     | 说明                        |
| ------- | -- | ------ | ------------------------- |
| filters | 否  | string | 自定义参数筛选，JSON 格式字符串，详见下方专节 |

#### 分页参数

| 参数       | 必填 | 类型  | 默认值 | 说明          |
| -------- | -- | --- | --- | ----------- |
| page     | 否  | int | 1   | 页码          |
| pagesize | 否  | int | 30  | 每页数量（最大100） |

### 智能分词（keyword 自动拆分）

当 keyword 中包含品牌名、品类名或子品类名时，接口会自动提取并转为对应的筛选条件，剩余部分作为关键词搜索。

| 用户输入 | 接口自动处理 |
|--------|----------|
| `keyword=美的555` | `brand=美的ID` + `keyword=555` |
| `keyword=对开门640` | `sclass=对开门ID` + `keyword=640` |
| `keyword=海尔冰箱500升` | `brand=海尔ID` + `pinlei=冰箱ID` + `keyword=500升` |
| `keyword=格力空调` | `brand=格力ID` + `pinlei=空调ID` |

**建议**：虽然接口支持自动分词，但机器人如果能识别出品牌、品类，建议优先使用 `brand`、`pinlei`、`sclass` 参数分别传入，这样匹配更精确。

### 强制条件要求

接口要求至少提供一个查询条件，否则返回 400 错误。有效的查询条件包括：

- keyword（关键词）
- pinlei（品类）
- brand（品牌）
- sclass（子品类）
- filters（自定义筛选）
- product_id（产品ID）
- min_price / max_price（价格范围）
- min_kuan / max_kuan 等（尺寸范围）
- tjnum（推荐等级）
- nengxiao（能效等级）

## 自定义 Filters JSON 构造指南

`filters` 参数用于按品类的自定义参数进行精确筛选。它是一个 **JSON 对象字符串**，key 是字段名（从结构接口获取），value 是筛选值。

### 字段类型与匹配规则

#### 1. tvar 类型（文本模糊匹配）

- **匹配方式**：模糊匹配（LIKE %value%）
- **适用场景**：文本类参数，如能效等级名称、型号特征、面板材质等
- **值格式**：纯文本字符串

```json
{
  "tvar1": "一级",
  "tvar3": "不锈钢"
}
```

#### 2. tint 类型（整数范围匹配）

- **匹配方式**：精确值 或 范围匹配
- **适用场景**：整数类参数，如容量(L)、功率(W)、转速等
- **值格式**支持以下写法：

| 写法         | 含义           | 示例                                  |
| ---------- | ------------ | ----------------------------------- |
| `单值`       | 精确等于该值       | `"500"` → 等于500                     |
| `最小-最大`    | 在范围内         | `"400-600"` → 400到600之间             |
| `最小-`      | 大于等于         | `"500-"` → 500及以上                   |
| `值1,值2,值3` | 多个值/范围（OR关系） | `"500,800-1000"` → 等于500 或 800到1000 |

```json
{
  "tint1": "400-600",
  "tint3": "1000-"
}
```

#### 3. tdou 类型（浮点数范围匹配）

- **匹配方式**：与 tint 完全相同，但支持小数
- **适用场景**：小数类参数，如能效比、洗净比等

```json
{
  "tdou1": "3.5-5.0"
}
```

### 多条件组合

filters 中的多个条件之间是 **AND（且）** 关系，所有条件必须同时满足：

```json
{
  "tvar1": "一级",
  "tint1": "400-600",
  "tint3": "1000-"
}
```

含义：能效等级包含"一级" **且** 参数1在400-600之间 **且** 参数3大于等于1000

### 完整请求示例

```
POST: http://clawapi.ltnwl.com/product/search/
pinlei=bingxiang
brand=201
min_price=2000
max_price=5000
filters={"tvar1":"一级","tint1":"400-600"}
page=1
pagesize=10
```

### 如何确定字段名？

**必须先调用结构接口获取！** 步骤如下：

1. 调用 `POST /product/structure/?pinlei=bingxiang`
2. 找到目标品类的 `自定义参数` 数组
3. 查看每个参数的 `字段名`（如 tint1、tvar2、tdou1）
4. 用这个字段名作为 filters JSON 的 key

不同品类的同序号字段含义完全不同。例如：

- 冰箱的 `tint1` 可能是"总容积(L)"
- 空调的 `tint1` 可能是"匹数"
- 电视的 `tint1` 可能是"屏幕尺寸"

**因此使用 filters 前务必先查对应品类的结构！**

## 智能搜索降级策略（产品词识别增强 · 重要！必读！）

### 为什么需要降级策略？

产品库搜索的 keyword 使用模糊匹配，但在以下情况下可能搜索不到已收录的产品：

| 失败场景 | 原因 | 错误示例 |
|---------|------|--------|
| 关键词太长/太复杂 | 完整产品名+型号一起搜，匹配率低 | `keyword=海尔冰箱BCD-510WDEBU1` |
| 品牌+数字混合 | 智能分词可能拆分错误 | `keyword=美的508冰箱推荐` |
| 型号格式不一致 | 用户输入与库中格式不同 | `BCD510` vs `BCD-510` |
| 包含修饰词 | 多余的词干扰匹配 | `keyword=最好的海尔冰箱` |
| 只记得部分型号 | 不完整型号无法精确匹配 | `keyword=海尔508` |

### 三级搜索降级流程（必须按顺序执行）

```
用户查询 → 提取产品关键信息（品类、品牌、型号）
    ↓
Level 1：纯型号精确搜索
    keyword = 去掉品牌和品类词后的纯型号
    例：keyword=BCD-510WDEBU1
    ↓ 无结果？尝试去掉连字符：keyword=510WDEBU1
    ↓ 仍无结果？
Level 2：品牌ID + 品类 + 短关键词
    先调结构接口获取品牌ID
    pinlei=品类标识 & brand=品牌ID & keyword=型号核心数字
    例：pinlei=bingxiang & brand={海尔ID} & keyword=510
    ↓ 无结果？
Level 3：品类 + 品牌 + 参数范围兜底
    pinlei=品类标识 & brand=品牌ID & filters={参数范围}
    例：pinlei=bingxiang & brand={海尔ID} & filters={"tint1":"500-520"}
    在返回结果中逐条查找目标产品
    ↓ 仍无结果？
确认产品库未收录 → 引导提供京东链接 → 调用添加接口
```

### Level 1：纯型号提取规则

从用户输入中提取**纯型号**作为搜索关键词：

| 用户输入 | 提取的 keyword | 去掉了什么 |
|---------|--------------|----------|
| 海尔冰箱BCD-510WDEBU1 | BCD-510WDEBU1 | 品牌+品类 |
| 美的空调KFR-35GW/N8MJA3 | KFR-35GW/N8MJA3 | 品牌+品类 |
| TCL电视75V8G Pro | 75V8G Pro | 品牌+品类 |
| 西门子洗碗机SJ256I16JC | SJ256I16JC | 品牌+品类 |
| 格力空调推荐3匹 | 3匹 | 品牌+品类+修饰词 |

**提取原则**：去掉品牌名、品类词、修饰词（推荐/最好/怎么样/评测），保留型号中的字母+数字+连字符。

### Level 2：品牌分离搜索示例

```
步骤1：获取品牌ID
POST http://clawapi.ltnwl.com/product/structure/
api_key=718af82b5941ddc5f0f3606683554077599e79169dc3dc2a&pinlei=bingxiang
→ 在品牌列表中找到"海尔"的ID（假设为201）

步骤2：品牌ID + 短关键词
POST http://clawapi.ltnwl.com/product/search/
api_key=718af82b5941ddc5f0f3606683554077599e79169dc3dc2a&pinlei=bingxiang&brand=201&keyword=510
```

**短关键词提取**：从型号中提取最核心的数字标识
- BCD-510WDEBU1 → `510`
- KFR-35GW/N8MJA3 → `35GW` 或 `35`
- 75V8G Pro → `75V8G`

### Level 3：参数范围兜底示例

```
步骤1：确认品类自定义参数字段名
POST http://clawapi.ltnwl.com/product/structure/
api_key=718af82b5941ddc5f0f3606683554077599e79169dc3dc2a&pinlei=bingxiang
→ 找到"总容积(L)"字段名为 tint1

步骤2：参数范围搜索
POST http://clawapi.ltnwl.com/product/search/
api_key=718af82b5941ddc5f0f3606683554077599e79169dc3dc2a&pinlei=bingxiang&brand=201&filters={"tint1":"500-520"}&pagesize=50

步骤3：在返回结果中逐条查找目标产品
```

### 常见搜索失败修复速查表

| 用户输入 | ❌ 错误做法 | ✅ 正确做法 |
|---------|-----------|----------|
| 海尔508冰箱 | `keyword=海尔508冰箱` | L2: `pinlei=bingxiang&brand={海尔ID}&keyword=508` |
| 美的大白Pro | `keyword=美的大白Pro` | L1: `keyword=大白Pro` → L2: `brand={美的ID}&keyword=大白` |
| BCD-510WDEBU1 | `keyword=海尔BCD-510WDEBU1` | L1: `keyword=BCD-510WDEBU1` → `keyword=510WDEBU1` |
| 3000元冰箱 | `keyword=3000元冰箱` | `pinlei=bingxiang&min_price=2500&max_price=3500` |
| 一级能效变频空调 | `keyword=一级能效变频空调` | `pinlei=kongtiao&nengxiao=一级&filters={"tvar1":"变频"}` |

> **核心原则**：keyword 只放纯型号或核心数字，品牌用 brand 参数，品类用 pinlei 参数，属性用 filters 参数。三级降级必须按顺序执行，不要跳级。

## 注意事项

1. **先结构后搜索**：使用 filters 高级筛选前，务必先调用结构接口确认字段名
2. **字段名因品类而异**：tint1 在冰箱是容积，在空调是匹数，不能跨品类复用
3. **分页获取**：默认每页30条，最多100条。数据量大时注意翻页
4. **推荐等级说明**：5=强烈推荐，4=推荐，3=一般，2=较低，1=不推荐
5. **价格字段**：官方价是指导价，参考价是参考售价，筛选和统计都用参考价
6. **图片链接**：图片列表、主图图片集、详情图片集均为完整URL，可直接展示
7. **一句话点评**：是人工编写的对这个产品的卖点特点摘要总结，适合直接向用户展示
8. **智能分词**：keyword 支持自动提取品牌名、品类名，但建议机器人优先使用 brand、pinlei、sclass 参数分别传入
9. **强制条件**：必须至少提供一个查询条件（keyword、pinlei、brand、sclass、filters 等），无条件查询将返回 400 错误
