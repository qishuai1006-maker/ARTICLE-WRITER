# 配图提示词生成规范 (精简版)

> **注意**：封面规则请看 `R03_封面规则`，图位闭环检查请看 `R05_图位闭环`。
> 本文件仅用于生成**具体的生图提示词**。

## 1. 提示词基本结构

生成 AI 绘画提示词时，必须严格遵守以下结构：

```
[主体描述] + [环境/背景] + [光影/材质] + [风格] + [特殊要求]
```

## 2. 封面图提示词模板

**核心原则**：留白、突出痛点/对比、不要过于杂乱。

**提示词示例**：
> "一分为二的对比图。左边是一台画质发灰、反光的电视（代表痛点），右边是一台色彩鲜艳、暗场深邃的Mini LED电视（代表解决）。现代极简客厅背景。高画质，摄影级别，留出上方和下方空间用于添加文字标题。"

## 3. 信息图/对比图提示词模板

**核心原则**：图形化表达参数，不要让 AI 直接生成文字表。

**提示词示例**：
> "微距摄影，特写电视屏幕的背光灯珠（Mini LED）。灯珠密集、明亮，体现科技感。背景是深邃的纯黑，带有微微的蓝色科技光晕。高清晰度，极简风格，留出大面积空白用于排版参数列表。"

## 4. 避坑检查

1. **绝对不要让生图模型直接写复杂中文**（如参数表、大段文字），它一定会拼错。必须是生成底图，文案由后期排版。
2. **切忌生成品牌 Logo**，容易发生扭曲或侵权。
3. **避免人物露脸**，以免带来不必要的视觉分散或版权问题。
