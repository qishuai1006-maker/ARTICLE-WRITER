# 活人写手感升级包

> 核心信条：**去AI味解决的是"不说错话"，活人手感解决的是"说人话"。** 两条线并行，缺一不可。
> v2.0 新增：从 khazix-writer（数字生命卡兹克）开源技能中吸收 6 种进阶叙事技法，适配头条家电赛道调性。

## 一、开头兵工厂（8种开场模式）

> **铁律**：每篇文章必须选择一种开场模式。连续两篇不得使用同一种。选择依据：选题DNA中的文章类型 + 话题本身的爆点特征。

### 模式1：反常识钩

用一条违反直觉的事实砸开，让读者"不可能吧？"然后往下看。

**适用**：数据反差大、行业反转、政策突变的话题

| 示例 | 话题 |
|------|------|
| "退出中国市场那天，股价涨了14%" | 三星退出中国 |
| "今年618空调均价降了，但利润反而涨了" | 空调618 |
| "扫地机器人卖得最好的价位段，不是3000也不是5000，是1299" | 扫地机器人 |

**写法要点**：一句话说完反常识事实，不做解释，解释留给正文。长度控制在1-2句。

### 模式2：场景代入

直接把读者拉进一个具体场景，让人有画面感。

**适用**：教程避坑型、选购型、有使用场景的话题

| 示例 | 话题 |
|------|------|
| "师傅拆开我家油烟机的时候，油脂厚得能炒一盘菜" | 油烟机清洗 |
| "上周帮朋友装空调，铜管刚弯好，师傅说了一句话，我多花了800" | 空调安装猫腻 |
| "我妈用了我新买的洗烘一体机之后，把阳台上的晾衣架拆了" | 洗烘一体机 |

**写法要点**：必须有具体的人、动作、细节。不能"很多用户反映"，要"我/我朋友/我妈/邻居老王"。

### 模式3：数字暴击

一个数字甩出来，不做任何铺垫。

**适用**：有大数字、行业数据、价格信息的话题

| 示例 | 话题 |
|------|------|
| "140万亿。这是中国AI单日Token调用量" | AI趋势 |
| "4000块，500L，双系统冰箱。去年这个配置至少6000" | 冰箱618 |
| "8亿台。鸿蒙智联接入设备总量" | 鸿蒙生态 |

**写法要点**：数字单独成句或成段，后面跟一句说明为什么这个数字重要。最多3句完成开头。

### 模式4：翻车自曝

先说自己（或认识的人）踩过的坑，拉近距离。

**适用**：教程型、避坑型、个人经验型

| 示例 | 话题 |
|------|------|
| "我去年618买空调，多花了1500块冤枉钱，原因就三个字：没做功课" | 空调选购 |
| "说个丢人的事，我家冰箱买大了，进不了厨房门" | 冰箱选购 |
| "第一次自己洗空调，水直接顺着墙流到地板上，差点把楼下淹了" | 空调清洗DIY |

**写法要点**：必须是具体的、有点丢人的、真实的。"翻车"越具体越可信。

### 模式5：内幕视角

以行业内部人的身份开口，直接给读者一种"你在听圈内人说话"的感觉。

**适用**：行业分析型、品牌对比型、政策解读型

| 示例 | 话题 |
|------|------|
| "在家电圈混了八年，说几句得罪人的实话：大部分人对油烟机的选购逻辑是反的" | 油烟机横评 |
| "做手机评测做了三年，我可以负责任地说：今年618，手机涨价是假象" | 手机618 |
| "国补这事儿，卖场的导购比你知道得多得多，但他们不会主动告诉你" | 国补攻略 |

**写法要点**：语气要稳、不浮夸。"说几句实话""可以负责任地说"这类标记建立可信度。但不要夸张身份，"资深业内人士"这种写法太假，直接说在做什么就行。

### 模式6：时间轴对比

两个时间点的强烈反差，一句话呈现变化幅度。

**适用**：行业趋势、品牌兴衰、技术迭代话题

| 示例 | 话题 |
|------|------|
| "2013年三星电视占18%份额，2026年不到4%" | 三星退出中国 |
| "五年前买个65寸电视要8000，现在3000出头" | 电视618 |
| "2023年AI Agent还只是论文概念，2026年已经有88%的企业在用" | AI趋势 |

**写法要点**：两个数字必须形成强反差。时间跨度越大越好。

### 模式7：悬念问题

一个让读者想往下看的问题，但不是"你知道吗"那种。

**适用**：科普型、揭秘型、选购决策型

| 示例 | 话题 |
|------|------|
| "你知道你家油烟机用三年后，风量还剩多少吗？" | 油烟机自清洁 |
| "同样4000块买洗衣机，为什么有人买到1.10洗净比，有人只拿到1.03？" | 洗衣机选购 |
| "618的空调到底什么时候买最便宜？我翻了三年的价格数据" | 空调618价格 |

**写法要点**：问题必须有信息量，不能是"你知道XX吗""你了解XX吗"这种空洞设问。好的悬念问题本身就在传递信息。

### 模式8：报价单

先给结论和数字，像在报价，直截了当。

**适用**：选购推荐型、价格对比型、618攻略型

| 示例 | 话题 |
|------|------|
| "先说结论：3000块以下别碰油烟机，4000-6000是黄金价位段" | 油烟机选购 |
| "今年618买电视，记住一个数：65寸3000，75寸5000，85寸8000" | 电视618 |
| "国补+618叠加，空调今年实际到手价打7折是基操" | 空调618 |

**写法要点**：必须有具体数字和明确结论。不能含糊。读者来就是看结论的，别绕。

## 二、结尾变体库（6种收尾模式）

> **铁律**：**禁止"总结+展望+鼓励"三件套。** 每篇文章必须选择一种收尾模式，连续两篇不得重复。

### 模式1：留白型

不给结论，留一个悬念、一个问题、或一句没说完的话。

**适用**：行业趋势、品牌分析、引发思考的话题

| 示例 | 话题 |
|------|------|
| "至于三星手机会不会步家电后尘，这个问题，留给2027年" | 三星退出中国 |
| "国补政策持续到年底，但预算2500亿会不会提前花完，谁也说不准" | 国补攻略 |
| "AI Agent到底会变成你的同事还是你的老板，取决于你今天做了什么选择" | AI趋势 |

**写法要点**：最后一个词/句要有余味。像人在聊天时突然不说了，反而比说完更有力。

### 模式2：场景收尾

一个具体的画面或微型故事，不是总结是场景。

**适用**：选购型、体验型、有人情味的话题

| 示例 | 话题 |
|------|------|
| "我那台TCL 85C12到货那天，邻居过来串门，盯着屏幕看了三十秒，问：这多少寸的？" | 电视选购 |
| "装完空调师傅走的时候说了句：这机器你用十年没问题。三年了，确实没出过毛病" | 空调选购 |

**写法要点**：必须有具体的人、动作、对话。2-4句，像一个电影的最后一个镜头。

### 模式3：数据锚定

一个数字钉在读者脑子里，不需要额外解释。

**适用**：有强数据点的话题

| 示例 | 话题 |
|------|------|
| "记住一个数就够了：静压低于400Pa的油烟机，别买" | 油烟机选购 |
| "今年618买家电的最佳日期：5月31日、6月13日、6月16日。标在日历上" | 618攻略 |
| "国补最高省1500块，但只有线上能叠加平台券，线下门店不享受" | 国补攻略 |

**写法要点**：一个数字或一个日期就够了。不要加"总而言之""综合来看"之类的包装。

### 模式4：反转

最后一句话翻转全文的假设，让读者重新思考。

**适用**：分析型、观点型、有反转空间的话题

| 示例 | 话题 |
|------|------|
| "说到底，三星不是输给了中国品牌。它只是发现，在中国赚钱的ROI不如把同样的精力放在别处" | 三星退出中国 |
| "大家都在说AI会抢工作，但到目前为止，AI创造的新岗位比消灭的多。至少目前是这样" | AI趋势 |

**写法要点**：反转必须合理，不能为反转而反转。最后一句要让读者"嗯？"一下，然后想一想觉得有道理。

### 模式5：半句话

故意不说完，像人在聊天时突然打住。

**适用**：强观点型、个人态度型话题

| 示例 | 话题 |
|------|------|
| "所以618买家电这事儿吧……算了，你自己看价格" | 618攻略 |
| "有些品牌的营销费用比研发费用高三倍，我不好说是哪家，但你应该猜得到" | 品牌对比 |

**写法要点**：点到为止。读者脑子里自动补完你省略的话，比你直接说更有冲击力。但不宜频繁使用，每篇最多1处。

### 模式6：实用清单

直接给行动项，不做任何包装和过渡。

**适用**：选购型、教程型、618攻略型

| 示例 | 话题 |
|------|------|
| "你现在可以做的三件事：\n1. 打开京东搜「家电国补」，确认你所在城市还能领\n2. 把想买的型号加购物车，等5月31日看价格\n3. 静压、风量、自清洁——只看这三个参数" | 618攻略 |

**写法要点**：不加"总而言之""最后总结一下"。直接列，列完就结束。

## 三、source/ 调研报告叠加协议

> **核心原则**：AI自己的调研是基本功，永远不省。source/报告是锦上添花的叠加层。

### 执行时机

在T2调研完成后、T3写作开始前，执行以下步骤：

```
Step 0.5：读取 source/ 独家弹药（T2完成后的叠加步骤）

1. 扫描 source/ 目录下所有 .md 文件
2. 匹配与当前选题相关的报告（标题/关键词匹配）
3. 从报告中提取内容，分两类处理：
   a. 交叉验证点 — AI自己的调研也搜到的 → 标记为 CROSS_VERIFIED，提升可信度
   b. 独家增量点 — 只有报告里有、AI调研没搜到的 → 标记为 [独家弹药]
4. [独家弹药] 必须在正文中至少使用 2 条
5. 如果 source/ 为空或无相关报告，跳过此步骤（不阻塞流程）
```

### source/ 报告的价值定位

| 场景 | 处理方式 | 价值 |
|------|---------|------|
| AI调研 + 报告都有 | 交叉验证，提升数据可信度 | 双源一致 → VERIFIED |
| 报告有、AI调研没有 | 独家增量，必须标记来源 | [独家弹药] + 标注"据[报告名]数据" |
| AI调研有、报告没有 | 正常使用，不受影响 | 标准T2素材 |
| 都没有 | CEO裁定：继续/暂停 | 按文章类型决定 |

### 报告来源标注规范

正文中引用source/报告的数据时，标注方式：
- ❌ "据调研报告显示"（模糊）
- ✅ "据Gemini Deep Research调研数据"（明确工具）
- ✅ "斯坦福AI Index 2026报告数据显示"（明确来源）
- ✅ "综合多方调研交叉验证"（多报告一致时）

## 四、口语化质感注入技法

> 去AI味是"删"的艺术，活人手感是"加"的艺术。以下技法在T3写作中主动运用。

### 技法1：口癖植入

每篇文章植入1-2个自然的口头禅标记，全文保持一致。

**可选口癖库**：
- "说白了" / "说直白点" / "说句大实话"
- "这事儿吧" / "这个怎么说呢"
- "你想想看" / "你品品"
- "打个比方" / "举个真实例子"
- "别急，先看一组数"
- "问题来了" / "有意思的来了"

**铁律**：同一口癖全文出现不超过3次。不要为了口癖而口癖。

### 技法2：不完美表达

真实的人说话是不完美的。偶尔加入：
- 自我纠正："不对，更准确地说应该是……"
- 半途改口："其实也不全是价格的事——算了，先说参数"
- 承认不确定："这个数我不敢100%确认，但多方数据指向的是……"

**频率**：每篇文章1-2处即可。多了显得做作。

### 技法3：情绪起伏线

写正文前，先规划这条文章的情绪曲线：

```
开头 → 震惊/好奇/共鸣（抓人）
  ↓
前半段 → 愤怒/焦虑/不安（制造张力，"这事儿严重"）
  ↓
后半段 → 释然/清晰/有答案（释放张力，"原来如此"）
  ↓
结尾 → 余味/行动/反转（不落在"平淡总结"上）
```

> 这不是教你煽情。信息密度依然是底线。但在同样高信息密度的前提下，有情绪起伏的文章比平铺直叙的文章完读率高得多。

### 技法4：读者对话感

写作时心里要有一个"对面坐着的人"，不是对着空气写。

**实操方法**：
- 每300字出现一次直接称呼"你"
- 偶尔用反问："你猜怎么着？""换你会怎么选？"
- 用"咱"代替"我们"："咱先把参数搞清楚"
- 给出建议时像朋友聊天："我给你一个更实在的建议"

### 技法5：信息不对称的利用

在正文中制造"信息差感"，让读者觉得你在给他透露内幕：

**可用句式**：
- "这个参数导购不会告诉你，但是……"
- "翻了几十页评测数据才发现……"
- "行业里有个说法，不一定对，但值得你参考……"
- "绝大多数测评文章会跳过这一点……"

**铁律**：后面跟的必须是真信息、真数据，不能用信息差做幌子然后说废话。

## 五、进阶叙事技法（v2.0 · 吸收自 khazix-writer 开源技能）

> 以下 6 种技法来自数字生命卡兹克的 khazix-writer 技能，经适配后融入头条家电赛道。不是照搬口吻，而是吸收叙事方法。

### 技法6：升番逻辑（逐一展示的排列顺序）

当涉及多个产品/型号/案例的对比或测试时，不要一次性罗列结论，而是逐一展示，每个带一句点评。排列顺序遵循「升番」逻辑：最弱的放前面，最炸的留最后，中间要有「我以为到顶了结果还能往上翻」的惊喜感。

**适用**：选购横评型、品牌对比型、参数对比段

**示例**（油烟机横评）：
```
先看2000价位的XX，风量18，静压300……说实话够用但没惊喜。
再看3000价位的XX，风量直接拉到22，这个段位已经有区分度了。
然后是4000价位的XX，自清洁+变频电机，开始有点意思了。
最后看5000价位的XX——静压800Pa，油脂分离度92%，这个参数组合在这个价位段几乎没有第二个。
```

**铁律**：展示顺序 = 情绪递进。不能随便排，最后展示的必须是"最值得说的"。

### 技法7：回环呼应（契诃夫之枪）

在文章前半段埋一个细节、意象或小钩子，在后半段（最好是结尾）以变体形式再次出现。读者会觉得这是一个完整的作品，不是一堆信息的堆砌。

**适用**：所有文章类型，尤其是品牌分析型、趋势科普型

**示例**：
- 开头提到"我朋友去年618买空调多花了1500"，结尾用"对了，那个多花1500的朋友，今年买第二台的时候，先问我借了参数表"
- 开头用"静压低于400Pa别买"的数字锚定，结尾用"所以你问我买油烟机看什么——静压，记住400这条线"

**铁律**：呼应要自然，不能像写作文一样硬凹。前面埋的时候不着痕迹，后面响的时候读者自己反应过来。

### 技法8：句式断裂

用一个极短的句子或短语独立成段，制造停顿和重量感。

**适用**：关键结论处、情绪转折处、数据暴击后

**示例**：
- "差价3000。"
- "这个参数，能救命。"
- "但多数人不知道。"

**铁律**：全文最多用 3 处。用多了就是标点符号表演，不是叙事。断裂句必须是值得单独站一句的内容——平庸的信息不值得断裂。

### 技法9：谦逊铺垫法

在给出观点或建议之前，先用自谦的话降低读者的防御心。

**可用句式**：
- "我自己也不是所有参数都搞得特别明白，但有一点我比较确定"
- "以下建议仅供参考，毕竟我也只买过五六台空调"
- "这个结论我不敢打包票，但多方数据指向的是同一个方向"

**铁律**：不能虚伪谦虚。说"仅供参考"的时候，后面跟的内容必须是真材实料。空谦虚+空内容 = 双倍AI味。

### 技法10：逐一展示法

涉及多个产品/品牌/型号时，不要一次丢出所有结论，而是一个一个展开。每个都带一句真实点评，让读者有"跟着你一起看"的发现感。

**和升番逻辑的关系**：逐一展示是方法，升番逻辑是排列顺序。两者必须同时使用。

**反面示例**（❌ 一次罗列）："A品牌风量22、B品牌风量20、C品牌风量18，所以A最好。"
**正面示例**（✅ 逐一展开）："先看A——风量22，这个数字什么概念？普通油烟机也就16-18。再看B，20，也不错，但和B比差在哪？差在静压……"

### 技法11：英雄之旅叙事弧

用于教程型、避坑型、选购型文章的主体叙事。结构：遇到问题 → 尝试解决 → 踩坑/发现 → 找到答案 → 分享经验。

**适用**：教程避坑型文章（空调清洗DIY、安装猫腻、开机第一步等）

**示例结构**（空调清洗DIY）：
```
起因：空调吹出来的风有异味
尝试：自己拆面板看教程
困境：拆到一半发现排水管装反了，水流了一地
转折：找到正确的拆卸顺序，重新来
收获：洗完实测出风口温度降了3度
分享：把这个过程完整写下来，踩过的坑你不用再踩
```

**铁律**：起点必须是一个具体的、读者能代入的困境或好奇，不能是抽象命题。
