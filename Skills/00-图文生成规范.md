## Step 0：选题DNA → 模板选择（T3 开始前必须执行）

> **此步骤不可跳过。** 未读取选题DNA就开始写作的稿件一律打回。

### 0.1 读取选题DNA

从 `outputs/T1_选题池.md` 中提取当前选题的以下字段：

| 字段 | 用途 | 找不到时的处理 |
|------|------|-------------|
| 搜索意图类型 | 决定主体模板 | 默认"商业调研型" |
| 预期内容结构 | 确认结构体 | 根据意图类型自行判断 |

| 竞品内容弱点 | 写作的核心超越点 | 参考T2素材包推断 |
| 核心关键词簇 | H2标题和正文自然覆盖 | 用品类关键词扩展 |

### 0.2 搜索意图 → 结构体 → 主体模板

| 搜索意图 | 结构体 | 主体模板 | 写作顺序 |
|---------|--------|---------|---------|
| 信息型 | 科普解析体 | 知乎先写 → 头条改口语 → smzdm加表格 → 小红书做场景化 |
| 商业调研型 | 横评对比体 | smzdm先写 → 头条改口语 → 知乎加论证 → 小红书做种草 |
| 交易型 | 深度评测体 | 头条先写 → smzdm加数据 → 知乎加深度 → 小红书做体验 |
| 经验型 | 真实案例体 | 小红书先写 → 头条拉长 → 知乎加论据 → smzdm加参数 |

## Humanizer 去AI味检查 v2.0（18项，每份稿必须通过）

### A. 通用检测（8项 · 所有平台必检）

- [ ] **零感叹号** — 全文 0 个 `!` 或 `！`
- [ ] **连接词口语化** — 搜索替换："因此"→"所以"，"但是"→"不过"，"此外"→删掉或"还有"，"同时"→"而且"
- [ ] **句式打散** — 不存在连续使用同一句式超过2次（如"首先...其次...最后..."）
- [ ] **至少1处"我"** — 第一人称真实代入场景（非泛泛而谈的"我觉得"）
- [ ] **承认边界感** — 用"建议"/"适合"而非"必须"/"唯一"/"最佳"
- [ ] **无空洞修饰** — 搜索"脱颖而出"/"璀璨"/"令人惊叹"/"表现优异"，命中数=0
- [ ] **无em dash堆砌** — `—` 在全文中出现不超过3次
- [ ] **无规则三强迫** — 不存在"有A、B和C三个优点"式机械列举连续2次以上

### B. 中文AI特征检测（10项 · 中文稿件必检）

- [ ] **零AI起始语** — 搜索"值得一提的是""不难看出""不难发现""需要注意的是""众所周知""在此背景下""让我们来看看""接下来让我们""总的来说""综上所述""事实上""毫无疑问""本质上""换句话说""不可否认""这意味着""意味着什么"，命中数=0
- [ ] **零负面并列** — 不存在 "不仅...更/还..." 句式
- [ ] **零假设全面** — 不存在 "无论是X还是Y，都..." 句式
- [ ] **零AI开头** — 不存在 "随着...的发展/普及" 开头
- [ ] **无段首机械加粗** — 连续3个以上 `**X**：` 格式的段首不存在
- [ ] **无同义词轮换** — 同一概念不用3个以上不同词指代
- [ ] **无完美对称** — 各章节字数不完全相等（允许±30%偏差）
- [ ] **无虚假权威** — 不存在"备受关注""广受好评""业界一致认为"等无来源权威表述
- [ ] **无AI总结腔** — 结尾不使用"展望未来""充满期待""令人期待"等AI结尾模式
- [ ] **无弯弯绕叙述** — 不存在"在X的过程中""在X的背景下""在X的推动下"等AI绕弯句式

### 🆕 C. 活人手感检测（v3.1 · 调用 10-Skill v2.0）

- [ ] **开头非禁区** — 开头不是"你知道吗/很多人不知道/今天我要分享/随着…发展/在当今…背景下"中的任何一种
- [ ] **结尾非三件套** — 结尾不是"总结+展望+鼓励"模式，不含"总而言之/综上所述/希望本文对你有帮助"
- [ ] **有口癖** — 全文有1-2个自然的口头禅标记（"说白了""这事儿吧""你想想看"等）
- [ ] **有不完美表达** — 至少1处自我纠正/半途改口/承认不确定
- [ ] **有读者对话** — 每300字有1次直接称呼"你"
- [ ] **source/弹药落地** — 如有source/报告，[独家弹药]至少使用了2条
- [ ] **🆕 有句式断裂** — 全文1-3处极短句独立成段，制造重量感
- [ ] **🆕 有回环呼应** — 前1000字有埋伏笔，后500字有callback（按文章类型选检）
- [ ] **🆕 升番排列** — 多产品对比段有情绪递进排列（选购横评型必检）

## GEO 结构化核查（每版稿件必检）

| 检查项 | 标准 | 检测方式 |

| H2 标题数量 | ≥4 个 | 计数 `##` 标记 |

## 标题写作规范（v4.0 · 来自11-Skill · T3 标题必须通过）

### 标题三法则

1. **标题 = 承诺 + 钩子** — 必须同时承诺读者会得到什么，并给他一个现在就点的理由
2. **具体 > 抽象，数字 > 描述** — 数字优先级：价格 > 数量 > 年份 > 百分比
3. **前15字定生死** — 遮住后半截，前15个字能让陌生人停下来吗？不能就重写

### 限流词全景清单（写标题/正文前必查 · P0）
