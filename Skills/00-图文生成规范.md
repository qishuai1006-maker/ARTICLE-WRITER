| 字段 | 用途 | 找不到时的处理 |

| 搜索意图 | 结构体 | 主体模板 | 写作顺序 |

| 信息型 | 科普解析体 | 知乎先写 → 头条改口语 → smzdm加表格 → 小红书做场景化 |

| 维度 | 头条 | 知乎 | 什么值得买 | 小红书 |
|------|------|------|-----------|--------|
| **最低字数** | ≥1500 | ≥2000 | ≥1800 | ≥500 |
| **信息密度** | ≥3点/100字 | ≥2点/100字 | ≥4点/100字 | ≥5点/100字 |
| **开头要求** | 结论前置，前3句定完读率 | 直击问题核心，不绕弯 | 直接对比核心差异 | 第一句=最强钩子，直击痛点 |

| **GEO必备** | H2含关键词、≥1个定义句 | 引用标注、分点论证、≥1个定义句 | ≥2个表格、数据来源标注 | ≥5个精准标签 |

### 头条：好词 vs 禁词

| ✅ 用这些 | ❌ 不要用 |
|----------|----------|
| 说白了 / 简单来说 | 综上所述 / 总的来说 |
| 你 / 咱 / 咱们 | 我们 / 笔者 / 本文 |
| 别看xxx其实xxx | 值得一提的是 |
| 举个例子 | 例如 |
| 说实话 / 不瞒你说 | 事实上 / 实际上 |
| 问题来了 | 在此背景下 |
| 但是吧 / 话说回来 | 然而 / 但是 |
| 数据说话 | 据相关数据显示 |

| ✅ 用这些 | ❌ 不要用 |

| 这里有个反直觉的点 | 不难看出 |

| ✅ 用这些 | ❌ 不要用 |
|----------|----------|

### 头条模板
```

[DNA: 开头3句用竞品没有的结论/数据]
第1句：甩核心结论 → 第2句：跟你关系 → 第3句：继续读的理由

## 痛点模块1 [GEO: H2含关键词]
[口语化，每段2-3句，数据带来源]
[GEO: ≥1个可引用定义句]
[对比表格]

## 痛点模块2 [GEO: H2含关键词]
[DNA: ≥1个竞品没覆盖的角度]

## 痛点模块3：选购建议
[分人群/预算段推荐]

## 总结
[2-3句客观总结，GEO: 精炼总结句]
```

### 知乎模板
```

先说结论：[一句话] [GEO: 可引用定义句]
```

## Humanizer 去AI味检查 v2.0（18项，每份稿必须通过）

### A. 通用检测（8项 · 所有平台必检）

- [ ] **零感叹号** — 全文 0 个 `!` 或 `！`
- [ ] **连接词口语化** — 搜索替换："因此"→"所以"，"但是"→"不过"，"此外"→删掉或"还有"，"同时"→"而且"
- [ ] **句式打散** — 不存在连续使用同一句式超过2次（如"首先...其次...最后..."）
- [ ] **至少1处"我"** — 第一人称真实代入场景（非泛泛而谈的"我觉得"）
- [ ] **承认边界感** — 用"建议"/"适合"而非"必须"/"唯一"/"最佳"
- [ ] **无空洞修饰** — 搜索"脱颖而出"/"璀璨"/"令人惊叹"/"表现优异"，命中数=0
- [ ] **无em dash堆砌** — `—` 在全文中出现不超过3次
- [ ] **无规则三强迫** — 不存在"有A、B和C三个优点"式机械列举连续2次以上

### B. 中文AI特征检测（10项 · 中文稿件必检）

- [ ] **零AI起始语** — 搜索"值得一提的是""不难看出""需要注意的是""众所周知""在此背景下""让我们来看看""总的来说""综上所述""事实上""毫无疑问"，命中数=0
- [ ] **零负面并列** — 不存在 "不仅...更/还..." 句式
- [ ] **零假设全面** — 不存在 "无论是X还是Y，都..." 句式
- [ ] **零AI开头** — 不存在 "随着...的发展/普及" 开头
- [ ] **无段首机械加粗** — 连续3个以上 `**X**：` 格式的段首不存在
- [ ] **无同义词轮换** — 同一概念不用3个以上不同词指代
- [ ] **无完美对称** — 各章节字数不完全相等（允许±30%偏差）
- [ ] **无虚假权威** — 不存在"备受关注""广受好评""业界一致认为"等无来源权威表述
- [ ] **无AI总结腔** — 结尾不使用"展望未来""充满期待""令人期待"等AI结尾模式
- [ ] **无弯弯绕叙述** — 不存在"在X的过程中""在X的背景下""在X的推动下"等AI绕弯句式

## GEO 结构化核查（每版稿件必检）

| 检查项 | 标准 | 检测方式 |
|--------|------|---------|
| H2 标题数量 | ≥4 个 | 计数 `##` 标记 |
| H2 含关键词比例 | ≥50% 的 H2 包含核心关键词 | 对照选题DNA关键词簇 |
| 可引用定义句 | ≥1 句 | 检查"X是Y"格式的精确定义 |
| 表格数量 | 头条≥1 / 知乎≥1 / smzdm≥2 / 小红书0 | 计数表格标记 |
| 选题DNA差异化落地 | 100% | 逐项核对DNA中的"差异化写作要求" |
| 竞品弱点补足 | ≥1处 | 核对DNA中的"竞品内容弱点"字段 |
| 数据来源标注 | 所有数据标注来源 | 全文扫描无来源的数据 |

**什么是"可引用定义句"**：大模型回答用户问题时可直接引用的句子。
- ✅ "DC调光是一种通过调节电流大小来控制亮度的方式，不会产生频闪"
- ❌ "DC调光的效果非常好，体验很舒适"

## 熔断机制 v2.0（量化检测版）

| 触发条件 | 处理 | 检测方法 |
|---------|------|---------|
| 信息密度不达标 | 🔴 立即重写 | 随机抽3段(各100字)计算信息点密度 |
| 无标题/无表格/无列表 | 🔴 立即重写 | `grep -c "^##" file` / `grep -c "|" file` |
| 前后矛盾/数据与T2不一致 | 🔴 立即重写 | 提取所有数字，与T2素材包逐条核对 |
| 生硬推荐/绝对化用语 | 🔴 立即重写 | 搜索"最""第一""必须""唯一""必买" |
| 广告法违禁词 | 🔴 立即重写 | 搜索违禁词清单（见04-Skill） |
| 信息增益为低增益 | 🔴 立即重写 | 内容与竞品TOP10高度重合 |
| 未通过Humanizer检查 | 🔴 立即重写 | 18项逐项核查 |
| 平台差异化不达标 | 🔴 立即重写 | 字数/结构/必备元素缺失 |
| 选题DNA差异化未落地 | 🟡 修改重交 | DNA逐项核查 |
| 中文AI高频词≥3处 | 🟡 修改重交 | 搜索中文AI起始语清单 |
