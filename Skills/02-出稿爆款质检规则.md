# 02-出稿爆款质检规则

## 核心定位
此文件是“Super Writer 快写线”的最后一道安检门。
当 Agent 完成一篇文章的“对标仿写”后，必须调用本规则，对刚生成的文章进行【100分制爆款潜力打分】。只有超过 80 分的稿件，才能交付给 CEO。

## 质检打分模型（满分 100 分）

每次生成文章后，Agent 必须在输出的末尾附带以下打分表，并逐项给出真实的得分及扣分理由。

| 维度 | 分数 | 满分 | 评分标准说明 | 绝对否决项（命中直接0分重写） |
|---|---|---|---|---|
| **标题拦截力** | | 20 | 遮住后半截，前15个字能否让陌生人停下？是否有反常识、数字或内幕感？ | 像说明书、参数介绍、纯科普，无任何悬念或利益点。 |
| **痛点强度** | | 20 | 选题是否命中了用户的核心恐惧（买贵、买错、被坑、后悔）？ | 无法用一句话说清用户为什么要看，痛点不痛。 |
| **信息差反转** | | 15 | 文章是否有“读者以为 A，其实是 B”的强认知反转？ | 通篇只是网络资料汇总，无任何新认知。 |
| **证据合规与推品** | | 15 | 推荐的型号及参数是否100%符合《推品逻辑手册_2026.md》？ | 推荐了单系统冰箱等被手册明确禁推的型号。 |
| **决策价值(可收藏)** | | 15 | 文章结尾是否提供了可截图保存的“避坑清单/判断标准”？ | 读完不知道怎么选，无可带走的结论。 |
| **情绪触发力** | | 15 | 开头或结尾是否有能让人想在评论区留言“我也遇到过”的钩子？ | 平铺直叙，像无感情的百科全书。 |

## 质检流程要求
1. **强制自我审查**：写完初稿后，执行本模型。
2. **强制脚本检查**：100 分打分前，必须运行：

```bash
python3 Scripts/lint_quick_article.py outputs/[终稿].md --evidence outputs/[轻量证据卡].md --json
```

脚本返回 ERROR 时，不得进入评分流程，必须先修稿。
3. **分数红线**：
   - **≥ 80分**：合格，可以交给 CEO。
   - **65 - 79分**：拦截，必须自行修改后再打分，直到超过 80 分。
   - **命中绝对否决项**：不论总分多少，直接推翻重写。
4. **打回上限**：最多打回 2 次。第 3 次仍不达标，必须停机反馈 CEO，附上具体的不达标维度和扣分原因。

## 闸门 A · 算法初筛层（决定算法敢不敢给初始展现）

近期复盘发现：lint 全过 ≠ 有推流。同智能体同流程对照实测——前 300 字硬实体 0 个的稿 90 展现被毙，4 个的 3676 展现。**算法初筛卡的是“实体密度 + 信息增益”**，过不了初筛，闸门 B 再好也拿不到展现。

| 闸门 A | 合格标准 | 由谁卡 |
|---|---|---|
| 文本密度（前 300 字硬实体） | 型号/带单位参数 ≥ 2 个（<2 直接 ERROR，<5 WARN） | `Scripts/lint_quick_article.py` 自动检查 |
| 信息增益 | 拆解卡填 1-3 个读者搜不到的非百科判断 | `Agents/01` 拆解阶段卡 |

**归因顺序**：展现低 → 先查闸门 A；展现高点击低 → 查闸门 B；点击高读完低 → 查首屏兑现 + 中段密度。

## 闸门 B · 用户行为层（原“流量硬闸门”，决定用户点不点、留不留）

`lint PASS / 证据卡完整 / Word 成品完整 / 图片落盘` 只能证明可发布，不能证明有推流。闸门 A 过了之后，正文动笔前还必须产出并通过以下 5 项“流量卡”，再进入正文、作图、Word 或 100 分打分：

| 闸门 | 合格标准 | 直接打回信号 |
|---|---|---|
| 15字点击钩子 | 标题前 15 字含品牌/型号信息差、具体损失、内幕反常识、强人设之一 | “XX怎么选”“预算从A到B”“看懂N个参数”但没有具体损失 |
| 首屏冲突 | 前 150 字出现价格跨度、踩坑后果、品牌矛盾、导购话术或真实人物场景 | “很多人买XX，一上来就看...”平铺解释 |
| 反常识判断 | 至少 1 个可证据兜住的“以为A，其实B” | 通篇都是中性科普、看需求、各有优势 |
| 收藏死线 | 至少 3 条可截图判断：低于不买、先问清、别被带偏、照着查 | 只有温和建议，没有硬判断 |
| 评论触发点 | 至少 1 个品牌/型号/参数争议或踩坑经历入口 | 结尾只有总结，没有可讨论点 |

**优先加分结构**：`S7 单品牌型号解码型`，如 `{品牌/系列}{品类}型号暗藏玄机？{N}招看懂{后缀/参数}，别多花冤枉钱`。`TCL电视型号暗藏玄机？3招看懂Pro和Ultra，别多花冤枉钱` 已获得 2.3 万展现，说明“型号迷宫 + 损失厌恶 + 具体品牌”比泛泛选购题更容易拿到初始推荐。

**直接打回条件**：如果稿子只是解释清楚，但没有型号信息差、价格跨度/后果冲突、明确立场和可截图死线，直接打回重写，不得进入作图或 Word。

## 打分校准机制（防止分数通胀）
Agent 03 在打分时必须严格遵守以下校准规则：

1. **标题拦截力测试**：截取标题前 15 个字，单独判断“如果普通人只看到这 15 个字，会不会停下来”。如果答案是“不确定”，此项不得超过 14 分。
2. **逐项证据绑定**：每个维度的得分，必须引用正文中的具体段落或句子作为评分依据。禁止写“整体不错”“表现良好”等笼统评语。
3. **合规扣分独立计算**：合规红线词库的扣分在 6 维总分基础上额外扣除。例如：6 维得分 92，但命中 1 个 A 类禁词，终审分 = 92 - 5 = 87。
4. **标题字数强制检查**：打分表中必须标注标题实际字数；不在 25-29 字区间内，直接打回不得进入评分流程。
