# 07-节奏与情绪引擎 (Rhythm & Emotion Engine)

## 核心定位
此规范专管**全文级别的节奏编排**。它解决的问题是：文章每一段单独看都不错，但连起来读像在听一首只有一个调的歌——没有起伏、没有惊喜、没有喘息。

**它不管"写什么"（由 05-长文原型规范 决定）和"怎么写"（由 04-活人写手感规范 + style_examples.md 决定），它只管"按什么节奏写"。**

在 Agent 02 的执行链中，本规范是**最后一道打磨**：初稿 → style_examples 比对 → 04 规范去 AI 味 → **本规范调节奏** → 06 合规扫描。

---

## 一、情绪波形 W 型法则

全文的情绪走势必须是 **W 型**（高-低-高-低-高），绝对禁止一马平川。

```
情绪强度
  ▲
高│  ●                     ●                  ●
  │ / \                   / \                / \
中│/   \       ●         /   \              /   \
  │     \     / \       /     \            /     \
低│      \   /   \     /       \          /       ●（余味）
  │       \ /     \   /         \        /
  │        ●       \ /           \      /
  └──────────────────●────────────\────/──────▶ 段落
   开头钩子  铺垫喘息 反转爆点  证据展开  收尾喘息  余味结尾
```

### 五段式情绪骨架

| 段位 | 情绪状态 | 功能 | 典型长度 |
|------|---------|------|----------|
| **① 钩子高潮** | 🔴 高 | 一秒抓人：反常识/数字暴击/场景代入 | 50-100 字 |
| **② 铺垫喘息** | 🟡 中低 | 补充背景、降低节奏、铺设知识地基 | 100-200 字 |
| **③ 反转爆点** | 🔴 高 | 核心反常识信息释放，最强震撼段 | 80-150 字 |
| **④ 证据展开** | 🟡 中 | 用型号/数据/场景来证明反转，信息密度最高 | 300-600 字 |
| **⑤ 余味收尾** | 🟢 低→中 | 留白/场景收尾/清单收尾，不做总结 | 50-150 字 |

### 铁律
- 不允许两个高潮段连续出现（会让读者疲劳）
- 不允许三个喘息段连续出现（会让读者离开）
- ④ 证据展开内部也要有小型波动（见下面的段落交替法则）

## 二、段落长度交替法则

段落长度是**视觉节奏**的核心。均匀的段落长度（每段都是 3-5 行）是 AI 文章最显眼的指纹之一。

### 四种段落长度

| 类型 | 字数范围 | 功能 | 示范 |
|------|---------|------|------|
| **⚡ 爆点短句** | ≤ 15 字 | 关键结论、数字暴击，独占一行 | "差价三千。" / "但多数人不知道。" |
| **💬 正常铺垫** | 50-80 字 | 日常叙述、参数翻译、场景描写 | 常规段落 |
| **📊 证据展开** | 100-150 字 | 详细论证、型号对比、多维度展开 | 深度分析段 |
| **😮‍💨 喘息废话** | 20-40 字 | 情绪缓冲、自嘲、吐槽、感慨 | "说实话查到这个数据我自己都没想到。" |

### 交替规则
- **禁止连续 3 个以上相同长度类型的段落**
- 理想节奏范例：`正常 → 爆点短句 → 证据展开 → 喘息废话 → 正常 → 爆点短句`
- 每个大型知识块（200-300 字）后，必须出现一个 ⚡ 或 😮‍💨 来"换气"

### 反面教材
```
❌ 均匀节奏（AI 味极重）：
[70字段落] → [65字段落] → [75字段落] → [60字段落] → [70字段落]

✅ 交替节奏（活人味）：
[80字段落] → [12字爆点] → [120字展开] → [30字废话] → [70字段落] → [10字爆点]
```

## 三、爆点段落（截图级段落）

每篇文章**必须有 2-3 个"爆点段落"**——即读者读到时会想截图发朋友、或者停下来重新读一遍的段落。

### 爆点段落公式
```
反常识事实 + 具体数字 + 短句收束 = 爆点段
```

### 爆点段落示范

**价格爆点：**
> 同样的华星光电面板，Q9L 标 3999，Q9L Pro 标 8551。
>
> 差价四千五。面板是同一块。

**认知爆点：**
> 300Hz 听着吓人。但这个数字是靠插帧撑上去的，不是屏幕原生刷新率。
>
> 真打游戏，该卡还是卡。

**对比爆点：**
> 华凌 2039，格力 2549。同压缩机，同铜管排数，同节流装置。
>
> 差了 500 块，外机几乎一样。

### 爆点段落的位置
- 第一个爆点：出现在文章前 1/3（300-500 字处），用来锁定读者
- 第二个爆点：出现在文章中段（核心论证区），用来制造"截图冲动"
- 第三个爆点（可选）：出现在结尾前，作为"最后一击"

---

## 四、喘息段落（情绪缓冲带）

每个爆点段落后**必须跟一个喘息段落**。爆点是猛药，喘息是解药。连续两个爆点会让读者审美疲劳。

### 喘息段落的来源
直接从 `style_examples.md` 第 11 节的 6 种废话模板中选用：
- 爆点后接**自嘲型**："我当时看到这个数据也愣了一下。"
- 爆点后接**吐槽型**："这参数表对着看半天才看明白，难怪普通人被绕晕。"
- 爆点后接**感慨型**："说白了，这行卷成这样，消费者反而是受益的。"

### 铁律
- 爆点后的喘息段**不超过 40 字**
- 喘息段不输出新知识点
- 喘息段必须有情绪色彩（自嘲/感慨/吐槽），不能是平淡过渡

## 五、节奏自检清单

Agent 02 在调用本规范时，必须对完稿进行以下自检：

- [ ] **W 型波形**：全文是否有至少 2 个明确的情绪高点和 2 个低点？
- [ ] **爆点数量**：是否有 2-3 个截图级的爆点段落？
- [ ] **爆点位置**：第一个爆点是否出现在前 1/3？
- [ ] **喘息跟随**：每个爆点后是否跟了喘息段？
- [ ] **段落多样性**：是否出现了 4 种不同长度类型的段落？
- [ ] **无连续同长**：是否避免了连续 3 个以上相同长度的段落？
- [ ] **爆点短句独占一行**：≤15 字的关键结论是否独占一行、不混在段落里？

任何一项未通过，必须修改后再提交。
