## 三、按品类召回（以空调为例）
- 推品手册 → 空调章节（首推型号）
- 家电知识库 → L1空调技术 + L2美的/格力 + L4空调选购策略
- 对标拆解库 → 爆款拆解卡_空调型号解码 + 品类弹药包/空调
- 参数翻译库 → 空调部分（APF / 匹数 / 双排 → 钱+体验）

## 四、召回清单格式（产出文末必填，主控验收）

```
## 召回清单
- 推品逻辑手册_2026.md → 用了：[具体型号]
- 家电知识库/L2_品牌档案/美的.md → 用了：[美芝GMCC垂直整合]
- 运营方法论/05_家电参数翻译库.md → 用了：[APF翻译≥3条]
- 对标拆解库/爆款拆解卡_空调型号解码.md → 复用内核：[信息差]
- WebSearch → [格力2021.3.1十年包修←新浪财经；型号价←京东]
```

## 五、数据使用铁律
- **推品手册 = 型号唯一来源**：不准编型号/参数；手册没有的 WebSearch 核实并带来源。
- **参数翻译库 = 参数→误解→后果→判断**：讲钱+体验，不讲性能。
- **对标拆解库 = 复用内核（运营04内核库6类）不复用形式**：同形式会疲劳（实测 13.9万→62）。
- **轻量证据卡 = 每个数字能溯源**：编不出标 UNSURE 或删，绝不留假数据。
- **MEMORY = CEO偏好/坑**：禁词「第一/最后」、开头≤50字、具像化品牌型号圈人、不踩海信/格力、我们是出处不标达人。
