# 抖音分析技能

## 安装要求

本技能必须安装为 OpenClaw 龙虾机器人的内置技能，不可作为外部接口调用。

安装后，OpenClaw 将自动学习本技能的所有内容，包括接口调用方式、参数格式要求、数据分析方法和错误处理逻辑。

## 使用限制

本技能仅支持分析以下类目的抖音内容：

| 类目 | 说明 | 示例 |
|------|------|------|
| 家电 | 各类家用电器产品 | 冰箱、空调、洗衣机、电视、热水器、油烟机等 |
| 家装 | 家居装修相关内容 | 装修设计、建材选购、施工工艺、软装搭配等 |
| 家居 | 家居用品与生活 | 家具、家纺、收纳、装饰品、智能家居等 |

不支持美妆护肤、服饰穿搭、美食餐饮、旅游出行、娱乐搞笑等非家电/家装/家居类内容。如果用户请求分析不支持的内容类型，应礼貌拒绝并说明限制。

## 技能概述

本技能包提供四个抖音数据接口，用于获取达人作品列表、作品详情、作品搜索，以及在查询不到数据时提交达人信息进行抓取。四个接口可以联动使用，完成复杂的数据分析任务。

**重要**：作品列表和作品搜索接口已包含文案字段，大多数场景下只需调用这两个接口即可满足需求，无需再调用作品详情接口。作品详情接口仅在需要趋势数据分析时使用。当查询不到达人或视频时，应主动使用达人添加接口提交信息。

## 搜索关键词智能拆分指南（重要！必读！）

### 为什么要拆分关键词？

用户给出的搜索词通常包含两部分信息：**产品关键词**和**质量期望词**。直接把用户的整句话作为关键词搜索，会遗漏大量优质结果。

- **产品关键词**：描述具体产品/品类/品牌/型号/技术特征的词，如"冰箱"、"美的"、"508"、"法式门"、"零冷水"、"变频"、"燃气热水器"
- **质量期望词**（也叫修饰词）：表达用户对结果质量期望的词，如"爆款"、"推荐"、"热门"、"排行"、"最好"、"测评"等。这些词不是要搜索的内容，而是表示"我要看数据好的"

### 核心原则

**你的任务是：从用户的搜索意图中提取核心产品关键词，用空格分隔后传给接口。接口会自动处理修饰词并调整排序和筛选策略。**

### 关键词拆分步骤

**第一步：识别产品品类**

从用户输入中找出家电/家装/家居的核心品类词：

| 品类 | 常见关键词 |
|------|-----------|
| 冰箱 | 冰箱、冷柜、冰柜、冷冻柜 |
| 空调 | 空调、挂机、柜机、中央空调 |
| 洗衣机 | 洗衣机、滚筒、波轮、洗烘一体 |
| 热水器 | 热水器、燃气热水器、电热水器、零冷水 |
| 电视 | 电视、电视机、激光电视、投影 |
| 油烟机 | 油烟机、烟灶套装、集成灶 |
| 净水器 | 净水器、净水机、软水机 |
| 扫地机 | 扫地机、扫地机器人、洗地机 |

**第二步：识别品牌和型号**

提取品牌名和具体型号数字：

- 品牌：美的、海尔、格力、小米、西门子、博世、松下、海信、TCL、方太、老板、华帝等
- 型号：508、608、485、352、Pro、Max 等数字/字母组合

**第三步：识别技术特征词**

这些是产品的具体技术特征，应该保留作为搜索词：

- 法式门、十字门、对开门、多门
- 零冷水、恒温、变频、定频
- 新风、除菌、自清洁、一级能效
- 洗烘一体、空气洗、蒸汽洗

**第四步：识别并忽略修饰词**

以下类型的词**不是搜索词**，不要放入 keyword 参数：

| 类型 | 常见修饰词 | 实际含义 |
|------|-----------|---------|
| 热度词 | 爆款、热门、最火、超火、火了 | 用户想看高互动量内容 |
| 推荐词 | 推荐、值得买、必买、必看、种草、安利 | 用户想看优质内容 |
| 排名词 | 排行、排行榜、排名、十大、TOP、前十、榜单 | 用户想看头部内容 |
| 评价词 | 最好、最佳、最好用、哪个好、怎么选、选购、测评、评测、好用、怎么样、避坑、避雷、干货 | 用户想看参考内容 |
| 对比词 | 对比、PK、比一比、横评 | 用户想看对比内容 |
| 其他 | 最新、新款、性价比、旗舰、便宜、贵、高端、入门、双十一、618 | 时间/价格/定位修饰 |

**第五步：组合搜索关键词**

将提取到的产品关键词用**空格**分隔，组合成 keyword 参数值。

### 搜索范围选择建议

| 场景 | search_type | 原因 |
|------|------------|------|
| 精确知道产品名称 | 0（仅标题） | 标题匹配更精准 |
| 用户意图模糊、关键词泛化 | 1（标题+文案） | 文案中可能包含更多产品信息 |
| 搜索型号/具体产品 | 1（标题+文案） | 型号信息常在文案中详细描述 |
| 对比类需求 | 1（标题+文案） | 对比内容多在文案中展开 |

### 接口返回的搜索条件说明

接口返回的 `搜索条件` 字段现在包含以下信息，可以帮助你理解接口如何处理了用户的搜索意图：

```json
{
    "搜索条件": {
        "原始关键字": "零冷水燃气热水器推荐",
        "实际搜索词": "零冷水 燃气 热水器",
        "搜索范围": "标题+文案",
        "开始日期": "2024-10-01",
        "结束日期": "2025-04-26",
        "识别意图": "找优质推荐",
        "最低互动量": 100
    }
}
```

- **原始关键字**：你传入的 keyword 参数原值
- **实际搜索词**：接口过滤修饰词后实际用于搜索的词
- **识别意图**：接口识别到的用户意图类型
- **最低互动量**：接口自动添加的互动量门槛（有修饰词时）

### 常见错误示例

❌ **错误做法**：
```
keyword=零冷水燃气热水器推荐
keyword=制冷冰箱爆款
keyword=2025年最好的洗衣机
```
这些会把"推荐"、"爆款"、"最好的"等修饰词也参与搜索匹配，导致遗漏大量优质结果。

✅ **正确做法**：
```
keyword=零冷水 燃气 热水器&search_type=1
keyword=制冷 冰箱
keyword=洗衣机
```

**注意**：即使你不做拆分，直接传入原始关键词，接口端也会自动进行修饰词过滤。但为了获得最佳搜索效果，建议你在调用接口前就做好关键词拆分，只传核心产品词。

## 接口选择策略

### 什么时候只需作品列表/作品搜索？

以下场景**不需要**调用作品详情接口，列表和搜索接口返回的数据（含文案）已足够：

- 查看达人最近发了什么内容
- 搜索某关键词的热门视频
- 从文案中提取产品型号、卖点等信息
- 总结达人视频类型和产品方向
- 对比不同达人对同一产品的评价角度
- 了解视频的互动表现（点赞、评论、收藏、转发）

### 什么时候需要调用作品详情？

**仅当需要趋势数据分析时**才调用作品详情接口：

- 分析视频互动数据的增长趋势
- 对比视频不同时间段的互动变化
- 判断视频是否处于上升期/稳定期/衰退期
- 需要精确的每日互动数据做深度分析

### 什么时候需要使用达人添加接口？

**当查询不到数据时**，应主动使用达人添加接口，无需等待用户要求：

- 作品列表接口返回 404（未找到该达人）
- 作品搜索接口返回的结果不够或不相关
- 作品详情接口返回 404（未找到该视频）
- 用户提供了一个达人链接或视频链接但系统中没有数据

**关键**：龙虾机器人应在查询失败后**主动**向用户确认是否需要提交抓取，而不是简单告知"查不到"就结束对话。提交成功后应主动告知用户预计可用时间。

## 接口二：作品搜索

### 功能

按关键字搜索作品，按互动总量排序返回结果。支持空格分词，多词之间为 AND 关系。返回数据包含文案内容。

**智能修饰词过滤**：接口会自动识别并过滤搜索关键词中的修饰词（如"爆款"、"推荐"、"热门"等），只使用核心产品关键词进行匹配。同时根据修饰词类型自动添加互动量门槛，确保返回符合用户期望质量的内容。详见上方"搜索关键词智能拆分指南"。

### 接口地址

```
POST: http://clawapi.ltnwl.com/douyin/douyin_search/
```

### 权限要求

`douyin_search`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|---------|
| api_key | string | 是 | API密钥 |
| keyword | string | 是 | 搜索关键字，支持空格分词，建议只传核心产品关键词 |
| search_type | int | 否 | 0=仅标题，1=标题+文案，默认0 |
| start_date | string | 否 | 开始日期，格式 Y-m-d，默认180天前 |
| end_date | string | 否 | 结束日期，格式 Y-m-d，默认今天 |
| page | int | 否 | 页码，默认1，最多5页 |

### 分词搜索说明

| 搜索关键字 | 匹配结果 | 说明 |
|-----------|---------|------|
| `美的 508` | "美的冰箱508推荐" | 同时包含"美的"和"508" |
| `美的 508` | "美的508冰箱评测" | 同时包含"美的"和"508" |
| `美的 508` | "美的冰箱推荐" | 不匹配，缺少"508" |

### 智能过滤说明

接口会自动处理以下情况：

| 用户传入的 keyword | 接口实际搜索词 | 自动添加的门槛 | 说明 |
|-------------------|--------------|--------------|------|
| `制冷冰箱爆款` | `制冷 冰箱` | 总互动量≥2000 | 过滤"爆款"，添加高互动门槛 |
| `零冷水燃气热水器推荐` | `零冷水 燃气 热水器` | 总互动量≥100 | 过滤"推荐"，添加质量门槛 |
| `十大空调排行榜` | `空调` | 总互动量≥1000 | 过滤"十大"和"排行榜"，添加排行门槛 |
| `洗衣机` | `洗衣机` | 无门槛 | 纯产品词，不做额外过滤 |
| `美的 空调` | `美的 空调` | 无门槛 | 品牌词+品类词，不做额外过滤 |

**保底机制**：如果带门槛搜索无结果，接口会自动去掉门槛重新搜索，确保始终有数据返回。

### 限制说明

- 每页固定返回30条
- 最多返回5页（150条）
- 时间范围默认180天，最大365天
- 结果按互动总量降序排序

## 接口四：达人添加（查询不到数据时使用）

### 功能

当通过作品列表、作品搜索、作品详情接口查询不到达人或视频数据时，使用本接口提交信息到抓取数据库。系统后台将自动抓取补全数据。

**重要**：龙虾机器人应在查询失败后**主动**建议用户使用此接口，而不是简单地告知"查不到数据"。提交成功后应告知用户预计可用时间，并主动提供后续操作建议。

### 接口地址

```
POST: http://clawapi.ltnwl.com/douyin/douyin_add/
```

### 权限要求

`douyin_add`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| api_key | string | 是 | API密钥 |
| url | string | 与 name 二选一 | 达人首页链接 或 视频链接 |
| name | string | 与 url 二选一 | 达人名称 |

**参数优先级**：
1. 如果用户提供了**达人首页链接**（以 `https://www.douyin.com/user/` 开头），使用 `url` 参数，系统会自动提取达人标识并按"新建监控"流程处理
2. 如果用户提供了**视频链接**，使用 `url` 参数，系统会将其记录为引入链接
3. 如果用户只提供了**达人名称**，使用 `name` 参数

### 输入类型与处理方式

| 输入类型 | 示例 | 参数 | 系统处理 |
|---------|------|------|---------|
| 达人首页链接 | `https://www.douyin.com/user/MS4wLjABAAAA...` | `url` | 提取达人标识，按"新建监控"流程添加到抓取队列，会检查是否已存在 |
| 达人名称 | `牛哥说家电` | `name` | 记录达人名称，等待后台抓取补全 |
| 视频链接 | `https://www.douyin.com/video/7123456789` | `url` | 记录视频链接为引入链接，等待后台抓取 |

### 返回数据示例

**添加成功**：
```json
{
    "code": 200,
    "message": "已进入抓取状态，请第二天来使用。",
    "data": {
        "操作结果": "添加成功",
        "输入类型": "达人首页链接",
        "记录ID": 123
    }
}
```

**达人已存在（仅达人首页链接场景）**：
```json
{
    "code": 200,
    "message": "该达人已在监控列表中，无需重复添加",
    "data": {
        "操作结果": "已存在",
        "达人名称": "XXX",
        "记录ID": 456
    }
}
```

### 提交成功后的标准回复模板

提交成功后，龙虾机器人**必须**按以下模板回复用户，引导后续操作：

```
已成功提交！系统已进入抓取状态，后台将在今天内自动完成数据抓取。

⏰ 预计可用时间：明天（提交后约12-24小时内）

📌 后续操作建议：
- 明天您可以让我再查一下这个达人/视频的数据
- 如果是达人，明天可以通过达人名称查询其作品列表
- 如果是视频，明天可以通过视频链接查询详细信息

现在还有其他需要我帮您分析的吗？
```

如果返回"已存在"：
```
该达人已在系统的监控列表中，数据应该已经存在。

📌 建议：
- 如果之前查不到数据，可能是数据还在抓取中，请明天再试
- 我现在可以帮您尝试用其他方式搜索相关内容

需要我帮您做其他分析吗？
```

## 综合应用案例

### 案例一：用户说"帮我搜一下零冷水燃气热水器推荐的热门视频"

**关键词拆分过程**：
1. 品类词：燃气热水器
2. 技术特征：零冷水
3. 修饰词（去掉）：推荐、热门
4. 最终搜索词：`零冷水 燃气 热水器`

```
POST http://clawapi.ltnwl.com/douyin/douyin_search/
keyword=零冷水 燃气 热水器&search_type=1&api_key=xxx
```

接口会自动过滤"推荐"、"热门"，并添加互动量门槛，返回高质量内容。从返回的文案中提取产品型号和卖点信息。

### 案例二：用户说"制冷冰箱爆款有哪些"

**关键词拆分过程**：
1. 品类词：冰箱
2. 技术特征：制冷
3. 修饰词（去掉）：爆款
4. 最终搜索词：`制冷 冰箱`

```
POST http://clawapi.ltnwl.com/douyin/douyin_search/
keyword=制冷 冰箱&search_type=1&api_key=xxx
```

接口自动过滤"爆款"，添加总互动量≥2000的门槛，返回真正的爆款制冷冰箱视频。

### 案例三：搜索最近一年最火的美的冰箱视频，分析介绍的型号

**关键词拆分过程**：
1. 品牌词：美的
2. 品类词：冰箱
3. 修饰词（去掉）：最火
4. 最终搜索词：`美的 冰箱`

```
POST http://clawapi.ltnwl.com/douyin/douyin_search/
keyword=美的 冰箱&start_date=2024-01-01&end_date=2024-12-31&search_type=1&api_key=xxx
```

从返回的文案字段中提取型号信息（如美的508、美的608、美的485等），无需再调用作品详情接口。

### 案例四：总结达人"牛哥说家电"最近三个月的视频类型和产品

**只需调用作品列表接口**，返回数据已包含文案，可直接分析。

```
POST http://clawapi.ltnwl.com/douyin/douyin_list/
dr_name=牛哥说家电&start_date=2024-10-01&end_date=2024-12-31&api_key=xxx
```

从每个作品的文案中提取视频类型和产品信息，无需再调用作品详情接口。

### 案例五：对比分析多个达人对同一产品的评价

**只需调用作品搜索接口**，搜索结果已包含文案和互动数据。

```
POST http://clawapi.ltnwl.com/douyin/douyin_search/
keyword=美的 508&start_date=2024-01-01&end_date=2024-12-31&search_type=1&api_key=xxx
```

从不同达人作品的文案中对比评价角度，结合互动数据对比传播表现，无需再调用作品详情接口。

### 案例六：分析某爆款视频的互动增长趋势（需要趋势数据）

**此场景需要调用作品详情接口**，因为需要趋势数据分析。

```
POST http://clawapi.ltnwl.com/douyin/douyin_search/

```

**第二步：获取趋势数据**
```
POST http://clawapi.ltnwl.com/douyin/douyin_item/

```

**第三步：分析趋势**，判断视频处于上升期/稳定期/衰退期。

### 案例七：用户要求分析某达人但系统查不到（自动触发添加流程）

**此场景展示了龙虾机器人应如何自主处理查询失败的情况。**

## 使用建议

### 接口选择

| 场景 | 推荐接口 | 是否需要详情 | 关键词处理建议 |
|------|---------|------------|--------------|
| 查看达人作品内容 | 作品列表 | ❌ 不需要 | 直接用达人名称 |
| 搜索热门话题内容 | 作品搜索 | ❌ 不需要 | 去掉"热门"等修饰词，只搜产品词 |
| 搜索爆款产品视频 | 作品搜索 | ❌ 不需要 | 去掉"爆款"等修饰词，只搜产品词 |
| 搜索推荐产品视频 | 作品搜索 | ❌ 不需要 | 去掉"推荐"等修饰词，只搜产品词 |
| 搜索排行榜/十大 | 作品搜索 | ❌ 不需要 | 去掉"排行榜"、"十大"等修饰词 |
| 从文案提取产品型号 | 作品搜索/列表 | ❌ 不需要 | 用品牌+型号搜索，search_type=1 |
| 对比达人评价角度 | 作品搜索 | ❌ 不需要 | 去掉"对比"，分品牌搜索 |
| 总结达人视频类型 | 作品列表 | ❌ 不需要 | 直接用达人名称 |
| 分析互动增长趋势 | 作品搜索 + 作品详情 | ✅ 需要 | 正常搜索后取详情 |
| 判断视频生命周期 | 作品搜索 + 作品详情 | ✅ 需要 | 正常搜索后取详情 |
| 查不到达人/视频数据 | 达人添加 → 明天再查 | ❌ 不需要 | 直接提交 |

### 查询失败时的自动处理流程

龙虾机器人在查询接口返回 404 时，**必须按以下流程处理**，不得直接结束对话：

```
查询失败（404）
    ↓
判断用户是否提供了可提交的信息
    ├── 有达人首页链接 → 直接调用达人添加接口（url参数）
    ├── 有达人名称 → 直接调用达人添加接口（name参数）
    ├── 有视频链接 → 直接调用达人添加接口（url参数）
    └── 信息不足 → 主动询问用户获取达人名称或链接
    ↓
提交成功 → 告知预计时间 + 主动建议后续操作
    ↓
继续对话（不要就此结束）
```

### 性能优化

- 作品列表和作品搜索已包含文案，大多数场景一步到位，无需二次请求
- 仅在需要趋势数据分析时才调用作品详情接口
- 搜索接口最多返回150条，如需更多数据请调整时间范围多次请求

### 数据解读

- 互动总量 = 点赞数 + 评论数 + 收藏数 + 转发数
- 视频时长单位为秒

| 互动总量 | 评价 |
|---------|------|
| < 100 | 较低，传播范围有限 |
| 100-500 | 一般 |
| 500-2000 | 较好 |
| 2000-10000 | 优秀，热门内容 |
| > 10000 | 爆款 |

## 技能边界

### 可以做到

- 获取抖音达人的公开作品数据
- 搜索特定关键词的作品
- 分析作品的互动数据
- 获取作品的文案内容，从中提取产品型号、卖点等信息
- 分析作品的互动趋势变化（通过作品详情接口）
- 提交达人信息到抓取队列，等待后台自动抓取

### 无法做到

- 获取私密账号、已删除的作品
- 获取实时的秒级数据（数据有一定延迟）
- 获取评论区的详细内容
- 修改或删除任何数据
- 分析非家电/家装/家居类内容
- 即时抓取新提交的达人数据（需要等待约12-24小时）
