# /import · 数据导入 Loop

**输入参数**：$ARGUMENTS = 头条后台导出的 Excel 文件路径（一个或多个，按账号分文件）

## 这一步在飞轮里的位置
```
/write 生产 → 发布 → /import 导数据 → /fupan 复盘
                     ↑ 你在这里（飞轮数据闸门）
```
CEO 从头条后台按账号导出 Excel → 扔进来 → 批量更新飞书表现数据。**每周例会前至少跑一次**。

---

## 执行流程（仅 🛑 Step 3 停下确认）

### Step 1 · 解析输入（自动）
- 从 $ARGUMENTS 取 Excel 路径。缺路径 → 问 CEO 要文件。
- 账号从文件名推断：含「牛科技说」→ 牛科技说，否则 → 牛科技。

### Step 2 · dry-run（自动）
```
python3 Scripts/import_toutiao_stats.py <excel...>
```
输出匹配报告：
- ✅ 唯一匹配 N 篇（将更新 X / 无变化跳过 Y）
- ❌ Excel有·飞书无 M 篇（新发布未登记飞书）

### 🛑 Step 3 · 确认（唯一人介入点）
展示报告，问 CEO：「确认 apply？」
- 报告里「Excel有·飞书无」的篇目 **--apply 时自动新建**（填 标题/链接/头条ID/账号/发布日期/品类(标题关键词匹配)/标题字数 + 全部表现字段）。
- **留空不填**：归因字段、标题结构模板、文章类型、互动率(%)（= /fupan 的活）。

### Step 4 · apply（CEO 确认后 · 自动）
```
python3 Scripts/import_toutiao_stats.py <excel...> --apply
```
- 按**头条 ID** 零歧义匹配，覆盖表现字段：展现/阅读/CTR/完读/收藏/评论/点赞/转发/分享/粉丝展现/粉丝阅读/平均阅读时长(s)
- **绝不碰归因字段**（那是 `/fupan` 的活）
- missing 篇（Excel有·飞书无）**自动新建**，填 标题/链接/头条ID/账号/发布日期/品类/标题字数 + 表现字段
- 单位转换：`点击率 0.12 → CTR 12`（小数×100取整）；`-1 → 0`（头条"无数据"标记）
- retry + backoff 防飞书限流（800004135）；**幂等**，可重复跑补失败项

### Step 5 · 报告（自动）
「✅ 导入完成 → 成功 X 篇 | 失败 Y 篇。失败项可重跑（幂等只补失败）。飞书数据已是最新，可跑 `/fupan` 复盘。」

---

## 硬约束
- 只更新**表现字段**，绝不碰归因（主因/辅因/下次动作等）
- CTR 小数→整数百分比；`-1`→0
- 按头条 ID 零歧义匹配
- 限流自动 retry+backoff；幂等可重跑
- 单文件脚本 / 标准库 / lark-cli
