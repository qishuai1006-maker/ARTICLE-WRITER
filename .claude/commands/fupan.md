# /fupan · 单篇复盘 Loop

**输入参数**：$ARGUMENTS

## 解析输入
从 $ARGUMENTS 识别两样：
- **归档目录**：`projects/` 下该篇归档路径（拿"当时预判了什么"）
- **头条文章链接**：含 `toutiao.com/i<数字>` 的链接（精确匹配飞书，零歧义）

若任一缺失，**先问 CEO 补全，不得瞎编**。

---

## 执行流程（严格遵守顺序，仅 🛑 Step 4 停下问人）

### Step 1 · 定位预判（自动 · 本地）
读归档目录里的：
- `01b_骨架确认_[品类].md`（选定的公式/结构/标题候选/人设）
- `03_风控主编终稿_[品类].md`（实际用的标题、100 分预判）
- `02b_轻量证据卡_[品类].md`（型号/参数）
重建"当时预判"：选了什么结构、什么标题、预期什么分层。

### Step 1b · 账号闸门（自动）
判定归档篇的发布账号（骨架确认 / 飞书"发布账号"）：
- **公司号**（牛科技 / 牛科技说）→ 继续
- **个人号**（宅研社 / 北北ks）→ 提示「个人号不复盘，飞轮只由公司号数据驱动」，**退出**

### Step 2 · 拉飞书真实数据（自动）
```
python3 Scripts/fetch_article_stats.py "<头条链接>"
```
拿到：`record_id` + 展现/阅读/CTR/完读/收藏/评论/点赞/转发/分享/互动率/粉丝展现 + 当前归因值。
- 若**未命中** → 问 CEO 确认链接/标题；若飞书未登记 → 让 CEO 先在飞书补登记再来。
- 注：`平均阅读时长` 字段飞书可能不返回，不影响复盘。

### Step 3 · 自动分层 + 列归因依据（自动）
- **表现分层自动判定**：超级爆款 / 展现王 / 爆款 / 点击强 / 承接强 / 普通 / 疑似限流 / 扑街
- **归因依据清单**（逐项摆数据）：
  - 预判分层 **vs** 实际分层 的偏差（哪里打脸 / 超预期）
  - 标题：预判标题 **vs** 实际 CTR（标题是否兑现点击承诺）
  - 正文承接：CTR 高但完读率低 = 承接弱；反之 = 承接强
  - 互动质量：收藏率（收藏/阅读）/ 评论数 / 评论第一条定调

### 🛑 Step 4 · 归因确认（唯一人介入点 · 必须停）
基于归因依据给**建议**，CEO 确认或修正。select 字段必须用预设选项：

1. **主因归因**（选 1）：标题强点击 / 平台愿意推 / 内容承接强 / 选题过窄 / 标题弱 / 疑似限流 / 时效失配 / 品类疲劳 / 公式可复用 / 公式需降权
2. **辅因归因**（选 1）：同上选项
3. **下次动作**（选 1）：复用 / 改标题再试 / 换账号试 / 降权 / 冻结 / 淘汰 / 降权观察
4. **可复用点**（自由文本）：这篇能复用什么
5. **问题点**（自由文本）：硬伤 / 待改进
6. **建议改写标题**（自由文本，可选）：标题弱时给改写

输出后**必须停下**，明确问 CEO：「以上归因确认？回复『通过』或指出改哪项。」
**CEO 确认 = 授权写回 + 授权公式库升降级**，不再二次确认（这是设计决策）。

### Step 5 · 写回飞书（CEO 确认后 · 自动）
```
python3 Scripts/writeback_review.py <record_id> 主因归因=... 辅因归因=... \
  下次动作=... 可复用点="..." 问题点="..." 建议改写标题="..." 复盘日期=YYYY-MM-DD
```
归因写回飞书文章追踪表（**事实进飞书**铁律）。select 字段经白名单校验，复盘日期自动转时间戳。

### Step 6 · 公式库联动（自动 · 飞轮进化）
按"下次动作"驱动公式生命周期：
- `复用` / `改标题再试` → 该结构升级 / 维持活跃
- `降权` / `降权观察` → 降级
- `冻结` / `淘汰` → 标记冻结
操作：改本地 `运营方法论/02_爆款公式库.md` 对应结构的状态与数据；需要时同步飞书公式库表 `tblExwpbnp875Vnh` 该结构生命周期。
> `关联公式`（link 字段）需公式库 record_id，本流程暂不自动写，后续可补。

### Step 7 · 反哺弹药包（自动）
更新 `对标拆解库/品类弹药包/[品类].md`：把该结构/标题的新表现样本补进 TOP 爆款 / 限流反面。

### Step 8 · 存复盘卡（自动）
从飞书归因派生本地复盘卡（飞书真相源的可读视图），存回归档目录：`06_归档复盘卡_[品类].md`。

### Step 9 · 提醒（自动）
输出：「✅ 复盘完成 → record_id=xxx | 公式库联动：[结构]→[新状态] | 弹药包已更新。飞轮右半边已闭合。」

## 硬约束
- 全程中文回复；脚本 / 命令保持英文
- **只在 🛑 Step 4 停下问人**，其余步骤自动推进
- select 字段（主因 / 辅因 / 下次动作）必须用预设选项，不准造新值
- 个人号（宅研社 / 北北ks）不复盘，闸门处直接退出
- 复盘结论写**飞书**（事实进飞书），本地复盘卡仅为派生视图
- 不造轮子：单文件脚本 / 标准库 / lark-cli
