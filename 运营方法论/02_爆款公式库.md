## 四点五、S7 单品牌型号解码型（新增复测模板）

**模板**：`{品牌/系列}{品类}型号暗藏玄机？{N}招看懂{后缀/参数}，别多花冤枉钱`

**已验证样本**：`TCL电视型号暗藏玄机？3招看懂Pro和Ultra，别多花冤枉钱`，展现 2.3 万+。

**为什么有效**：
- 单品牌/系列命中正在下单的人，用户意图比“XX怎么选”更强。
- `型号暗藏玄机` 激活信息差；`Pro/Ultra` 给出具体型号迷宫；`别多花冤枉钱` 给出损失厌恶。
- 正文必须兑现 3 件事：后缀/参数到底差在哪；哪些钱是体验提升，哪些钱是营销溢价；下单前照着查的清单。

**可迁移方向**：
- 海尔冰箱：云溪 / 麦浪 / 山茶花 / 零嵌 / 双系统。
- 美的空调：神机 / Pro / 全面风 / 新一级 / APF。
- 小天鹅洗衣机：小乌梅 3.0 / 5.0 / 水魔方 / 洗净比。
- TCL / 海信电视：Pro / Ultra / E7 / E8 / Mini LED / 刷新率。
- 方太 / 老板烟机：风量 / 静压 / 顶侧双吸 / 烟灶套装后缀。

**失效风险**：如果只写后缀科普，没有具体价格跨度、型号对照和“别为哪个点多花钱”，会退化成说明书。

> 自测规则：1-2 篇试投，进"点击强/爆款"才升活跃；连续 2 篇普通则降权。

## 五、公式生命周期（5 态）

| 状态 | 条件 | 使用策略 |
|---|---|---|
| 🟢 **活跃** | ≥2 篇 点击强/爆款/承接强，或均展现领先 | 优先排期 |
| 🟡 **验证中/活跃需提纯** | 有爆款但普通多 / 样本小 | 小规模测试，提取爆款共性 |
| ⚪ **新公式/待自测** | 外部验证未自测 / 单篇样本 | 1-2 篇试投 |
| 🟠 **降权** | 连续普通或均 CTR<3% | 暂停 1-2 周 |
| 🔴 **冻结** | 实测限流或明确失效 | 暂存可解冻 |

## 八、公式使用守则（主笔 Agent 02 必读）

1. **套结构不套句式**：迁移需求机制（钩子→反转→降维），不抄原文。见 `01_对标拆解工作流规范.md` 迁移闸门 6 问。
2. **同品类同天双号错角度**：A 号避坑/选购线，B 号内幕/技术线。
3. **疲劳信号即停**：同公式连续 2 篇 CTR<5% 本月不再排期。
4. **公式×账号匹配**：S2 只给 B 号；S1/S4/A1 只给 A 号；S3/S5/S6 两号均可。
5. **A1 双刃剑守则**：A1 要爆必须带**具体损失金额 + 强烈动作词**（"多花500块/白送也别装"），泛劝退（"别比品牌"）和标题党（"再便宜也别碰"）会被限流（110 篇实锤：141K 爆 vs 27 展现限流）。
6. **S7 使用守则**：必须单品牌/系列深挖，不写泛品牌横评；标题里必须出现具体后缀/参数词；正文首屏必须给价格跨度或型号迷宫；结尾必须有下单前清单。
