## 一、品类战略定位

### 1.1 品类四象限

```
              高展现
               |
    电视(22篇)  |  空调(10篇)
    冰箱(11篇)  |
               |
 低潜力 ———————+—————————— 高潜力
               |
    手机(1篇)   |  洗衣机(6篇)
    AI(1篇)     |  油烟机(6篇)
    家电综合    |  热水器(5篇)
               |
              低展现
```

### 1.2 品类分级

| 级别 | 品类 | 策略 | 理由 |
|------|------|------|------|
| **核心品类** | 电视、空调 | 维持存在感，优化结构 | 已验证爆款，是流量底盘 |
| **增长品类** | 冰箱、洗衣机 | 加大投入，抢占空白 | 冰箱先发优势+洗衣机待开发 |
| **潜力品类** | 油烟机、热水器 | 换结构再测 | 有市场但还没找到最优打法 |
| **探索品类** | 洗碗机 | 低频试水 | 外部验证有需求，自有0篇 |
| **边缘品类** | 手机、AI、家电综合 | 暂停 | 不垂直，数据极差 |

| 品类 | 频率 | 理由 |

| 电视 | 1篇/周 | 最强品类保持存在感，避免过度消耗 |

| 冰箱 | 1-2篇/周 | 先发优势，竞品少，抓紧占位 |

| 油烟机 | 1篇/周 | 中等品类，S2/S3/S6均有空间 |
| 热水器 | 1篇/周 | 外部爆款多但自有表现一般，换结构再试 |
| 洗碗机 | 1篇试水 | 全新赛道，先用S1内幕避坑型测试 |

### 2.3 轮换红线

- 同品类2篇之间间隔 ≥ 3天
- 同品类同天内耗 → 两号同品类必须用不同结构
- 连续3天不发同一品类
- 每周至少覆盖3个不同品类

## 五、选题来源优先级

### 5.1 四级选题来源

| 优先级 | 来源 | 可靠度 | 说明 |
|--------|------|--------|------|
| **P0** | 已验证爆款结构平移 | ⭐⭐⭐⭐⭐ | 从91篇数据中提炼的S级结构×未消费品类 |
| **P1** | 品类热点+产品库新品 | ⭐⭐⭐⭐ | 产品库推荐等级变化、新品上市、京东价格波动 |
| **P2** | 抖音/搜索热点 | ⭐⭐⭐ | 抖音高互动视频反映用户痛点，但不直接引述 |
| **P3** | 行业事件/政策 | ⭐⭐ | 国补/618/价格战等时效性选题，窗口窄 |

### 5.2 选题评估三步法

```
Step 1：这个选题有没有已验证的结构可以套？
  → 有 → 直接排期（确定性最高）
  → 没有 → 进入 Step 2

Step 2：这个选题击中读者的哪种情绪？
  → 能归入五种钩子之一 → 可以做
  → 归不进去 → 换选题

Step 3：这个选题的推品支撑够不够？
  → 推品逻辑手册有对应品类推荐型号 → 放行
  → 没有 → 先补推品逻辑再做
```

| W25 | 618决战+复盘 | 电视+空调 | A5/A7 | 价格悬念+反常识钩子 |

### 6.2 618选题禁忌

- 不做"618选购全攻略"（太泛，CTR极低）
- 不做价格预测（去年做了，阅读弱）
- 不做跨品类合集（家电号不跨品类）
- 必须有具体品牌+具体价格段+具体结论

## 七、长期品类拓展路线

### Phase 1（当前·6月）：巩固家电七品类
- 电视/空调/冰箱/洗衣机/油烟机/热水器/洗碗机

- 扫地机器人/净水器/新风系统等小家电
