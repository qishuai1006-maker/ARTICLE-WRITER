# 标题选题判断训练场

> 目的：解决“爆了以后倒推一堆理由，但不知道哪条是真因”的问题。  
> 本文件不是标题模板库，而是标题/选题判断能力的校准机制。

## 一、核心问题

过去对标、拆解、仿写是有效路径，但最大缺口不是“不够会仿”，而是：

- 爆款出现后，我们没有确认到底做对了什么。
- 拆解时容易把结果倒推成原因，生成一堆看似合理但未经验证的解释。
- 一篇爆文可能拆出 10 条理由，其中 3 条是真因，7 条是噪音；如果不区分，后续会把错因也沉淀成规则。
- 流程越补越重时，文章可能更正确、更完整，但不一定更想点。

因此，后续不能只做“爆款复盘”，必须做“预测 - 验证 - 修正”的判断训练。

## 二、第一性原理

今日头条家电标题的第一性原理不是“吸引眼球”，而是：

> 在信息流里，让读者瞬间感觉这条内容能降低他的购买决策风险。

更具体地说，读者会点，是因为他在 1 秒内感到：

1. 这件事和我现在或未来的购买决策有关。
2. 我以为自己懂，但可能有一个认知漏洞。
3. 如果不看，可能多花钱、买错、装不了、用不好或后悔。
4. 点进去成本很低，可能马上得到一个判断标准。

所以标题评估的底层问题不是“有没有某个爆款句式”，而是：

> 这个标题有没有制造真实的决策威胁？

## 三、三层拆解法

### 第一层：表层标题特征

只记录，不直接当结论：

- 是否具象
- 是否有对比
- 是否有品牌/型号/系列
- 是否有数字
- 是否有老手身份
- 是否有反常识
- 是否有损失表达
- 是否有收藏动作

表层特征只能说明“像爆款”，不能说明“能爆”。

### 第二层：读者决策任务

判断读者点进来到底想解决什么：

- 买哪个？
- 哪个别买？
- 参数怎么看？
- 哪个钱不该花？
- 什么场景不适合？
- 两个方案怎么选？
- 买前必须查什么？

没有明确决策任务的标题，容易变成知识科普。

### 第三层：决策威胁

判断不点会担心什么：

- 多花钱
- 买错型号
- 装不了
- 用不好
- 维修贵
- 后悔三个月
- 被营销词骗
- 被家人抱怨
- 过季/梅雨/入住后任务失败

第三层成立，标题才有真实点击潜力。

## 四、已观察到的有效变量

以下是候选真因，不是永久结论，必须继续用历史样本和新稿验证。

### 1. 具象

具象降低理解成本。

弱：冰箱怎么选  
强：法式门和对开门真实差距  
强：Pro、三代、新一级怎么分  
强：零冷水差距不在秒热

### 2. 对比

对比对应真实购买选择。

强对比包括：

- 法式门 vs 对开门
- 洗烘一体 vs 洗烘套装
- 新一级 vs 老一级
- 顶吸 vs 侧吸
- Pro vs Ultra
- 冷凝 vs 热泵

### 3. 用户已知但不懂的词

读者听过，但不确定怎么判断，最容易产生点击。

例如：

- Pro / Ultra
- 新一级 / 老一级
- 零冷水
- 双系统
- 热泵
- 法式门
- 十字门

### 4. 反默认认知

标题指出“你以为差距在 A，其实在 B”。

例如：

- 新一级和老一级，真实差距不是电费
- 零冷水差距不在秒热
- 对开门看着大，但可用空间未必大

### 5. 买后才发现的后悔

“用三个月才看清”“入住后才知道”“梅雨季才知道”比普通选购攻略更强，因为它制造延迟后悔感。

### 6. 可收藏的决策清单

“3招看懂”“下单前查5点”“认准这3个参数”不是因为数字神奇，而是给读者一个买前可用的判断工具。

### 7. 具体锚点

抽象价差、泛尺寸、泛参数不是天然选题。它们必须绑定具体购买锚点，才可能变成读者关心的决策任务。

可用锚点包括：

- 品牌锚点：TCL、海信、创维、格力、海尔等真实竞争场。
- 型号锚点：T7M Ultra、T7M Pro、Pro、Ultra、三代等可被搜索和比较的对象。
- 技术锚点：SQD、Mini LED、RGB-Mini LED、双系统、热泵等影响购买判断的词。
- 尺寸锚点：75 vs 85、85寸主流、客厅大屏、卧室65寸等真实场景选择。
- 榜单锚点：618成交榜、爆款大屏榜、平台热销榜等外部推荐信号。
- 人群锚点：35-50岁技术男、客厅升级、大屏预算用户、给父母换家电等。

执行口径：先找锚点，再写标题。没有锚点的“差价值不值”“配置值不值”，大概率只是作者视角。

## 五、两个已验证母体的当前判断

### A. 型号解码型

成立条件：

- 品牌/品类有真实命名迷宫。
- 后缀/系列词是读者见过但不懂的词。
- 后缀直接影响价格、配置或购买判断。
- 能写出具体暗号，不只说“型号有猫腻”。

较强样本：

- 格力空调型号暗藏玄机？3招看懂Pro、三代、新一级，别多花冤枉钱
- TCL电视型号暗藏玄机？3招看懂Pro和Ultra，别多花冤枉钱

较弱样本：

- 海尔冰箱型号暗藏猫腻，给爸妈买认准这3招，别花冤枉钱

弱因判断：冰箱用户的主决策未必在型号后缀，而在门型、容量、嵌入、循环、保鲜和使用场景。

### B. 生活决策差距型

成立条件：

- 用户正在两个可见方案之间纠结。
- 大众默认判断是错的或不完整。
- 真实差距不是参数，而是使用一段时间后的体验。
- 能给出 3 个以上生活后果。
- 能形成一句决策口诀。

较强样本：

- 做了十年冰箱评测，法式门和对开门真实差距，用三个月才看清
- 做了十年热水器评测，零冷水差距不在秒热
- 做了十年空调评测，新一级能效和老一级能效的真实差距不是电费

注意：可复用的是“生活决策差距”，不是每天套“做了十年”。

## 六、拆解纪律

以后拆爆款时，禁止写“这篇爆在 10 点”然后全部当规则沉淀。

固定输出四类：

1. **确信真因**：最多 1-3 条，必须能解释读者为什么停手/点击/收藏。
2. **可能有效但待验证**：最多 2-3 条，需要后续样本验证。
3. **看似合理但不能证明**：只记录，不进入生产规则。
4. **噪音或不建议复用**：例如过强情绪词、偶然时效、账号扶持、低质标题党。

数据好不等于内容好。  
内容差不等于没流量价值。  
爆了不等于可复用。  
可复用也不等于适合当前账号。

## 七、标题预测表

每篇开写前，先做预测，不允许只在发布后解释。

| 字段 | 填写要求 |
|---|---|
| 标题 | 候选标题 |
| 品类 | 冰箱/空调/电视/洗衣机等 |
| 账号 | 牛科技/牛科技说/宅研社/北北ks |
| 母体 | 型号解码型/生活决策差距型/价格段解码型/清单推荐型等 |
| 具体对象 | Pro/Ultra、法式门/对开门、零冷水/普通热水器等 |
| 决策任务 | 读者点进来要解决什么选择 |
| 决策威胁 | 不点会担心什么损失 |
| 具象度 | 高/中/低 |
| 对比强度 | 高/中/低/无 |
| 反常识 | 有/无 |
| 收藏动作 | 有/无 |
| 预测展现层级 | <3000 / 3000-10000 / 10000-30000 / 30000+ |
| 预测点击来源 | 标题/封面/品类需求/时效/争议 |
| 最大风险 | 选题窄/标题泛/证据弱/同质化/账号不匹配 |
| 发布后实际数据 | 展现、阅读、点赞、评论、收藏 |
| 偏差复盘 | 预测哪里错了，哪条规则升权/降权 |

## 八、当前执行要求

1. 后续选题先过“决策威胁”判断，再进入 01c 深调研。
2. 选题会只允许沉淀 1-3 条确信真因，不允许堆 10 条漂亮解释。
3. 每篇文章开工前写预测；发布后对照实际数据修正。
4. 目标不是证明某篇为什么爆，而是训练我们提前判断哪篇值得写。

## 九、反例校准：抽象价差不是选题

反例：

《65寸和75寸电视差价3000，拆开配置才发现钱花得值》

核心问题不是标题不够顺，而是选题对象错了。

- “差价3000”没有品牌、型号、平台、时间和促销锚点，读者不知道这笔差价发生在哪个真实购买场景。
- 65寸 vs 75寸不一定是当前客厅电视主决策，客厅大屏更可能是75/85/98之间的选择；65寸更多偏卧室或小客厅。
- 题目没有抓住当前电视赛道更强的流量场：TCL/海信/创维格局、TCL vs 海信竞争、SQD技术、T7M Ultra/Pro型号差异、85寸大屏榜单信号。
- “拆开配置才发现值”是作者分析动作，不是读者的即时决策焦虑。

可改造方向：

- TCL T7M Ultra 85寸为什么能冲到大屏榜第一？
- TCL T7M Ultra和Pro差在哪，85寸该怎么选？
- 618大屏榜被85寸刷屏，客厅电视为什么不再只盯75寸？
- TCL赢在SQD还是屏厂？海信还能不能打？
- 75寸和85寸电视怎么选？先看客厅距离，再看TCL/海信这几档。

执行规则：

电视选题优先落到品牌、型号、技术、尺寸、榜单和人群，不写没有锚点的抽象价差。榜单是选题弹药，不是正文装饰；必须先验证榜单来源和时间，再决定是否进入标题或首屏。
