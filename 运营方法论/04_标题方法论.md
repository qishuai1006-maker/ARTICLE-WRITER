## 二、五种情绪钩子

每个爆款标题的情绪驱动力必属以下五种之一：

| 钩子 | 心理机制 | 对应结构 | CTR区间 |
|------|---------|---------|---------|
| **认知颠覆** | 用户以为对的其实是错的 | S5, A5 | 8-10% |
| **信息不对称** | 行业在隐瞒 | S1, S2 | 8-10% |
| **时间见证** | "做了N年"赋予可信度 | S2, A3 | 8-10% |
| **损失规避** | 有人踩过坑 | A1, A4, S1 | 7-10% |
| **数字冲击** | 反常识数字打破预期 | S5, A7 | 7-9% |

### 钩子选择规则

1. 避坑/教程类选题 → 首选信息不对称或损失规避
2. 选购/横评类选题 → 首选认知颠覆或时间见证
3. 趋势/科普类选题 → 首选数字冲击
4. 拿不准 → 选信息不对称（CTR最稳定）

## 三、标题硬规则

### 3.1 必须做到

| 规则 | 原因 | 数据依据 |
|------|------|---------|
| 标题≤30字 | 头条截断限流 | 所有爆款标题均≤30字 |
| 标题含≥1个品牌名 | 泛品类标题CTR<2% | 无品牌标题平均CTR 1.5% |
| 标题有明确钩子 | 点击驱动力 | 钩子明确的标题平均CTR 7.8% |
| 标题给确定性承诺 | 读者要答案不是问题 | "才看清""不踩坑""不纠结"等承诺词CTR高 |

### 3.2 绝对禁止

| 禁止 | 后果 | 替代方案 |
|------|------|---------|
| "智商税" | 展现<10 | "踩坑""多花冤枉钱" |
| "完美" | 展现<100 | "适合你的""刚好够用" |
| 感叹号❗ | CTR明显降低 | 用句号或问号 |
| 绝对化词（碾压/吊打/最好/最强/唯一） | 广告法风险+限流 | "领先""有竞争力""排名靠前" |
| 标题>30字 | 截断限流 | 精简到≤30字 |
| 品牌名+绝对化词组合 | 双重限流 | 品牌名+具体参数/事实 |

### 3.3 限流词完整清单

**标题严禁使用（一次都不行）**：

| 词汇 | 类型 | 替代 |
|------|------|------|
| 智商税 | 平台限流词 | 踩坑/多花冤枉钱/避坑 |
| 完美 | 广告法绝对化 | 适合你/够用/靠谱 |
| 碾压 | 广告法绝对化 | 明显领先/优势大 |
| 吊打 | 广告法绝对化 | 差距明显/优势突出 |
| 最好 | 广告法绝对化 | 表现突出/排名靠前 |
| 最强 | 广告法绝对化 | 第一梯队/竞争力很强 |
| 唯一 | 广告法绝对化 | 少有的/为数不多的 |
| 独家 | 广告法绝对化 | 不多见/少见 |
| 必须买 | 绝对化 | 建议买/推荐 |
| 一定要 | 绝对化 | 推荐/建议 |
| 毫无疑问 | AI味词 | 直接说结论 |
| 不得不说 | AI味词 | 直接说内容 |

**正文也需注意的AI味词**（lint_article.py自动检测）：
不难发现、本质上、换句话说、不可否认、让我们来看看、接下来让我们、这意味着

## 四、标题四步迁移法

拿到外部爆款标题，按以下步骤迁移到自己的选题：

### Step 1：识别钩子

这个标题打的是哪个情绪？（认知颠覆/信息不对称/时间见证/损失规避/数字冲击）

### Step 2：识别结构

剥离品类后，骨架对应S1-S6 / A1-A8哪一种。

### Step 3：替换品类+场景

把原品类换成目标品类，场景对应替换。**数字没有实测支撑就不照搬。**

### Step 4：微调句式

加入1个差异化信息点（品牌/型号/实测数据），让标题与原版有区分度。

### 迁移校验清单

- [ ] 钩子类型已标注
- [ ] 结构编号已对应
- [ ] 品类已替换（不是原品类的原文案）
- [ ] ≥1个差异化信息点
- [ ] ≤30字
- [ ] 无限流词
- [ ] 推品逻辑手册有该品类推荐型号

### 5.2 标题效果归因

| 现象 | 可能原因 | 下一步 |
|------|---------|--------|
| 展现高CTR低 | 标题没接住推荐 | 检查标题钩子，改标题再试 |
