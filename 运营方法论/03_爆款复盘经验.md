# 爆款复盘经验

**最后更新**：2026-05-28
**数据基础**：64篇已发布文章，其中爆款6篇、点击强13篇、推荐强5篇

---

## 一、爆款定义与分级

| 分层 | 标准 | 数量 | 占比 |
|------|------|------|------|
| **爆款** | 展现≥10K 且 CTR≥8% | 6篇 | 9.4% |
| **点击强** | CTR≥7% | 13篇 | 20.3% |
| **推荐强** | 展现≥20K | 5篇 | 7.8% |
| **承接强** | 完读率≥20% 或 收藏/阅读≥3% | 3篇 | 4.7% |
| **普通** | 数据中等 | 33篇 | 51.6% |
| **疑似限流** | 展现<100 或 阅读=0 | 4篇 | 6.3% |

### 爆款门槛（从数据中提炼）

- **展现≥10K**：平台愿意推 + 选题覆盖面够广
- **CTR≥7%**：标题点击效率高于平台平均（头条家电CTR均值约4-5%）
- **阅读≥1000**：实际触达规模有意义
- 三个同时满足 = 爆款；只满足两个 = 有明确信号可放大

## 二、六大爆款拆解

### 爆款 #1：做了十年电视评测，海信TCL创维的真实差距才看清

| 维度 | 分析 |
|------|------|
| **数据** | 牛科技说 · 展现137,714 · 阅读10,949 · CTR 8% · 评论37 · 收藏100 |
| **结构** | S2内幕视角型 |
| **钩子** | 时间见证（"做了十年"） |
| **爆因** | 三品牌同台+经验背书+"真实差距"四个字制造信息差感 |
| **可复制点** | "做了N年+品类+品牌组合+真实差距"结构可跨品类平移 |
| **注意** | B号王牌结构，A号不要用 |

## 三、爆款共性提炼

### 3.1 六大爆款共同特征

| 特征 | 6/6命中 | 说明 |
|------|---------|------|
| 标题含品牌名 | 5/6 | 爆款标题几乎必含品牌，泛品类标题无爆款 |
| 标题≤30字 | 6/6 | 无一例外 |
| 标题无感叹号 | 6/6 | 0篇爆款用感叹号 |
| 标题有明确钩子 | 6/6 | 每个标题都能归类到五种情绪钩子之一 |
| 标题给确定性承诺 | 5/6 | "才看清""不纠结了""不踩坑""差距在哪" |
| 正文信息密度高 | 6/6 | 每100字≥3个信息点 |

### 3.2 爆款的三个条件

一个爆款 = **选题覆盖面广** × **标题点击效率高** × **内容承接得住**

| 条件 | 对应指标 | 爆款达标线 |
|------|---------|-----------|
| 选题覆盖面 | 展现量 | ≥10K |
| 标题效率 | CTR | ≥7% |
| 内容承接 | 完读率/收藏率 | 完读率≥15% 或 收藏/阅读≥2% |

三个条件缺一不可：展现高但CTR低 = 标题弱；CTR高但展现低 = 选题窄；CTR和展现都高但完读率低 = 内容没接住。

## 四、失败教训

### 4.1 疑似限流（4篇）

| 标题 | 展现 | 限流原因 | 教训 |
|------|------|---------|------|
| 海信TCL创维怎么选？三分钟看懂，别再交**智商税** | 3 | "智商税"触发限流 | 绝对不用"智商税"，用"踩坑"替代 |
| 2026电视选购全景指南：一张表搞定你的**完美**选择 | 87 | "完美"属绝对化用语 | 禁止标题使用绝对化词 |
| 618，iPhone 17五款机型这样买最省钱**！** | 824 | 品类不垂直+感叹号 | 家电号不发手机；去感叹号 |
| 2026年618洗衣机价格预测 | 1,171 | 预测类泛标题 | 预测类只在618强窗口用 |

### 4.2 高展现低阅读（标题没接住推荐）

| 标题 | 展现 | 阅读 | CTR | 问题 |
|------|------|------|-----|------|
| 618烟灶选购指南：我扒了四大品牌30款，每个价位只推荐2款 | 1,080 | 2 | 0% | 标题过长，信息密度过高 |
| 三星家电被中国赶走了：34年来它做错了什么？ | 852 | 3 | 0% | 强负面叙事，平台不推 |

### 4.3 失败模式总结

| 模式 | 后果 | 规则 |
|------|------|------|
| 标题含限流词 | 展现<100 | 严格审核标题，参考限流词清单 |
| 标题泛化无品牌 | CTR<2% | 标题必须含≥1个品牌名 |
| 标题带感叹号 | CTR明显降低 | 永远不用感叹号 |
| 品类不垂直 | 展现极低 | 家电号只发家电，不发手机/AI |
| 负面叙事过强 | 阅读极低 | 降负面强度，用"差距"不用"赶走" |
| 泛选购指南 | CTR弱 | 必须加具体冲突/痛点/品牌 |

## 五、爆款复制方法论

### 5.1 爆款结构复用优先级

| 优先级 | 结构 | 已验证爆款数 | 可平移品类 |
|--------|------|------------|-----------|
| **P0** | S1内幕避坑 | 2篇（空调42K+冰箱32K） | 全品类 |
| **P0** | S2内幕视角 | 1篇（电视137K） | 全品类 |
| **P0** | S4价格段推荐 | 1篇（电视46K） | 电视/空调/冰箱 |
| **P0** | S5反问悬念 | 1篇（电视49K） | 电视/空调/冰箱 |
| **P0** | S6对比选择 | 1篇（显示器58K） | 全品类 |
| **P1** | S3品牌对决 | 外部验证 | 空调/电视/冰箱 |
| **P2** | A1换N次+N不买 | 外部1381互动 | 全品类（待自有验证） |

### 5.2 爆款复制操作流程

```
1. 选结构：从P0结构中选择一个上次没用过的
2. 选品类：从品类轮换计划中选择本周品类
3. 选钩子：根据品类痛点选择对应的情绪钩子
4. 写标题：套入结构公式，确保≤30字、无禁用词、含品牌名
5. 校验：标题通过lint_article.py检查
6. 生产：T1-T7标准流程
```

### 5.3 爆款复盘检查清单

每篇文章发布72小时后做复盘：

- [ ] 展现是否≥5K？（低于5K检查是否限流）
- [ ] CTR是否≥5%？（低于5%优化标题结构）
- [ ] 收藏/阅读是否≥2%？（低于2%检查内容实用性）
- [ ] 归入哪个表现分层？（爆款/点击强/推荐强/普通/限流）
- [ ] 主因归因为什么？（只能选一个）
- [ ] 下次动作是什么？（复用/改标题/降权/冻结）
- [ ] 如果是爆款：提炼标题公式，写入公式库
