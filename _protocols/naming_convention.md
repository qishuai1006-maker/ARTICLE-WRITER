# Super Writer · 命名规范 v1.0

> **最后更新**：2026-06-11

## 一、核心原则

- **文件名 = 语义 + 时间 + 序号**
- **目录 = 阶段隔离 + 主题分类**
- **永远是绝对的，从不相对**

## 二、test_run/ 命名规范

### 每篇记录（强制）

```
test_run/
├── 选题_2026-06-XX_[品类]_[简短话题].md   ← T1+T1.5+T2 全部记录
└── 成品_2026-06-XX_[品类]_[简短话题].md   ← T3 正文 + T4 自检
```

**示例**：
- `选题_2026-06-11_冰箱_法式门vs对开门.md`
- `成品_2026-06-11_冰箱_法式门vs对开门.md`

**双篇同跑**：
- `选题_2026-06-11_冰箱_双篇.md`
- `成品_2026-06-11_冰箱_A_法式门.md`
- `成品_2026-06-11_冰箱_B_对开门.md`

### 验证报告

```
test_run/v1.0_验证报告_2026-06-XX.md
test_run/单篇验证_T1-T4_第X篇_2026-06-XX.md
```

## 三、assets/ 命名规范

### titles/ 爆款标题库

**文件命名**：
```
[品类]_[模板]_[数量]个.md
```

**示例**：
- `冰箱_反问悬念型_5个.md`
- `空调_闭眼入清单型_3个.md`
- `电视_多品牌对决型_4个.md`

**单文件结构**：
```markdown
# [品类] · [模板] 标题库（[数量] 个）

> **数据来源**：[内部100 篇 / 外部54 篇 / 混合]
> **采集日期**：2026-06-XX
> **展现/互动基准**：[样本中位展现 X,XXX]

## 标题样本（按数据表现排序）

1. **「[完整标题]」** — 展现 X,XXX（来源：内部）
2. **「[完整标题]」** — 互动 X,XXX（来源：外部）
...

## 共同公式

[提炼 1-3 个共性公式]

## 不许抄的部分

[标明哪些是品类锚点可换、哪些是结构性必留]
```

### openings/ 优质开头库

**文件命名**：
```
[骨架]_[数量]个.md
```

**示例**：
- `问题链_5个.md`
- `拆解面_8个.md`

### golden_lines/ 金句库

**文件命名**：
```
[类型]_[数量]个.md
```

**类型**：
- `一句话带走`（问题链结尾）
- `评论区钩子`（各种结尾）
- `转折金句`（故事线）

### titles_proven/ 自己已爆款标题

**文件命名**：
```
[品类]_[模板]_[数量]个_已爆.md
```

**示例**：
- `冰箱_内幕视角型_3个_已爆.md`
- `空调_对比选择型_2个_已爆.md`

**单文件额外字段**：
```markdown
## 已验证效果

| 标题 | 展现 | 互动率 | 完读率 | 发布日期 |
| --- | --- | --- | --- | --- |
| 「[完整标题]」 | 106,499 | 16.7% | 22.3% | 2026-XX-XX |
```

## 四、prompt 引用规范

### 对话开头固定话术

**T1 对话开头**：
```
读取 test_run/[完整路径] （如不存在则新建），
按 /Users/aaron/.../prompts/01-选题/选题_三追问.md 跑 T1。
记住：只输出 5 个角度的摘要（每个 ≤ 200 字），不要写正文。
```

**T2 对话开头**：
```
读取 test_run/[完整路径] 的 T1 摘要部分，
按 /Users/aaron/.../prompts/03-深度/深度_三追问.md 跑 T2 三层深度。
记住：每层 ≤ 400 字，三层递进要清晰。
```

**T3 对话开头**：
```
读取 test_run/[完整路径] 的全部记录，
按 /Users/aaron/.../prompts/04-写作/写作_骨架填空模板.md 写正文。
参考 /Users/aaron/.../assets/titles/[对应品类+模板].md 选择标题样本。
参考 /Users/aaron/.../assets/openings/[对应骨架].md 选择开头样本。
记住：正文 1500-2500 字，五步不许跳。
```

**T4 对话开头**：
```
读取 test_run/[完整路径] 和 test_run/成品_[完整路径]，
按 /Users/aaron/.../prompts/05-自检/发布前自检清单.md 跑 12 项检查。
记住：输出 PASS/FAIL/WARNING 三档结论。
```

## 五、YAML 接力包命名

```
test_run/_handoff/[文章ID]_T[阶段].yaml
```

**示例**：
- `test_run/_handoff/article_001_T1.yaml`
- `test_run/_handoff/article_001_T2.yaml`

## 六、禁止事项

- ❌ 在文件名里用空格（用 `_` 或 `-`）
- ❌ 在文件名里用中文标点（，、。？！）
- ❌ 文件名长度 > 80 字符
- ❌ 把过程文件放到 `outputs/`（v7.2 老路径，已废弃）
- ❌ 文件名不带日期（不利于追溯）
- ❌ 跨阶段文件不分离（T1 摘要 + T3 正文混在一起）
