## 一、快速开始（30秒出图）

1. 从下方「七类配图模板」中选择你需要的类型
2. 把 `[方括号内容]` 替换为实际数据

## 二、全局风格规则（每张图都必须遵守）

### 硬性要求
- **全中文文字**，包括标题、标签、图注
- **禁止水印**，任何角落不得出现"原创""版权""AI生成"等小字标注
- **禁止英文混入**（品牌英文名如"Haier"可保留，但图注/标题必须中文）
- **浅色背景为主**（白色/浅灰/浅米色），避免深色背景影响阅读
- **数据必须真实**：图中的所有参数、价格、数值必须与文章素材一致，不可编造
- **风格统一**：科技家电赛道，专业感 > 花哨感，干净清晰 > 炫技堆砌

### 配色方案
- 主色：深蓝 `#1a365d`（科技感）
- 辅色：浅灰 `#f7fafc`（背景）
- 强调色：翠绿 `#38a169`（优势项）、红色 `#e53e3e`（劣势项）、金色 `#d69e2e`（价格/推荐）
- 字体：无衬线体（黑体/思源黑体风格）

### 尺寸规格
| 类型 | 比例 | 推荐尺寸 | 用途 |
|------|------|---------|------|
| 横版 | 16:9 | 1920×1080 | 封面图、参数对比图、场景对比图 |
| 方版 | 1:1 | 1080×1080 | 人群选购图、优缺点图 |
| 竖版 | 9:16 | 1080×1920 | 小红书封面（仅小红书稿件用） |

## 三、NotebookLM vs ChatGPT 分工建议

| 配图类型 | NotebookLM | ChatGPT/Codex | 原因 |
|---------|:----------:|:-------------:|------|
| 参数对比图 | ✅ 首选 | ⚠️ 次选 | 数据表格是 NotebookLM 强项 |
| 封面图（场景代入型） | — | ✅ 首选 | ChatGPT 擅长场景渲染 |
| 封面图（避坑警示型） | — | ✅ 首选 | ChatGPT 擅长视觉冲击 |
| 封面图（产品对决型） | ✅ 可用 | ✅ 首选 | ChatGPT 做产品视觉对比更灵活 |
| 封面图（价格冲击型） | ✅ 可用 | ✅ 首选 | 大数字视觉 ChatGPT 效果好 |
| 封面图（参数一击型） | ✅ 可用 | ✅ 首选 | 超大数字排版 ChatGPT 更可控 |
| 优缺点总结图 | ✅ 首选 | ⚠️ 次选 | 结构化对比 NotebookLM 更清晰 |
| 人群选购图 | ✅ 首选 | ⚠️ 次选 | 分栏布局 NotebookLM 更整齐 |
| 场景对比图 | ✅ 可用 | ✅ 首选 | 场景渲染是 ChatGPT 强项 |
| 价格档位图 | ✅ 可用 | ✅ 首选 | 阶梯视觉 ChatGPT 更有设计感 |
| 技术原理图 | — | ✅ 首选 | 概念示意图 ChatGPT 擅长 |
| 产品外观对比图 | — | ❌ 不适合 | 用品牌官网/京东实拍图拼接 |

**结论**：ChatGPT 最适合 **封面图 + 场景类 + 价格档位 + 技术原理图**，NotebookLM 最适合 **参数对比 + 优缺点 + 人群选购** 这类结构化数据图。两者搭配使用，既省 NotebookLM 额度，又能获得更多样的视觉风格。

## 四、封面图提示词模板（v2.1 · 基于头条封面执行规范）

> **Source of Truth：`参考资料库/头条封面执行规范.md`**
> **核心原则：封面不是配图，是广告Banner。0.5秒拦截用户手指。**
> **文字铁律：文字是标签不是主角，视觉面积≤20%，内容必须与文章标题互补不重复。**
> **封面文字公式（五套）**：A≠B / 不是A是B / 买前先看X / 这X种慎买 / 数字差异

### 封面通用提示词结构（所有模板共用）

```
生成一张今日头条家电图文封面图，尺寸 1280×720，16:9 横图。

【主题】
[文章核心矛盾，一句话]

【画面主体】
[家电品类 + 核心细节特写]
不使用产品远景全景图，不堆多个产品，优先特写关键部位。
画面主体占 60% 以上，是绝对视觉中心。拿掉文字后，图片本身应仍能传达核心信息。

品类对应主体参考：
- 冰箱：保鲜抽屉、内胆分区、食材对比、蒸发器
- 电视：屏幕画质细节、暗场画面、游戏画面
- 空调：出风口、压缩机、室外机、温度计实测
- 油烟机：灶台油烟、吸口距离、滤网、烟道截面
- 洗衣机：滚筒内部、衣物洗后状态、烘干效果对比
- 热水器：管路、花洒水流、循环路径示意

【构图】
[产品主体占画面 60%—70%]
[文字放置位置：角落小色块，视觉面积不超过画面的 15%—20%]
[是否左右对比 / 三分栏 / 剖面图]

【封面文字】
主标题：[6—10 字，与文章标题互补不重复，从五套公式中选取]
辅助标签：[最多 1—2 个短标签，可不加]
文字视觉面积 ≤ 画面的 15%—20%，字号控制在"缩略图下勉强可读"的大小。

【视觉风格】
真实测评感，家电自媒体专业风格。
不要品牌广告感，不要电商主图感，不要棚拍过度精美感。
高对比配色，背景简洁，文字粗黑体。
可加入真实测评元素：温度计、分贝仪、手部操作、烟雾、对比实验。

【颜色】
主色不超过 3 种。
- 深蓝 / 深灰：专业科技感
- 红色 / 橙红：风险警示、避坑
- 绿色 / 亮蓝：正确答案、推荐
- 黄色 / 橙色：重点提醒、价格
推荐结构：深色背景 + 白色小字 + 红 / 黄 / 绿重点色块

【禁止项】
不要水印，不要小字堆砌，不要复杂背景，
不要过度精美棚拍，不要官方宣传海报感，
不要产品排排站全景，不要超过 3 种主色，
不要让封面文字的视觉面积超过画面的 20%。
```

### 模板 A：产品特写 + 小标签文字（v2.1）

**适用**：避坑 / 误区纠正 / 单品分析 / 技术纠错

```
（在通用结构基础上，【构图】部分填写以下内容：）
【构图】
- 产品核心细节特写占画面 60-70%（左侧或中下），是绝对视觉中心
- 角落（右上或右下）放小面积深色色块（≤画面20%），色块内放白色粗体文字
- 文字是标签角色，不是主角。拿掉文字，图片本身仍应能传达核心信息
- 背景简洁，可以是真实厨房/客厅场景但虚化处理
```

**示例（油烟机 · 避坑型 · 文章标题：开放式厨房选油烟机，别先问风量，先看烟道和静压）**：
```
生成一张今日头条家电图文封面图，尺寸 1280×720，16:9 横图。

【主题】油烟机选购最大误区：风量够大但油烟排不出去，因为静压不够

【画面主体】
油烟机侧吸口特写——从灶台到吸口之间的局部区域。灶面上有一口正在爆炒的锅，白色油烟从锅面升起后被侧吸口拉出一条清晰可见的烟流轨迹。画面中靠右下角可见一个手持仪器屏幕显示"350Pa"的数字（小型、不抢眼，像测评现场自然存在的）。
不使用油烟机整机全景图，不使用厨房整体场景。

【构图】
油烟轨迹+吸口特写占画面65%以上（左侧和中部），是绝对视觉中心。
右下角小面积深蓝灰色色块（占画面约15%），色块内放白色粗体小字。
背景虚化到只剩模糊的灶台轮廓。

【封面文字】

辅助标签：（无）

【视觉风格】
真实测评感，像自媒体用手机在灶台前随手拍的参数实测照片。
不要品牌广告感，不要棚拍光效，不要电商主图那种均匀布光。
油烟轨迹要肉眼可见（像真实炒菜时的白烟），火焰自然。
高对比度，整体偏暗调，让火焰和油烟轨迹跳出来。

【颜色】
深灰/深蓝暗调背景 + 橙红火焰 + 白色油烟轨迹 + 右下角小色块内白字。
主色不超过3种。

【禁止项】
不要水印，不要小字堆砌，不要复杂背景，
不要过度精美棚拍，不要官方宣传海报感，
不要产品排排站全景，不要超过3种主色，
不要让封面文字的视觉面积超过画面的20%。
```

### 模板 B：左右对比分割图（v2.0）

**适用**：横评 / 品牌对比 / 反常识 / 实验结果

```
（在通用结构基础上，【构图】部分填写以下内容：）

```

**示例（油烟机 · 横评型 · 文章：顶吸侧吸集成灶真实差距）**：
```

【画面主体】

右侧：侧吸油烟机近距离吸烟，油烟被锁住没扩散的场景特写（正确状态）
中间用白色竖线分割。

【构图】
左右对半分割，各占50%。左半背景偏暖黄/橙（油烟感），右半背景偏冷蓝/白（干净感）。中间竖线。

【封面文字】
左侧文字：距离远了

（不讲风量，讲捕获距离）

【视觉风格】
真实测评对比感，两侧对比鲜明。
不要广告感，不要品牌宣传图。

【颜色】
左暖色 + 右冷色 + 白色分割线 + 白色粗体文字，主色不超过3种。
```

### 模板 7：价格档位图

**适用**：按价格区间推荐产品，放在"选购建议"章节

```
生成一张16:9横版价格档位推荐信息图。

入门档（¥xxx-xxx）：推荐 [型号名]，核心配置：[关键参数2-3个]
```

## 五、质量检查清单（出图后逐项确认）

### 必须通过（任一不通过需重新生成）

- [ ] **尺寸正确**：16:9 横版（≈1920×1080）或 1:1 方版（≈1080×1080）
- [ ] **中文可读**：图中所有中文文字清晰，无乱码/模糊/重叠
- [ ] **数据准确**：图中参数/价格/数值与文章素材完全一致
- [ ] **无水印**：任何角落没有"原创""版权""AI"等标注
- [ ] **路线完整**：图中技术路线/产品/方案的数量 ≥ 文章实际涉及的数量
- [ ] **封面文字 ≤ 10字**：封面图上文字不超过10个汉字（封面类型才需检查）
- [ ] **封面不含文章标题**：封面图上不得出现完整文章标题

### 建议通过（不影响使用但影响质量）

- [ ] 风格与同篇文章其他配图协调（同为信息图风格，不要一张极简一张花哨）
- [ ] 色调统一（蓝/绿/金为主色调，不要彩虹配色）
- [ ] 文字大小适中（手机端也能看清主要信息）

## 六、常见问题

### Q：ChatGPT 生成的中文数字出错怎么办？
A：这是 ChatGPT 生图的已知局限。对策：
1. 提示词中强调"所有数字必须与表格完全一致，不可四舍五入"
2. 如果只有个别数字错误，用截图工具+文字工具手动修正
3. 如果数字大面积错误，回退用 NotebookLM 或 Pillow 代码生成

### Q：ChatGPT 不认识中国品牌的产品外观怎么办？
A：封面图和场景图不需要精确的产品外观，用剪影/轮廓/抽象表示即可。如果需要真实产品图，用品牌官网/京东实拍图，不走 AI 生图。

### Q：一张图生成要多久？
A：ChatGPT gpt-image-1 通常 15-30 秒一张。NotebookLM 信息图通常 30-60 秒。速度相当。

### Q：每天能生成多少张？
A：ChatGPT Plus 用户每天可生成大量图片（远超 NotebookLM 的 12-13 张限制），具体额度随 OpenAI 政策变化。

### Q：可以用 Codex 吗？
A：可以。Codex 内置 GPT-4o 图片生成能力，直接在对话中粘贴提示词即可，流程与 ChatGPT 相同。
