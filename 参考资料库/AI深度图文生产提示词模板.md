## 数据准备

1. **读取 source/** — 读取所有调研报告，提取与各篇文章相关的数据
2. **冲突检测** — 多份报告之间如有数据矛盾，用 Tavily/WebSearch 针对该点重新调研，以最新可验证数据为准
3. **信息缺口补全** — 报告未覆盖但对核心论点必要的数据，主动搜索补充
4. **交叉验证** — 关键参数（价格/规格/性能数据）用产品信息库 + Tavily 双源验证

## 执行流程

按 T1-T7 流程执行，[单篇/双篇]并行推进：
- 组建 Agent Teams（5 Agent）并调用对应 Skill 执行；
- 选题情报官负责 T1（选题方向已由CEO锁定，聚焦选题角度细化+抖音爆款佐证）
- 内容研究员负责 T2（产品信息库+Tavily双源交叉验证+source/报告叠加+抖音观点采集）
- 全栈写手负责 T3（头条图文，注意调性差异化：牛科技说偏技术发烧、牛科技偏实用导购）
- 合规风控师负责 T4（审查+产品数据抽查）
- 视觉分发师负责 T5+T6（配图+头条终稿）
- T5 与 T2/T3 并行。等所有任务完成后向CEO汇报。

## 写作风格（必须遵守）

### 基调
- 口语化、像跟朋友聊天，零情绪营销词
- 结论前置（前3句话决定完读率）
- 专家视角：拆解者/内行人
- 不催互动

### 开头（从以下模式中选择一种，两篇不要重复）
1. 反常识结论型 — 一句话打破常见认知
2. 数据冲击型 — 用一组对比数据开场
3. 场景代入型 — 描述一个具体的购买/使用场景
4. 行业内幕型 — 透露一个行业不愿说的真相
5. 代价计算型 — 算一笔读者没想到的账
6. 技术原理解构型 — 从原理出发推翻常识
7. 亲身经历型 — "我见过一个案例..."
8. 时间线倒叙型 — 先说结果再倒推过程

### 结尾（从以下模式中选择一种，两篇不要重复）
1. 选购建议清单 — 精简到3条具体建议
2. 一句话定论 — 全文浓缩成一句结论
3. 反问收束 — 留一个问题让读者自己判断
4. 信息差总结 — 列出2-3条行业不说的真相
5. 价格锚定 — 给出具体价位段推荐
6. 开放讨论 — 提出一个有争议的观点

### 禁止（红线）
- 禁止感叹号
- 禁止绝对化用语（最好/最强/碾压/吊打/毫无疑问/不得不说/没有对手/只此一款）
- 禁止"总结+展望+鼓励"三件套结尾
- 禁止"你知道吗/很多人不知道/今天我要分享/随着…发展/在当今…背景下"开头
- 禁止"总而言之/综上所述/希望本文对你有帮助/展望未来"结尾
- 禁止引述抖音达人
- 禁止"首先…其次…最后"三段式
- 禁止AI高频词（不难发现/本质上/换句话说/不可否认/让我们来看看/接下来让我们/这意味着）

### 口语化质感
- 全文1-2个口癖自然出现（"说白了""这事儿吧""你想想看"）
- 至少1处不完美表达（自我纠正/半途改口/承认不确定）
- 每300字称呼一次"你"

### 数据规范
- 单一来源数据必须标注来源
- 无法验证的数据用"建议"而非确定语气
- 每100字≥3个信息点（选购横评型≥4个）

## 输出格式

直接输出Markdown格式正文，不需要标题。段间空行，短段落为主。
