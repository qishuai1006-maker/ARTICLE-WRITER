# 今日头条家电封面执行规范（Claude Code 精简版）

> 适用：Claude Code 内容生产工作流中的封面策划、封面提示词生成、封面验收步骤。
> 原则：封面的唯一任务是在 0.5 秒内拦截用户手指，让用户意识到"这篇内容和我有关"。

---

## 一、尺寸规范

| 用途 | 尺寸 | 比例 |
|---|---|---|
| 今日头条图文单封面（主要使用） | 1280×720 或 1440×960 | 16:9 横图 |
| 三图模式封面（次要） | 1080×1080 | 1:1 方图 |

**默认使用 16:9 横图，不使用 1:1 方图。**

---

## 二、五步执行流程

### Step 1：提取核心矛盾

从文章中找出最能触发点击的一个矛盾点。

优先级从高到低：

1. 买错风险
2. 参数误区
3. 安装隐患
4. 真假概念
5. 结果对比
6. 价格损失

**只取排名最高的一个，不叠加。**

---

### Step 2：选择封面模板

| 文章类型 | 使用模板 |
|---|---|
| 避坑 / 误区 / 技术纠错 | 模板A：产品特写 + 强观点文字 |
| 横评 / 品牌对比 / 实验结果 | 模板B：左右对比分割图 |
| 参数纠错 / 选购决策 | 模板C：红绿判断图 |
| 技术拆解 / 安装分析 / 结构科普 | 模板D：剖面图 / 透视图 |
| X个坑 / X类人群 / X种风险 | 模板E：三分栏风险图 |

---

### Step 3：生成封面文字

每张封面只选一个核心钩子，6—10 字，最多不超过 12 字。

**文字定位：标签，不是主角。**
- 封面文字的视觉面积不超过画面的 15%—20%
- 图片主体是主角（60%+），文字是辅助标签
- 如果拿掉文字，图片本身应该仍然能传达核心信息

**文字内容铁律：必须与文章标题互补，绝不重复。**
- 封面文字和标题说同一件事 = 信息浪费，点击冲动互相抵消
- 正确做法：标题说"为什么"，封面文字给"具体数字/结论"；或者标题说结论，封面文字给场景
- 生成封面文字前，必须先看文章标题，确认两者传达的是不同维度的信息

从以下五套公式中选最匹配的一套：

**公式一：A ≠ B（纠正误区）**
- 120Hz ≠ 流畅
- 风量大 ≠ 吸得净
- 双循环 ≠ 双系统
- 一级能效 ≠ 一定省钱
- 洗烘一体 ≠ 洗烘套装

**公式二：不是 A，是 B（反常识科普）**
- 不是风量，是静压
- 不是门数，是发泡层
- 不是容量，是蒸发器数量
- 不是 120Hz，是输入延迟

**公式三：买前 / 装前先看 X（避坑提醒）**
- 挂墙前先看墙
- 买烟机先看烟道
- 装零冷水先看户型
- 买冰箱先看蒸发器

**公式四：这 X 种慎买 / 慎装（风险警示）**
- 这 3 种户型慎装
- 这 2 类家庭慎买
- 这 4 类电视别当游戏机

**公式五：数字差异（实测结果）**
- 差了 15 分贝
- 省电差 100 度
- 3 天 vs 7 天
- 500 元隐性成本
- 10kg ≠ 烘 10kg

### Step 4：生成画面提示词

使用以下标准结构填写，不要自行发挥：

```
生成一张今日头条家电图文封面图，尺寸 1280×720，16:9 横图。

【主题】
[文章核心矛盾，一句话]

【画面主体】
[家电品类 + 核心细节特写]
不使用产品远景全景图，不堆多个产品，优先特写关键部位。

品类对应主体参考：
- 冰箱：保鲜抽屉、内胆分区、食材对比、蒸发器
- 电视：屏幕画质细节、暗场画面、游戏画面
- 空调：出风口、压缩机、室外机、温度计实测
- 油烟机：灶台油烟、吸口距离、滤网、烟道截面
- 洗衣机：滚筒内部、衣物洗后状态、烘干效果对比
- 热水器：管路、花洒水流、循环路径示意

【构图】
[产品主体占画面 50%—70%]
[文字放置位置：左上 / 右上 / 底部色块]
[是否左右对比 / 三分栏 / 剖面图]

【封面文字】
主标题：[6—10 字，从五套公式中选取，必须与文章标题互补不重复]
辅助标签：[最多 1—2 个短标签，可不加]
文字视觉面积 ≤ 画面的 15%—20%，字号控制在"缩略图下勉强可读"的大小，不要占据画面主角位置。

【视觉风格】
真实测评感，家电自媒体专业风格。
不要品牌广告感，不要电商主图感，不要棚拍过度精美感。
高对比配色，背景简洁，文字粗黑体，手机缩略图下清晰可读。
可加入真实测评元素：温度计、分贝仪、手部操作、烟雾、对比实验。

【颜色】
主色不超过 3 种。
- 深蓝 / 深灰：专业科技感
- 红色 / 橙红：风险警示、避坑
- 绿色 / 亮蓝：正确答案、推荐
- 黄色 / 橙色：重点提醒、价格
推荐结构：深色背景 + 白色大字 + 红 / 黄 / 绿重点色块

【禁止项】
不要水印，不要小字堆砌，不要复杂背景，
不要过度精美棚拍，不要官方宣传海报感，
不要产品排排站全景，不要超过 3 种主色。
```

### Step 5：验收检查

生成封面后必须执行以下三项检查，任何一项不合格则修改后重新输出。

**检查一：0.5 秒识别**

快速看一眼，能否马上回答：
- 讲的是哪个家电品类？
- 有什么问题或矛盾？
- 为什么值得点进去看？

三问答不出来 → 重做。

**检查二：缩略图检查**

将封面缩小到微信头像大小，检查：
- 主体还能识别
- 大字还能读
- 对比关系还能看懂
- 色彩还能跳出来

缩小后只剩一团颜色 → 重做。

**检查三：标题互补检查**

检查封面和文章标题是否重复：
- 合格：封面放大核心矛盾，标题完整表达选题，两者互补
- 不合格：封面直接复制标题全文，或者两者传达完全相同的信息

重复 → 调整封面文字，换一个角度表达。

**常见问题修改方向：**

| 问题 | 修改方式 |
|---|---|
| 主体看不清 | 放大主体，裁掉无关背景 |
| 文字看不清 | 减少字数，加粗，加色块底 |
| 不知道讲什么 | 增加品类特写或测试场景 |
| 不够抓眼 | 加强红 / 黄 / 绿对比色 |
| 太像广告 | 增加真实测评感元素 |
| 信息太满 | 只保留主标题，删辅助标签 |

## 三、五种模板快速参考

**模板A：产品特写 + 强观点文字**
- 产品核心细节占画面 50—70%
- 文字放上方或侧边色块中
- 适合：测评、避坑、误区纠正、单品分析

**模板B：左右对比分割图**
- 左侧：错误 / 普通 / 低配 / 问题
- 右侧：正确 / 升级 / 高配 / 结果
- 中间加竖线或 VS 标识
- 适合：横评、反常识、选购对比

**模板C：红绿判断图**
- 左红：错误认知、风险做法
- 右绿：正确判断、核心指标
- 适合：参数纠错、选购指南、真假概念

**模板D：剖面图 / 透视图**
- 只展示一个关键结构
- 箭头粗，标注少，颜色区分路径
- 适合：技术拆解、管路分析、风道结构

**模板E：三分栏风险图**
- 横向三栏，每栏一个场景或风险
- 底部一个总结论
- 适合：X 个坑、X 类户型、X 种风险

## 四、ChatGPT 封面风格指南（v2.2 · 基于电视vs油烟机封面实测）

> **核心发现**：ChatGPT 生成封面的能力不是均匀分布的。信息图/场景叙事风格远优于真实照片/精细视觉对比。

### ChatGPT 擅长的风格（优先选用）

| 风格 | 说明 | 成功案例 |
|------|------|---------|
| **信息图/扁平设计** | 三段式/分层/阶梯式数据可视化，ChatGPT 渲染精准 | MiniLED三价位段全景图（CTR数据好） |
| **单场景叙事** | 一个清晰的故事场景，主体+背景+情绪三要素即可 | 电视挂墙安全隐患图（裂缝+空心砖+危险感） |
| **结构化标签** | 产品参数卡、规格对比卡、标签式信息展示 | 三机参数卡 |

### ChatGPT 不擅长的风格（避免使用）

| 风格 | 问题 | 失败案例 |
|------|------|---------|
| **"真实照片"** | ChatGPT 无法渲染逼真的家电实物照片，提示词写"realistic photo"出来的画面假 | 油烟机封面被评价为"丑" |
| **精细视觉对比** | 左右两侧的细微差异（如油烟扩散程度）ChatGPT 渲染不出区别，两侧画面几乎一样 | 油烟机三种方案左右对比图失败 |
| **动态效果展示** | 油烟流动、水雾扩散、风吹效果等动态场景，静态图无法呈现差异 | 吸烟距离对比图效果差 |

### 提示词风格关键词替换

| ❌ 不要写 | ✅ 应该写 |
|----------|----------|
| realistic photo / 真实照片 | infographic style / 信息图风格 |
| detailed product shot | flat design / 扁平设计 |
| showing the difference between | labeled comparison / 标注式对比 |
| photorealistic rendering | clean modern infographic |

### 模板选择建议（基于 ChatGPT 能力）

| 模板 | ChatGPT 可靠性 | 备注 |
|------|--------------|------|
| **A：产品特写+小标签** | ⭐⭐⭐⭐⭐ 最稳 | 单主体+信息图风格，ChatGPT 最强组合 |
| **B：左右对比** | ⭐⭐ 有风险 | 仅当左右差异极其明显时可用（如 OLED黑 vs LCD灰），精细差异必翻车 |
| **C：红绿判断** | ⭐⭐⭐⭐ 可靠 | 色块对比ChatGPT能做好 |
| **D：剖面图** | ⭐⭐⭐⭐ 可靠 | 结构图+箭头+标注，ChatGPT擅长 |
| **E：三分栏风险** | ⭐⭐⭐ 一般 | 三栏场景如果需要精细渲染可能不稳定 |

**默认选 Template A，除非文章类型强制要求其他模板。**

## 五、执行口诀
