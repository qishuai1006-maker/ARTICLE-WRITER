## 二、开机前5个必查项操作步骤 + 判断标准

### 【检查①】室外机环境检查

**步骤：**
1. 断电后目视检查支架是否锈蚀、松动（重点：安装超5年的支架）
2. 清除机器周围杂草、杂物，确保进风/出风口畅通（至少留50cm间距）
3. 检查排水管出口是否被堵（接雨水槽/绿化带最易堵塞）

**判断标准：**
- ✓ 支架无明显锈斑、无松动晃动
- ✓ 外机周围无遮挡，散热片可见、无大面积积灰
- ✓ 排水管出口通畅，朝下无折弯

> 警示案例：支架锈断→外机坠落事故（2024年夏季多地见报）

---

### 【检查②】室内机滤网 + 蒸发器检查

**步骤：**
1. 打开面板，取出滤网（通常两侧有卡扣，向外抽出）
2. 用清水冲洗滤网，正反面都要冲净
3. 手电照射蒸发器翅片，检查有无霉斑（黑色/黄绿色斑点）
4. 闻出风口是否有霉味、酸味（滤网霉变的直接信号）

**判断标准：**
- ✓ 滤网干净，无明显灰尘结块
- ✓ 翅片白色/银白色，无霉斑
- ✓ 出风无异味

**处理方案（有霉斑）：**
购买"空调蒸发器清洗剂"（含杀菌成分），对准翅片喷洒，15分钟后开制冷模式自清洁15分钟，重复2-3次。

---

### 【检查③】首次通电 → 压缩机启动监听

**步骤：**
1. 设定制冷模式，温度调至最低（18℃），风速最大
2. 站在外机旁（约1米），听压缩机启动声
3. 观察外机风扇是否顺畅启动（约10-15秒内达到全速）

**判断标准：**
- ✓ 压缩机"嗡"一声平稳启动，无明显金属摩擦声
- ✓ 外机风扇启动无异响、无明显振动
- ⚠ 异常症状：
  - 压缩机"吭吭"反复启动不运转 → 压缩机卡缸，需报修
  - 风扇转速明显变慢/颤抖 → 电机或电容问题

---

### 【检查④】制冷效果测试（设定18℃，运行15分钟）

**步骤：**
1. 关闭门窗，确保房间密封
2. 用温度计（或手机APP+蓝牙温湿度计）测量出风口温度
3. 运行15分钟后记录出风口温度读数

**判断标准（国标GB/T 7725规定）：**
- ✓ 出风口温度应降至 **12-16℃**（环境温度30℃条件下）
- ✓ 室内温度应明显下降（约2-5℃，视房间大小而定）
- ⚠ 异常症状：
  - 出风口温度 >20℃：制冷剂不足或压缩机不工作
  - 温度不降反升：可能是四通阀串气
  - 管路结霜：制冷剂过量或蒸发器堵塞

---

### 【检查⑤】运行30分钟后综合检查

**步骤：**
1. 手摸连接管路（粗管=回气管，细管=供液管）：
   - 回气管（粗）应凉且有凝露
   - 供液管（细）应温热
2. 检查室内机下方是否漏水
3. 听室内机运行噪音（是否有明显振动或嗒嗒声）

**判断标准：**
- ✓ 两根管温差明显，无结霜
- ✓ 内机下方干燥，无水滴
- ✓ 运行噪音 ≤45dB(A)（1米距离测量）

## 三、不做检查直接开的典型损失案例

### 案例1：压缩机烧毁
- **场景**：停用8个月后直接开最高制冷
- **故障**：压缩机卡缸导致电机过流烧毁
- **维修费**：压缩机更换 **800-2000元**（1.5匹）
- **对比**：开机前检查+简单处理 **0元**

### 案例2：冷凝水倒灌损坏墙面/地板
- **场景**：滤网堵塞+排水管堵塞同时发生
- **故障**：内机冷凝水溢出，浸湿墙面和木地板
- **修复费**：墙面刷新500-1500元，地板修复1000-3000元
- **对比**：清洗滤网（0元）+ 疏通排水管（约100元）

### 案例3：滤网/蒸发器霉变引发呼吸道问题
- **场景**：霉变空调吹出含霉菌孢子的空气
- **后果**：过敏、咳嗽、甚至肺部感染（军团菌感染案例见诸医疗文献）
- **解决**：彻底清洗+更换，费用约150-300元
- **注意**：体质敏感者、婴幼儿家庭尤其要重视

## 五、空调"自清洁"功能实测效果评估

| 品牌/技术 | 原理 | 实测效果评估 |
|----------|------|------------|
| 美的 第四代智清洁 | 凝霜→融霜带走灰尘 | 去除普通灰尘有效，霉斑基本无效 |
| 美的 56°高温自清洁 | 蒸发器加热至56℃持续30min | 对大肠杆菌、金色葡萄球菌有效率>99% |
| 格力 56°C净菌自洁 | 同上 | 除菌效果接近，但翅片深处仍有残留 |
| 海尔 内外机自清洁 | 内机56°C+外机反转除尘 | 外机反转除尘效果明显，减少散热片灰尘 |
| 华凌 56°自清洁 | 同上 | 效果同格力/美的同类技术 |
| 小米 内外机自清洁 | 烘干+高温 | 对普通灰尘有效 |
| TCL 58°C自清洁 | 略高于56° | 略优于56°型，但差距不大 |

**结论：**
- ✓ 自清洁可以替代"灰尘层面"的日常维护（每年1-2次）
- ✗ 自清洁无法替代"霉斑层面"的手动刷洗（有明显霉斑必须手动处理）
- ✓ 内外机双自清洁（海尔/小米部分型号）比单纯内机自清洁更有价值
- 建议：即使有自清洁，建议每年深度清洗1次蒸发器翅片

## 九、真正的差距在非电费项

### 差异①：制热能力——低温环境下差距最明显

**老一级痛点：**
- 低温（≤-5℃）制热衰减严重，制热量可能下降30-40%
- 压缩机低频运行能力差，频繁启停，室温波动大（±2-3℃）
- 部分老一级无电辅热，-10℃以下基本无制热能力

**新一级优势：**
- 搭载变频直流压缩机，低频运行稳定（部分机型可至15Hz）
- 冷媒环/凉芯桥技术（美的/海尔）支持 -35℃~60℃宽温域运行
- 低温制热衰减极小（多数品牌-15℃仍能维持80%以上制热能力）
- 温控精度±0.5℃，室温波动小

**实测参考（消费者报道/评测数据）：**
- 格力云锦三代：-15℃环境，制热能力保持85%以上
- 华凌N8HE1Pro：-10℃环境，额定制热能力基本不衰减
- 老一级典型（APF=3.6）：-5℃时制热衰减明显，-10℃接近无效

---

### 差异②：噪音表现

| | 老一级典型 | 新一级典型 |
|--|---------|---------|
| 睡眠档噪音 | 28-35 dB | 18-25 dB |
| 最高风量 | 40-48 dB | 35-42 dB |

**新一级噪音更低的原因：**
- 全直流风机电机（无刷电机 vs 有刷电机）
- 压缩机变频化（无固定频率"嗡嗡"声）
- 风扇叶形优化，减少风切声
- 隔音棉用量更多（整机重量更重）

---

### 差异③：温控精度

| | 老一级（毛细管） | 新一级（电子膨胀阀） |
|--|--------------|----------------|
| 温控精度 | ±1.5~2℃ | ±0.5℃ |

> 体感和适人群：±2℃会让敏感人群感到忽冷忽热，±0.5℃基本感受不到温度波动。适用于婴幼儿、老人、睡眠敏感者。

## 十一、二手房/租房场景决策建议

### 场景1：租房/短住（1-2年内搬家）
- **建议：不换**
- 理由：老一级（APF=3.6）vs 新一级（APF=5.3）电费差每年约¥61，设备差价回本需要6年以上，租期内无法回本
- 替代方案：入住前做一次深度清洗（约¥150），够用

### 场景2：自购二手房，装修重做
- **建议：换**
- 理由：老一级机型普遍使用8年以上，压缩机寿命已消耗大半；换新一级不仅省电，制热/噪音/温控体验全面提升；能效标识投诉多（部分老一级实际APF不达标）

### 场景3：现有老一级（2013年前购买），已使用超8年
- **建议：优先换**
- 理由：压缩机寿命通常10-12年，8年以上维修概率急剧上升；新一级比修一次老机更划算（一次大修≈¥800-1500）

### 场景4：出租房配置（房东视角）
- **建议：选新三级或便宜的新二级**
- 理由：租客不care能效，采购成本低才是核心；推荐格力三级能效（品牌认知度高，维修体系完善）
