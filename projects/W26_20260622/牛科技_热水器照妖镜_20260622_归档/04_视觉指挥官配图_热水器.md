## 生成与核对流程

1. `notebooklm create "牛科技_热水器_照妖镜_配图_20260622"` → 记下 notebook ID
2. `notebooklm source add` 投喂 03 终稿（让 notebooklm 有热水器上下文，降低乱编概率）
3. `notebooklm use <id>` 切到新笔记本
4. `notebooklm generate infographic "<description>" --orientation landscape --detail detailed --style professional --language zh_Hans --wait`（×2）
5. `notebooklm download infographic <output.png>` 落盘到本目录（×2）
6. 每张 `sips -g pixelWidth -g pixelHeight` 验尺寸 ≥1920×1080
7. 核对：description 里写死的文字（±5/±3/±0.5、水量伺服器、10层以下）有没有被 notebooklm 篡改（主控无 vision，靠 source 零型号/零价格降险 + CEO 肉眼复核）
8. 全部落盘 → `python3 Scripts/validate_visual_outputs.py outputs/牛科技_热水器_20260622`
9. validate 通过 → 回填正文占位符为真实图引 + 更新本表状态列
