# 02b 轻量证据卡：客厅风管机 vs 柜机

项目：北北ks_空调_20260623
对应正文：03_风控终稿_空调.md

## 可直接使用的证据

1. 风管机是一拖一大功率内机藏吊顶，适合客厅要颜值又不想全套中央空调。
   - 来源：家电知识库 L1《空调》
   - 可用位置：正文、封面、信息图
   - 置信度：高

2. 柜机适合大客厅/餐厅，优势是风量大、循环距离远、安装维护路径更直接。
   - 来源：家电知识库 L1《空调》+ L4《空调》
   - 可用位置：正文、信息图
   - 置信度：高

3. 风管机方案要提前确认吊顶、检修口、回风口、排水、安装配合。
   - 来源：格力官网搜索片段 + 01c外部检索 + 安装逻辑
   - 可用位置：正文、信息图
   - 置信度：中高

4. 客厅空调路线的核心不是“谁高级”，而是“谁适合你家装修阶段、预算、层高、动线和维护偏好”。
   - 来源：01c综合判断
   - 可用位置：正文、封面、信息图
   - 置信度：中高
