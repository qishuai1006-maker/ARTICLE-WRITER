# 02b_轻量证据卡_冰箱

## 标题

给家里换冰箱别只看容量，法式十字对开门差距，用三个月才懂

## 主证据对象

冰箱门体结构决定家庭日常使用体验：取放路径、横向空间、冷冻格局、单次开门冷量流失、厨房安装适配。双系统/双蒸发器决定防串味的结构底线，零嵌散热和预留尺寸决定能不能真正塞进橱柜。

## 可写硬事实

1. 法式四门：上部冷藏横向空间完整，下部多为冷冻抽屉，适合普通家庭和大件冷藏。
2. 十字门：分区更细，适合母婴、熟食、生食、药材、辅食等精细分储。
3. 对开门：左冷冻右冷藏，横向单格偏窄，开门时暴露面积更大；适合狭长厨房或习惯明确的人，不宜作为多数家庭默认答案。
4. 双系统/双蒸发器：冷藏、冷冻制冷路径更独立，比只写“双循环”的单系统方案更能降低串味风险。
5. 零嵌不是单纯看薄，必须看散热方式、整机厚度、宽度预留和门能不能打开。
6. 3500 元以上、在意串味的家庭，优先看双系统；客餐厅一体尽量看低噪音。
7. 冷冻能力用 kg/12h 判断，不要只看冷冻室多少升。

## 可提及型号与边界

| 型号/系列 | 可用作用 | 边界 |

| 容声 556 战神 | 入门双系统例子 | 不写实时价；不做唯一推荐 |

| 海尔 503 云溪 | 海尔保鲜/双系统例子 | 同配置偏贵，不硬推 |
| 美的 555 | 制冰功能热度例子 | 版本命名复杂，不让用户照抄下单 |
| 东芝 548 | 保鲜/自动制冰/平嵌例子 | 售后网点不如国产密 |
| 海尔 630 云溪MAX | 大容量零嵌例子 | 宽度要求高，小厨房不适合 |

## 禁写内容

- 不写“对开门绝对不能买”。
- 不写“某型号当前最低价”。
- 不写“完全不串味”“唯一正确答案”。
- 不暴露内部资料、手册、知识库名称。
- 不把电商平台登录受限页面当证据。

## 信息图可上图事实

- 门体三选一：法式门 = 大件好放；十字门 = 分区更细；对开门 = 格子窄、看场景。
- 下单前 5 条死线：门体、双系统、零嵌尺寸、冷冻能力、噪音。
- 可用数字：500L、550L、600L、600mm、594mm、5kg/12h、36dB、38dB。

## 风险降级表达

- “多数家庭更适合”替代“必须买”。
- “更稳妥”替代“唯一”。
- “容易出现”替代“一定会”。
- “预算紧或场景特殊可以接受”替代“不能买”。
