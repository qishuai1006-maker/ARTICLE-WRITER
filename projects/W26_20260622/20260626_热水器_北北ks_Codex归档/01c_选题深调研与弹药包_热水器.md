## 1. 选题判断

### 读者决策任务

装修或换机前，判断自家燃气热水器到底买 13L 还是 16L；尤其是一厨一卫、一厨两卫、北方冬季、顶喷花洒、厨房卫生间可能同时用水的家庭。

### 决策威胁

- 升数买小：冬天进水温度低，出热水量下降，厨房一开热水，洗澡端可能水量变小、温度波动。
- 升数买大：一厨一卫、普通花洒、用水距离短的家庭可能多花钱，且还要看燃气表、安装空间和排烟条件。
- 只看人口数：容易漏掉花洒流量、同时用水点、冬季温升、燃气表最大流量。

### A1 选题自审

- 15字点击钩子：13升16升别乱选
- 高意图人群：正在装修、旧机换新、准备买燃气热水器的家庭用户
- 首屏冲突：大家以为“几口人”决定升数，实际抢水的是花洒、厨房龙头、冬天进水温度和燃气表。
- 反常识判断：升数不是储水量，是温升 25℃ 条件下的每分钟热水能力。
- 收藏死线：下单前查同时用水点、花洒流量、冬季进水温度、燃气表、安装/排烟条件。
- 评论触发：你家 13L 够不够？厨房一开热水，浴室会不会变凉？
- 结论：PASS。

## 3. 参数翻译表

| 参数/词 | 用户容易误解 | 翻译成人话 | 购买后果 |
|---|---|---|---|
| 13L / 16L | 以为是储水量，或按人口数选 | 指标准温升下每分钟能产多少热水，不是水箱有多少水 | 冬天进水冷、花洒大、两处同时用水时，13L 可能不够稳 |
| 温升 25℃ | 觉得标称升数任何季节都一样 | 标称是把水升高 25℃ 的能力，进水越冷，达到同样出水温度时实际流量越小 | 北方冬天更容易觉得水小、温度不稳 |
| 花洒流量 | 只看“几口人” | 普通花洒 6-10L/min，顶喷 8-15L/min，花洒越大越吃热水能力 | 豪华顶喷配小升数，可能水流不爽 |
| 同时用水点 | 觉得一个卫生间就够 | 厨房龙头、洗手池、浴室花洒可能同时要热水 | 一开厨房，浴室变凉或水变小 |
| 水量伺服器 | 看到“恒温”就信 | 主动调进水量，配合燃气阀控温，比单纯比例阀更稳 | 多点用水时更不容易忽冷忽热 |
| 燃气表 | 很少下单前确认 | 升数越大，对燃气供给也有要求 | 表不够、气源不匹配，可能水不热或安装受限 |
| 零冷水 | 以为能解决所有忽冷忽热 | 零冷水主要解决管路冷水等待，不等于升数更大或恒温更强 | 没回水管盲装，可能费气、冷水管变热 |
| 强排/平衡式 | 只看价格和升数 | 强排常装厨房/阳台；浴室内安装要看平衡式等条件 | 装错位置是安全风险，不是体验小问题 |

## 4. 核心观点候选

1. 13L 和 16L 的差距，不是“多 3 升水”，而是冬天、多点用水、顶喷花洒时的余量。
2. 一厨一卫普通花洒，13L 不一定不能用；但只要有两处同时用热水、冬季进水冷、顶喷花洒，16L 更稳。
3. 升数不是唯一指标，水量伺服器、下置风机、燃气表、安装排烟条件也要一起看。
4. 零冷水不解决升数问题；它解决的是管道冷水等待，没回水管要谨慎。
5. 北北ks 语气要落到“家里洗澡别吵架”：厨房洗碗、浴室洗澡、老人孩子怕忽冷忽热。

## 6. 用户痛点

- 新房装修时预算不想浪费，但怕装完水量不够。
- 北方冬天洗澡时，水流变小、温度变低。
- 家里有人洗澡，厨房洗碗一开热水，浴室端就不舒服。
- 买了大顶喷，水流不够，花洒体验变成“摆设”。
- 导购说 13L 够一家三口，但没问用水点和进水温度。
- 看到零冷水、恒温、增压、一级能效，分不清哪个和升数有关。
- 老小区/高楼低层水压低，还没看增压。
- 燃气表、气源、安装排烟不确认，买完才发现装不了或效果打折。
