## 四、文章骨架清单

### 文章A · 牛科技 ·「1.5匹空调，1000块和3000块差距在哪？冬天才是照妖镜」

**人设**：做空调安装维修10年的老师傅
**文章类型**：选购横评型
**信息密度**：每100字≥4信息点
**字数**：≥1500字

**骨架**：
1. **开头**（场景代入式）：冬天开空调，屋里就是不暖和——这事儿我装了10年空调，太清楚了。[开场模式：场景代入]
2. **核心论点**：夏天1000块的空调也能凉快，冬天才是照妖镜
3. **价位段1：1000-1500元（入门级）**
   - 硬件拆解：8.9cc小排量压缩机 + 毛细管 + 单排铜管
   - 冬季表现：-5℃制热保留率仅45-65%，几乎靠电辅热死撑
   - 电费账：电辅热COP=1.0，1度电=860kcal，开一小时多耗1度电
4. **价位段2：1500-2500元（主流级）**
   - 硬件跃升：10.3cc双转子 + 电子膨胀阀 + 双排铜管
   - 冬季表现：-10℃保留率50-65%，化霜频率低、室温波动小
   - 关键差异：电子膨胀阀比毛细管只多花80-150元，但省电10-15%
5. **价位段3：2500-3500元（高端级）**
   - 硬件满配：10.8-11.8cc大排量 + 增焓技术 + 无电辅热
   - 冬季表现：-10℃保留率70-85%，华凌Ultra在-15℃仍能热泵制热
   - 独家信息差：压缩机"性能封印"——国产空调故意限制性能至70-80%
6. **化霜体验对比**：入门级每45分钟化霜一次→室温降3-5°C vs 高端级不停机化霜→波动≤1°C
7. **选购建议**：
   - 南方仅夏季用：1500-2000元够用
   - 北方/冬季制热刚需：2000-3000元档性价比最高
   - 极寒地区（-15℃以下）：必选增焓或日系
8. **结尾**（判断式收尾）：冬天制热能力是空调硬件底子的终极检验。[收尾模式：判断式]

**代表机型验证要求**：
- 入门级：美的省电星/奥克斯省电侠/小米巨省电 → 至少1款有详细参数
- 主流级：华凌HE1 Pro/美的酷省电Pro → 核心对比对象
- 高端级：美的风尊Pro/小米强劲风/华凌Ultra → 制热之王候选

### 文章B · 牛科技说 ·「新风空调拆机实录：多花的2000块到底买了什么」

**人设**：家电拆解测评博主，拆过上百台空调
**文章类型**：选购横评型
**信息密度**：每100字≥4信息点
**字数**：≥1500字

**骨架**：
1. **开头**（反常识式）：拆了20多台新风空调，发现一个扎心的事实——多花的2000块，硬件成本可能不到400块。[开场模式：反常识]
2. **新风模块BOM拆解**：
   - 离心风机：35-85元（决定新风量上限）
   - 全热交换芯：90-180元（有/无是核心分水岭）
   - HEPA滤网：20-45元（每6个月换一次，年成本100-300元）
   - 风道+降噪件：25-55元
   - 穿墙风管：10-25元
   - **合计**：180-390元纯BOM → 终端溢价1000-2000元
3. **真新风 vs 弱新风**：
   - 格力云舒氧：双向流+全热交换，热回收效率65-70% → 真新风
   - 美的/小米/TCL/海信：微正压单向流，无热回收 → 弱新风
   - 冬季实测：弱新风开新风=给室内灌冷风，制热能耗增加10-15%
4. **新风量标称陷阱**：
   - 标称60m³/h → 实测仅51-54m³/h（衰减10-18%）
   - 免打孔工况下更惨，仅为标称的60%
   - 新风风机最大风量档噪音>40dB → 影响睡眠
5. **新风对制热/制冷效率的实际影响**：
   - 无全热交换：制热量下降5-10%，能耗增加15-20%
   - 有全热交换：制热量下降2-5%，能耗增加5-10%
   - 结论：弱新风=高能耗换气扇
6. **各品牌新风空调性价比对比**：
   - 小米：价差仅112元（性价比之王）
   - 格力：价差932元但技术领先一代
   - 华凌/奥克斯：入门新风，新风量≤40m³/h
7. **选购建议**：
   - 预算有限选小米（+112元即享新风）
   - 追求真新风选格力云舒氧（双向流+全热交换）
   - 不推荐弱新风（冬天拉低室温，不如开窗）
8. **结尾**（警示式收尾）：如果你家冬天要开制热，弱新风就是花钱买罪受。[收尾模式：警示式]

**代表机型验证要求**：
- 格力云舒氧、TCL小蓝翼、小米新风Pro → 真新风/弱新风判定
- 全热交换效率数据 → 需交叉验证
- 新风量实测数据 → 豆包+Gemini双源
