## 三、技术原理深度素材

### 3.1 两种光路完整路径

**SQD Mini LED 光路（减法光学）**
```
白光LED芯片 → 发出全光谱白光 → 穿越超级量子点膜 → 蓝光激发量子点释放窄频RGB光
→ 超级蝶翼华曜屏/高色阻层二次过滤 → 光谱收敛 → 液晶面板调制 → 人眼
```
- 核心：先产生包含所有光谱的高能白光，再通过过滤"减去"不需要的波段
- 量子点膜是色彩灵魂，整个系统依赖这层化学发光材料
- 控制逻辑："光与色分离"——背光芯片只控明暗，色彩由量子点膜被动完成

**RGB Mini LED 光路（加法光学）**
```
R芯片(红) + G芯片(绿) + B芯片(蓝) + 天青芯片(青) → 四色独立发光
→ 直接物理混光 → 无需量子点膜 → 液晶面板调制 → 人眼
```
- 核心：不同颜色的微小光源按比例直接合成目标色彩，没有过滤带来的能量浪费
- 无量子点膜依赖，色彩完全由半导体发光芯片控制
- 控制逻辑："光色同控"——H7芯片同时对每个分区内四颗芯片的功率独立实时调节

### 3.2 两大核心差异矩阵

| 维度 | SQD（减法光学） | RGB（加法光学） |
|------|----------------|----------------|
| **哲学本质** | 过滤提纯（从白光中筛出色彩） | 物理混光（从无到有合成色彩） |
| **光路复杂度** | 长（LED→QD膜→色阻→液晶） | 短（LED直出→液晶） |
| **光效损耗** | 较高（蓝光转换损耗约30%） | 低（无转换损耗） |
| **控制维度** | 二维：分区+亮度（光色分离） | 三维：分区+亮度+色彩（光色同控） |
| **峰值亮度上限** | 更高（单灯白光能量集中，6000-10000nits） | 稍低（多芯片散热受限，5000-5300nits主流） |
| **色准上限** | ΔE<0.99（专业级） | ΔE<0.7（监视器级） |
| **色域天花板** | 100% BT.2020 | **110% BT.2020**（玲珑4芯） |
| **功耗** | 较高 | 较低（约省30%） |
| **有害蓝光** | 标准 | 降低42-60%（物理级规避） |
| **护眼方式** | 软件降蓝光（调黄画面） | 硬件级（发光源即无有害波段） |

### 3.3 海信"玲珑4芯"天青色芯片解析

- **问题**：传统LED在480-520nm波段存在"青色断层"，自然界天空渐变、海洋色彩难以精准还原
- **方案**：在RGB三色基础上加入第四颗独立天青色（Cyan）发光芯片
- **效果**：
  - 色域从100% BT.2020突破至110% BT.2020
  - 在10.7亿色基础上额外解锁1.2亿种极限色彩
  - 来源：新华网、新浪科技、凤凰科技 CROSS_VERIFIED
- **物理意义**：这是从"三原色混合模拟青色"进化到"原生青色直出"，不再是数学近似，而是物理真色

### 3.4 两大技术争议焦点

**争议1：量子点材料长期可靠性**
- RGB阵营：SQD依赖的量子点材料存在"怕热怕湿"问题，传统量子点寿命5-8年衰减严重
- SQD阵营：新一代极彩量子晶体已从分子结构层面克服，TCL测试30000小时衰减<5%
- 裁定建议：两者各有数据支撑，文章中应客观呈现双方观点，不做站队判断

**争议2：RGB三色衰减不一致**
- SQD阵营：RGB三色LED因物理材质不同，热衰减曲线极不一致（尤其红光芯片），长期使用后偏色
- RGB阵营：海信采用车规级LED，理论寿命16万小时，并通过H7芯片实时校准补偿
- 裁定建议：两者都是真实技术挑战，文章中呈现为"行业待解之题"
