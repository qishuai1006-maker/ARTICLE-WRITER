### 3.2 关键达人观点提炼（按互动量排序）

> 注意：根据CLAUDE.md v5.1规定，正文禁止引述抖音达人。以下观点用于洞察用户痛点，正文中内化为独立判断。

**TOP 1：Mini LED选购类（互动量最高达6.6w赞）**
- 核心诉求：怕买到参数虚标产品、需要「内行人话术」
- 高频话术：Mini LED > OLED（性价比）、分区数硬指标、真4K鉴别
- **洞察**：消费者对技术分化(分区效率差异)已有模糊认知，但无法区分SQD和RGB

**TOP 2：RGB Mini LED导购类（互动量4.7w赞）**
- 核心诉求：RGB被视为「高端选择」
- 高频话术：「RGB Mini LED属于给白色发光体直接换成三色RGB发光，要啥色来啥色」
- **洞察**：RGB的营销渗透很成功，消费者认为RGB=更高端

**TOP 3：SQD技术科普类（互动量3.4w赞）**
- 核心诉求：技术对比解密
- 高频话术：「一个分区顶三个用」「2952个万象分区=8856个普通RGB分区」「记住咱要的是全局不是局部」
- **洞察**：消费者对分区效率(1灯1区 vs 3灯1区)的关注度极高，这是SQD的核心传播点

**TOP 4：SQD技术下放普及类（互动量未核实）**
- 核心诉求：SQD从旗舰下放至Q10M让更多人买得起
- 高频话术：「SQD技术从X11L下放到Q10M，100% BT.2020全局高色域」
- **洞察**：技术下放的速度是消费者最敏感的决策信号

## 四、核心技术数据速查表（SQD vs RGB 完整参数对比）

### 4.1 技术参数对比

| 维度 | SQD-Mini LED（TCL主导） | RGB-Mini LED（海信/索尼主导） |
|------|------------------------|---------------------------|
| **全称** | Super Quantum Dot Mini LED | RGB三色直出Mini LED |
| **发光原理** | 蓝光LED → 超级量子点层 → 白光 → 液晶面板 | R/G/B(/Cyan)三/四色芯片独立直发 → 混合 |
| **光学哲学** | 减法光学（先发全光谱白光，再过滤提纯） | 加法光学（不同色光按比例混合） |
| **量子点依赖** | 核心依赖（系统的色彩灵魂） | 完全不需要（物理切除量子点层） |
| **背光控制逻辑** | 光色分离：只控明暗，色彩被动 | 光色同控：同时控制亮度和色彩 |
| **单分区灯珠数** | 1灯 = 1区（最高效率） | 3灯 = 1区（3倍灯珠才1区） |
| **旗舰分区数** | 20,736（X11L 98"） | 43,008（UX2026 116"） |
| **旗舰峰值亮度** | 10,000 nits（X11L） | 5,300 nits（E8S）/ 约8,000 nits(UX) |
| **BT.2020色域** | 100%（全局稳定） | 100%-110%（局部/四芯可超100%） |
| **色准ΔE** | <0.99 | <0.7 (海信E8S Pro) |
| **面板** | CSOT华星HVA屏/WHVA 2.0 Ultra | 黑曜屏Pro(改良广视角) |
| **原生对比度** | 7,000:1 (HVA) | 约5,000-6,000:1 |
| **刷新率** | 144Hz (兼容300Hz) | 原生180Hz (兼容330Hz) |
| **控光芯片** | TSR AI + 伏羲大模型 | 信芯AI H7 Pro (134bit) |
| **典型功耗** | 较高（蓝光→量子点转换有损耗） | 省电约30% (无转换损耗) |
| **有害蓝光** | 依赖软件层降蓝光 | 硬件级降低42-60% |
| **环保** | 量子点含镉（新一代向无镉演进） | 无量子点层，无镉 |
| **核心优势** | 亮度天花板、暗场纯净、全局色域稳定、抗光强 | 色彩原生、色准高、低功耗、护眼、无量子点衰减 |
| **核心短板** | 功耗高、侧看可视角度略弱、量子点长期衰减争议 | 高亮散热压力大、暗场依赖算法、串色风险(Display Week) |
| **对芯片算力要求** | 中等（主要算明暗灰阶） | 极高（需实时计算RGB四通道混合比例） |
| **面板自主权** | 自有华星光电(CSOT)，全产业链垂直整合 | 对外采购面板为主 |
| **主力价位(85寸)** | X11L ¥29,999 / QM7L(待确认) | E8S补贴后¥14,999 / E7S Pro ¥11,499 |

### 5.2 供应链站队分析

```
SQD 阵营上游支持者（TCL生态内）：
  ├── 华星光电 (面板+背光 → 100%绑定TCL SQD)
  ├── TCL自研量子点材料 (量子点膜 → 独家供应)
  └── 部分中小封装厂 (SQD白光封装门槛低，供应充足)

RGB 阵营上游支持者（海信+三星+索尼共同拉动）：
  ├── 兆驰股份 (LED芯片 → 海信主供)
  ├── 国星光电 (LED封装 → 海信/TCL双供，RGB增速快)
  ├── 晶科电子 (LED芯片+封装 → 海信主供)
  ├── 芯瑞达 (背光模组 → 海信/创维)
  ├── 翰博高新 (背光组件 → 海信/小米)
  ├── 京东方/友达/群创 (面板 → 适配RGB背光)
  └── 三安光电 (LED芯片 → 多客户)

关键判断：
  → SQD供应链 = TCL垂直整合的「封闭花园」，效率极高但外人进不去
  → RGB供应链 = 多家独立上游厂商共同投资的「开放生态」，参与者越多降本越快
  → 国星光电同时供应SQD和RGB，但RGB出货增速(150-200%)远超SQD
  → 韩系(首尔半导体/LG Innotek)和美系(Cree)也在加大RGB LED芯片投入
```

### 5.3 上游投资方向判断

**对终局的启示**：RGB路线上游参与者数量是SQD的5倍以上。更多的投资主体 = 更快的降本速度 = 更强的产业共识。封闭生态的优势是短期效率，开放生态的优势是长期规模。

### 6.3 LEKIN 专利网络对 Mini LED 路线的影响

**LEKIN是谁**：苏州立琻半导体，2021年从LG Innotek收购了10,000+件美国LED专利。之后通过分拆转让给NPE（非实施实体）发起专利诉讼。

**影响逻辑**：
- LEKIN原属于LG体系，其专利资产主要覆盖蓝光LED + 荧光粉/量子点转换的背光架构 → 这是SQD的技术根基
- LEKIN系NPE(LGI/FairLight)已同时起诉TCL和海信 → 诉讼结果对两边都有影响
- 但专利攻击对SQD路线的威胁更大，因为SQD严重依赖量子点转换技术
- RGB路线因为「物理切除」了量子点层，在LEKIN的专利射程外

**关键引用**：Ideahub (LEKIN管理方) 通过 FairLight 在 2026年2月起诉TCL，声称TCL至少自2021年3月起已知悉相关专利。涉案5项专利中3项来自LEKIN。被控产品包括TCL的LED/QLED/QD-Mini LED全线产品。

> **专栏判断**（需CEO确认）：专利博弈是中长期的慢变量，短期内不会直接改变技术路线。但LEKIN系专利若在2027年前做出对TCL不利的判决，将显著增加SQD路线的知识产权风险溢价。

### 6.4 CTA 全球统一标准的影响

2025年3月26日，美国消费技术协会（CTA，CES主办方）正式发布RGB-Mini LED技术认定标准：

> **核心定义**：只有背光光源的每一个单元均实现红、绿、蓝三色LED独立控制，才能被定义为RGB-Mini LED电视。

**影响**：此标准精准封堵了「双色LED混光冒充RGB」的行业乱象，确立了RGB路线的官方身份。标准的存在降低了消费者认知混乱，加速了RGB路线的市场教育。

### 8.3 成本下降对终局的影响

**SQD的降本天花板**：量子点膜是化学材料，不遵循摩尔定律。即使TCL自有量子点材料工厂，化学合成的降本空间有限。SQD的降本主要靠「面板垂直整合」而非「材料降本」——这是TCL独有的优势，其他品牌无法复制。

**RGB的降本加速度**：RGB LED芯片是半导体，遵循类摩尔定律。当兆驰、国星、晶科、三安等5-6家供方同时扩产，产能翻倍带来的价格下降是指数级的。2026年RGB芯片产能预计增长150-200%（国星光电数据），2027年若再翻番，RGB芯片成本可能降至当前的1/3。

**专栏判断**：如果只看2026-2027，SQD的性价比仍领先（85"中端SQD比同档次RGB便宜约¥4,000）。但如果看2028-2030，RGB的成本下降加速度将远超SQD。

### 9.3 综合推演：三种可能终局

#### 终局A：SQD守住高端，RGB覆盖主流（概率：50%）
```

           RGB在10,000-20,000价位快速扩大份额

           类似手机芯片市场的「大小核」格局
```

```
           类似等离子→液晶的过渡
```

### 9.4 我们的核心判断（写入正文）

基于六大维度交叉分析，我们给出以下预判：

> **2027年，SQD和RGB都不会「终局」。2027年的真实格局是：SQD守住亮度+控光的旗舰天花板，RGB在10,000-20,000元价位段加速渗透。2028-2030年，RGB凭借上游供应链规模效应和参与品牌数量优势，大概率在出货量上反超SQD，成为Mini LED的主流路线——但不是因为RGB技术本身更优秀，而是因为它是一个「开放生态」，而SQD是一个「封闭花园」。**
