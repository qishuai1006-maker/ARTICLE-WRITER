### 迁移计划
- 目标替换品类：**电视（TCL 主牌 + 雷鸟子品牌，Mini LED 路线）**
- 本文需替换的具体证据：
  - 格力6款1.5匹 → TCL/雷鸟后缀体系（T7L Ultra / Q9L / Q9L Pro / Q9M Pro / Q10M + 雷鸟鹤6 / 鹤6 Ultra / 鹤7 Pro）
  - 外机三件套（铜管/压缩机/节流）→ 面板三件套（背光分区 / 峰值亮度 / 面板路线）
  - 循环风量+导风 → 画质芯片 + 刷新率真假 + 无广告
  - 卧室/西晒/老人房场景 → 客厅视距 / 游戏需求 / 采光反光 / 广告容忍
- 我的独家增量/新判断（原文绝没有）：
  1. **万象分区 ≠ 普通分区**：TCL/雷鸟自研方案，与小米/海信的普通分区算法不同，数字不能跨品牌直接比大小（推品手册 L136 明确）
  2. **300Hz 是插帧不是原生**：标注的高刷多为倍频/MEMC 技术，原生刷新率才是游戏真正吃的那一档
  3. **「绚彩XDR 6000nits」是激发峰值**：一瞬间激发，不是你天天看的持续亮度

### 品类适配层（必填）

- **目标品类用户最怕什么**（电视）：
  - 分区数虚标、刷新率数字被骗、同价位买贵、开机广告关不掉、画质不如宣传、买回家发现尺寸不合适
- **目标品类的决策死线**（必须知道的底线）：
  - 背光分区数 500 以下别碰（入门线），1000 是甜点线
  - 游戏党认准**原生**刷新率 120Hz+ / HDMI2.1，别被 300Hz 插帧带偏
  - TCL + 雷鸟 + 华为全系无开机广告；海信 / 小米 / 创维有广告
  - TCL/雷鸟的「万象分区」数字不能拿来和小米/海信的普通分区直接比
- **目标品类的「反常识点」**（原文反转的品类平移）：
  - 原文「后缀越高级、外机三件套其实差不多，钱花在内机体验」
  - → 电视「后缀/参数堆得越高，同面板路线下画质天花板其实差不多，钱主要花在芯片调校 + 亮度峰值 + 无广告体验上」
