## 说明：为什么封面留给后续

NotebookLM 的 `generate infographic` 适合做**信息密度高的结构化信息图**（理解/收藏功能），但**不适合做封面**——封面要的是 0.5 秒视觉钩子（真实场景、主体清晰、低文字密度），NotebookLM 生成的图文字密、偏教学图风格，承担不了头条信息流的点击任务。

封面按配图规范必须走 ChatGPT/Codex 生图模型，或用 `imagegen` skill 的 CLI（需 `OPENAI_API_KEY`）。这两条路我当前都走不通：
- ChatGPT/Codex 生图：我无此工具
- `image_gen.py` CLI：环境未设置 `OPENAI_API_KEY`

**建议**：封面 Prompt 已写好可直接复制，CEO 手动到 ChatGPT 生图，或交 Claude Code 用其 `image_gen` 工具生成后放入 `outputs/zcode/T5_ChatGPT_封面.png`。
