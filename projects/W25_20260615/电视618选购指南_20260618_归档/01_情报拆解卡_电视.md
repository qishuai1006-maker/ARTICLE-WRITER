## 拆解三层

### 第一层：点击（为什么点？）

- **用户的心理反应**："618要买电视，参数太多看不懂，正好有个'销量榜第一'的推荐，省事" → 想要省心的决策捷径
- **最核心的钩子词**：
  - **"今年618买电视"**（时间锚定 + 强购买意图人群）
  - **"别被参数绕晕"**（精准痛点：电视参数确实复杂，分区/亮度/色域/刷新率一堆）
  - **"销量榜第一"**（社会证明 + 从众心理，最强钩子）
  - **"值得看看"**（弱促销，降低防备）
- **驱动力**：**省力（决策捷径）+ 从众（销量第一）+ 时效焦虑（618）**
- **标题机制提炼**：
  - 公式化：`{时间节点}买{品类}，别被{复杂参数/行业术语}绕晕，这台{社会证明}的{品类}值得看看`
  - 核心机制：**场景锚定 + 痛点降维 + 社会证明背书**

### 第二层：阅读（为什么看完？）

- **开头套路（破冰层）**：
  - **场景化切入**：不直接讲产品，从"英超阿森纳夺冠"热点切入 → "球迷看球家里电视没接住精彩画面" → 自然过渡到"画质不行会错失激动时刻"
  - **巧妙点**：用具体场景（看球赛）而非抽象参数开场，让用户先产生"我也有过这体验"的代入感
- **正文骨架类型**：**理论框架 + 单品验证型**
  - 第 1 部分：建立"画质铁三角"理论框架（对比度 / 色域 / 峰值亮度）—— 给用户一个**判断标准**
  - 第 2 部分：用这个框架去评价 TCL T7M Pro（每段 = 一个铁三角维度 × 对应卖点）
  - 第 3 部分：618 价格优势收尾
- **信息释放节奏**：
  - **先立标准 → 再用标准验证产品**——这是软广文最高级的写法：不直接说"这电视好"，而是"教你怎么判断好电视"，然后这电视恰好符合标准
  - 用户在看的过程中已经被"教育"了判断框架，自然觉得"按这个标准它确实值"
- **反转点（隐性）**：
  - 没有显性反转，但有**认知重塑**：让用户从"看品牌/看尺寸"升级到"看画质铁三角"，把 TCL T7M Pro 塑造成"懂行人才选"的标的

### 第三层：收藏/评论（为什么留下动作？）

- **可截图/收藏的干货点**：
  - "画质铁三角"理论（对比度/色域/峰值亮度）——可保存的判断框架
  - TCL T7M Pro 的三个核心参数（背光分区 / 色域 / 亮度数值）
- **容易引发共鸣的槽点**：
  - 看球赛画质翻车 → 体育迷共鸣

## 关键判断：这篇文章的本质与可借鉴度

### 它是软广，不是中立评测
**必须看清**：原文是 TCL 品牌方/带货号的单品种草文，"销量榜第一"是营销话术，"画质铁三角"也是为 T7M Pro 量身定制的框架（刚好 T7M Pro 三项都强）。

### 可借鉴的机制（金子）
1. **场景化开场**（不直接讲产品，用热点/生活场景切入）—— 比参数堆砌的开场强 10 倍
2. **"先立判断标准，再用标准验证产品"**的软广结构 —— 最高级的种草，用户不设防
3. **社会证明钩子**（销量第一/榜单）—— 标题最强武器
4. **痛点降维**（把复杂参数提炼成 N 个维度）—— 让小白也能跟

### 不可借鉴的部分（要警惕）
1. ❌ "销量榜第一"这种未经验证的绝对化营销话术（**广告法风险 + lint 会拦**）
2. ❌ 全篇单品种草（宅研社虽然是个人号，但推品手册要求**型号多样性**，不能通篇一个型号）
3. ❌ 把"画质铁三角"当成客观真理（这其实是厂商话术，可借鉴思路但要重构为更中立的框架）
4. ❌ 原文型号 T7M Pro 在推品手册里**没有收录**（推品手册主推 TCL Q9L/鹤7 Pro/小米 S Mini LED 等），不能照搬
