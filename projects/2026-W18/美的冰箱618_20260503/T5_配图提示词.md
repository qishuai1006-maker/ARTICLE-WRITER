# T5 配图生成提示词

**用途**：美的冰箱618选题《2026年618美的冰箱选购指南》配图生成
**生成工具**：NotebookLM（主力）或 generate_image（降级）

---

## T5_01_封面图

**NotebookLM提示词**：
```
请生成一张《2026年618美的冰箱选购指南》的封面信息图：

【内容要求】
- 主标题（大字）：2026年618美的冰箱选购指南
- 副标题：哪些值得买，哪些是坑，5分钟看懂
- 可添加：国补15%、双系统不串味等关键词标注

【设计要求】
- 风格：科技感、专业、视觉冲击力强
- 配色：深色背景 + 亮色文字
- 可加入冰箱图标、购物车图标
- 语言：全中文
- 尺寸：1920×1080（16:9）
```
