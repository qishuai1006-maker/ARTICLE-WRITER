## 关键教训

### 1. T3 机型选择必须基于 T2 数据库
**问题**：T3 初版选用了美的风观/小米F2A1等型号，这些不在 T2 产品信息库中，导致参数无法核实

**教训**：T3 写手必须严格使用 T2 数据库 verified 机型，不得自行添加未核实型号

**改进**：后续流程中，T2 素材包应产出"文章可用机型清单"，T3 写手只能从中选择

### 2. 后台 Agent 执行不稳定
**问题**：T1/T2/T3 后台 Agent 响应缓慢，部分 Agent 身份混淆

**教训**：复杂多 Agent 任务建议直接主会话执行，避免委托

### 3. 配图生成无法自动化
**现状**：NotebookLM 生图需要手动操作，无法通过 API 自动执行

**建议**：在流程中明确标注"需人工介入 NotebookLM 生图"节点
