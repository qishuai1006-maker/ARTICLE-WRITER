## 六、渠道商实操SOP（可直接引用）

### 6.1 国补申领三步流程

```
第一步：打开京东APP，搜索"领国补855"或"家电攻略888"
第二步：进入对应省市页面，点击领取补贴资格码
第三步：选购一级能效空调，在结算页确认已自动抵扣
```

### 6.2 限时地区抢单SOP

```
1. 提前完成实名认证和银行卡绑定
2. 设置各省市额度更新时间提醒（如山东9:00、青海10:30）
3. 提前10分钟登录系统待命
4. 避开准点更新后的服务器拥堵高峰（约5-10分钟后）
5. 锁定目标产品后立即下单，避免犹豫导致额满
```

### 6.3 极限底价组合方案模板
