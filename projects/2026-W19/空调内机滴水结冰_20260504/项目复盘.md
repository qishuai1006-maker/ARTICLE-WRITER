## 二、致命教训（本次项目）

### 1. T1 选题偏移问题（v5.0 新增教训）
- **现象**：选题情报官连续3次产出错误选题（"开机前检查"而非"滴水/结冰"）
- **根因**：Agent 未能遵循用户原始需求，抖音爆款数据"诱惑"了选题方向
- **处理**：CEO 强制干预，多次发消息要求重做
- **建议**：后续 v5.1 应在 T1 执行前增加"选题方向锁定"步骤，CEO 明确表态后再执行

### 2. NotebookLM Rate Limit 问题（已解决）
- **现象**：T5 执行器多次遇到 NotebookLM infographic API rate limited
- **根因**：Google 账户限额
- **解决方案**：NotebookLM 生成幻灯片 PDF → PyMuPDF 拆分为每页一张 PNG（分辨率2x）
- **注意**：需提前准备降级方案

### 3. 多 Agent 任务边界混乱
- **现象**：选题情报官、内容研究员均尝试执行 T1；T5 分配给多个 Agent
- **根因**：Agent Teams 任务分配机制不清晰，重复执行已废弃的任务
- **处理**：CEO 直接 spawn 专用执行器绕过团队协调
- **建议**：v5.1 改进任务分配策略，每个任务仅分配给一个明确 Agent
