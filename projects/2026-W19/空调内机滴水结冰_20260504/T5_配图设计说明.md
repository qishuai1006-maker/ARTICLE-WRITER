# 空调滴水/结冰故障排查：5张系列信息图设计规格说明书

本说明书由高级家用电器维修顾问与视觉信息设计师联合制定，旨在通过高精度的视觉引导，帮助用户在3秒内识别故障属性，区分“零成本自修”与“专业报修”，杜绝夏季空调维修中的“缺氟骗局”。

---

## 1. 设计总则与视觉规范

*   **设计风格**：工业感实景摄影 + 高级矢量标注。底图采用高分辨率空调内/外机拆解图，标注线使用45度角对齐。
*   **视觉层级（3秒识别原则）**：
    *   **一级层级**：结论勋章（Verdict Badges）。使用全图最大字号的“✅ 极简操作”或“❌ 专业干预”印章式设计，置于各板块右上角。
    *   **二级层级**：核心故障逻辑线。
    *   **三级层级**：技术细节说明（无衬线字体）。
*   **配色逻辑**：
    *   **DIY路径 (#0055FF 科技蓝)**：用于所有用户可自行解决的步骤。
    *   **警示/专业路径 (#FFCC00 警示黄)**：用于涉及拆机、加氟等风险操作。
*   **全图页脚声明**：在图3至图5显著位置标注“专家忠告：空调系统是密封的，正常使用不会无故缺氟。进门直言‘要加氟’多为维修骗局。”

## 2. 图1：核心决策逻辑——三级自查决策树（Funnel Design）

**设计规格**：采用“漏斗式”分层判断逻辑，路径需通过颜色（蓝/黄）进行潜意识引导。

*   **第一层：看现象（初筛）**
    *   分支 A：出风口飘水、喷雾、伴随酸臭味 ——> [关联：滤网脏堵]
    *   分支 B：内机底部漏水、侧边滴水 ——> [进入第二层判断]
*   **第二层：看时间与位置（精确定位）**
    *   **20分钟法则（使用秒表图标）**：开机前10-20分钟正常，随后开始严重漏水 ——> [关联：排水管堵塞]
    *   **20cm法则（使用标尺线标注内机底部）**：漏水集中在单侧约20cm范围内 ——> [关联：安装不平]
*   **第三层：看硬件状态（专业分流）**
    *   拆下面板，观察翅片是否有白霜？
    *   检查室外机连接管：**细管（液管）结霜**？ ——> [关联：系统缺氟/蒸发器结冰]

## 3. 图2：轻度故障——滤网脏堵与安装平衡自检

**设计规格**：强调“20cm范围”的视觉测量感。

*   **模块 A：滤网脏堵 (✅ 极简操作)**
    *   **视觉要求**：展示“脏堵滤网”与“洁净滤网”的高清微距对比图。
    *   **诊断核心**：肉眼可见灰尘封死翅片缝隙。
*   **模块 B：安装不平 (✅ 视觉校准)**
    *   **视觉要求**：在内机上方叠加一个“虚拟水平仪”UI，显示气泡偏向一侧。
    *   **核心指标**：使用**标注尺**画出内机底部漏水最严重的“20cm区间”，解释由于倾斜导致冷凝水溢出水槽的物理原理。

## 4. 图3：中重度故障——排水堵塞与结冰深度解析

**设计规格**：采用左右分屏（Split-Screen）对比排查法。

*   **左屏：排水系统故障 (✅ 简单疏通)**
    *   **关键图标**：秒表图标（标注20分钟）。
    *   **诊断逻辑**：室内机不结霜但漏水严重；检查室外排水管是否出现“U型弯”或管口入水盆导致的“气堵”。
*   **右屏：蒸发器结冰 (❌ 专业干预)**
    *   **核心视觉**：展示内机翅片大面积结白霜的实拍图。
    *   **专家级判定（关键点）**：
        1. 关机后冰融化才产生大量漏水。
        2. **室外机细管（高压管）结霜**：这是缺氟的典型信号。
        3. **对比提醒**：若粗管（气管）结霜，则可能是室内机风速过低或滤网极脏，而非缺氟。
    *   **结论**：严禁自行加氟，需联系专业售后测压。

## 5. 图4：实操手册——零成本DIY步骤与工具箱

**设计规格**：所有工具必须使用**矢量线条画（Vector Line Art）**。

*   **工具箱清单**：旧牙刷（洗滤网）、长毛巾（垫机身）、手持吸尘器（吸排水管）、垫片/硬纸片（调平衡）。
*   **标准操作三部曲**：
    1.  **滤网深洗**：箭头指向扣位，演示“顺着翅片纹路”刷洗。
    2.  **管道疏通**：视觉演示如何用吸尘器或吹风机（冷风）对着排水管口施压，排出淤积物。
    3.  **水平微调（核心视觉）**：使用**半透明/透视图（Ghosted Overlay）**展示内机挂钩背后的结构，示意如何通过在低位侧挂钩处“垫高垫片”来纠正倾斜。

## 6. 图5：终极避坑——专业维修定价参考与防骗术

**设计规格**：制作一份高权威感的“维修避坑参考表”。

| 维修项目 | 合理价格区间 | 避坑Pro Tip (防宰指南) |
| :--- | :--- | :--- |
| **上门检测费** | ￥50 - 100 | 若产生后续维修，此费用通常应包含在内。 |
| **深度清洗** | ￥120 - 200 | 必须包含风轮和接水盘清洗，只洗滤网是忽悠。 |
| **加氟 (R32/R410a)** | ￥150 - 400 | 按压计费或按台计费。**进门不测压直接说缺氟的百分百是骗子。** |
| **排水管更换** | ￥80 - 150 | 仅限外露部分。若需拆墙，价格另计。 |

*   **必须叫师傅的三大界限**：
    1. 观察到外机细管结霜且制冷无力（确认系统泄漏）。
    2. 排水管预埋在墙体内且简易疏通无效。
    3. 控制面板弹出故障代码（如E1/F1等），涉及电路主板。

*   **设计师特别标注**：底部使用醒目的亮黄色底块加黑字，重复“系统密封，不会无故缺氟”的专家警示。
