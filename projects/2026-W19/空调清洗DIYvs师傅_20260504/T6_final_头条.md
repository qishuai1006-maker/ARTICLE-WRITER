### 这钱到底该花不该花？先看结论

空调清洗，150元叫师傅还是30元自己搞定？

答案不是非此即彼。关键看你空调的使用年限和当下的状态。

**给你一个判断标准：3个条件满足任意1个，直接叫师傅；其余情况，DIY更划算。**

哪3个条件？

条件一：空调使用超过3年，从未做过深度清洗
条件二：空调已经出现明显异味、制冷效果变差、或者有异响
条件三：空调是变频挂机超过10年、或者中央空调

如果你的空调中了上面任意一条，别省那150块钱，乖乖叫个师傅上门。不是我吓你，是因为变频空调和中央空调的深度拆洗涉及到电路和冷媒，没有专业设备真的搞不定，搞砸了修一次少说上千。

要是上面3个条件你一个都没中，那接下来的内容能帮你省下一笔师傅费。

---

### DIY适合什么情况

简单说：新空调日常维护、换季简单保养、滤网看起来不算太脏的情况下，DIY完全够用。

我自己家的空调就是这么处理的。每年夏天第一次开空调之前，我会花10分钟把滤网拿出来刷一刷，再用空调自带的自清洁功能跑一遍，制热烘干1小时。整个过程不需要任何工具，最多就是一块软布加一把旧牙刷。

算下来成本接近零，时间半小时左右，换来的是干净的风和心里踏实。

下面给你详细说说3种DIY方案，从简单到复杂，自己对号入座。

---

### 路线一：DIY日常维护型（零成本，10分钟）

**适合谁**：空调使用不到3年，平时没有明显异味，只是想做基础保养

这个方案的核心工具就是你家空调自带的遥控器。

**步骤一：滤网清洗（10分钟）**

![滤网清洗步骤图解](T5_03_滤网清洗图.png)

操作很简单：先断电，打开面板，把滤网抽出来。滤网一般就是一层塑料网格，上面会积一层灰。用软刷或者旧牙刷配合清水刷一刷就行，刷完放到阴凉处晾干，别拿太阳直射，塑料会变形。

等滤网彻底干透，装回去，合上面板，滤网这块就搞定了。

**步骤二：自清洁功能（30-60分钟）**

![自清洁功能操作图解](T5_04_自清洁功能图.png)

这个功能其实大部分空调都有，但很多人都不知道或者从来没按过。

操作方法：关机状态下，同时按住遥控器的「灯光」键和「辅热」键，保持3秒左右。遥控器屏幕会显示「CL」，室内机也会显示「CL」，这就代表自清洁模式启动了。

接下来等待30到60分钟，让空调自己跑完整个清洁程序。它会先用低温冷凝水冲刷蒸发器，然后用高温加热烘干。整个过程不需要你做任何操作，也不需要在旁边守着。

跑完之后再开空调，你会发现风确实清爽了不少。

**步骤三：高温烘干法（2小时，可选）**

这是抖音达人李莽分享的一个偏方，我试过确实有用，专门对付空调吹出来有酸臭味的情况。

操作方法：关掉制冷，开到30度制热模式，运行1小时。然后切换到送风模式，再运行1小时。

原理很简单：制热的时候蒸发器温度升高，可以杀灭一部分细菌；送风的时候把排水管里的积水吹干，异味根源就消除了。

**路线一参数表**：

| 项目 | 参数 |
|------|------|
| 费用 | 零成本（仅需水和软刷） |
| 耗时 | 10分钟（不含自清洁等待时间） |
| 操作难度 | 零门槛 |
| 清洁效果 | 基础级，能维持空调健康状态 |

**路线一优缺点**：

优点：
1. 零成本，不需要购买任何工具
2. 操作简单，10分钟搞定
3. 没有风险，不会对空调造成任何损伤

缺点：
1. 无法清洁蒸发器深处的顽固污渍
2. 对已经发霉发臭的空调效果有限

### 路线二：DIY深度清洁型（¥30-50工具，60分钟）

**适合谁**：滤网拿出来发现翅片明显积灰、空调吹出来有明显酸味、或者上次清洗已经超过1年

这个方案比路线一要复杂一点，但清洁效果会好很多，基本能达到师傅普通清洗的80%水平。

**第一步：准备工具**

![深度清洁6步骤图解](T5_05_深度清洁套装步骤图.png)

你需要买一套空调清洗套装，网上搜这四个字就行，电商平台一搜一大把，价格30到50块钱一套。套装里面一般包含：接水袋、清洗剂、风轮刷、喷壶。

工具清单：

| 工具 | 用途 |
|------|------|
| 防尘口罩、手套 | 安全防护，必须戴 |
| 软毛刷或旧牙刷 | 清洁滤网和翅片 |
| 超细纤维布 | 擦拭外壳 |
| 吸尘器（带毛刷头） | 吸除松散的灰尘 |
| 清洗剂 | 分解油污和霉菌 |
| 喷雾瓶 | 喷洒清洗剂 |
| 脸盆 | 浸泡滤网 |
| 空调清洗套装 | 深度清洁蒸发器核心 |

**第二步：接水和防护**

把接水袋挂在空调下方，袋口对准排水管位置。这一步是为了接住清洗过程中流下来的脏水，别让它们滴到墙上或地板上。

然后戴好口罩和手套，清洗剂的气味虽然不算刺鼻，但最好还是做好防护。

**第三步：喷洒清洗剂**

把空调清洗剂摇匀，喷在蒸发器翅片上。注意要均匀喷洒，让清洗剂充分覆盖每一排翅片。喷完之后等待10分钟左右，让清洗剂充分分解污渍。

这里有个关键点：避开电机部分。电机一般在蒸发器中间位置，颜色和翅片不一样，不要往那里喷任何液体。

**第四步：刷洗和冲洗**

用风轮刷顺着翅片的方向轻轻刷洗，把已经松动的污垢刷下来。刷的时候力道要轻，翅片是铝片，容易变形。

然后用装有清水的小喷壶或者花洒，从上往下冲洗，把脏东西冲掉。同样避开电机。

**第五步：干燥**

冲洗完之后，开到送风模式，让空调最大档运行30分钟，把内部的水分彻底吹干。

等完全干透之后，装回滤网，合上面板，深度清洁就完成了。

**路线二参数表**：

| 项目 | 参数 |
|------|------|
| 费用 | ¥30-50（清洗套装，一次性购买可多次使用） |
| 耗时 | 约60分钟 |
| 操作难度 | 中等，有一定风险需注意 |
| 清洁效果 | 进阶级，接近专业师傅普通清洗水平 |

**路线二优缺点**：

优点：
1. 清洁彻底，可以处理蒸发器深处的污垢
2. 总花费控制在百元以内，性价比高
3. 可清洁到滤网看不到的翅片区域

缺点：
1. 需要购买专用工具，30到50块钱
2. 操作有风险，必须避开电机和电路部分
3. 全程耗时约1小时

### 路线三：专业师傅深度清洗（¥150-400/台）

**适合谁**：空调超过3年没深度洗过、出现异响或制冷效果明显下降、使用的是变频挂机超过10年或中央空调

这个方案就不需要你自己动手了，但钱要花到位。

**什么情况下必须叫师傅**

先说清楚，不是所有情况都需要叫师傅。但下面这几种情况，我强烈建议你别省这个钱：

变频挂机超过10年：这种老空调内部零件可能已经老化，拆洗过程中稍有不当就可能出问题。而且10年以上的变频机，冷媒管路密封性普遍下降，自己动手清洗反而可能引发泄漏。

中央空调：中央空调的室内机结构比挂机复杂得多，风轮和蒸发器都在吊顶里面，没有专业工具和培训根本碰不了。这钱省不得。

空调出现异响或者制冷效果突然变差：这种情况往往意味着内部有积灰导致散热不良，或者某些部件出了问题。师傅上门不只是清洗，还能顺便帮你做个简单排查。

**价格行情（CEO裁定版）**

![DIY vs 师傅参数对比图](T5_02_参数对比图.png)

这是根据大陆市场通用行情整理的价格区间：

| 清洗类型 | 价格区间 | 说明 |
|---------|---------|------|
| 普通清洗 | ¥100-200/台 | 滤网+蒸发器表面清洗 |
| 深度拆洗 | ¥200-400/台 | 全拆清洗，高温蒸汽消毒 |

警惕低于¥100的报价。这种价格往往是引流套路，上门之后会以各种理由加钱：冷媒不够要加、配件老化要换、深度清洗要另算等等。

**怎么选靠谱的师傅**

第一选择：品牌官方售后。如果你的空调还在保修期内，或者品牌有付费清洗服务，这是最靠谱的渠道。价格透明，服务规范，出问题有售后兜底。

第二选择：京东、天猫平台有保障的商家。这些平台对商家有入驻门槛和评分体系，相对靠谱。选评分4.8以上、销量过千、评价里有真实使用反馈的。

第三选择：朋友推荐。熟人用过的师傅最靠谱，服务质量有保证。

**路线三参数表**：

| 项目 | 参数 |
|------|------|
| 费用 | ¥150-400/台（根据清洗深度） |
| 耗时 | 约60-90分钟 |
| 操作难度 | 无需自己操作 |
| 清洁效果 | 最佳级，高温蒸汽消毒+全面拆洗 |

**路线三优缺点**：

优点：
1. 清洁最彻底，包括高温蒸汽消毒
2. 有专业设备加持，效果最佳
3. 师傅可以顺便排查潜在故障

缺点：
1. 费用较高，每台150到400元
2. 存在师傅操作不当的风险
3. 需要预约，可能要等几天才能排上

### 说点实用的

关于清洗频率，我建议一般家庭每年做1到2次。夏天和冬天第一次开空调之前各做一次基础保养，中间如果感觉风不对劲，用自清洁功能跑一遍就行。

有小孩、老人或者过敏体质的家庭，建议每年至少做一次深度清洁。空调里的霉菌和灰尘对呼吸道的影响比你想象的严重，特别是对小孩子。

还有个小提示：师傅清洗完之后，自己记着做一次高温烘干法。这样可以把师傅清洗残留的水分彻底吹干，减少细菌滋生的可能。
