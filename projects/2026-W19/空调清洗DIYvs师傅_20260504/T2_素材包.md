## 五、文章骨架清单（技术路线图）

### 路线一：DIY日常维护型
**适用场景**：空调使用＜3年、无明显异味、只是想做基础保养

**核心步骤**：
1. 滤网清洗（10分钟）：断电→取滤网→软刷+清水→晾干→装回
2. 自清洁功能（30分钟）：灯光+辅热键3秒→CL显示→等待30-60分钟
3. 高温烘干法（2小时）：30°制热1小时→送风1小时

**代表产品**：各品牌空调遥控器自带功能（无需额外购买）

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 零成本（仅需水和软刷） | 无法清洁蒸发器深处 |
| 操作简单，10分钟完成 | 对顽固污渍效果有限 |
| 无风险，不损伤空调 |  |

### 路线二：DIY深度清洁型
**适用场景**：滤网取出后看到翅片明显积灰、空调有明显酸味

**核心步骤**：
1. 购买空调清洗套装（约¥30-50）
2. 挂接水袋→喷清洗剂→等10分钟→风轮刷刷洗→冲洗（避开电机）→送风干燥

**代表工具**：空调清洗套装（电商平台搜索「空调清洗套装」）

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 清洁彻底，效果接近专业师傅 | 需购买工具（约¥30-50） |
| 可清洁蒸发器 | 有一定操作风险（避开电机） |
| 总花费控制在百元内 | 耗时约60分钟 |

### 路线三：专业师傅深度清洗
**适用场景**：空调超过3年未深度清洗、出现异响/制冷效果差、变频/中央空调

**价格区间**：¥150-400/台（参考值，待CEO裁定）

**选择建议**：
- 优先选品牌官方售后
- 次选JD/天猫平台保障商家
- 警惕低于¥100的低价诱惑（可能有加项套路）

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 深度清洁，包括高温蒸汽消毒 | 费用较高（¥150-400/台） |
| 专业设备，效果最佳 | 存在师傅操作风险 |
| 可排查潜在故障 | 预约等待 |
