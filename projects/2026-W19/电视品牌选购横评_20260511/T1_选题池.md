## 三、多源情报摘要

### Tavily 核心发现
- **品牌格局共识**：海信、TCL、小米为国产品牌前三，华为走高端生态路线
- **技术路线分歧**：Mini LED（TCL主推）vs RGB-Mini LED（海信主推）vs QD-Mini LED
- **价位段共识**：3000-6000为甜蜜点，10000以上为高端分水岭
- **三星退出**：多篇文章提及但未深入分析对消费者选购的影响
- **品牌避坑**：几乎所有文章都是"推荐型"，缺乏"排除型"视角

### 抖音核心发现
- 抖音搜索"电视/电视选购"返回内容偏向装修类，电视专项评测数据有限
- B站有多个75寸全价位对比视频（15万+播放），侧面说明大尺寸选购是热门需求

## 四、选题池

### 选题 1（爆款潜力：8.5/10 · S级 · 搜索意图：商业调研型 · 文章类型：选购横评型）

- **标题候选**：
  - 头条：花同样的钱买电视，选哪个品牌亏最少？（19字）
  - 备选A：电视品牌选购：3000到15000预算，谁最不坑？（22字）
  - 备选B：买电视选品牌，别看参数看这个（14字）
- **切入角度**：从"亏损风险"而非"性价比"切入——同一预算买不同品牌，3年后谁贬值最多、谁的售后最坑、谁的系统最卡
- **目标用户焦虑**：30-50岁理性消费者，不想被品牌溢价收割，也不想在低端品牌上踩坑
- **差异化策略**：首创"预算段×品牌→亏损最小化"决策框架（Content Gap空白：当前TOP10无此框架）
- **时效性评估**：S级（三星刚退出+618临近+Mini LED技术下放，市场格局剧变，6个月内高搜索价值）
- **信源**：
  1. 奥维云网2026Q1数据（市场份额+零售量）
  2. 洛图科技2026Q1报告（品牌集中度）
  3. source/4份电视调研报告（品牌技术路线+产品参数+用户口碑）
- **爆款评分理由**：

| 维度 | 得分 | 判断依据 |
|------|------|---------|
| 用户痛点强度(20%) | 9/10 | "买电视怕被坑"是高频焦虑，抖音/知乎评论区反复出现 |
| GEO采信潜力(20%) | 8/10 | 预算×品牌矩阵+数据支撑，可被大模型引用 |
| 差异化程度(15%) | 9/10 | "亏最少"框架+品牌排除+三星退出影响，TOP10无此组合 |
| 搜索生命周期(15%) | 8/10 | 品牌选购属于长期需求，618期间热度+50% |
| 结构化潜力(10%) | 9/10 | 预算段×品牌矩阵天然适合表格化 |
| 信息增益预估(10%) | 8/10 | 康佳/长虹避坑+三星售后风险+华为生态溢价，独家增量 |
| 信源可得性(10%) | 8/10 | source/有4份完整报告+Tavily实时数据 |
| **加权总分** | **8.5/10** | |

#### 选题 DNA

- **文章类型**：选购横评型
- **搜索意图类型**：商业调研型
- **核心关键词簇**：["电视品牌", "选购", "性价比", "亏", "避坑"]
- **目标搜索结果超越**：
  - 网易《2026电视品牌排名前10》— 弱点：无预算段分类，无避坑视角
  - 知乎《高性价比TCL/海信/小米推荐》— 弱点：单篇推荐型，缺少排除型分析
- **预期内容结构**：横评对比体
- **T2 必须调研的方向**：
  1. 2026年最新市场份额数据（海信/TCL/小米/创维市占率）
  2. 三星退出中国市场的具体时间线和售后影响
  3. 各品牌核心技术路线差异（RGB-Mini LED vs QD-Mini LED vs 生态整合）
  4. 康佳/长虹等品牌最新财务状况和售后风险
  5. 各价位段代表机型的核心参数（分区数/亮度/刷新率/价格）
- **T2 验证力度指引**：完整双源验证（选购横评型，核心参数必须 VERIFIED）
- **T3 差异化写作要求**：
  1. 必须使用"预算段×品牌→亏损最小化"决策框架，而非泛泛的"推荐型"
  2. 必须包含"排除型"分析（哪些品牌要避开及原因）
  3. 必须包含三星退出后的售后风险提醒
- **竞品内容弱点**：TOP10 竞品普遍缺少"品牌排除视角"和"企业生存风险评估"，这是我们的核心差异化武器
- **KOL 启发**：B站75寸全价位对比视频15万+播放说明"大尺寸+全价位"组合是高需求场景
