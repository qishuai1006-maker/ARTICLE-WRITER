## ② 参数对比图 (landscape / professional)

```
生成产品参数对比信息图。标题：2026年电视选购·六款核心机型参数横评。横向对比6款推荐产品，对比维度包括价格、控光分区数、峰值亮度、刷新率、特色技术。产品数据：雷鸟75S585C Pro（3095元/640分区/1300nits/120Hz/无广告+低音炮），TCL 75T7K（3599元/640分区/1600nits/144Hz/QD-Mini LED），海信75E5ND-PRO（3439元/704分区/2000nits/144Hz/信芯AI），小米85 S Pro 2025（5999元/1440分区/2400nits/120Hz/澎湃OS），海信85E5Q-PRO（6799元/1248分区/2200nits/300Hz/信芯AI），TCL 85Q10L（10499元/2880分区/5000nits/144Hz/华星HVA）。优势参数用绿色高亮标注。底部注明数据来源产品库和奥维云网2026Q1。
```

## ③ 场景对比图 (landscape / editorial)

```
生成场景选购建议信息图。标题：五个场景五个答案·电视选购地图。场景1：客厅主屏追求画质→推荐海信或TCL。场景2：预算有限首选性价比→推荐TCL雷鸟75S585C Pro。场景3：家里老人使用→推荐华为（零开机广告+鸿蒙流畅+灵犀遥控器）。场景4：游戏玩家→推荐TCL雷鸟（满血HDMI2.1+144Hz+低输入延迟）。场景5：已有华为或小米全屋智能→直接选对应品牌。每个场景用不同色块区分，配场景图标。
```

## ④ 优缺点图 (square / professional)

```
生成品牌优缺点对比信息图。标题：四大品牌优缺点一览。海信：优点-自研独立画质芯片信芯AI可识别22类场景，RGB-Mini LED色域覆盖100%BT.2020，对低码率视频优化出色；缺点-系统较臃肿预装应用多，中端性价比不如TCL。TCL：优点-华星光电面板自供成本控制领先，Mini LED全球市占率31.1%连续五年第一，全系无开机广告；缺点-VA屏侧视色彩衰减，高端线溢价不如海信有质感。小米：优点-澎湃OS生态联动体验独一份，75英寸已杀入2000价位极致性价比；缺点-开机广告需手动关闭，同型号混用VA/IPS面板存在面板抽奖，无独立画质芯片。华为：优点-鸿蒙系统流畅度排名靠前，投屏延迟低至8ms，灵犀遥控器交互领先；缺点-画质参数同价位明显偏低，买华为三到五成是为生态买单。用绿色标记优点红色标记缺点，白底清晰对比。
```
