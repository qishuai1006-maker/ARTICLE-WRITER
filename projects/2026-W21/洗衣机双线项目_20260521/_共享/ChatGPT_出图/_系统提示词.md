# 系统提示词 · ChatGPT APP 生图专用

**版本**：v2.0（2026-05-21）
**变更**：从 Codex 扫描模式 → ChatGPT APP 项目模式

## 项目配置

ChatGPT APP 中创建项目「文章配图」，配置如下：

1. **Project Instructions**：复制 `ChatGPT项目指令_粘贴到Project Instructions.md` 的内容到项目设置
2. **上传文件**：将 `上传到项目_配图设计手册.md` 上传到项目中作为永久参考

配置完成后，在项目的任意对话中粘贴提示词即可生图。

## 工作流程

```
1. Claude Code 在 T5 阶段生成配图方案
2. Claude Code 将 ChatGPT 类型的提示词输出为可复制的格式
3. 你打开 ChatGPT APP → 进入「文章配图」项目 → 新建对话
4. 逐条粘贴提示词 → 生成图片 → 下载 PNG
5. 将下载的图片保存到 outputs/ 目录，命名格式：T5_ChatGPT_[功能描述].png
6. 回到 Claude Code 继续后续流程
```

## 文件命名规则

| 来源 | 命名格式 | 示例 |
|------|---------|------|
| ChatGPT APP | `T5_ChatGPT_[功能描述].png` | `T5_ChatGPT_封面图.png`、`T5_ChatGPT_场景对比图.png` |
| NotebookLM | `T5_[功能描述].png` | `T5_参数对比图.png`、`T5_优缺点图.png` |

## 你负责的图片类型（ChatGPT APP 生成）

- 封面图（5种类型轮换）
- 场景对比图
- 价格档位图
- 技术原理图
- 流程/避坑图

## 你不负责的图片类型（NotebookLM 生成）

- 参数对比图
- 优缺点总结图
- 人群选购图
- 文章内表格转图
