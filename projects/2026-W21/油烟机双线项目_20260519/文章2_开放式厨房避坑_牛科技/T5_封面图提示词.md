
## 文章2：开放式厨房避坑

### 封面 A — 2.35:1 横幅封面

```
一张简洁的扁平风格装修避坑封面图。画面中央：一个现代开放式厨房场景，厨房与客厅之间没有隔断。灶台上方安装着一台油烟机。一条大号黄色卷尺横贯画面，从油烟机位置量到天花板烟道出口。三个编号步骤图标用箭头连接：① 卷尺图标（量烟道）、② 计算器图标（算静压）、③ 产品包装盒图标（选型号）。核心视觉内容集中在画面中间60%的横向条带内。顶部20%和底部20%为暖灰色渐变背景（#f5f5f0到#e8e4df），无任何内容，用于裁切。温暖大地色系，矢量插画风格，无水印，无多余文字。
```

### 封面 B — 1:1 方形封面

```
一张醒目的扁平风格方形封面图。画面中央：一个开放式厨房的俯视平面图。中心位置有一个油烟机图标，外围环绕5个小图标顺时针排列：卷尺、计算器、产品盒、扳手、闪光清洁。厨房平面图向四周渐隐。顶部有一个醒目的黄色警示三角图标。核心内容集中在画面中央55%的方形区域。左右两侧为柔和暖灰色背景（#f0ece4），无内容，用于裁切。顶部和底部留充足的暖灰色空间。温暖大地色调（米色、赤陶色、鼠尾草绿），矢量插画，无水印。
```

## 裁切参考

| 目标比例 | 从 16:9 裁切方式 | 提示词策略 |
|---------|----------------|-----------|
| 2.35:1 | 裁掉上下各约 24% | 主内容集中在中间 60% 横带，上下纯色渐变 |
| 1:1 | 裁掉左右各约 22% | 主内容集中在中间 55% 方形区域，左右纯色 |
