# 开放式厨房选油烟机，先量烟道再挑型号，顺序反了全白费

上个月帮一个朋友看开放式厨房的装修方案，他把油烟机型号都选好了，美的AK7 PRO，28m³风量、1100Pa静压，参数没问题。我问他：你家烟道量过没有？烟道口在哪、管子要走多远、几个弯头？

他愣了一下："烟道……没量。"

这就是大多数人选油烟机的顺序：先看品牌和参数，再看看别人的推荐，最后下单。烟道条件这件事，排在最后甚至压根没考虑过。

但开放式厨房的排烟难度，和封闭厨房根本不是一个量级。你连烟道都没搞清楚就选型号，参数再好看也可能白买。

## 一、开放式厨房的排烟，到底难在哪

封闭厨房有个推拉门，炒菜的时候门一关，油烟机在几立方米的空间里建负压，油烟跑不掉。开放式厨房没有这扇门，厨房和客餐厅连在一起，空间从15立方米直接扩到100立方米以上。

油烟机在这么大的空间里根本建不起有效的负压场。你炒个辣椒，油烟一升起来，客厅空调风一吹、人走动带起来的气流一搅，油烟就散了。散出去容易，吸回来难。

所以开放式厨房对油烟机的要求比封闭厨房苛刻得多：风量要大（≥25m³/min），静压要高（≥1000Pa），最好还是顶侧双吸结构——侧吸近距离截断油烟，顶吸大范围笼烟，双路同时工作。

但光知道这些参数需求还不够。**选油烟机的首要步骤不是看参数，是量烟道。**

## 二、第一步：搞清楚你家的烟道类型

先去厨房看一眼烟道口，判断你家属于哪种情况：

**情况A：公共烟道（90%的高层住宅）**
- 特征：烟道口在吊顶上方，连接的是一个通往楼顶的竖向管道
- 判断方法：如果是高层住宅（7层以上），基本都是公共烟道
- 注意：公共烟道的排烟阻力动态变化，做饭高峰期阻力会暴增2-3倍

**情况B：独立烟道/外墙直排（别墅、自建房、部分老小区）**
- 特征：烟道口直接连接外墙，管道短、弯头少
- 判断方法：能从厨房看到烟道管直接穿墙出去
- 注意：独立烟道排烟阻力小，但对静压要求也低很多

确定是公共烟道后，量三个数据：

1. **烟道口到油烟机安装位置的距离**（水平+垂直总长度）
2. **弯头数量**（有几个90度转弯）
3. **烟道口直径**（标准160mm或180mm）

这三个数据直接决定你需要多少静压储备。

## 三、第二步：算清楚你家需要多少静压

我给你一个简化的算法，不用精确到个位，但能帮你判断大概范围：

**基础静压需求（按楼层——楼层越低，需要静压越高）：**

| 楼层 | 基础静压需求 | 原因 |
|------|------------|------|
| 1-6层 | ≥800Pa | 排烟路径最长，需克服上方所有楼层压力叠加 |
| 7-15层 | ≥600Pa | 上下楼层同时排烟，阻力波动较大 |
| 16-30层 | ≥450Pa | 距排风口较近，但高峰期仍有背压 |
| 30层以上（顶层附近） | ≥350Pa | 距排风口最近，阻力最小 |

**附加修正（按烟道条件）：**
- 排烟管超过3米：静压需求+200Pa
- 弯头超过2个：静压需求+100Pa
- 开放式厨房（无隔断）：静压需求+200Pa

举个例子：你家住30层高层住宅的第5层（低楼层），排烟管走了4米、2个弯头，开放式厨房。
基础需求800Pa + 管长+200Pa + 开放式+200Pa = 实际需要约1200Pa静压。

如果你住的是30层超高层底层，开放式厨房，管子还长，那静压需求可能到1200-1300Pa。反过来，如果你住在30层楼的28层，离排风口近，静压需求反而没那么高，400-500Pa可能就够用。

**不会算也没关系，记住一个原则：开放式厨房+公共烟道，静压至少1000Pa起步。能到1200Pa更好。**

## 四、第三步：按静压需求挑型号

根据前面的测算结果，对照以下推荐选型号：

**预算2000元左右：**
- **美的AK5pro升级款**（约¥1999）：25m³/min + 1000Pa静压 + 蒸汽洗 + 顶侧一体。2000元预算开放式厨房的入门之选。蒸汽洗功能对天天做饭的家庭特别实用，定期洗一次能保持吸力不衰减。

**预算2500-3000元：**
- **老板小黑翼D1U**（约¥2879）：28m³/min + 1350Pa静压 + 顶侧双吸。1350Pa的静压在3000元以下几乎属于第一梯队。顶侧双吸结构对开放式厨房特别合适，侧吸口近距离截油烟，顶部负压区大范围笼烟。

**预算3000-4000元：**
- **美的AK7 PRO**（约¥3199）：28m³/min + 1100Pa静压 + 蒸汽洗。单品销量10万+，这个价位段的标杆。蒸汽洗+变频电机的组合，长期使用吸力衰减比普通型号慢很多。

**预算4000元以上：**
- **老板L3+D2**（约¥4238）：27m³/min + 1200Pa + 烟灶套装。老板中高端套装，性能均衡。
- **方太V1S-G**（约¥5798）：28m³/min + 1450Pa + 烟灶联动。1450Pa静压基本是民用级别的天花板了。开放式厨房+超高层底层这种最难搞的场景，选它不会出错。

选型优先级建议：
- 预算有限但静压需求高 → 优先选老板D1U（1350Pa只要2879元）
- 天天爆炒+懒得拆洗 → 优先选美的AK7 PRO（蒸汽洗）
- 预算充足+追求极致 → 选方太V1S-G（1450Pa天花板）

## 五、安装环节四个大坑，比选错型号还严重

型号选对了，安装搞砸了，效果照样打折。这几个坑我见太多了：

**坑1：烟管走向乱走**

装修公司为了吊顶美观，把烟管绕了好几个弯塞进吊顶里。流体力学上，每多一个90度弯头，排烟阻力呈非线性增加（不是简单叠加，而是指数级增长）。走管原则就三个字：短、直、少。距离最短、弯头最少、管径不缩。

如果因为户型限制，管子实在要超过3米或弯头超过2个，别省那个钱了，直接上高静压变频型号（1200Pa以上）。

**坑2：止逆阀用开发商自带的**

公共烟道建议装止逆阀，而且要换成金属双开型的。开发商自带的塑料止逆阀有两个致命问题：一是弹簧太硬，油烟机要额外消耗150-200Pa的静压才能顶开它；二是叶片容易被油污粘住，时间长了关不严，邻居家的油烟直接灌进你家。

装修的时候，让师傅把原来的砸掉，换一个100-200块钱的金属止逆阀，性价比极高的升级。

**坑3：安装高度差几厘米**

侧吸式油烟机底部距灶台35-45cm，顶吸式距灶台65-75cm。别小看这几厘米的容差范围。有用户实测反馈，油烟机装高了2厘米，排烟效果明显变差，调回标准高度后立刻好转。

2厘米。就差这么一点。

**坑4：安装辅料加价**

油烟机本体价格现在电商比价很透明，利润已经很薄了。但安装环节才是利润的大头。加长烟管、止逆阀、装饰罩，这些辅料在安装现场可能被加价300%-500%。建议提前在建材市场买好标准的金属止逆阀和加厚铝箔烟管，只让师傅收几十块安装费就行。

## 六、自清洁功能要不要选

开放式厨房的油烟机使用频率高、油污积累快，自清洁功能值得考虑。但要对它有个合理的预期：

- **美的蒸汽洗**：110℃高温蒸汽溶解叶轮油污，再高速甩干。能延缓性能衰减，但不等于不用洗。建议每1-2个月用一次。重油烟家庭选这个。
- **老板/方太不粘油涂层**：内腔涂有疏油层，油污不容易附着。轻度使用的话确实能减少清洗频率。轻油烟家庭够用。
- **高温热熔洗**（华帝等）：用高温融化叶轮表面油污。原理类似蒸汽洗，但温度更高。

说直白点：自清洁能延缓衰减，但不能替代深度拆洗。用了3年以上的油烟机，建议至少做一次专业深度拆洗，这是恢复出厂静压和消除噪音最有效的方式。

## 七、开放式厨房油烟机的终极选购流程

把前面的内容浓缩成一个操作流程：

**第一步：量烟道** → 确定公共烟道还是独立烟道，量管长和弯头数
**第二步：算静压** → 按楼层+管长+开放式修正，得出静压需求值
**第三步：选型号** → 按静压需求和预算，选对应的变频型号
**第四步：盯安装** → 止逆阀换金属、走管短直少、安装高度卡标准
**第五步：善维护** → 有自清洁的定期用，3年以上做一次深洗

顺序千万别反了。先量烟道再挑型号，是省钱；先挑型号再想烟道，大概率花冤枉钱。

---

你现在可以做的三件事：

1. 去厨房看一眼烟道口，判断公共烟道还是独立烟道，用卷尺量管长和弯头
2. 按楼层对照上面的静压需求表，算出你家的静压下限
3. 拿这个数值去对照推荐型号表，风量和品牌都是次要的——**静压达标才是你该优先关注的核心**
