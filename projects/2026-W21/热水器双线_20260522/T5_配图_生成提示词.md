### 图7：户型判断流程图
```
创建一张决策流程图，标题"你家适合装零冷水吗？"

起始节点：管路长度是否超过5米？
→ 否 → 结论：不建议装（等待时间短，投入产出不划算）
→ 是 → 装修时是否预埋了回水管？
  → 是 → 用水点是否分散（2个以上卫生间/厨房+阳台）？
    → 是 → 结论：三管零冷水，体验最好（绿色）
    → 否 → 结论：可以考虑，但优先级不高（蓝色）
  → 否 → 冷水管上是否接了RO净水器或智能马桶？
    → 是 → 结论：建议选ECO半程循环，或放弃零冷水（橙色）
    → 否 → 结论：H阀方案可用，选定时模式（蓝色）

配色：结论节点按推荐度着色（绿色=推荐，蓝色=可选，橙色=谨慎，红色=不建议）。节点用圆角矩形，箭头用灰色。
```
