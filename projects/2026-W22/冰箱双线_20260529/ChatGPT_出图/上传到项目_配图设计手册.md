# 家电图文配图设计手册

**用途**：此文件上传到 ChatGPT 项目「文章配图」作为永久参考。ChatGPT 生成每张配图时，参考本手册中的模板和示例。

---

## 一、项目背景

我们运营两个今日头条家电账号：

- **牛科技**（实用导购调性）— 帮读者做选购决策
- **牛科技说**（技术发烧调性）— 从技术角度深度拆解

文章类型主要有三种：
1. **选购横评型**：品牌对比、价位推荐（需要参数对比图+价格档位图）
2. **教程避坑型**：DIY步骤、安装猫腻、使用技巧（需要流程图+避坑图）
3. **趋势科普型**：行业趋势、技术原理科普（需要原理图+数据图）

每篇文章需要 5-6 张配图，其中 3-4 张由你（ChatGPT）生成，另外 2-3 张由 NotebookLM 生成（结构化数据图，不归你管）。

你负责的图片类型：**封面图、场景对比图、价格档位图、技术原理图、流程图、避坑类图**。

## 二、9 种配图模板

### 模板 1：封面图 — 产品对决型（C1）

**适用**：横评对比、品牌选购、两条路线二选一

**画面结构**：
- 画面左右对半分割
- 左侧蓝色色块 + 右侧橙色色块
- 正中央超大白色粗体"VS"字样
- 左右各标注 1 个核心参数数字
- 总文字 ≤ 10个汉字

**示例提示词**：
```
生成一张16:9横版产品对决封面图。

画面左右对半分割。左侧是老板油烟机的产品剪影轮廓，深蓝色色块背景。右侧是方太油烟机的产品剪影轮廓，橙色色块背景。正中央超大白色粗体"VS"字样。

左侧底部标注"静压 1350Pa"，右侧底部标注"静压 1450Pa"。总文字不超过10个汉字。无文章标题，无水印，无小字标注。干净简洁，视觉冲击力第一。专业科技感，不要卡通风。全中文。
```

---

### 模板 2：封面图 — 价格冲击型（C2）

**适用**：618/双11/价格敏感选题

**画面结构**：
- 画面中央两个超大价格数字
- 左右对比，用红色和绿色区分
- 价格数字占画面 60% 以上
- 底部可加一行价格来源说明

**示例提示词**：
```
生成一张16:9横版价格对比封面图。

画面中央两个超大价格数字。左侧"¥1999"红色加粗，右侧"¥5599"绿色加粗。两个价格之间用对比箭头连接。

底部小字"京东5月实时价"。总文字不超过10个汉字。无文章标题，无水印。浅色背景，数字是唯一视觉焦点。全中文。
```

---

### 模板 3：封面图 — 避坑警示型（C3）

**适用**：避坑指南、不推荐清单、翻车揭秘

**画面结构**：
- 画面中央红色 STOP 标志或大叉图标
- 背景是模糊的产品轮廓剪影
- 主色调红+黑+白
- 警示短句 4-6 个字

**示例提示词**：
```
生成一张16:9横版避坑警示封面图。

画面中央是醒目的红色大叉图标，背景是模糊的油烟机轮廓剪影。主色调红+黑+白。

画面上标注4个字："别买这种"。无文章标题，无水印，无长文字。警告感强烈但不过度，保持理性专业感。全中文。
```

---

### 模板 4：封面图 — 场景代入型（C4）

**适用**：使用场景、体验感受、生活痛点

**画面结构**：
- 真实家庭使用场景的写实画面
- 像手机随手拍的照片感
- 场景标注关键词 ≤ 6 个字

**示例提示词**：
```
生成一张16:9横版场景代入封面图。

画面是厨房里油烟弥漫的瞬间，一个人在炒菜被油烟呛得皱眉。真实生活感，像手机随手拍。

画面上标注4个字："串味现场"。无文章标题，无水印。色调自然真实，不要科技感处理。全中文。
```

---

### 模板 5：封面图 — 参数一击型（C5）

**适用**：硬核技术参数、单一核心数据做钩子

**画面结构**：
- 画面 90% 给一个超大参数数字
- 数字用金色或红色，加粗
- 深色背景（深蓝或纯黑）
- 底部一行参数含义说明

**示例提示词**：
```
生成一张16:9横版参数冲击封面图。

画面90%空间给一个超大数字"1450Pa"，金色加粗字体。深蓝色背景。

底部一行小字"最大静压越高排烟越强"。数字+含义总共不超过12个汉字。无文章标题，无水印。简洁极致，不要多余装饰。全中文。
```

### 模板 6：场景对比图

**适用**：不同场景/方案的使用效果对比

**画面结构**：
- 三个场景，三个色块（蓝/绿/橙）
- 每个色块内：场景名 + 推荐方案 + 核心优势
- 顶部标题，底部一行建议
- 白底信息图风格

**示例提示词**：
```
生成一张16:9横版场景对比信息图。

三个场景，三个色块：

场景1（蓝色块）：低楼层老小区公共烟道
  推荐方案：变频1000Pa+
  核心优势：做饭高峰也能排干净

场景2（绿色块）：高层新房独立烟道
  推荐方案：定频500Pa够用
  核心优势：预算省一半效果不打折

场景3（橙色块）：开放式厨房大户型
  推荐方案：变频1350Pa+
  核心优势：爆炒也不跑烟

顶部标题："三种场景，各适合什么油烟机？"
底部一行："先看场景再看参数，选油烟机的正确顺序"。
白底，干净专业，信息图风格。全中文。
```

### 模板 7：价格档位图

**适用**：按价格区间推荐产品

**画面结构**：
- 阶梯式布局，价格从低到高
- 颜色渐变（浅蓝→深蓝 或 浅金→深金）
- 每个档位：档位名 + 价格 + 型号 + 核心配置
- 顶部标题，底部价格来源

**示例提示词**：
```
生成一张16:9横版价格档位推荐信息图。

五个档位，从左到右递增：

入门档 ¥1999：美的AK5pro，25m³风量 / 1000Pa静压
性价比档 ¥2879：老板D1U，28m³风量 / 1350Pa静压
中高端档 ¥3199：美的AK7 PRO，28m³风量 / 1100Pa静压
高端档 ¥4238：老板L3+D2，27m³风量 / 1200Pa静压
旗舰档 ¥5798：方太V1S-G，28m³风量 / 1450Pa静压

阶梯式布局，颜色从浅蓝渐变到深蓝。每个档位标注：价格+型号+风量+静压。
顶部标题："油烟机各价位段静压标杆"。
底部小字："京东2026年5月实时价"。
白底，专业信息图风格。全中文。所有数字必须与上面完全一致不可修改。
```

### 模板 8：技术原理图

**适用**：科普工作原理、技术路线差异

**画面结构**：
- 用箭头和图标展示流程/路径
- 关键步骤用序号标注
- 对比时左右分栏
- 工程图风格，线条清晰

**示例提示词**：
```
生成一张16:9横版技术原理示意图。

展示油烟机风机工作时的气流路径：
烟从灶具升起 → 被吸烟口吸入 → 经过油网过滤 → 进入蜗壳被叶轮加速 → 通过排烟管推向公共烟道。

左侧标注"普通定频电机：转速固定，遇阻力不提速"
右侧标注"变频电机：遇阻力自动提速，风压最大1450Pa"

用箭头和图标展示流程，关键步骤用序号标注。左右分栏对比。
顶部标题："油烟机排烟路径"。浅色背景，线条清晰，工程图风格。全中文。
```

### 模板 9：流程/避坑图

**适用**：选购步骤流程、避坑检查清单

**画面结构**：
- 步骤型：序号 + 每步要点，箭头连接
- 避坑型：❌ 红色标记错误做法，✅ 绿色标记正确做法
- 信息图风格，每个要点 ≤ 8 个字

**示例提示词（避坑型）**：
```
生成一张16:9横版避坑检查清单信息图。

空调安装四大坑：

❌ 坑1：不加吊装费直接外机挂墙（震动+噪音翻倍）
❌ 坑2：抽真空不足15分钟（制冷效果打折20%）
❌ 坑3：铜管弯折超3次（冷媒泄漏风险）
❌ 坑4：不测漏直接收工（几个月后才知道漏）

底部一行："安装前把这几条拍给师傅看"。
红色❌标记每个坑，白色背景，清晰醒目。全中文。
```

## 三、质量标准

生成后对照以下清单检查，不通过需重新生成：

- [ ] 尺寸正确：16:9 或 1:1
- [ ] 中文可读：文字清晰，无乱码/模糊
- [ ] 数据准确：数字与提示词完全一致
- [ ] 无水印：任何角落没有"原创""版权"标注
- [ ] 封面文字 ≤ 10字（封面图才检查）
- [ ] 封面不含完整文章标题
- [ ] 路线完整：图中产品/方案数量 ≥ 实际涉及数量
