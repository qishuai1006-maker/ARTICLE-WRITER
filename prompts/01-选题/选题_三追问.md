# T1 选题 · 三追问第一轮：撒网

> **目标**：第一轮 prompt 不许写正文，只撒 5 个完全不同的角度，从中选 1。

## 核心 Prompt 模板

```
我要写一篇关于 [话题] 的文章，目标读者是 [具体人群]。

先不要写正文。给我 5 个完全不同的切入点——不同的角度、不同的叙事方式、不同的核心观点。

每个切入点用两句话说清楚：
1. 核心观点是什么
2. 文章怎么展开
```

## 关键技巧

1. **"先不要写正文"是硬约束**——AI 默认会直接写，必须显式禁止
2. **"5 个完全不同"逼 AI 把隐藏选项摊出来**——AI 默认只给"最安全的"那个
3. **选角度时挑让你"想说点什么"的那个**——不是"最合理"的，是"最想表达"的
4. **目标读者必须具体**——"年轻人"不行，"30-35 岁、家有 6 岁娃、想换家电但不想被坑"才行

## Prompt 变体

### 变体 A：教程型（问题链）

```
我要写一篇关于 [XX 工具 / XX 方法] 的教程，目标读者是 [零基础 / 入门 / 进阶] 的 [具体人群]。

先不要写正文。给我 5 个完全不同的切入点——不同的角度、不同的叙事方式、不同的核心观点。

每个切入点用两句话说清楚：
1. 核心观点是什么
2. 文章怎么展开
```

### 变体 B：观点型（拆解面）

```
我要写一篇关于 [XX 现象 / XX 趋势] 的观点文章，目标读者是 [具体人群]。

先不要写正文。给我 5 个完全不同的切入点——不同的角度、不同的叙事方式、不同的核心观点。

每个切入点用两句话说清楚：
1. 核心观点是什么
2. 文章怎么展开

提示：好的观点文章切入点通常包括——
- 主流观点的盲点
- 一个被忽略的变量
- 一个反常识的案例
- 一个跨领域的类比
- 一个"看起来对但其实不然"的常识
```

### 变体 C：故事型（故事线）

```
我要写一篇关于 [XX 经历 / XX 反思] 的文章，目标读者是 [具体人群]。

先不要写正文。给我 5 个完全不同的切入点——不同的角度、不同的叙事方式、不同的核心观点。

每个切入点用两句话说清楚：
1. 核心观点是什么
2. 文章怎么展开

提示：好的故事文章切入点通常包括——
- 一个具体的时刻作为开头
- 一个"当时的反应→后来的转折→现在的理解"弧线
- 一个你想带走的金句作为结尾
```
