# T2 深度 · 三追问第二轮：推三层

> **目标**：第二轮 prompt 不许直接写正文，先把核心观点往深处推 3 层。

## 核心 Prompt 模板

```
基于你给的第 [X] 个角度 [完整复述]：

先不要写正文。把这个角度的核心观点往深处推三层：

第一层：这个观点表面说的是什么？
第二层：这个观点背后，挑战了什么默认假设？
第三层：如果这个观点成立，对读者的实际行为会有什么改变？

把每一层都展开写。不要缩写成一句话。
```

## 为什么有效

- AI 默认的行为是"给一个最安全、最平均的答案"——它不会主动冒险
- 第一层是常识，第二层开始有意思，第三层开始有"只有这篇文章能说出"的东西
- 人类的"深度感"来自触碰常识底下藏着的、不太舒服的真相——AI 不会主动挖，第二追问是逼它挖到那一层

## 三层关系的力学

```
第一层（常识）→ 第二层（默认假设）→ 第三层（行为改变）
     ↓                ↓                  ↓
   "是什么"        "为什么是这样"     "所以读者该怎么做"
   所有人都能说     只有少数人能说     只有这篇文章能说
```

**真正的洞察在第三层**——但没有第一、第二层的铺垫，第三层会显得突兀。

## 推三层后的判断标准

三层写完后，问自己：

1. **第三层有没有让你"卧槽"？**
   - 如果没有 → AI 没挖够，重新 prompt 加一句"挑战得更深"
2. **第三层有没有"具体到读者能做"？**
   - 如果只停留在抽象哲学层面 → 推得还不够"行为级"
3. **三层之间有没有递进？**
   - 如果第二层和第一层是平行的 → 中间缺一层

## 输出格式

推完三层后，记录到 `test_run/选题_第X篇.md`：

```markdown
## T2 三层深度

### 第一层（常识层）
[完整展开，约 200-400 字]

### 第二层（默认假设层）
[完整展开，约 300-500 字]

### 第三层（行为改变层）
[完整展开，约 300-500 字]

### 我的判断
- 第三层"卧槽"程度：[1-5 分]
- 三层递进：[连贯 / 中间缺层 / 平行]
- 需要再深挖？[YES / NO]
```

## 反例：如果三层不够深怎么办

如果 AI 返回的三层都比较"安全"（没有挑战默认假设），用这个 Prompt 加码：

```
你刚才的三层太"安全"了。我要的不是常识的重新排列——是挑战读者认知的东西。

重新推第三层：你的读者现在普遍相信的"常识"是什么？这个角度如何颠覆它？

不要怕"冒犯"——只怕"没新意"。
```

## 注意事项

- ⚠️ 不要跳过第一层和第二层——它们是第三层的铺垫
- ⚠️ 三层都要"展开写"——禁止"缩写为一句话"
- ⚠️ 如果推到第三层发现"立不住"——回到 T1 换角度，不要硬写
