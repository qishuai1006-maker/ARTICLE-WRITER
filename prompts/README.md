# Super Writer v0.1 · 头条图文新工作流

> **版本**：v0.1 · 三追问 + 三骨架融合版
> **最后更新**：2026-06-11
> **定位**：新工作流的最小可行骨架（MVP），专为新个人号起量期设计

## 一、设计哲学

**旧 v7.2 的问题**：数据能产出但不稳定——依赖 Codex 教练 + 9 Skills + 多次交接，链路长、每一步都可能踩坑。

**v0.1 的目标**：用更轻的链路，拿到更稳定的产出。

三个核心思路：
1. **三追问**（老七聊 AI 启发）——AI 默认给平均答案，强制多轮对话深挖
2. **三骨架**（老七聊 AI）——问题链 / 故事线 / 拆解面，五步结构强制脊梁骨
3. **个人语调锚点**——喂 AI 一段你自己的爆款，文字风格不再"平均值"

## 二、工作流（T1-T4）

```
T1 选题（10 分钟）
  └─ 第一追问：5 个角度撒网 → 选 1
T1.5 骨架选型（5 分钟）
  └─ 教程/避坑 → 问题链 │ 个人感悟 → 故事线 │ 观点输出 → 拆解面
T2 深度（15 分钟）
  └─ 第二追问：核心观点推 3 层洞察
T3 写作（30 分钟）
  └─ 第三追问：喂语调样本 + 骨架填空
T4 自检（10 分钟）
  └─ 骨架完整性 + 三段一致性 + 评论钩子
─────────────────
总计：约 70 分钟 / 篇
```

**对比 v7.2**：
- 步骤：7 步 → 4 步
- Agent 数：2 个 → 1 个
- 对话轮数：1 轮 → 强制 3 轮
- 配图：NotebookLM 多图 → 极简 1-2 张主图
- 发布：五平台 → 仅头条

## 四、核心规则

1. **强制三轮对话**：单轮 prompt 直接拒绝，必须走 3 轮
2. **选题必走"五角度"**：第一轮不许直接写，先撒 5 个角度
3. **骨架填空不许跳步**：五步缺一不可，可调顺序不许删
4. **语调样本必喂**：第三轮必须贴一段你自己的爆款做锚点
5. **配图极简**：每篇 1-2 张主图，不许堆图
