# T3 写作 · 三追问第三轮：换皮 + 骨架填空

> **目标**：第三轮喂语调样本 + 用骨架填空模板生成正文。

## 第三轮核心 Prompt 模板

```
好，基于以上深度分析（T2 的三层），现在开始写正文。

但有一个要求——用下面这篇文章的语气和节奏来写：

[粘贴一段你自己满意的、语调自然的文章，200-400 字即可]

不是让你抄内容。是让你学习它的：
- 句子长度的比例
- 段落切换的节奏
- 连接词的使用方式
- 第一人称和读者的距离感

现在请按以下骨架写一篇 1500-2500 字的 [问题链 / 故事线 / 拆解面] 结构的文章：

[粘贴下方对应骨架的填空模板]
```

## 三骨架填空模板

### 骨架一：问题链

```
请严格按以下五步结构写关于 [话题] 的文章：

第一步：痛点现场
用一段具体的场景或数据，让读者立刻感受到"这个问题跟我有关"。

第二步：常见误区
列出读者面对这个问题时最容易踩的 3 个坑。
每一条用一句话说清楚"为什么不对"。

第三步：真正的原因
不是"使用不当"，是更底层的东西。
挖到读者自己可能都没意识到的那一层。

第四步：解决方案
不是泛泛的"要多练习"。是具体到"第一步做什么、第二步做什么"的操作序列。

第五步：一句话带走
不要总结全文。给读者一句能截图、能转发、明天还能记住的话。
```

### 骨架二：故事线

```
请严格按以下五步结构写关于 [话题] 的文章：

第一步：一个具体的时刻
不要从"最近""当今"开头。直接从某个具体的瞬间切入——
你在哪、发生了什么、你什么感受。

第二步：当时的反应
你当时是怎么想的？做了什么决定？为什么那样做？

第三步：后来的转折
发生了什么让你意识到"之前的想法可能不对"？
那个转折点是什么？

第四步：现在的理解
经过了这些之后，你现在怎么看当初那个问题？
跟当初有什么不同？

第五步：读者能带走的东西
不是"所以我们要 XXX"。是"如果你也在经历类似的事，
这一句话可能对你有用"。
```

### 骨架三：拆解面

```
请严格按以下五步结构写关于 [话题] 的文章：

第一步：主流观点
先说清楚"大家现在普遍怎么认为"。
不要讽刺，不要贬低，客观陈述。

第二步：数据的裂缝
拿出一个具体的、有来源的数据或案例，
让它跟主流观点产生矛盾。

第三步：被忽略的变量
解释这个矛盾为什么存在——不是主流观点错了，
是它忽略了一个关键变量。

第四步：新的视角
基于那个被忽略的变量，重新理解这个问题。
给出一个跟主流观点不同但更完整的框架。

第五步：对读者的意义
这个新视角对他们有什么实际影响？
他们今天开始可以做什么不一样的事？
```

## 写作时的硬约束

1. **不许用默认口吻**——必须基于你贴的语调样本
2. **五步不许跳**——可以调顺序，不许删步
3. **每段开头不许用**"最近"、"当今"、"值得注意的是"、"综上所述"
4. **结尾必须留"评论钩子"**——一句能引发讨论的话（不是金句结束）
5. **配图极简**——每篇 1-2 张主图，不许堆图

## AI 默认文风的反制

AI 默认文风是"几十亿篇安全文本的平均值"——特征：
- 段落长度整齐划一（3-5 行）
- 连接词泛滥（"不仅...而且..."、"综上所述"）
- 第一人称和读者距离感远
- 形容词堆砌（"显著的"、"巨大的"）

**反制方法**：
- 句子长短比例：3:1（短句 70%，长句 30%）
- 段落切换要有节奏（有时 2 行一段，有时 5 行一段）
- 第一人称距离感：根据你贴的样本
