# T1.5 骨架选型速查表

> **目标**：根据 T1 选定的角度，3 秒决定用哪个骨架。
> **数据基础**：基于 100 篇历史文章复盘数据反推

---

## 一、三骨架总览

| 骨架 | 五步结构 | 力学 | 读者心智运动 | 数据表现 |
| --- | --- | --- | --- | --- |
| **问题链** | 痛点 → 误区 → 原因 → 方案 → 金句 | 张力 + 解释 + 行动 | "追答案" | 教程避坑型主流骨架 |
| **故事线** | 时刻 → 反应 → 转折 → 理解 → 共鸣 | 弧线 + 共情 + 升华 | "代入体验" | 适合"做了 X 年 XX"人设背书 |
| **拆解面** | 主流 → 裂缝 → 变量 → 新视角 → 意义 | 认知落差 + 框架升级 | "自我更新" | **你的账号主流骨架**（爆款 12 篇主用） |

---

## 二、决策树

```
你的文章是"教别人做一件事"？
  ├─ YES → 问题链
  └─ NO ↓
你的文章是"讲一段个人经历和感悟"？
  ├─ YES → 故事线
  └─ NO ↓
你的文章是"推翻一个常见观点"？
  └─ YES → 拆解面（⭐️ 数据驱动首选）
```

**数据洞察**：你的账号 100 篇里，**选购横评 69 篇 + 教程避坑 23 篇**占绝对主流（92%）。这两种类型天然适配**拆解面 + 问题链**。故事线用的少。

---

## 三、一句话速判

- **问题链**：读者读完知道"下一步做什么"
- **故事线**：读者读完感觉"这说的就是我"
- **拆解面**：读者读完想转发给朋友"我之前竟然不知道这个"

## 四、不确定用哪个？

把话题用一句话写下来，自己读一遍——你直觉上觉得它更像：
- **教程**（步骤、避坑、方法）→ 问题链
- **故事**（经历、感悟、反思）→ 故事线
- **辩论**（观点、立场、反驳）→ 拆解面

**直觉通常是对的**。

## 五、骨架 × 选题域适配矩阵（数据反推）

| 选题域 | 推荐骨架 | 数据依据 |
| --- | --- | --- |
| 冰箱横评 | **拆解面** | 爆款率 57%，主流结构 |
| 空调选购 | **问题链 + 拆解面** | 师傅猫腻/参数对比 |
| 电视横评 | **拆解面** | 多品牌对决型主流 |
| 显示器 | **对比选择型** | 样本都是爆款 |
| 油烟机避坑 | **问题链** | 选购避坑型主流 |
| 热水器 | 谨慎 | 爆款率仅 14% |
| 洗衣机 | **避开** | 爆款率仅 11% |

## 六、骨架交叉验证清单

| 检查项 | 问题链 | 故事线 | 拆解面 |
| --- | --- | --- | --- |
| 第一段是痛点现场？ | ✅ | ❌（应是具体时刻） | ❌（应是主流观点） |
| 第二段是张力/反应/裂缝？ | ✅ | ✅ | ✅ |
| 结尾是金句/共鸣/意义？ | ✅ | ✅ | ✅ |
| 篇幅 1500-2500 字？ | ✅ | ✅ | ✅ |
