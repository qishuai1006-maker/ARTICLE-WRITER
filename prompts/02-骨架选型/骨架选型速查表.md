# T1.5 骨架选型速查表

> **目标**：根据 T1 选定的角度，3 秒决定用哪个骨架。

## 三骨架总览

| 骨架 | 五步结构 | 力学 | 读者心智运动 |
| --- | --- | --- | --- |
| **问题链** | 痛点 → 误区 → 原因 → 方案 → 金句 | 张力 + 解释 + 行动 | "追答案" |
| **故事线** | 时刻 → 反应 → 转折 → 理解 → 共鸣 | 弧线 + 共情 + 升华 | "代入体验" |
| **拆解面** | 主流 → 裂缝 → 变量 → 新视角 → 意义 | 认知落差 + 框架升级 | "自我更新" |

## 决策树

```
你的文章是"教别人做一件事"？
  ├─ YES → 问题链
  └─ NO ↓
你的文章是"讲一段个人经历和感悟"？
  ├─ YES → 故事线
  └─ NO ↓
你的文章是"推翻一个常见观点"？
  └─ YES → 拆解面
```

## 一句话速判

- **问题链**：读者读完知道"下一步做什么"
- **故事线**：读者读完感觉"这说的就是我"
- **拆解面**：读者读完想转发给朋友"我之前竟然不知道这个"

## 不确定用哪个？

把话题用一句话写下来，自己读一遍——你直觉上觉得它更像：
- **教程**（步骤、避坑、方法）→ 问题链
- **故事**（经历、感悟、反思）→ 故事线
- **辩论**（观点、立场、反驳）→ 拆解面

**直觉通常是对的**。

## 骨架交叉验证清单

| 检查项 | 问题链 | 故事线 | 拆解面 |
| --- | --- | --- | --- |
| 第一段是痛点现场？ | ✅ | ❌（应是具体时刻） | ❌（应是主流观点） |
| 第二段是张力/反应/裂缝？ | ✅ | ✅ | ✅ |
| 结尾是金句/共鸣/意义？ | ✅ | ✅ | ✅ |
| 篇幅 1500-2500 字？ | ✅ | ✅ | ✅ |

## 选题 × 骨架适配矩阵（基于老七聊 AI 经验 + 头条算法偏好）

| 选题类型 | 推荐骨架 | 头条数据表现预期 |
| --- | --- | --- |
| 家电选购指南 | 问题链 | 中高（信息密度高） |
| 家电横评对比 | 拆解面 | 高（争议性强） |
| 家电踩坑复盘 | 故事线 / 问题链 | 中高（共鸣 + 实用） |
| AI 工具教程 | 问题链 | 中高 |
| AI 行业观点 | 拆解面 | 高（评论钩子强） |
| 个人成长反思 | 故事线 | 中（依赖作者人格魅力） |
| 育儿/家庭 | 故事线 / 问题链 | 高（情感共鸣） |
| 财经解读 | 拆解面 | 高（数据钩子） |
