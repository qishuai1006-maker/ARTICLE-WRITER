## 1. 选购决策骨架（三步走 · 顺序不能乱）

```
第 1 步：选门体（先于一切 · 按生活习惯/地域选，不按预算/颜值）
第 2 步：选品牌（看核心技术入手口诀，不看故事/联名）
第 3 步：选型号（在同品牌内识破减配溢价）
```

**核心原则：门体 > 品牌技术 > 具体型号。**
> "门体是血一样的教训——那些都是次要的，门体是你拿回家使用体验的事，净味保鲜都没它重要。"

**为什么门体排第一**（背后的物理逻辑）：门数越多 = 单次开门冷量流失越少 = 温度波动越小 = 保鲜越好。对开门单次开门从上到下全开，冷量流失大、温度波动大、不利保鲜——这是对开门被淘汰的物理根。

## 2. 品牌入手口诀（差一个不买）

| 品牌 | 入手口诀（认准什么才买） | 口诀背后的逻辑 |
|---|---|---|

## 3. 反常识钩子库

### 共识型（我们的定论 · 可直接下判断）
- **门体梯队：法式门 > 十字门 > T 型门 > 对开门**——法式是未来主流，对开门因冷量流失大被淘汰
- **双系统（双蒸发器）是防串味唯一工程级解**——单系统（含"单系统双循环"）再加多少净味模块都治标不治本
- **线上线下同配置不同价 = 溢价陷阱**——不存在"门店品质更好"，同品牌不分双生产线
- **保鲜技术路线**：海尔全空间 / 卡萨帝 MRA 低氧窖藏 / 美的微晶 / 容声 WILL / 东芝雾化
- **除菌净味梯队**：EPP ≈ Fresh Turbo Pro > IDP / PST > PT / DEO（主动净味 > 被动）

### 独家型（强钩子 · 颠覆大众认知）
- **"双循环 ≠ 双系统，差一整套蒸发器"**——商家话术陷阱。单系统双循环温度能分控，但冷气照样串味，不是真双系统
- **"东芝大法式 = 美的产线贴牌"**——买东芝必须选日式多门产线，否则失去买日系品牌的意义
- **"普通人冰箱天花板 6000"**——销量榜卖得好的没超 6000；8000 以内别碰高端御三家（卡萨帝/COLMO/璀璨），那个预算遮住标就是海尔美的海信
- **"同技术底子换皮 = 溢价陷阱"**——多一个抽屉/换个外观就贵 1000-2000，1000 块够干不少事

### 争议型（业内有两种声音 · 评论触发器）
- **"单系统双循环（如海尔 485/512 这类）能不能买？"**
  - 防串味底线党：不主动推，单系统照样串味
  - 够用党 / 预算紧 / 空间小：单系统多风道带净化也能用，防串味不是唯一标准
  - **我们的建议：看需求分两类**——3500+ 预算、在意串味，认双系统；预算紧或不在意串味，单系统不是不能买。别一刀切

## 4. 减配溢价识破方法论（不点具体型号 · 只讲类型）

| 溢价类型 | 识破方法 | 我们的判断 |
|---|---|---|
| **多抽屉溢价** | 同底子，多一个抽屉贵 1000-2000 | 用不上的抽屉 = 白花，pass |
| **换外观溢价** | 同底子，换面板/颜色贵一截（金属→玻璃等） | 为颜值买单要想清楚，否则同预算看更高端 |
| **减配借名气** | 借老型号名气，但净味/技术降级（如 PST→PT） | 直接 pass——真减配借名 = 坑 |
| **减配做价格差** | 去掉某功能（如制冰）补满配空缺，价差明显 | 反而值得薅——补市场空缺，性价比高 |

## 5. 价位天花板 / 人群·场景分流

| 价位 / 人群 | 我们的判断 |
|---|---|
| **普通人天花板 = 6000** | 销量榜卖得好的没超 6000，正常人 3000-5000 |
| **8000 以内** | 别碰高端御三家（卡萨帝/COLMO/璀璨），遮住标 = 海尔美的海信 |
| **8000 以上** | 单买冰箱才值得碰高端；高端要成套买才有体验 |
| **北方 / 囤货党** | 法式五门（闭眼推，未来趋势，什么习惯都满足） |
| **南方 / 精细分储** | 十字门（买得少样多，好找好放） |
| **出租屋** | 对开门够用（其他场景不推荐） |
| **装修人群** | 先定零嵌（底部散热，橱柜预留 600mm 深）；宽度预留 × 机型对照见 L1 |

## 6. 本品类特别注意的元原则
- **每家能买的型号不超过 3 款**——用口诀筛掉 90%，别在品牌里海选
- **看厂家意图**——去年容声嵌入式都是单系统、市场反馈差，今年上双蒸双净是想打回来（这类"补救款"反而性价比高）
