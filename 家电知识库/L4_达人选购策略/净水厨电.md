# 一、净水设备

## 1. 选购骨架（先懂全屋水路，再选设备）
净水是**唯一需要先懂"系统"再选单品**的——串联系统，不是孤立设备。

```
水表 → 总闸 → 前置过滤器 → 中央净水机 → 软水机 → 末端 RO → 热水器/管线机/水槽/浴室/淋浴/马桶/洗衣机/洗碗机/地暖
```

## 2. 净水套餐（核心三件套）
| 设备 | 角色 | 必备？ |
|---|---|---|
| **前置过滤器** | 全屋第一关，过滤砂石/铁锈，无需换芯 | ⭐ 必备（保护下游所有设备） |
| **RO 净水器** | 核心，过滤后直饮，装橱柜下 | ⭐ 必备（直饮唯一解） |
| **管线机** | 加热指定温度 | 可选（需搭零陈水，距离 ≤ 10 米，同品牌适配） |

**核心**：RO 必须搭前置（延长 RO 膜寿命），管线机按需。

## 3. 反常识钩子库
### 独家型（强钩子）
- 🔥 **"超滤水不能直饮，只有 RO 反渗透能直饮"**——反"装了净水器就能喝"（超滤 0.01 微米滤不掉病毒/重金属/钙镁）
- **"通用滤芯不推荐，主流品牌已不生产"**——反"通用滤芯便宜好用"
- **"RO 膜优先选陶氏膜"**——行业标杆，脱盐率高
- **"零陈水优选"**——非零陈水第一杯不可喝（放置后杂质渗透）；零陈水纯水回流，第一杯直饮

## 4. RO 净水器核心参数
**通量 800G+**（3-4 秒接满 150ml，800G 以下不推荐）/ **废水比 3:1 > 2:1 > 1:1** / 额定净水量越大越好 / 零陈水优选 / 双出水性价比高 / TDS 数显优选

## 5. 前置过滤器三原则
- **要安全**：≤ 40 微米，316 不锈钢，品牌售后
- **要省心**：反冲洗免换芯，通量 ≥ 4T/H，带水压表、月份盘
- **要高配**：铜接口，防爆防冻瓶

## 6. 净水品牌判断（按配置 · 待内部稿补口诀）
美的（白泽/星河，星河用陶氏 RO + 零陈水）/ 海尔（鲜活水 1200G）/ 352（陶氏膜性价比）/ 小米 / COLMO

# 二、厨电小品类（洗碗机 / 蒸烤 / 消毒柜）

## 共性选购框架
**先按"人数/家庭规模"选容量/套数 → 看核心硬指标 → 附加功能按需。**

## 洗碗机
- **价值锚点**：每天省半小时，**一年相当于多 7 天假期**
- **套数**：1-2 人 10 套 / 3-4 人 13 套 / 4-6 人 16 套 / 6 人+ 18 套
- **重点看**：水压（越高越干净）、消毒星级（二星/三星/四星）、储存时间（72h+ 更佳）

## 蒸烤一体机
- **容量**：1-2 人 45L / 4-5 人 50L / 6-8 人 55L / 8 人+ 65L
- **内胆**：预算足选**搪瓷**（莫氏硬度 9，耐刮易清洁），预算少选釉感自净

## 消毒柜
- **消毒方式**：紫外线 + 臭氧组合（主流家用，效果好对餐具要求低）
- **消毒等级**：**优先二星级**（可杀乙肝病毒、脊髓灰质炎等顽固细菌，除菌率 99.99%）
- **材质**：优选 304 不锈钢
- **容量**：1-2 人 30-60L / 4-8 人 100L

## 厨电反常识钩子
- **"洗碗机一年省 7 天假期"**（价值锚点）
- **"消毒柜优先二星级，能杀乙肝病毒"**（硬指标）
- **"蒸烤内胆选搪瓷（莫氏硬度 9），不选釉感"**（耐刮）
