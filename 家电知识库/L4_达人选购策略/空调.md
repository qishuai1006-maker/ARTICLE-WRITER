## 1. 选购决策骨架（四步 · 空调是参数驱动型）

```
第 1 步：选匹数（按适用面积——空调的"物理形态"）
第 2 步：选内外机配置（压缩机/节流装置/铜管——核心技术分歧）
第 3 步：看参数（能效/风量/自清洁）
第 4 步：选型号（按价位段 · 看配置有没有减配）
```

## 2. 品牌入手判断（按配置档位 · 非口诀式）
> 选购指南未给"差一个不买"式品牌口诀，按配置档位判断。待内部达人稿补口诀。

| 价位段（国补后） | 配置最猛 | 配置保守 / 慎选 |
|---|---|---|
| **2000 档** | 华凌神机二代 Pro / TCL 真省 / 海尔净省（双排+电子膨胀阀+高 APF+大风量） | 格力云佳（一代内机 + 低风量 640） |
| **2500 档** | 海尔净省电 pro / 美的风尊二代 / 小米自然风 pro | 格力云锦 3 代（风量 660 偏低） |
| **3000 档** | 美的风尊二代 pro / 无风感 pro / 小米上出风 pro | 格力 AI 节能王子（1.6 排） |

**判断**：同价位华凌/TCL/海尔配置最实在（双排铜管 + 电子膨胀阀 + 高 APF + 大风量）；**格力一贯配置保守**（一代/1.6 排内机 + 低风量），价位却高，性价比弱。

## 3. 反常识钩子库

### 共识型（我们的定论）
- **卧室挂机**：变频 + 电子膨胀阀（静音 + 精准控温）
- **客厅柜机**：变频 + 毛细管/电子膨胀阀均可（柜机可忽略电子膨胀阀和铜管）

### 独家型（强钩子 · 颠覆大众认知）
- **"1P 和 1.5P 差 200 块，但配置差一代"**——1P = 单排 + 毛细管，1.5P = 1.6 排 + 电子膨胀阀。花 200 买的是**配置代差**不是制冷量
- **"1 级能效贵的不只是省电，贵在配置全面更优"**（铜管多 + 节流装置好 + 舒适性好）。3 级能效配置缩水
- **"柜机不用纠结电子膨胀阀和铜管"**——反"参数都要看"
- **"顶楼/西晒/层高 3 米以上/密封差/高海拔要升一档匹数"**——反"按面积表照搬"

### 争议型
> 空调外部资料争议点较少，待内部达人稿补争议钩子。

## 4. 减配溢价识破方法论（不点具体型号）

| 溢价类型 | 识破方法 | 我们的判断 |
|---|---|---|
| **小匹数减配** | 1P = 单排+毛细管（vs 1.5P 的 1.6 排+电子膨胀阀） | 差 200 买配置代差，优选 1.5P |
| **能效减配** | 3 级能效配置全面缩水 | 不只省电问题，是配置差，优选 1 级 |
| **格力配置保守** | 同价位一代内机 / 1.6 排 / 低风量 | 为品牌溢价买单，性价比弱 |
| **铜管减配** | 双排 > 1.6 排 > 单排 | 看铜管排数，别只看品牌 |

> 匹数-面积完整对照、内外机配置详解见 `L1_品类技术原理/空调.md`。

## 5. 价位 / 人群·场景分流

| 场景 | 我们的判断 |
|---|---|
| **卧室** | 1.5P 挂机 + 变频 + 电子膨胀阀 |
| **客厅** | 3P 柜机（海信/华凌性价比突出；格力价位高风量反而小） |
| **特殊场景**（顶楼/西晒/层高 > 3 米/密封差/大面积玻璃/高海拔/过冷过热） | 匹数**升一档** |
