## 1. 选购决策骨架（四步 · 比冰箱/电视多一步——电机）

```
第 1 步：选款式（单洗/洗烘一体/套装 · 按地域 + 实际需求选）
第 2 步：选电机（直驱 vs 皮带 · 按换洗频率选——洗衣机核心技术分歧）
第 3 步：选品牌（电机定下后，品牌自然收窄）
第 4 步：选型号（同品牌内识破减配溢价）
```

**为什么比冰箱/电视多一步**：洗衣机有核心技术分歧（直驱 vs 皮带），这个分歧决定了能选哪些品牌——**直驱只有海尔/LG 做，皮带是小天鹅/松下/西门子**。所以必须先定电机再定品牌。

## 2. 品牌入手口诀（差一个不买）

| 品牌 | 入手口诀（认准什么才买） | 电机派 |
|---|---|---|
| **小天鹅** | **超微净泡 + 磐石电机 + 12 公斤**（水魔方买 **2 代**） | 皮带 |
| **海尔** | **直驱（1400 转）+ 精华洗 + 六维减震** | 直驱（蓝色星球只有海尔/LG 做，海尔 3000 内能买到） |
| **松下** | 套装认准**双转子变频压缩机 + 三重绒毛过滤** | 皮带（套装/烘干机强项） |

## 3. 反常识钩子库

### 共识型（我们的定论 · 可直接下判断）
- **洗烘套装 > 洗烘一体**（除非 6000+ 热泵，其他洗烘一体"给狗狗都不使"）
- **烘干机看双擎 1:1 正反转 + 绒毛过滤**
- **容量越大洗得越干净**（不只看家庭人数，关乎洗净效果——明年全是 12 公斤）

### 独家型（强钩子 · 颠覆大众认知）
- **"直驱不一定比皮带好，看你换洗频率"**——反"直驱 = 高端 = 好"。换洗勤选直驱（洗得快），攒一块洗选皮带（慢工出细活，护衣）
- **"水魔方买 2 代（超微净泡），1 代没效果 3 代蓝氧是溢价"**——反"代数越高越好"
- **"北方买套装白扔 3000，烘干机八百年不用一回"**——反"一步到位"
- **"洗衣机除菌再好也比不上阳台晒一会"**——反"除菌值得加钱"
- **"云溪 30+ 款只看 2 款，其他都是换皮溢价"**——反"型号多 = 选择多"

### 争议型（业内有两种声音 · 评论触发器）
- **转速选 1200 还是 1400？**
  - 护衣/静音党：1200 转噪音小、护衣、寿命长
  - 脱水效果党：1400 转脱水更干，同价位被降到 1200 = 减配
  - **我们的建议：日常家用 1200-1400 都行**；但要识破"同价位悄悄降 1200 转"的减配——主动选 1400 不算亏，被动被降要 pass

## 4. 减配溢价识破方法论（不点具体型号）

| 溢价类型 | 识破方法 | 我们的判断 |
|---|---|---|
| **型号海选陷阱** | 一个系列 30+ 款让人挑花眼 | 用口诀筛到 2-3 款（海尔云溪 30 款只看 2 款） |
| **带"轻"字减配** | 轻奢/轻享款 | 今年最大的坑，pass |
| **除菌溢价** | 同底子多个除菌贵 500-800 | 不值，阳台晒一会比除菌强 |
| **代数溢价** | 水魔方 3 代蓝氧贵 1000+ | 普通衣服用不上，2 代（超微净泡）够 |
| **波轮/筒径盲区** | 只看型号没看波轮vs滚筒、筒径 | 波轮适合老人/出租屋（快、便宜、磨损大）；大筒径（525/535）摔打路径长、少褶皱 |

## 5. 价位 / 人群·场景分流

| 人群 / 场景 | 我们的判断 |
|---|---|
| **北方** | 单洗（3000 就是顶配，多花 200 买洗烘一体 = 白花） |
| **南方 / 北方养宠** | 洗烘套装（5000+，用过后悔买晚了） |
| **极致懒人 + 6000 预算** | 洗烘一体（**必须热泵烘干**，冷凝式不行） |
| **换洗勤** | 直驱（海尔） |
| **攒一块洗 / 重护衣** | 皮带（小天鹅） |
| **老人 / 出租屋 / 预算紧** | 波轮（快、便宜，接受磨损大） |

## 6. 本品类特别注意的元原则
- **用不上的就别买**——北方套装、非热泵洗烘一体、蓝氧 3 代都是"用不上"的典型
- **每家能买的型号不超过 3-4 款**——云溪 30 款只看 2 款
