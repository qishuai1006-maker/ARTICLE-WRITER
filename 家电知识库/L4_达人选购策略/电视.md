## 1. 选购决策骨架（三步走 · 顺序不能乱）

```
第 1 步：选尺寸（先于一切 · 按观影距离选，不按预算/客厅大小）
第 2 步：选品牌（看核心技术路线——屏幕派还是芯片派，不看故事/联名）
第 3 步：选型号（同品牌内按技术口诀筛）
```

**核心原则：尺寸 > 品牌技术 > 具体型号。**
> "尺寸选错，看啥都白费。无论你选什么品牌、花多少钱，沉浸感一定不好——画质好那都是后话。"

**为什么尺寸排第一**：电视的核心体验是**沉浸感**，沉浸感由尺寸×距离决定，**不是由画质参数决定**。3 米观影距离买 65 寸，跟 1 米距离看平板一样，多余花电视钱。

## 2. 品牌入手口诀（差一个不买）

**底层元认知：电视画质只有两条技术路线——要么屏幕好，要么芯片好，没有第三条。** 只有掌握这两者之一的品牌才算"带核心技术"，只能在这 4 家里选。

| 品牌 | 入手口诀（认准什么才买） | 路线 |
|---|---|---|
| **TCL** | **SQD + 万象分区 + 星曜屏**（三个都带才能买） | 屏幕派（华星光电面板厂自产） |
| **海信** | **带独立画质芯片（信芯）能买，不带不能买** | 芯片派（国产唯一自研） |
| **创维** | **只买壁画/壁纸电视**，其他不看 | 差异化路线（没走屏幕/芯片两条路） |
| 三星 / 索尼 | 技术派但外资 | 禁推（售后/溢价，见 L1） |

## 3. 反常识钩子库

### 共识型（我们的定论 · 可直接下判断）
- **画质只有两条路：屏幕派（TCL/三星）或芯片派（海信/索尼）**，没有第三条
- **尺寸按观影距离选，不是越大越好**（完整 7 档对照见 L1）
- 电视是**重资产长周期**行业，搞技术靠积累沉淀，不是今天想做屏/芯片就能做

### 独家型（强钩子 · 颠覆大众认知）
- **"买 TCL 不能看画质调教，那倒反天罡"**——TCL 强项是屏幕不是调校，不在强项上花钱就是买错
- **"不带画质芯片的海信，有的比带芯片的还贵"**——价格锚定陷阱，贵 ≠ 带核心技术
- **假洋品牌识破**：东芝 = 海信做的（已被收购）、松下 = TCL 代工（已退出国内）、夏普 = 技术落后档次差、飞利浦仅高端可买
- **"尺寸选错，画质再好也白搭"**——反"先看画质参数"，沉浸感才是根

### 争议型（业内有两种声音 · 评论触发器）
- **华为电视能不能买？**
  - 高端画质/游戏党：不推荐——不支持杜比视界、SOC 差、无 HDMI2.1、条状控光分区、定价高
  - 鸿蒙生态/无广告党：可考虑——系统流畅、生态联动、无开机广告
  - **我们的建议：看需求分两类**——追求画质/游戏别买华为；图鸿蒙生态 + 无广告的老人/华为全家桶用户可选

## 4. 减配溢价识破方法论（不点具体型号）

| 溢价类型 | 识破方法 | 我们的判断 |
|---|---|---|
| **同配置不同价** | 同样的分区/亮度/芯片，换个型号壳贵 2000 | 纯溢价，pass，看配置不看型号名 |
| **买错强项（倒反天罡）** | 买 TCL 看"画质调教"、买海信看"屏幕好" | 在品牌非强项上花钱 = 买错，认准品牌核心技术再买 |
| **联名/艺术溢价** | 哈曼卡顿联名音响、艺术电视外壳 | 差异化话术非核心技术，同预算看屏幕/芯片 |

## 5. 价位 / 人群·场景分流

| 场景 | 我们的判断 |
|---|---|
| **沉浸感优先** | 尺寸买够（3 米起 75 寸），别在尺寸上省钱——尺寸是体验根 |
| **画质党** | 屏幕派选 TCL、芯片派选海信，**别交叉买**（TCL 买调校/海信买屏幕 = 倒反天罡） |
| **装修/颜值** | 创维壁纸（差异化路线），但画质不如同价 TCL/海信 |
| **主机游戏** | 物理刷新 ≥ 120Hz + HDMI 2.1（参数见 L1） |
| **避坑** | 东芝/松下/夏普/飞利浦低端 = 假洋品牌/代工/贴牌，同预算选 TCL/海信 |

## 6. 本品类特别注意的元原则
- **买大牌选性价比，不买小牌选对的**——电视只剩 4 家带核心技术，别碰杂牌/假洋品牌
- **看核心技术，不看故事/联名**——创维哈曼卡顿/艺术电视都是话术
