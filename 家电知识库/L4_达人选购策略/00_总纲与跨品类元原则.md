## 一、L4 的定位（与 L1/L2/推品手册的分工）

| 层 | 回答什么 | 内容性质 | 稳定度 |
|---|---|---|---|
| **L1 技术原理** | 这个品类**怎么工作 / 参数什么意思 / 虚标陷阱** | 客观知识 + 硬指标 | 高（1 年） |
| **L2 品牌档案** | 品牌是谁 / 技术路线 / 产品线定位 | 品牌客观背景 | 中（季度） |
| **L4 达人选购策略** | **作为内行我们怎么一步步选 / 每个品牌认准什么 / 怎么识破溢价** | 主观策略 + 人味钩子 | 骨架长期 / 口诀约 1 年 |
| 推品手册 / MCP | **推哪款型号 / 什么价** | 决策表 + 实时价 | 低（型号价格常变） |

**写稿时的召回组合**：
- **避坑型 / 观点型 / 争议型文章** → 重召回 **L4**（钩子 + 口诀 + 减配识破）+ L1 兜底技术
- **参数百科型 / 指南型文章** → 重召回 **L1**（参数词典 + 分档矩阵）+ L4 补人味
- **涉品牌文章** → 必叠加 **L2**

⚠️ **L4 不含推荐型号池 / 价格表**（归推品手册 / MCP）。L4 只放"为什么这么选"的判断与方法论。
⚠️ **L4 不标任何出处**——所有判断就是我们（意见领袖）自己的。共识是我们的定论；分歧内化成"看需求分两类"的分人群建议；争议表述"业内有两种声音"，不点名任何来源。

## 二、弹性选购骨架（3-6 步 · 首尾固定 · 中间弹性）

经多品类验证，选购方法论骨架**稳定但步数弹性**：

```
第 1 步【必有】：物理形态 —— 门体/尺寸/款式/造型/匹数/容量（按使用习惯/地域/户型选）
第 2 步【可选】：核心技术分歧 —— 电机/内外机/清洁技术/类型分歧（有技术路线分叉的品类才填）
第 3 步【可选】：参数层 —— 风量静压/能效/转速/通量（参数重的品类单列）
第 N 步【必有】：品牌入手口诀 —— "差一个不买"
第 N+1 步【必有】：型号减配溢价识破 —— 同品牌内识破换皮/减配/差价
```

| 品类 | 步数 | 独有维度 |
|---|---|---|
| 冰箱 / 电视 | 3 | — |
| 洗衣机 / 空调 / 净水 | 4 | 电机 / 内外机 / RO vs 超滤 |
| 油烟机 | 5 | 参数（风量静压）+ 清洁技术（两派） |
| 热水器 | 6 | 类型分歧（燃气 vs 电）+ 零冷水 |

## 三、跨品类选购元原则（长期稳定 · 写稿价值观主线）

> 以下经冰箱 / 电视 / 洗衣机 / 油烟机验证稳定；空调 / 热水器 / 净水 / 厨电复核中。是所有 L4 品类卡的共同价值观底座，写稿时可作"内行人设"的贯穿主线。

1. **买大牌选性价比，不买小牌选对的**——别在杂牌里挑"对的"，在大牌里挑性价比
2. **第一步是物理形态，错了后面全白费**——门体/尺寸/款式先定，型号次要
3. **看核心技术，不看故事/联名/营销词**——哈曼卡顿联名、艺术电视都是差异化话术，不是核心技术
4. **"差一个不买"口诀收尾**——每个品牌一句强判断，可截图、易传播
5. **不是最新技术就是最好的**——新技术上来先看价格，溢价太高就拉倒
6. **用不上的就别买**——多花 200 万一用得上 = 白花钱（反功能堆砌）
7. **同技术底子换皮 = 溢价陷阱**——多一个抽屉/换外观/加个除菌就贵几百上千，识破它
8. **按使用习惯/地域选，不按预算/跟风选**——北方单洗/南方套装；防串味底线党/够用党
9. **每家能买的型号不超过 3-4 款**——用口诀筛掉 90%，别在品牌里海选
10. **看厂家意图，不盲目选**——去年单系统今年上双蒸=想打回来；买去年款=清库存

## 四、写稿策略：钩子型素材 vs 参数型素材

L4 里的素材分两种性质（**标内容性质，不标来源**），写不同文章用不同组合：

| 素材性质 | 特征 | 适合文章类型 |
|---|---|---|
| **钩子型**（反常识/口诀/减配识破/争议） | 有立场、颠覆认知、可截图、能引评论 | 避坑型 / 观点型 / 争议型 |
| **参数型**（对照表/分档矩阵/尺寸公式/技术排名） | 硬数据、结构化、收藏价值高 | 指南型 / 百科型 / 清单型 |

**最强组合**：钩子型给灵魂（点击+信息增益），参数型给血肉（密度+收藏死线）。一篇好稿 = L4 钩子 + L1 参数。
