# 家电知识库 · 索引与召回规则

> 本库是推品逻辑手册的**背景层补充**：手册管"推哪款"（决策），本库管"为什么这么选"（技术原理 + 品牌背景 + 场景调研）。
> 三层正交，互不复制。

## 三层定位
| 层 | 回答什么 | 稳定度 | 谁召回 | 何时召回 |
|---|---|---|---|---|
| **L1 品类技术原理** | 参数怎么来的、原理是什么、避坑点 | 高（一次建好） | Agent 02 | 动笔前按品类 |
| **L2 品牌档案** | 品牌历史/技术路线/产品线/售后 | 中（季度更新） | Agent 02 | 写涉品牌选题 |
| **L3 场景调研报告** | 特定场景的定制调研结论 | 低（按需产出） | Agent 01/02 | 写匹配场景 |
| **L4 达人选购策略** | 怎么选 / 入手口诀 / 反常识钩子 / 减配识破方法论 | 骨架长期 / 口诀约 1 年 | Agent 02 | 写避坑/观点/争议型文章 |

## 多维召回规则（Agent 02 动笔前必查）

写某品类选题时，召回组合：
1. **必读**：`L1_品类技术原理/<品类>.md`（技术背景，决定参数怎么写）
2. **涉品牌**：`L2_品牌档案/<正文出现的品牌>.md`（品牌弹药，决定品牌论述深度）
3. **避坑/观点/争议型文章**：`L4_达人选购策略/<品类>.md`（达人选购策略 = 反常识钩子 + 入手口诀 + 减配识破方法论 = **信息增益的核心弹药**，补 L1 没有的"人味判断"）。参数百科型文章可跳过 L4 重 L1。
4. **场景匹配**：若选题是特定场景（高端/租房/母婴/养宠…），查 `L3_场景调研报告/` 有无匹配报告
5. **决策层**：仍以 `推品逻辑手册_2026.md` 对应章节为**首推型号唯一来源**——本库不替代决策，只提供"为什么"
6. **事实核对**：contentfleet MCP（✅已接入）调 `product_search` 验证型号参数 + `tavily_search` 双源交叉 + `douyin_search` 趋势信号（实时，防静态知识过期）

## 切片召回示例
- 写「洗衣机 3000-5000 档」→ `L1_洗衣机.md`(§4 价位段) + `L2_小天鹅.md`(小乌梅5.0) + `L2_海尔.md`(云溪4.0) + 推品手册 §三
- 写「万元高端洗烘套装」→ `L1_洗衣机.md`(§烘干/热泵) + `L3_高端洗烘套装调研`(若有) + 推品手册 §三洗烘套装
- 写「老人专用波轮」→ `L1_洗衣机.md`(§5 场景/§波轮) + `L2_小天鹅.md`(水魔方) + 推品手册 §三波轮

## 维护规则
- L1/L2 卡片**观点必须标注来源**（CEO / MCP / tavily / 调研），不可飘。
- 价格/型号类信息标注 `更新日期`，超 3 个月需用 MCP `product_search` 复核。
- 调研报告标注 `有效期`，过期重跑 `deep-research`。
- **L4 达人选购策略**：选购骨架长期稳定（不标 Valid_Until）；品牌入手口诀随技术迭代，标 Valid_Until 约 1 年；⚠️ **L4 不标任何外部/达人出处**——所有判断就是我们（意见领袖）自己的；L4 不含推荐型号池（归推品手册），争议钩子里的靶子型号仅作识破对象指代。
- 本库**不复制**推品手册的价格表/型号表，只引用章节号。
