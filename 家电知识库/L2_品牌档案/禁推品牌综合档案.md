来源：`推品逻辑手册_2026.md` §一、电视（TV） · 禁推品牌（禁推品牌表）、§七、跨品类通用规则 · 2. 品牌矩阵总览（跨品类汇总）

### 1. 三星（Samsung）
- **禁推硬理由**：2026年5月宣布退出中国家电市场，**售后无保障**。
- **同价位替代推荐**：
  - 75寸甜点段 → TCL 75 Q9L Pro（¥8551，万象分区 + 20万+已销）

### 2. 索尼（Sony）
- **禁推硬理由**：**溢价严重，过保修期维修费高昂，性价比极低**。
- **同价位替代推荐**：画质路线对标 → 海信 E7S / E8S 系列（RGB-Mini LED + 信芯芯片，画质调校第一梯队）

### 3. 康佳（Konka）
- **禁推硬理由**：**财务崩溃（*ST），产品质量和售后均无保障**。
- **同价位替代推荐**：入门段 → 雷鸟 鹤6 26款 / 小米 S Mini LED 2026

### 4. 长虹（Changhong）
- **禁推硬理由**：**业务萎缩，技术落后，市场边缘化**。
- **同价位替代推荐**：入门段 → 创维 A7H 系列 / 华为 Vision 5

## 四、热水器禁推品牌

来源：`推品逻辑手册_2026.md` §四、热水器 · A. 燃气热水器（禁推品牌表）、§七、跨品类通用规则 · 2. 品牌矩阵总览（跨品类汇总）

### 1. 万和（Vanward）——特指 RX6 豆蔻
- **禁推硬理由**：**RX6豆蔻无增压、仅二级能效无国补，2000元价位不如海尔 KL7**。
  - 无增压 → 高楼低层用户痛点全踩。
  - 仅二级能效 → 拿不到 15% 国补，等于变相贵 300+。
- **同价位替代推荐**：
  - 1600-2000 段 → 海尔 KL7（¥2210，下置风机 + 水量伺服器 + TSI 增压，16L 增压机）
  - 2000-2500 段 → 海尔 KD7 MAX（¥2379，该价位唯一一级能效燃热，能拿国补 15%）

### 2. 能率（Noritz）
- **禁推硬理由**：**与林内同属日系但产品线窄、价格不透明**。
  - 仅在北方寒冷地区可作有限考虑（待验证新品观察清单 §九、待验证新品观察清单（2026-05））。
- **同价位替代推荐**：
  - 3500-4000 日系路线 → 林内 GD72 16L（¥3909，0.5C 精准控温）
  - 国产高端路线 → 美的 M10S Max（¥3999，一级能效 + 无冷感 + 107.2% 热效率）

## 七、使用规则

1. **禁推理由必须来自手册**：本卡所有理由均可在 `推品逻辑手册_2026.md` 对应章节找到，不得自行扩展或编造。
2. **禁推品牌只能作反面对照**：文章里可以出现（"贵的反而洗不干净"、"售后无保障"），不能进推荐清单。
3. **替代方案优先指向手册主推型号**：本卡列出的替代型号均为推品手册当前段位首推/备选，价格变动以手册为准。
4. **西门子/博世洗衣机走独立档案**：写作涉及洗衣机禁推时，读取 `西门子.md` 获取更详细的智商税对照。
5. **能率例外条款**：北方寒冷地区（东北/华北/西北）-20度防冻需求下，能率北方专用系列可作待验证考虑，但价格偏高（>4000元），需向用户明确告知风险。
