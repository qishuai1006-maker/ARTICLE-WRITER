## 1. 品牌速写
- **一句话定位**：参数性价比 + 智能生态双buff，米家联动是核心壁垒。
- **所属集团**：小米集团（互联网+生态链打法，非自研白电基因）。
- **主推结论**：主推。两个品类都靠"参数堆到极致 + 智能生态联动 + 10年包修"撕市场。
  - 电视：高分区性价比路线，S Pro 75寸 2304分区/5200nits ¥6999 爆款（3万+已售）。
  - 空调：巨省电Pro **APF6.30 行业最高**，米家联动。
- **核心短板**：
  - 电视：面板混用、音响弱、系统长期卡顿、有开机广告。
  - 空调：售后网点少于传统品牌。

## 2. 技术路线
- **高分区堆料**：电视 S Pro 系列 2304 分区 / 5200nits / 330Hz，参数同价位无敌，但 **用联发科公版 SoC，无独立画质芯片调校**（同参数画质不如海信）。
- **APF 能效极致**：空调巨省电Pro **APF6.30 是行业天花板**，超过华凌神机二代Pro(6.02)、海尔净省电Plus(6.12)、统帅超省电Ultra(6.28)。
- **面板混用是短板**：电视不同批次混供屏，参数一致但观感波动，无法像 TCL（华星自供）/海信（信芯调校）那样稳定。
- **米家智能联动**：电视+空调+扫地机+灯光一键场景，是小米相对传统家电品牌的生态护城河。
- **10 年包修**：2025年1月起空调整机 10 年包修（与格力齐平），电视沿用小米官方售后。

## 3. 各品类档案

### 3.1 电视（TV）
- **定位标签**：高分区性价比。
- **爆款**：小米 75 S Pro Mini LED 26款——2304分区 + 5200nits + 330Hz + **3万+已销**，参数同价位无敌。
- **入门走量款**：小米 85 S Mini LED 2026（¥5756）；小米 65 S Mini LED 2026（¥3216，760分区 + 2000nits + 低反屏）。
- **百寸线**：小米 100 S Mini LED 2026（¥10999，1920分区 + 低反屏 + 288Hz）。
- **已知槽点**：
  - 面板混用（不同批次屏源不同）。
  - 音响弱（同价位音响硬件不及创维哈曼/TCL安桥）。
  - **系统长期卡顿**（MIUI TV 老问题，长期使用后流畅度下降明显）。
  - **有开机广告**（与海信/创维并列"有广告阵营"，对比 TCL/雷鸟/华为"无广告阵营"是劣势）。
- **目标用户**：参数党、米家生态用户、预算敏感型。

### 3.2 空调（KT）
- **定位标签**：参数 + 智能生态。
- **爆款**：巨省电Pro（国补后 ¥2208）——**APF6.30 行业最高** + 10年包修 + 米家联动。
- **入门走量款**：巨省电双排版（国补后 ~1900）——9.8cc 压缩机 + 双排冷凝器 + 双排蒸发器 + 900m³/h + 10年包修。
- **柜机/大挂**：巨省电 3P（10年包修）、巨省电 2P；自然风Pro 3P（新风高端线）。
- **已知槽点**：
  - 售后网点少于传统品牌（美的/格力/海尔），三四线覆盖率低。
  - 品牌家电基因弱于传统白电三巨头，靠参数+生态撬市场。
- **目标用户**：米家全屋智能用户、追求 APF 极致省电的参数党。

## 4. 售后与口碑
- **电视售后**：小米官方售后，覆盖 OK 但专业度不及海信/TCL 自有白电服务体系。
- **空调售后**：10 年包修政策已对齐格力，但**网点密度低于传统品牌**——三四线城市安装/维修响应慢是已知短板。
- **口碑**：参数党口碑强（"性价比天花板""APF 最高"），但长期耐用性/系统流畅度口碑弱于传统品牌。
- **生态口碑**：米家联动是绝对加分项，年轻用户+IoT用户黏性强。
