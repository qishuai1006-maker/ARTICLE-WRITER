## 1. 品牌速写
- **一句话定位**：参数性价比之王——靠华星光电面板自产打出"同价位参数最暴力"的牌面。
- **所属集团**：TCL 科技 / TCL 实业（电视业务主体），旗下 **华星光电（CSOT）** 是中国前二的面板厂。
- **主推结论**：主推。核心壁垒=**华星光电面板垂直整合**（自产 HVA / 蝶翼星曜屏），让 TCL 主牌 + 雷鸟子牌共用同一套面板资源，成本和产能都占优势。
- **核心短板**：画质调校不如海信（无独立信芯、靠 TSR AI 光色同控芯片 SoC 集成）；低段位型号用料波动明显。
- **开机广告**：TCL 主牌 + 雷鸟全系 **无开机广告**——对海信/小米/创维的绝对差异化卖点。

## 2. 品牌历史与技术路线
- **华星光电面板垂直整合**：TCL 自建高世代面板产线，从上游面板到整机一体化，是 TCL 在电视品类最大的护城河（也是雷鸟能"共享华星面板、价格更低"的根源）。
- **万象分区（自研分区方案）**：TCL/雷鸟主推的背光分区方案，⚠️ 为自研方案，与竞品普通分区不直接等价，比较分区数时需要换算口径。
- **SQD-Mini LED**：TCL 2026 年主推的高端背光路线，色域最广（色域路线排序：SQD-Mini LED > RGB-Mini LED > QD-Mini LED > Mini LED），对应 Q9M Pro / Q10M 旗舰线。
- **蝶翼星曜屏 / 蝶翼华曜屏**：华星光电自研 HVA 系高阶屏体，是 TCL/雷鸟中高端型号的标配面板。

## 3. 各品类 / 子品牌档案

### 3.1 TCL 电视（主牌）
- **定位标签**：参数性价比之王。
- **爆款锚点**：**Q9L Pro 75 寸 20 万+ 已售**——TCL 主牌销量王者，万象分区 + QD-Mini LED，75 寸旗舰性价比首选（手册 §一、电视（TV） · 价格段推荐表）。
- **旗舰线（从低到高，手册 §一、电视（TV） · TCL/雷鸟 2026 产品线定位（必知））**：
  - T7L Ultra（进阶入门）
  - Q9L / Q9L Pro（爆款主力）
  - Q9M（RGB 高色域，TCL 首款 RGB 路线，100% BT.2020）
  - Q9M Pro（SQD 旗舰，98 寸 3 万+ 爆款）
  - Q10M / Q10M Pro（超旗舰，SQD + 超级蝶翼华曜屏 + 6000nits）
- **画质分水岭**：海信有自研信芯（独立画质芯片），TCL 是 SoC 集成的 TSR AI 光色同控芯片——同参数下海信画质优于 TCL，但 TCL 同价位参数更暴力。
- **已知槽点**：低段位型号用料波动；T7K 已下架不推荐（仅 640 分区/1600nit，被雷鸟鹤6 Pro / 鹤7 PLUS 碾压）；T7M Pro / T7M Ultra 京东未找到商品页，暂不推荐。
- **开机广告**：无。

### 3.2 雷鸟电视（TCL 性价比子牌）
- **定位标签**：TCL 性价比子品牌，"共享华星面板 + 全系无广告 + 2026 款统一'26款'后缀"。
- **品牌逻辑**：与 TCL 主牌同面板厂、同技术栈（万象分区 / QD-Mini LED / 蝶翼华曜屏），但价格更低、品牌力更弱、售后网点少于 TCL 主牌。
- **核心产品线（手册 §一、电视（TV） · TCL/雷鸟 2026 产品线定位（必知））**：
  - 鹤6 26款（入门 Mini LED，65 寸 ¥2797 / 75 寸 ¥3599）
  - 鹤6 Ultra 26款（进阶，85 寸 ¥5964，TCL 主牌同面板更便宜）
  - 鹤7 26款（高性价比，85 寸 ¥8234）
  - **鹤7 Pro 26款（准旗舰，极景 QD-Mini LED + 蝶翼华曜屏 + 万象分区）**——85 寸 ¥8399，"比 TCL Q9L Pro 便宜但面板同级"，参数逼近 TCL 主牌。
- **雷鸟 vs TCL 主牌选择原则**（手册 §一、电视（TV） · TCL/雷鸟 2026 产品线定位（必知））：
  - 追求极致性价比 → 雷鸟（无广告 + 共享华星面板）
  - 追求 SQD 色域 + RGB 路线 + 品牌售后再上 TCL 主牌

### 3.3 TCL 冰箱
- **定位标签**：价格杀手。
- **核心优势**：**4000 元以下能买到的零嵌**——同价位唯一能做到零嵌 + 双系统的品牌。
- **核心技术**：双磁鲜技术、法式门 / 十字门形态。
- **核心短板**：产品线窄、保鲜技术积累浅（不如海尔全空间保鲜、容声 IDP2.0、东芝雾化保鲜有代际积累）。
- **价位段定位**：走 3500-4500 元入门段，主攻"零嵌 + 双系统 + 低价"组合拳。

## 4. 售后与口碑
- **电视售后**：TCL 主牌全国服务网点密度在线；雷鸟售后网点少于 TCL 主牌——这是雷鸟作为子牌的明牌短板。
- **冰箱售后**：TCL 冰箱售后覆盖弱于海尔，但优于禁推品牌（三星/索尼/康佳/长虹）。
- **口碑锚点**：参数党、性价比党首选；"同价位买 TCL/雷鸟 = 参数最暴力"是用户认知。
