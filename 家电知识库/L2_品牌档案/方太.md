## 1. 品牌速写
- **一句话定位**：烟灶高端标杆，**品牌溢价行业最高**。
- **所属集团**：宁波方太集团（Fotile Group）。
- **主推结论**：主推。**静压 1450Pa、烟灶联动智能感知**，参数不及老板暴力但**品牌面子属性最强**——精装送礼、追求"高端厨电"认知的首选。
- **核心短板**：**价格贵（4000+ 起步）**、性价比低，纯比参数不如老板、比性价比不如华帝。

## 2. 品牌历史与技术路线
- 方太 1996 年创立（浙江宁波），中国高端厨电的开创者，长期占据"中国高端厨电第一品牌"心智。
- **静压 1450Pa**：旗舰机型静压可达 1450Pa（略低于老板 1700Pa 但仍是第一梯队）。
- **烟灶联动智能感知**：方太的技术差异化重点——灶具点火自动启动烟机、火力自动调节风量，体验感顺滑。
- **品牌溢价路线**：参数不一定堆到极致，但**用料、做工、品牌心智**三项加起来定高价——适合"面子消费"和精装房配套场景。

## 3. 烟灶产品线档案

### 高端标杆 · 起步 4000+
- **高端（4000-5000）**：**F2.i + THK21B 套装（¥4558）** —— 24m³ + 1000Pa + 5.2kW + **烟灶联动**，方太智能体验代表（备选，首推为老板 L3+D2）。
- **旗舰（5000+）**：**V1S-G 套装（¥5798）** —— 28m³ + 1450Pa + 5.2kW，**方太旗舰套装**，5000+ 价位首推。

### 核心技术标签
- 静压 1450Pa（第一梯队，略低于老板 1700Pa）
- **烟灶联动智能感知**（最大差异化）
- 品牌溢价最高（高端心智、面子属性）
- 性价比低（同价位参数不如老板、华帝）

### 适合场景
- 精装房配套 / 送礼 / 追求"高端厨电"心智的用户
- 中产家庭愿意为品牌和体验感支付溢价

## 4. 售后与口碑
- 方太售后以"高端服务"为卖点，覆盖全国主要城市（网点密度略低于海尔/美的，但服务规范度高）。
- **口碑基本盘**：品牌认知"高端""有面子"，烟灶联动体验顺滑是用户高频好评点。
- **已知槽点**：性价比低——同价位老板参数更暴力，华帝价格更低、风量更大；纯比"硬指标"方太常被压一头。
