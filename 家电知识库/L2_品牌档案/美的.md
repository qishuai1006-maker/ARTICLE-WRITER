## 1. 品牌速写
- **一句话定位**：2026 年跨品类最激进的"推手型"集团，四大白电（冰箱/热水器/烟灶/空调）全部进入主推清单。
- **所属集团**：美的集团（A 股上市，总部广东顺德）。
- **主推结论**：主推。在冰箱（机皇 555 制冰销冠 + 熊墩墩旗舰）、燃气热水器（无冷感恒温 + 一级能效最多）、烟灶（蒸汽洗自清洁之王）、空调（技术路线最全 + 酷省电 AI）四条线均占头部位置。
- **子品牌矩阵**：
  - **美的**（主牌）：覆盖冰箱/热水器/烟灶/空调中高端线。
  - **小天鹅**：洗衣机子品牌（美的约 2008 年收购），洗衣机品类第一推荐品牌。
  - **COLMO**：高端线（对标卡萨帝，万元以上精装市场）。
  - **华凌**：性价比子牌，共享美的技术与美芝压缩机，覆盖冰箱（518）与空调（神机二代 Pro），是各价格段的"低价杀手锏"。
- **核心短板**：高端不如方太/老板"有面子"、不如格力"十年包修"；个别冰箱型号命名混乱（如 555 有三个版本，需重点区分）。

## 2. 品牌历史与技术路线
- 1968 年起家（广东顺德，风扇/塑料起家），80 年代进入白电，目前是全球最大白电集团之一。
- **美芝压缩机（GMCC）自研**：美的与东芝开利合资（美的控股），是全球出货量最大的压缩机厂之一，不仅供给美的/华凌/小天鹅自有产品，也外供给众多同行——这是美的在冰箱与空调品类最深的成本与供应链护城河。
- **PST+ 智能净化（冰箱）**：3 分钟急速净味、主动除菌除病毒，是美的冰箱保鲜之外的差异化卖点（区别于海尔"全空间保鲜"、容声"IDP 双净"、东芝"雾化保鲜"）。
- **无冷感恒温（燃气热水器）**：美的燃热核心护城河，水温差控制到接近无感，配合下置风机 + 恒温增压；2026 年燃热一级能效产品最多，国补 15% 红利吃满。
- **蒸汽洗自清洁（烟灶）**：行业内最早把"蒸汽洗"做成成熟量产技术的玩家，是美的烟灶超越老板/方太的差异化武器。
- **酷省电 AI 算法 / 全面风舒适送风（空调）**：美的空调两条技术主轴——AI 省电（酷省电系列）与舒适送风（全面风系列 180° 旋转控风）。

## 3. 各品类档案

### 3.1 冰箱 — "2026 最激进推手"
- **定位标签**：2026 最激进推手（推品手册 §二、冰箱 · 品牌定位矩阵）。
- **核心技术**：PST+ 智能净化（3 分钟急速净味）+ 双系统 2.0 + 60 分钟急速制冰。
- **主推产品线**：
  - **机皇 555**（制冰销冠，抖音 618 TOP1，国补后 ¥5099）—— 双系统 2.0 + PST+ + 玻璃面板。
  - **熊墩墩 600Pro**（冰箱旗舰，600L + 双系统 + 制冰，国补后 ¥5670）/ **熊墩墩 628**（新品超大容量旗舰）。
  - **小机皇 520**（不制冰版，适合不需要制冰的用户）。
  - **508**（双系统冰箱性价比标杆，20 万+ 销量验证，国补后 ~¥3299）。
  - **餐边柜 427**（45cm 新品类切入，定位厨房与客厅之间的二次存储场景）⚠️ 手册外型号，价格待 CEO 核实。
- **华凌子牌**：**华凌 518**（双系统 + PST+ + 自动制冰 + 零嵌，国补后 ¥3599），3500-4000 元零嵌首推，2026 替代美的 541 成为该段性价比标杆。
- **⚠️ 型号命名硬伤**：**555 有三个版本**（冰镜/普通/其他），写稿时必须明确具体版本，避免用户买错；**541** 配置不错但 CEO 偏好少推。
- **价格段分布**：2500-3500（508）/ 3500-4000（华凌 518 子牌）/ 5000-6000（555 制冰销冠 / 熊墩墩 600Pro）/ 6000+（熊墩墩 628 新品）。
- **价格细节**：以推品手册 §二、冰箱 · 价格段推荐表为准（本卡不复制价格表）。

### 3.2 燃气热水器 — "技术创新王"
- **定位标签**：技术创新王（推品手册 §四、热水器 · A. 燃气热水器）。
- **核心技术**：**无冷感恒温** + 恒温增压 + 下置风机 + **一级能效产品最多**（吃满国补 15%）+ 蒸汽洗差异化。
- **主推型号**：
  - **M9S MAX**（¥3229，2500-3500 元首推：安睡无冷感 + 恒温增压 + 下置风机）。
  - **M10S Max**（¥3999，3500-4000 元首推：一级能效 + 无冷感 + **107.2% 热效率**，4000 元燃热天花板）。
  - M9max（¥2209，2000-2500 备选，二级能效无国补）/ P60MAX（¥1699，预算极紧备选）。
- **电热水器线**（顺带提及）：UDplus（¥1919，扁桶甜点）/ UDproS（¥2639，亲肤活水 + 0 水垢 + 14 倍增容）/ P80（¥3039，**超导热水器**，无内胆无镁棒，电热第三条路线）。
- **核心短板**：高端型号价格接近林内（日系高端），2000 元价位段被海尔 KL7 / KD7 MAX 压制（海尔在该段有一级能效独家优势）。
- **价格细节**：以推品手册 §四、热水器 · A. 燃气热水器 价格段推荐表为准。

### 3.3 烟机灶具 — "自清洁之王"
- **定位标签**：自清洁之王（推品手册 §五、烟机灶具 · 品牌定位矩阵）。
- **核心技术**：**蒸汽洗技术最成熟**（行业最早量产的成熟自清洁方案），覆盖全价格段。
- **主推型号**：
  - **AK7 PRO**（¥3199，3000-4000 元首推：28m³ + 1100Pa + 蒸汽洗，**单品 10 万+ 销量**验证，3200 元烟灶标杆）。
  - **AK7max**（¥2519，2000-3000 备选：蒸汽洗 + 顶侧一体，性价比更高）。
  - **AK5pro 升级款**（¥1999，2000 元以下首推：25m³ + 1000Pa + 顶侧一体 + 蒸汽洗）。
- **主要竞争**：老板（性能旗舰，参数最暴力但无自清洁）/ 方太（高端标杆，品牌溢价最高）/ 华帝（性价比，波浪洗 vs 美的蒸汽洗）。
- **核心短板**：高端不如方太/老板"有面子"（送礼/精装房高端市场仍倾向方太老板）。
- **价格细节**：以推品手册 §五、烟机灶具 · 价格段推荐表（烟灶套装） 价格段推荐表为准。

### 3.4 空调 — "技术路线最全"
- **定位标签**：技术路线最全（推品手册 §六、空调（KT） · 品牌定位矩阵）。
- **核心技术**：**酷省电 AI 省电算法** + **全面风系列 180° 旋转舒适送风** + 产品线最广。
- **主推型号（美的主牌）**：
  - **全面风 Pro**（~¥3000，2500+ 舒适进阶首推：180° 旋转控风 + 双排 + 省电 37%）。
  - **风尊三代 Pro** / **酷省电二代 Pro**（备选）。
  - 3P 柜机：酷省电二代 Pro 3P（双出风 + 鸿蒙）/ 全面风风尊二代 3P。
- **华凌子牌（空调性价比之王）**：
  - **神机二代 Pro N8HE1Pro**（国补后 ¥2039，2000-2500 元首推：**APF 6.02 堆料王** + 48 根铜管大双排 + 液冷散热 + 外机 30kg，2000 出头堆料天花板）。
  - **神机二代**（国补后 ~¥1800，2000 元以内首推：双排铜管 + 电子膨胀阀 + 800m³/h）。
  - **神机二代 3P**（~¥4799，3P 柜机首推）。
- **供应链护城河**：华凌共享美芝压缩机 + 整条美的供应链，同配置比美的主牌低 300-500 元，是美的系空调的"价格杀手锏"。
- **核心短板**：高端不如格力"十年整机免费包修"（格力从 2021 年起人工+材料+上门全免 10 年，美的仅 6 年）。
- **价格细节**：以推品手册 §六、空调（KT） · 1.5P挂机价格段推荐表为准。

## 4. 售后与口碑
- **售后网络**：美的集团全国售后网点密度行业前三（与海尔并列），是跨品类共享的核心壁垒；小天鹅、华凌、COLMO 全部走美的售后体系。
- **口碑锚点**：
  - 冰箱：**555 制冰销冠**（抖音 618 TOP1，"美的把制冰功能带火"已成品类心智）。
  - 燃热：**无冷感恒温**（"洗澡不忽冷忽热"用户认知强）+ 一级能效国补。
  - 烟灶：**蒸汽洗自清洁**（重油烟家庭刚需，AK7 PRO 单品 10 万+ 验证）。
  - 空调：**酷省电 AI** + 华凌神机堆料（年轻用户群体认知最强）。
- **已知槽点**：
  - 冰箱 555 三个版本命名混乱，易混淆。
  - 高端市场（卡萨帝 / 方太 / 格力十年包修）品牌力不及对手。
  - 2000 元价位段燃热被海尔 KL7 / KD7 MAX 压制。
