## 1. 品牌速写
- **一句话定位**：日系精致派冰箱，保鲜界扛把子，自动制冰+平嵌做工精致。
- **所属集团**：日本东芝（Toshiba），后被海信收购中国业务，但研发与品控延续日系标准。
- **主推结论**：主推。**雾化保鲜4.0 + 自动制冰 + 600mm平嵌 + 做工精致**，是 5000 元以上追求保鲜品质与精致外观用户的"日系答案"。
- **核心短板**：价格偏高、售后网点不如国产品牌密集。

## 2. 品牌历史与技术路线
- 东芝 1875 年成立，日本白电元老之一，冰箱保鲜技术积累深厚。
- **雾化保鲜 4.0**：东芝独家保鲜技术，通过雾化水分子的方式让果蔬 cell 保持水润——这是东芝在冰箱品类最大的技术差异化，业界称"保鲜界扛把子"。
- **600mm 平嵌**：机身厚度控制精准，适配现代精装修嵌入式橱柜，平嵌工艺日系水准。
- **自动制冰**：日系冰箱的看家功能，东芝自动制冰模块成熟稳定。
- 做工精致：钣金、铰链、抽屉滑轨细节水准高于国产，使用寿命和质感口碑好。

## 4. 子品牌 / 高低端线
- **东芝**：主品牌（冰箱主推，延续日系研发与品控）。
- 不同于海尔（卡萨帝/Leader）和美的（华凌）的多品牌矩阵，东芝在中国冰箱市场主要靠东芝主品牌单一作战，型号相对集中但款款精品。

## 5. 价位段策略
- **5000-6000**：**东芝 548 白珍珠（¥5399）—— 该段备选**，日系雾化保鲜 + 平嵌，做工比国产更精致（首推为美的 555，东芝作为追求保鲜品质的备选）。
- **6000-8000**：**东芝 638（¥8060）—— 大容量旗舰备选**，雾化保鲜 + 自动制冰，适合追求保鲜品质的大家庭（首推海尔 630 云溪MAX）。
- **8000-10000**：**东芝 638（¥8060）—— 该段首推**，大容量旗舰 + 雾化保鲜 + 自动制冰 + 日系精致做工。

## 6. 售后与口碑
- **售后网点不如国产品牌密集**：东芝（海信系运营）服务网点密度低于海尔/美的/容声，二三线城市维修响应较慢——消费者偶有吐槽。
- 写稿时如实呈现：追求保鲜品质且预算充足、所在城市有网点 → 推东芝；看重售后便利性 → 推海尔/容声。
- 口碑：雾化保鲜 4.0 + 自动制冰 + 做工精致 = "保鲜效果好、用着精致"，老用户复购率高。
- 已知槽点：同价位比容声/美的贵，售后不如国产密集。
