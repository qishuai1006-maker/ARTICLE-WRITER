## 1. 品牌速写
- **一句话定位**：壁纸差异化——不靠参数堆料、靠颜值和装修一体化打差异化路线。
- **所属集团**：创维集团（Skyworth），国产电视老牌之一。
- **主推结论**：主推（差异化方向）。核心壁垒=**A7H 系列 3.9cm 超薄壁纸电视 + 哈曼音响**，切入的是"装修一体化 / 颜值导向"的用户，而非参数党。
- **核心短板**：整体技术落后海信 / TCL 半代——无独立画质芯片、无 RGB-Mini LED 路线、无万象分区等自研方案，纯靠贴墙形态 + 音响组合做卖点。
- **开机广告**：部分型号无（非全系无广告，不如 TCL/雷鸟/华为彻底）。

## 2. 技术路线
- **3.9cm 超薄壁纸电视**：创维核心差异化，整机贴墙挂装、与装修一体化，是创维区别于海信（画质派）/ TCL（参数派）/ 小米（性价比派）的形态级卖点。
- **哈曼音响**：A7H 系列搭哈曼调音音响，对应壁纸电视的"薄机身 + 不妥协音质"组合逻辑。
- **整体技术位置**：在面板路线（SQD / RGB / QD-Mini LED）、分区方案（万象分区）、画质芯片（信芯 / TSR）三个维度均落后海信/TCL 半代——创维不是技术领跑者，是形态差异化玩家。

### 3.3 选购逻辑
- 创维适合 **追求颜值 + 装修一体化 + 非参数导向** 的用户。
- 参数党 / 画质党 / 性价比党不推创维，分别对应 TCL / 海信 / 小米。
- "壁纸"和"哈曼音响"是写稿时的两个核心记忆锚点，其他参数（分区数 / 亮度 / 芯片）在创维话术中是次要项。

## 4. 售后与口碑
- 创维作为国产电视老牌，全国售后网点覆盖尚可，弱于海尔系（电视品类海尔非主推），与海信/TCL 同档。
- 口碑锚点：壁纸电视 = 创维、装修党首选；非壁纸型号认知度低。
- 已知槽点：同价位参数不如 TCL/小米；画质调校不如海信；开机广告非全系无广告。
