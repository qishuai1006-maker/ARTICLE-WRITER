## 1. 核心技术原理

### 滚筒 vs 波轮（两种根本不同的工作方式）
- **滚筒**：内筒横向旋转，靠**重力摔打**衣物（像在河边用棒槌捶），水流少、磨损低、能加热、能洗娇贵面料。**绝对主流**。
- **波轮**：底部的波轮盘旋转带动水流**涡流摩擦**衣物，磨损大、易缠绕、但便宜、操作直观（老人友好）、中途加衣方便。
- 结论：除「预算<2000」或「老人不会用滚筒」两种场景外，**一律推滚筒**。

### 电机的三种驱动方式（决定噪音、寿命、精度）
- **FPA 直驱**（Fisher & Paykel 斐雪派克，海尔 2012 年收购）：电机轴**直接连**内筒轴，无皮带无减速器。静音、脱水稳、能做精准控制（如摇篮洗）。**海尔独家**。→ 这是"真直驱"。
- **DD 直驱**（广义）：结构上也是直驱，但杂牌 DD 用的电机/磁极数不够，**易失步**（电机与内筒失去同步）、噪音大、寿命短。→ 多为噱头，"假直驱"。
- **BLDC 变频（皮带传动）**：电机通过皮带驱动内筒，成熟稳定、有缓冲、成本低。**小天鹅/松下**用。皮带是耗材（约 8-10 年换一次），但整体可靠。
- 一句话：**直驱本身没错，海尔 FPA 才是真直驱；杂牌 DD 不如 BLDC**。

### 洗净的物理基础
滚筒靠**摔打 + 加热 + 化学洗涤剂**三者结合。水温能到 60-90℃（煮洗），高温本身就能溶解油脂、杀螨除菌。所以滚筒「洗净比」普遍高于波轮（波轮靠摩擦，受限于磨损上限）。

### 烘干的两种热力学路线
- **热泵烘干**：压缩机循环工质，低温（50-70℃）冷凝水分。**护衣、省电（约为冷凝的 1/2）、烘得透**。必推。
- **冷凝烘干**：电加热高温（70-90℃）蒸发水分再冷凝。**伤衣（缩水/变形/掉色）、费电、常烘不干**。禁推。
- 洗烘一体机 95% 是冷凝；要真烘干效果，**买「洗烘套装」上热泵烘干机**。

## 3. 选购指标体系（决策死线）

不达标直接 pass：
1. **洗净比 ≥ 1.10**（西门子 1.03 = 智商税线，禁推）
2. **电机只选 FPA 直驱（海尔）或 BLDC 变频（小天鹅/松下）**——杂牌 DD 不推
3. **洗烘套装必推热泵烘干**——冷凝式坚决不推
4. **西门子/博世全面禁推**（共用平台、1.03 洗净比、国产后品质下降、"德国品牌"溢价）
5. **波轮仅限预算<2000 或老人场景**——否则推滚筒

## 4. 价位段分层逻辑（滚筒）

| 价位段 | 能买到 | 加钱升级点 | 适合人群 |
|---|---|---|---|
| 2000-2500 | 入门滚筒（BLDC + 1.10-1.21 洗净比 + 基础除菌）| 电机升级到 FPA、容量到 10kg | 首套房/租房过渡 |
| 2500-3000 | **主流甜点**（FPA 直驱 或 1.21 洗净比 + 精华洗）| 洗净比到 1.36、热泵烘干 | 三口之家主流选择 |
| 3000-4000 | 进阶（蓝氧护色 / 活水洗 / 更强除菌）| 容量到 12kg、洗烘套装 | 护色/娇贵面料需求 |
| 4000-5000 | **高端**（1.36 洗净比天花板 + 磐石电机 + 超微除菌气泡 Pro）| 洗烘套装热泵 | 追求洗净极限 |
| 洗烘套装 4500-10000 | 滚筒 + 热泵烘干机 | 双擎热泵、更大容量 | 南方回南天/无阳台/有娃 |
| 10000+ | 高奢套装（小乌梅5.0 高奢 / COLMO 黑珍珠）| 设计感、用料、全屋适配 | 大平层/高端送礼 |

> 波轮另有独立价位段（1500-3000），见 §5 场景分流。

## 5. 场景分流

| 场景 | 推荐方向 | 理由 |
|---|---|---|
| **三口之家主流** | 10kg 滚筒，2500-3000 甜点档（FPA 或 1.21 洗净比）| 容量够、洗净好、性价比最高 |
| **四口+洗被子** | 12kg 滚筒（小乌梅5.0 12kg）| 大容量一次洗完四件套/被芯 |
| **老人专用** | 波轮（小天鹅水魔方防缠绕）| 老人不会用滚筒门；波轮中途加衣方便；水魔方解决缠绕痛点 |
| **租房/预算紧** | 1500-2000 波轮 或 2000-2500 入门滚筒 | 搬迁方便、够用就好 |
| **母婴/有娃** | 高温煮洗 + 超微除菌气泡 + 护色 | 除菌除螨刚需，婴儿衣物护色 |
| **南方回南天/无阳台** | 洗烘套装热泵（必热泵）| 冷凝烘不干还伤衣；热泵省心 |
| **养宠** | 防缠绕 + 除毛 + 大容量 | 宠物毛发缠绕是核心痛点 |
| **大平层/高端** | 10000+ 洗烘套装（小乌梅5.0高奢/COLMO）| 设计感、静音、全屋适配 |

## 6. 避坑点（反常识 · 文章钩子素材）

- **误区**："直驱一定好" → **真相**：杂牌 DD 易失步噪音大；只有海尔 FPA（斐雪派克）才是真直驱。
- **误区**："越贵洗得越干净" → **真相**：3000 元西门子洗净比 1.03，输给 2500 元小乌梅 1.21——贵反而洗不干净。
- **误区**："大容量 = 一次洗更多" → **真相**：标称约 7 折水分，10kg 实际约 7kg 干衣；小容量更费时（分批洗）。
- **误区**："洗烘一体方便又便宜" → **真相**：一体机 95% 是冷凝，伤衣费电烘不干；要真烘干买套装上热泵。
- **误区**："德国品牌品质好" → **真相**：西门子/博世国产后共用平台、洗净比垫底 1.03，靠品牌光环收智商税。

## 7. 禁推红线
- **西门子 / 博世**：1.03 洗净比（底线）、国产后品质下降、智商税。对照点：2500 元小乌梅 1.21 完胜 3000 元西门子。
- **冷凝式烘干机**：伤衣、费电、烘不干。
- **杂牌 DD 直驱**：易失步、噪音、寿命短（标注"直驱"但非 FPA）。
- **标称洗净比 < 1.10** 的任何型号。
- **非小天鹅水魔方/海尔 Mate6 的波轮**（其他品牌波轮不推）。
