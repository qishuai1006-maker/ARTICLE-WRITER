## 1. 核心技术原理

### 制冷的物理本质（卡诺逆循环）
空调本质是**热泵**——把室内的热量搬运到室外。靠压缩机驱动冷媒（R32/R410A）走完一个完整的逆卡诺循环，四个核心部件各司其职：

1. **压缩机**（系统心脏）：低温低压气态冷媒 → 高温高压气体。决定噪音、寿命、能效上限。**美芝**（美的/华凌系）、**凌达**（格力自研）、**松下**、**三洋**是主流。
2. **冷凝器**（室外机散热）：高温高压气体 → 中温高压液体，**向室外放热**。这里是"双排铜管 vs 1.6 排/单排"的核心战场——铜管越多，散热面积越大，能效天花板越高。
3. **节流装置**（毛细管 vs 电子膨胀阀）：高温高压液体 → 低温低压液气混合物。**电子膨胀阀**能精准控制冷媒流量（精度比毛细管高一个数量级），是变频空调精准控温、提升 APF 的关键。毛细管是廉价固定节流，控温粗。
4. **蒸发器**（室内机吸热）：低温低压冷媒 → 蒸发吸热 → **向室内吹冷风**。

> 一句话：**压缩机决定上限，膨胀阀决定精度，铜管排数决定能效真不真**。这三件套就是空调"堆料"的全部内涵。

### 变频 vs 定频（这一代必须懂的根本区别）
- **定频**：压缩机只有"开/关"两档。室内温度到了就停机，温度漂上去再启动。**忽冷忽热、启动电流大（最费电）、噪音冲击**。已基本被市场淘汰。
- **变频**：压缩机转速可连续调节（直流变频 FOC 控制），**低频维持运转、不频繁启停**。三个收益：
  1. **省电**：变频低频维持的功率远低于定频每次重启的峰值（变频一夜约 0.5-1 度，定频约 2-3 度）。
  2. **舒适**：温度波动可压到 ±0.5℃（定频 ±2-3℃），不忽冷忽热。
  3. **静音**：低频运转时压缩机和风扇都低速。
- **全直流变频**（旗舰级）：压缩机 + 室内外风扇电机都是直流变频，比"仅压缩机变频"再省 20-30%，是高端机型标志。
- 结论：**新一级能效空调 100% 是变频**，定频只在低端二级三级能效里残留，禁推。

### APF 能效比（空调的"考试分数"）
- **APF（Annual Performance Factor，全年能源消耗效率）**：全年（含制冷 + 制热）的综合能效，比单纯制冷的 EER 或制热的 COP 更贴近真实使用。**这是新国标 GB 21455-2019 的核心指标**。
- **能效等级对应 APF**（以 1.5 匹挂机为例）：
  - **新一级**：APF ≥ **5.00**（强制底线，2020 年实施）
  - **新二级**：APF ≥ 4.0（无国补）
  - **新三级**：APF ≥ 3.5（淘汰边缘）
- **行业分档**（自家口径）：
  - **5.0-5.5**：入门一级（合格）
  - **5.5-6.0**：优秀（主流甜点）
  - **6.0+**：超一级天花板（华凌神机二代Pro 6.02 / 海尔净省电Plus 6.12 / 统帅超省电Ultra 6.28 / 小米巨省电Pro **6.30** 行业最高）
- **APF 越高一年能省多少电**：1.5 匹从 APF 5.0 → 6.0，按年均制冷 1136 小时算，约省 **150-200 度/年**，10 年省 1500-2000 元（基本回收购机差价）。

### 冷暖 vs 单冷
- **单冷型（KF-）**：只制冷，南方无供暖需求场景可用。
- **冷暖型（KFR-）**：制冷 + 制热。制热走**四通阀换向**，把冷凝器和蒸发器角色对调——室外吸热、室内放热。
- **电辅热**：当室外温度低于 -5℃（冷媒制热效率崩塌），冷暖空调会启动**电加热丝**（PTC）辅助加热。**注意：电辅热是纯电阻加热，1 度电 = 1 度热，COP=1**，远低于冷媒热泵的 COP 2-3。**北方寒冬电辅热会单月电费翻倍**。

### 高端技术（决定 4500+ 价位的差异化）
- **无风感（美的全面风系列）**：通过**微孔导风板**把一股强风打散成数千股微风，体感"有凉意无风感"。**对老人/婴儿/怕风人群刚需**。原理是空气动力学扩散，不是营销词。
- **新风空调（海信/小米/TCL）**：在室内机集成**新风模块**，通过独立管道从室外引入经过滤的新鲜空气，在不开窗的前提下实现"空调房增氧换气"。适合**卧室闷、长期关窗、鼻炎/过敏人群**。但要注意：① 新风量普遍 30-100 m³/h，远低于开窗换气；② 会增加约 500-1500 元成本；③ 滤芯是耗材（半年-1 年一换，约 100-300 元）。
- **自清洁（几乎所有品牌标配）**：通过**结霜 → 化霜 → 冲洗**循环，清理室内蒸发器（部分支持室外机自清洁）。能减少霉味、细菌，但**不能替代深度清洗**（出风口、过滤网仍需手动）。
- **AI 省电算法（美的酷省电/海信智省电）**：云端学习用户习惯 + 室外温湿度，自动调温调频，宣称再省 10-37%。属于锦上添花，不是核心硬指标。

### 挂机 vs 柜机 vs 中央空调
- **挂机**：壁挂，1-2.5 匹，**卧室/小客厅主流**。便宜、好装、好修。
- **柜机（立柜式）**：2-3 匹以上，**大客厅/餐厅主力**。风量大、循环距离远。圆柱柜机比传统方柜省空间。
- **中央空调（多联机/VRF）**：一台外机拖多台内机，藏在吊顶。**新房装修一次性投入 2-5 万**，适合 3 室以上全屋。**后期维修极麻烦**（漏点难找、清洗需专业）。
- **风管机**：中央空调和挂机的折中——一拖一大功率内机藏吊顶，适合客厅要颜值又不想全套中央空调。

## 3. 选购指标体系（决策死线）

不达标直接 pass：
1. **必须新一级能效（APF ≥ 5.0）**——二级三级一律禁推（无国补、费电）。
2. **必须变频**——定频彻底淘汰。
3. **必须双排铜管 + 电子膨胀阀**——1.6 排/单排、毛细管节流的"伪一级"禁推。
4. **1.5 匹外机重量 ≥ 30kg**（满配基准），低于 26kg 直接判缩水。
5. **匹数必须匹配面积**：1 匹 ≤ 12㎡、1.5 匹 13-20㎡、2 匹 20-30㎡、3 匹 30-45㎡。顶楼/西晒/层高>3m **升一档**。
6. **国补必须算进到手价**：一级能效 15% 补贴（最高 1500 元），最终价 = 国补后价。

## 6. 避坑点（反常识 · 文章钩子素材）

- **误区**："匹数越大越好/制冷越快" → **真相**：匹数过大压缩机频繁启停（变频也压不住），忽冷忽热还费电；按面积选才是科学，顶楼/西晒升一档即可。
- **误区**："新一级能效都一样省电" → **真相**：新一级底线 APF 5.0，行业天花板 APF 6.30（小米巨省电Pro），**差 1.3 个 APF 一年差 150-200 度电**。
- **误区**："能效越高越好" → **真相**：APF 标"额定值"用最优工况，长期高温天会打折；外机重量和铜管排数才是"真实能效"的硬证据。
- **误区**："新风空调就是噱头" → **真相**：**半对半错**。新风量小（30-100 m³/h）确实远不如开窗，但对**卧室长期关窗、鼻炎过敏、空气差地区**确有改善；价格高 500-1500 元、滤芯半年一换是真成本——值不值看场景。
- **误区**："电辅热好用就开" → **真相**：电辅热是纯电阻加热（COP=1），1 度电 = 1 度热；冷媒热泵 COP 2-3，**电辅热费电是热泵的 2-3 倍**。北方寒冬开电辅热单月电费可翻倍。
- **误区**："自清洁就不用洗了" → **真相**：自清洁只清蒸发器内部霉味/细菌，**过滤网、出风口、风道仍需手动拆洗**（建议每月一次过滤网，每年一次深度清洗）。
- **误区**："贵的就是好/进口品牌靠谱" → **真相**：三菱/大金溢价严重，国产华凌/小米/格力 APF 已达 6.0+，**省下的钱够 10 年电费差价**。
- **误区**："双排铜管没用" → **真相**：双排冷凝器是 APF 能到 6.0+ 的硬件基础，1.6 排/单排的"伪一级"长期高温天能效打折明显，**外机 <26kg 大概率缩水**。
- **误区**："十年包修就是营销" → **真相**：格力 2021 起整机 10 年免费包修（人工+材料+上门全免），空调寿命 10-12 年，**过保后换压缩机 720-2000 元**——十年包修≈整机兜底，是格力的真护城河。
- **误区**："国补是商家噱头" → **真相**：2026 一级能效 15% 补贴（最高 1500 元）是真金白银，**到手价 = 标价 × 0.85**，必须算进去对比。

## 7. 禁推红线

- **奥克斯**：品控不稳定，参数虚标（手册明确禁推）。
- **科龙**：与海信共用产线但品质下降，性价比反而输华凌。
- **三菱 / 大金（家用户用挂机/柜机）**：溢价严重，性价比极低（中央空调/低温热泵另议）。
- **定频空调**：彻底淘汰。
- **二级、三级能效**：无国补、费电。
- **1.6 排 / 单排冷凝器、毛细管节流的"伪一级"机型**：能效虚标、长期性能打折。
- **1.5 匹外机 < 26kg 的新一级机型**：大概率缩水，禁推。
- **无电子膨胀阀的变频**：控温精度差、APF 上不去。
