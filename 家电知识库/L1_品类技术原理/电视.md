## 1. 核心技术原理

### 背光的三条技术路线（决定画质的根）
电视本身不发光，靠**背光照亮液晶**。背光的"分区数 × 控光精度"决定对比度与色彩。2026 主流已全面进入 **Mini LED**（灯珠尺寸为传统 LED 的 1/10-1/100，可塞进更多、更小的灯），但同叫"Mini LED"有三条物理路线：

- **QD-Mini LED（量子点）**：在蓝光 LED 上叠量子点膜，把光谱提纯到纯红/纯绿/纯蓝。**亮度高、色域广（覆盖 95%+ DCI-P3）、成本低**。主流性价比路线——TCL Q9L / 雷鸟鹤系 / 小米 S Pro / Vidda 发现X 都走这条。
- **RGB-Mini LED**：直接用红、绿、蓝**三种独立 LED 灯珠**发光（不靠量子点转换），光谱天生纯净，**色域可达 100% BT.2020**、色彩过渡更准。成本高 30-50%。**海信独家路线**（E7S / E8S / 小墨 E5S Pro）。
- **SQD-Mini LED**：在 QD 基础上**额外提纯**（结构量子点），色域逼近 RGB 但亮度更猛。**TCL 高端专用**（Q9M Pro / Q10M 系列）。
- 一句话：**色域排序 RGB ≈ SQD > QD > 普通 Mini LED**；亮度排序 SQD ≥ RGB > QD；性价比排序 QD > RGB ≈ SQD。

### 分区背光（控光）为什么重要
背光若整块亮灭，**暗部被迫提亮 → 黑位发灰、对比度塌**。把背光切成几百到几千个**独立分区**，每个分区单独亮灭：日出时太阳区域全亮、夜空区域全灭，**对比度成倍提升**。
- 分区数门槛：500 分区 = 入门 / 1000 分区 = 甜点 / 2000 分区 = 旗舰 / 3000+ 分区 = 超旗舰。
- ⚠️ **"万象分区"是 TCL/雷鸟自研方案**（算法 + 微透镜 + 分区协同），与竞品"普通分区"标注**不直接等价**——同标"2000 分区"，万象方案控光精度更高。横向比参数时需注明。

### 面板类型（决定原生对比度）
液晶分子排列方式不同，决定了"黑得下去"：
- **HVA / VA（垂直排列）**：原生对比度 5000:1-7000:1，**黑位深、漏光少**。华星光电 HVA、TCL"蝶翼星曜屏/蝶翼华曜屏"是 VA 高阶版本。**画质党首选**。
- **IPS（水平排列）**：对比度仅 1000:1-1500:1，黑位发灰，但**可视角度大、响应快**。多用于游戏取向机型。
- **黑曜屏 / 墨晶屏（海信）/ 黑晶屏（华为）**：在 VA/IPS 基础上做**抗反光涂层 + 深色偏光片**，关灯看片时黑位更深、白天看不反光。是 2026 中高端的差异化卖点。
- 一句话：**画质党选 HVA/VA + 黑曜屏；游戏党才考虑高刷 IPS**。

### 独立画质芯片（品牌分水岭）
液晶画质不只看面板，还要看**后处理算力**——把低分辨率片源超分到 4K/8K、动态补偿、色彩管理、HDR 映射，全靠独立芯片实时算：
- **海信 信芯**（H6/H7，独立芯片）：行业唯一自研独立画质芯片，调校公认第一。
- **TCL TSR AI 光色同控**：集成在主 SoC 里，算力强但非独立调校。
- **小米 / 公版**：用联发科 SoC，**无独立调校**——同参数画质输给海信/TCL。
- 一句话：**同面板同分区下，海信画质 > TCL > 小米**。

### 刷新率与 MEMC（动态补偿）
- **刷新率（Hz）**：60Hz 够看剧；**120Hz 是游戏 + 体育刚需**；288/330Hz 是高刷卖点（多靠插帧实现，原生物理刷新通常为 120Hz/144Hz）。
- **MEMC（运动估计与补偿）**：通过插帧把 24/30fps 拉到 60/120fps，**消除拖影**。看球赛/动作片关键。但 MEMC 会引入"肥皂剧效应"，电影党建议可关。

## 3. 选购指标体系（决策死线）

不达标直接 pass：
1. **背光分区数 ≥ 500**（且为物理分区非动态分区）——普通 LED 与低分区 Mini LED 一律不推。
2. **峰值亮度 ≥ 1000 nits**——HDR 下限，否则画面发灰。
3. **物理刷新率 ≥ 120Hz**（HDMI 2.1 接口）——游戏党硬指标。
4. **75 寸及以上优先推荐**——65 寸仅限"用户明确说空间不够"。
5. **预算 8000+ → 必须有 RGB-Mini LED 或 SQD-Mini LED**——纯 QD 在该价位无竞争力。
6. **开机广告**：用户明确"无广告执念" → 只推 TCL/雷鸟/华为；海信/小米须提前告知。

## 6. 避坑点（反常识 · 文章钩子素材）

- **误区**："分区数越多越好，比参数就行" → **真相**：TCL"万象分区"算法 ≠ 普通分区；同标 2000 分区，海信 + 信芯调校画质优于纯堆参数。
- **误区**："亮度越高越好，5000nits 一定赢 3000nits" → **真相**：日常客厅 1500-2500nits 已足够；峰值亮度只在 HDR 短暂高光下出现，标"全局亮度"才是持续可用值。
- **误区**："色域 100% 一定好" → **真相**：**DCI-P3 与 BT.2020 是两套标尺**，100% DCI-P3 ≈ 75% BT.2020；商家混标欺骗。
- **误区**："288Hz / 330Hz 超高刷无敌" → **真相**：多为**插帧实现**，**原生物理刷新通常 120/144Hz**；HDMI 2.1 接口才能接真 120Hz 源，否则白搭。
- **误区**："开机广告无所谓" → **真相**：老人/执念党痛点极大；同价 TCL/雷鸟/华为无广告，**海信/小米广告可关但每次开机仍弹**。
- **误区**："买 65 寸够用了" → **真相**：75 寸已成甜点（3000-7000 元），65 寸仅在"用户明确说空间不够"才推；多数家庭 75 寸最佳。
- **误区**："国外品牌品质好" → **真相**：三星 2026 年已宣布退出中国家电市场（售后无保障）；索尼溢价严重、过保修维修费高昂；国产海信/TCL 已全面领先。
- **误区**："百寸买得进就买" → **真相**：98/100 寸**必须先确认入户条件**（电梯门、楼道转角、入户门尺寸），否则可能要拆窗吊装。

## 7. 禁推红线

- **三星**：2026 年 5 月宣布退出中国家电市场，售后无保障。
- **索尼**：溢价严重，过保修维修费高昂，性价比极低。
- **康佳**：财务崩溃（*ST），产品质量和售后均无保障。
- **长虹**：业务萎缩，技术落后，市场边缘化。
- **背光分区数 < 500** 或标"动态分区"实为软件模拟的型号。
- **峰值亮度 < 1000 nits**（HDR 看不了，画面发灰）。
- **物理刷新率 < 120Hz**（游戏党硬指标，60Hz 不推）。
- **预算 8000+ 仍推纯 QD-Mini LED**（该价位必须有 RGB 或 SQD 路线）。
