# L3_场景调研报告

这里存放可复用的“写作前深调研与爆文弹药包”。

## 命名规则

`YYYYMMDD_账号_品类_选题关键词_L3调研报告.md`

示例：

`20260622_北北ks_油烟机_老板型号解码_L3调研报告.md`

## 进入 L3 的标准

- 不是每篇文章的临时 01c 都必须沉淀到 L3。
- 只有当调研对后续同品类/同场景可复用时，才复制一份到本目录。
- 价格/政策/国补信息必须写有效期，过期重跑。

## 与 01c 的关系

- `01c_选题深调研与弹药包_[品类].md`：单篇生产目录内的写前弹药包。
- `L3_场景调研报告`：可复用沉淀库，供后续同类选题召回。
